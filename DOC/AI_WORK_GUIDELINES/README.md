# AI 工作规范入口

规则按稳定职责集中维护，不按单条要求拆文件：

| 文档 | 何时读取 |
|---|---|
| `AI_WORKFLOW.md` | 所有非简单任务：方案门禁、任务卡、并行、DailyPlan/Report、交接和夜间规则 |
| `PROJECT_ARCHITECTURE_RULES.md` | 设计或修改代码、蓝图、数据和目录结构前 |
| `AI_Coding_Guide.md` | 使用 MCP、Skill 或其他工程工具时 |
| `GIT_INTERNAL.md` | 执行任何 commit/push 前，尤其是 push |
| `RULES_INBOX.md` | 整理用户临时提出的工作规则时；非权威，不作为常规启动上下文 |

新增稳定规则优先合并进以上对应文档。只有形成新的、长期独立的适用领域时才新增规范文件，并同步更新本表和 `DOC/README.md`；禁止重复记载同一规则。
