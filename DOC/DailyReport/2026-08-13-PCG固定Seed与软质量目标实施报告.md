# 2026-08-13 PCG 固定 Seed 与软质量目标实施报告

## 本次完成

- 玩家确认后的公开 Seed 不再因生成失败被自动替换，也不再通过重载游戏关卡执行换 Seed 重试。Seed 只保留玩家显式设置入口。
- 删除 `AlgorithmVersion`、`ProfileVersion`、签名中的版本字段和玩家到 Exit 最大路线字段；原 `AlgorithmVersion=7` 对随机序列的固定扰动融合为内部常量盐，机关与资源随机域的既有序列保持不变。
- WFC 每层最多搜索 3 棵确定性树：第一张硬合法候选立即保存，后续只做软质量择优；四项软评分全满时立即停止，不再浪费第二、三棵树。
- 普通格目标、整栋总量、路线覆盖、最长直线、结构端点分散及玩家/追猎者出生距离不再成为完整地图硬拒绝；密度从求解开始调节 Empty 权重，长直线从候选排序阶段降权，但候选权重永不归零。
- WFC 在固定预算内没有找到硬合法结果时，在同一 Seed、同一楼层使用现有网格约束构造连通兜底：连接必需格与必开边，再按 Seed 驱动的前沿生长接近软密度目标。没有新增求解器、生产类或生产文件。
- 每次整栋结构候选拥有独立固定预算；撤销可选楼梯时恢复可用预算，但保留真实诊断消耗，避免更简单的必需结构方案被前一次搜索饿死。
- 高厅改为正式配置和构造硬合同：每栋至少 2 个，且至少 1 个不在顶层；高厅先于可选楼梯放置，间距只影响排序。
- 正式 Generation Profile 的每层 WFC 尝试数改为 3，三档难度高厅下限均为 2，目标数量中删除 0、1 个高厅选项。

## 当前硬约束与软目标

| 分类 | 当前规则 |
|---|---|
| 产品硬规则 | 公开 Seed 不自动改变；同 Seed + Difficulty 确定性重放；每栋至少 2 个高厅且至少 1 个非顶层 |
| 结构硬约束 | Outside/边界、RequiredOpen/RequiredClosed、公共边双向一致、必需格和结构接口存在并连通、所有非空格连通 |
| 最低可玩硬约束 | 一层至少 2 个普通格，其他层至少 1 个普通格；玩家、追猎者与 Exit 必须存在并可达 |
| 软质量目标 | 普通格数量、整栋总格数、路线覆盖、最长直线、端点分散、玩家与追猎者距离、可选楼梯数量与分散 |
| 独立运行故障 | 非法配置、代码不变量、实例化错误或 Recast/碰撞故障仍会显式报错，但不得换 Seed 掩盖 |

## 当前边界与用户验收

- 本轮没有修改楼梯 Opening Set 或三层楼梯表现；多个开口方案留待下一轮结合 Level0 已有样例讨论。
- 本轮没有修改机关、摆锤、资源投放、高厅灯光或 Loading UI。
- 自动化证明正式 Profile 的规划不会因软质量或 WFC 搜索预算终局失败；它不等于引擎、资产或导航配置损坏时强行提交错误地图。此类故障会保留原 Seed 并显式清理，而不是偷偷换 Seed。
- 导航门禁自动化已通过，但真实一局的动态 Recast、玩家全楼梯实走、追猎者跨层追逐和最终地图观感仍由用户次日验收。
