- 用户已确认轻受击效果可见、`Slow + 局部物理` 可继续；剩余问题是奔跑跳跃中被制导弹命中会突然向前位移，以及头部反馈偏弱。
- 制导弹第一次提交 Light 后改为忽略 Pawn，但仍保留环境碰撞；避免自由物理弹体在后续帧持续顶住角色 Capsule。
- Light 物理窗口内，角色 Mesh 暂时忽略普通 `PhysicsBody`；结束时完整恢复 Collision Profile、CollisionEnabled 与全部响应，避免同一枚弹体二次挤压局部模拟身体或留下 `Custom` 碰撞状态。
- 玩家参数调整为满强度冲量 `13000`、Hold `0.11s`、BlendOut `0.22s`，没有修改 CharacterMovement、HeavyImpact 或角色 Transform。
- 修正后 DemoEditor 模块构建成功，CharacterImpact + HeavyImpact 自动化仍为 7/7。
- 标准 PIE 中制导投射物连续三次向玩家提交 Applied；其中一次实际路由到 `upperarm_l` 并施加 `13000` 表现冲量。保存日志未出现无效 AddImpulse 或碰撞基线恢复警告。
- 玩家实际奔跑跳跃中的位移修复和头部反馈强度仍需现场手感验收；在此之前不将任务归档。

## 最终用户验收

- 2026-08-13 用户确认奔跑跳跃中的异常位移问题已不再出现，本轮 Light 修正可以收口。
- `Slow + 局部物理` 的玩法方向成立；局部物理观感仍偏弱，但当前版本勉强够用，暂不继续扩大物理架构或增加机关特判。
- 当前验收基线：制导投射物和磁力物对玩家使用 `Slow`；磁力物对追猎者使用 `Stop + 三方向动画`；Heavy 仍独立负责击飞、倒地与起身。
- 本轮技术任务可以归档。后续若需要增强画面，优先调整来源强度或补 Stop 动画，不重新设计 Light/Heavy 身体所有权。

## 新机关接入审视

- `UCharacterImpactResponseComponent` 与 `UHeavyImpactResponseComponent` 均未包含磁力、制导、地刺、摆锤或冲锤类型判断；核心接收层目前与具体机关解耦。
- 新机关接 `None / Slow / Stop` 时，只需要来源 DataAsset、稳定事件 ID，以及在自身 Hit/Overlap 中构造一次 `FStandingImpactRequest`；不需要修改角色受击核心。
- 同一来源可在 Profile 中分别配置玩家与追猎者结果，角色差异不应写回机关分支。
- 新机关接 Heavy 时也不修改接收端，但必须在机关侧实现自身几何与运动对应的接触前预测，并由同一个真实动态刚体随后完成 Chaos 接触。这是来源适配，不是角色系统特判。
- 弹体销毁、穿透、反弹、命中后忽略 Pawn，或持续气流的 Update/End，仍由来源自己管理；这些生命周期不能塞进受击组件。
- 当前权威接入合同已整理到 `DOC/Outputs/Physics/CHARACTER_IMPACT_INTEGRATION_GUIDE.md`。
