# 2026-08-13 PCG 固定 Seed 与软质量目标收敛实施计划

## 目标

在不更换求解器、不新增生产文件的前提下，让玩家公开 Seed 在一局内永不改变；质量目标从搜索开始提供倾向，但不再成为最终硬拒绝；WFC 搜索预算耗尽时在同一层、同一 Seed 下生成简化但硬合法的结果；每栋保证至少两个高厅且至少一个不在顶层。

## 已确认规则

- Public Seed 只由玩家请求写入，删除失败后换 Seed 和关卡重载。
- 边界、双向开口、Required 接口、非空连通和必需端点连通是硬约束。
- 一层普通格硬下限为 2，其他层为 1。
- 普通格目标、整栋总量、路线覆盖、端点分散、最长直线和出生距离都是软目标。
- 同 Seed 内最多 4 个 `WholeAttempt` 暂时保留，只处理必要楼梯、高厅或 Required 潜在图的硬结构冲突；不得由质量或 WFC 预算触发。
- 每层最多 3 棵确定性 WFC 搜索树；第一张硬合法图立即保存，固定预算内只做择优。
- 三棵树均无硬合法结果时，使用同层 BFS 路径并集与 seeded frontier 生长收敛；不换 Seed、不增加第二套表现系统。
- 高厅先于可选楼梯放置；每栋至少 2 个，至少 1 个非顶层。可选楼梯不能拖垮必需结构。

## 明确排除

- 不修改楼梯 Opening Set 内容或三层楼梯表现。
- 不修改机关、摆锤、资源投放规则和对应资产。
- 不实现高厅灯光和 Loading UI。
- 不新增求解器、通用评分框架、备用 Level、硬编码安全地图或生产 C++ 文件。
- 不解决 Recast Bounds、模块碰撞或导航配置专项；本轮只保留正确等待、记录并做代表验证。

## 实施步骤

1. 完成并推送全工作区基线；记录本次功能开始前提交哈希。
2. 删除 `AlgorithmVersion` / `ProfileVersion` 及外层自动换 Seed 流程，把当前固定随机扰动融合进 `MakeRandomStream`。
3. 将单层输入拆成硬最低值与软目标；把总量、普通格、覆盖和长直线从硬 Reject 移出。
4. 在 WFC 既有候选排序中加入非零的长直线软降权；按每层目标调整每棵树的 Empty 权重。
5. 每层最多三棵树保存 hard-valid incumbent，并在无解/预算耗尽时进入同层确定性收敛。
6. 多层 Planner 保留硬结构 Attempt，删除质量触发的整栋重试；高厅先于可选楼梯并保证数量/楼层分布；出生点和 Exit 质量规则降级。
7. 更新 DataAsset、测试和运行指标；不让 wall-clock 决定地图。
8. 完成构建、Automation、每难度 300 Seed 扫描与代表 PIE/Recast 验证。
9. 写 DailyReport、更新项目记忆，提交并推送最终实现；功能状态保持“待用户验收”。

## 验证

- 同一 Seed + Difficulty 重跑布局 Hash 一致，失败路径也不修改 Public Seed。
- 质量目标未满足时仍提交硬合法地图；只有长直线可走时也必须成功。
- 收敛结果满足 Outside、RequiredOpen、RequiredClosed、开口对称、最低普通格与全连通。
- Easy / Normal / Hard 各 300 Seed：规划成功率 100%、Seed 漂移 0、高厅少于 2 为 0、全部高厅在顶层为 0。
- 分开记录结构 Attempt、WFC 首候选、三候选择优、同层收敛、实例化、Recast 等待和路径验证。
- Development Editor 构建、相关 Automation、DataAsset 回读、代表 PIE/Recast 均留证；最终手感待用户验收。

## 回退边界

- Version/Seed 流程、WFC 软引导、单层收敛、多层高厅规则和 DataAsset 可按模块分别回退。
- 若同层收敛率超过 5%，先调整本方案已有权重或固定预算，不把警戒线变成运行时硬拒绝。
- 任何配置或代码不变量错误都必须显式报告，不能通过换 Seed、额外重试或硬编码地图掩盖。
