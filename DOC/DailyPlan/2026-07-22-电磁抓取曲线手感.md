# 2026-07-22 电磁抓取曲线手感

## 目标与边界

- 在现有 Physics Handle 基线上增加确定性的吸取锚点曲线，实现慢启动、中段加速、近身快速平滑刹停。
- Physics Handle 与 Chaos 约束从抓取开始始终有效；只在吸取阶段关闭 Handle 自带目标插值，曲线结束后恢复并进入稳定悬持。
- 首版只增加参考速度、最短时长、弧高比例和最大弧高四项全局参数，仍由 `UMagneticGrabTuningData` 唯一持有。
- 不加入 Timeline、随机摆动、单物体质量倍率、最大吸取时长、分阶段刚度/阻尼、释放限速、蓄力投掷、Physics Control、自研 PD 或近墙安全算法重写。

## 职责与状态 Owner

- `UMagneticGrabTuningData`：吸取曲线四项调参的唯一运行时来源，并负责范围校验。
- `UElectromagneticGrabComponent`：独占 `None / Pulling / Holding` 阶段、曲线起点、方向、时长和计时；所有释放路径恢复 Handle 插值及现有刚体覆盖。
- `UPhysicsHandleComponent`：始终维持抓取约束；Pulling 阶段直接接收曲线锚点，Holding 阶段恢复自身目标插值。
- Chaos：继续决定真实刚体的质量、惯性、碰撞、旋转、滞后与过冲；曲线不直接搬运物体。
