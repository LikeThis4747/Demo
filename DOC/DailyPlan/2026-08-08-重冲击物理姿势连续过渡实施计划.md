# 2026-08-08 重冲击物理姿势连续过渡实施计划

- 状态：代码与技术验证完成，等待用户画面验收。
- 目标：在不改变真实 Chaos 冲量、飞行轨迹和最终倒地点的前提下，让物理身体在落地减速阶段逐渐靠近起身动画开头，减少倒地僵住和切入起身时的整人闪切。
- 权威边界：`UHeavyImpactResponseComponent` 唯一管理重冲击与恢复状态；`UHeavyImpactAnimInstance` 只暴露短生命周期姿势数据；AnimBP 只产生目标姿势；DataAsset 只保存玩家/AI 参数。

## 实施范围

- 修改现有 HeavyImpact AnimInstance、响应组件、调参资产类和自动化测试，共七个 C++ 文件。
- 修改玩家项目 AnimBP、追猎者 AnimBP和两份 HeavyImpact DataAsset。
- 不修改四条起身动画、玩家 Character Blueprint、官方 `ABP_Unarmed`、Physics Asset/PCA、Level0、摆锤/冲锤/制导机关、PCG 与旧追猎者局部受击代码。

## 核心流程

1. `Prepared/Simulating` 保留现有真实物理受击与飞行。
2. 身体有地面支撑且明显减速时进入内部 `PreparingPose`。
3. AnimBP 从当前物理姿势逐渐混到对应正躺/趴倒起身动画的开头；Physics Control 用有限角向扭矩追随该目标，刚体、碰撞、重力和骨盆世界位移继续由 Chaos 决定。
4. 姿势准备完成后再次验证安全 Capsule 位置，再关闭全身物理并从同一动画采样时间播放动态 Montage。
5. 无空间时保持 Downed 并定时重试；整理期间失稳或再次受撞时取消旧准备并回到物理模拟。

## 参数与止损

- 首版：准备时间 `0.40 s`、初始控制比例 `0.30`、正/反面采样时间 `0.0 s`。
- A/B：`demo.HeavyImpact.RecoveryPosePreparation 1/0`；普通布娃娃比较仍使用 `demo.HeavyImpact.PureRagdoll 1/0`。
- 如果新方案看不出身体收拢、明显缩短击飞距离或出现持续穿模，不继续叠加补丁；先回退该显式分支并重新评估目标姿势和 PCA 强度。
