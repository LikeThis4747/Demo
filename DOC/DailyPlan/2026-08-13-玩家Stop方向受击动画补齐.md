# 2026-08-13 玩家 Stop 方向受击动画补齐

- Owner：Codex `/root`
- 状态：已完成并获用户现场验收；当前版本可用，少量观感问题留待 2026-08-14 按实际反馈微调。
- 实施基线：`e961882f909839befa4205813e30aa887b512963`，已推送并核对内部 `origin/main`。

## 目标

- 玩家进入 `Stop` 时播放可读的正面、左侧、右侧全身受击动画。
- 复用现有 CharacterImpact 动态 Montage 和 `DefaultSlot`，不新增第二套受击状态机。
- 保留 Stop 可选局部物理；动画用于明确读感，局部物理只提供命中位置与短余势。

## 当前缺口

- `/Game/ZeroEscape/Physics/Impact/DA_PlayerStandingImpact` 的 `FrontReaction / LeftReaction / RightReaction` 当前均为 `None`。
- 玩家 Slow 已完成，且按当前合同不播放全身动画。
- 玩家 Stop 的移动阻断已经工作，但即使来源将 `bPlayReactionAnimation` 设为 true，也没有可播放的玩家动画资产。

## 最小方案

1. 复制追猎者现有三条非 Additive、无 Root Motion Sequence：
   - `MM_SciFi_Character_08_standing_react_large_gut`
   - `MM_SciFi_Character_08_standing_react_large_from_left`
   - `MM_SciFi_Character_08_standing_react_large_from_right`
2. 按已验收的玩家 Heavy GetUp 工作流，为玩家创建三份副本并替换到玩家 Skeleton：
   - `/Game/ZeroEscape/Characters/Animation/MM_Player_standing_react_large_gut`
   - `/Game/ZeroEscape/Characters/Animation/MM_Player_standing_react_large_from_left`
   - `/Game/ZeroEscape/Characters/Animation/MM_Player_standing_react_large_from_right`
3. 在 Persona 使用玩家实际 Mesh 预览，人工检查方向、手臂、脚底、武器姿势和首尾帧。
4. 把三条玩家 Sequence 填入 `DA_PlayerStandingImpact`。
5. 把现有玩家 Stop 来源 `/Game/ZeroEscape/Physics/Impact/DA_SpikeStandingImpact` 的 `PlayerReaction.bPlayReactionAnimation` 打开，用真实 Stop 路径验收。

## ABP 边界

- 当前实现通过 `PlaySlotAnimationAsDynamicMontage` 使用已有 `DefaultSlot`；第一轮不修改 AnimBP。
- 实施前必须用官方 MCP 重新确认玩家运行 AnimBP 仍包含 `DefaultSlot`。
- 若现场出现 Slot 层级、IK、脚底或武器姿势问题，需要用户在 AnimBP/Persona 中参与调整时应立即说明；不得用错误 Skeleton、代码姿势修补或额外 Montage 资产绕过。

## 明确不修改

- CharacterImpact/HeavyImpact 的接口、状态机和优先级。
- 玩家 Slow 参数与制导投射物、磁力投掷物接入。
- 追猎者三条原始动画。
- Heavy PCA、倒地、起身与攻击系统。
- Level0、PCG、地刺 C++、玩家输入和生命值。

## 验证

1. 官方 MCP 回读三条新 Sequence 的路径、Skeleton、Additive 类型与 Root Motion。
2. `DA_PlayerStandingImpact` 三方向引用持久化；`DA_SpikeStandingImpact` 玩家 Stop 开启动画。
3. Blueprint warnings-as-errors 编译通过，无无关资产 diff。
4. 玩家站立、移动和空中分别从正面、左侧、右侧触发 Stop；方向正确且只播放一次。
5. Stop 结束后移动、跳跃、抓取和投掷恢复；镜头与松手释放始终可用。
6. Stop 动画期间触发 Heavy，Heavy 仍优先并正常击飞、倒地和起身。

## 止损

- 三条重定向动画若在玩家骨架上明显变形，先停在 Persona/重定向资产层处理，不改 CharacterImpact 核心。
- 若 DefaultSlot 与玩家现有动画层产生无法接受的冲突，再单独评估 ABP；不预建专用 Slot 或新状态机。
