## 一、已确认的硬约束

1. 题目要求 PCG **实时、非工具**：最终打包游戏开始一局后现场生成完整可玩关卡，不依赖 Editor-only 模块、预烘焙最终地图或固定地图随机摆放。
2. 难度由玩家在设置中选择；开始一局时快照并固定，本局中不动态改变。
3. 困难难度不应明显延长单局时间；各难度保持近似的关键路线长度与目标时长。
4. 所有难度都限制长距离回头路；困难增加选择、目标和危险压力，不以重复跑图制造难度。
5. 当前场景素材采用 `/Game/Assets/SFCorridors`，但生成算法不得直接依赖该路径或第三方资产命名，未来允许更换素材。
6. 当前收集、追猎者和陷阱规则仍可能变化；它们只能作为可替换 Flow/Content Profile，不能成为空间算法的不变量。

## 二、V2.1 架构结论

采用 **流程图 + 空间拓扑图 + 混合布局求解 + 内容规划 + 全局验证 + 运行时实例化**：

```text
GenerationRequest（Seed、难度、Flow、Topology、Catalog 版本）
    ↓
Difficulty Resolver（固定时长下分配拓扑、目标、危险、敌人预算）
    ↓
Progression Plan（首版只支持逃离、Collect All、Collect K of N）
    +
Spatial Graph（主路、短支路、经过房、前向汇合、局部环路）
    ↓
Intent Placement（目标先绑定进度带和拓扑角色，不绑定固定房型）
    ↓
Layout Request（占地、保留区、Portal、房间包围盒）
    ↓
Hybrid Layout Solver
    ├─ 规则模块：有限 2D/2.5D Simple-Tiled WFC
    └─ 大厅、楼梯、多格模块：Socket 约束放置/回溯
    ↓
GeneratedLevelPlan（只含稳定逻辑 ID、Transform、连接和内容槽位）
    ↓
Objective / Reward / Trap / Enemy Planner（按已启用功能注册）
    ↓
Validator + 有限修复
    ↓
Runtime Instantiator（验证成功后一次性进入场景）
```

WFC 是可替换的局部空间求解器，不负责决定通关流程、难度含义或目标房必须有几个出口。宏观主路线与前向推进关系先由 Spatial Graph 确定，避免纯 WFC 只满足局部连接却产生全局绕路。

## 三、难度如何进入生成

设置界面可以保留简单/普通/困难，但运行时先解析为多个独立预算：

| 预算 | 影响阶段 | 原则 |
|---|---|---|
| 关键路线与目标时长 | Progression / Topology | 各难度保持近似区间 |
| 拓扑复杂度 | Spatial Graph | 提高选择点、分支深度、汇合和多出口房间密度 |
| 目标负担 | Progression / Intent Placement | 调整候选数 N、要求数 K、进度带和绕行成本 |
| 陷阱压力 | Trap Planner | 调整危险预算、必经路占比与连续危险限制；未实现时整层关闭 |
| 敌人压力 | Enemy Planner | 调整数量、最大并发、活动区域重叠与恢复窗口；未实现时整层关闭 |
| 奖励与恢复 | Reward Planner | 调整可选探索收益和安全窗口 |
| 折返上限 | Validator | `MaxRequiredBacktrackDistance` 等硬上限不随难度放宽 |

“困难”不等于所有数值同时放大。更多房间、环路、材料或敌人未必自动更难，最终结果还要由 Difficulty Validator 按实际路线、选择密度、目标成本和压力重叠重新评分。困难需要更多材料但不延长时长时，额外目标应更多分布在主路、短支路或前向汇合路线，而不是放在远端死路。

## 四、SFCorridors 初步适配结论

UE Asset Registry 当前确认该目录共有 295 项资产，其中 70 个 Static Mesh、4 个 Blueprint 和 2 个示例 World。结构候选包括：

- 规则房间：`SM_Room_Pass`、`SM_Room_LeftTurn`、`SM_Room_RightTurn`、`SM_Room_T`；
- 走廊：`SM_SideWalls`、`SM_Corridor_Segment`、`SM_Corridor_Angled`、`SM_Corridor_Divider`；
- 特殊空间：`SM_hub`、`SM_largeHall`、`SM_stairs`；
- 边界与内容：门、玻璃墙、柱子、箱子、桶、显示器、管线和灯。

示例地图表明这些模块不是统一尺寸：Room 家族、SideWalls、Corridor Segment、大厅和楼梯具有不同长度、占地或高度。V2.1 不等待整个素材包测量完毕才设计代码，而是把 SFCorridors 立即作为第一套 `Module Catalog + Presentation Profile`：

1. 首个 PIE 竖切只登记实际要用的最小结构集；每加入一个模块，只补该模块的 Bounds、Pivot 修正、Portal、碰撞和净空数据，不先审计全部 70 个 Static Mesh。
2. 尺寸可归一的 `SM_Room_Pass`、`SM_Room_LeftTurn`、`SM_Room_RightTurn`、`SM_Room_T` 作为首批 Simple-Tiled WFC 候选；若实测不能共用一个 Cell，则通过包装 Transform 或转为 Socket 模块，不改上层流程图。
3. `SM_hub`、`SM_largeHall`、`SM_stairs` 等作为多格/特殊 Socket 模块，由布局层先预留占地并把入口约束注入相邻 WFC Cell。
4. 长直走廊由宏观层决定长度，再让 WFC 在有限走廊带中选择直行、转角和汇合外壳；不让 WFC 自由决定整关主路线。
5. 门、灯、柱子和普通道具属于内容/表现层，不增加结构 WFC 状态；缺少的封口或测试件允许暂时用项目灰盒补位。
6. 第三方目录保持只读，不重命名、不添加项目逻辑、不修改原始 Blueprint。

因此，“素材适配数据”是首个 PIE 竖切必须填好的输入，不是“完成后下一批算法代码才允许进入”的串行门禁。算法接口和 SFCorridors 最小适配可以并行设计；真正实例化前才要求被选模块的数据完整且通过校验。

示例场景包含约 777 个 Actor，其中约 663 个为独立 StaticMeshActor，运行时生成不能照搬这种装配方式。重复结构和普通装饰优先使用 ISM/HISM 或模块级聚合；交互物体才保留独立 Actor。素材自带闪烁灯 Blueprint 使用已连接的 Tick/Delay/Timeline，不纳入批量生成基线。

## 五、素材可替换边界

生成核心只读取项目自有逻辑契约：

```text
Logical Module Catalog
- StableModuleId（整数，参与排序与 Hash）
- DisplayName（只供编辑器阅读）
- Footprint / HeightLayer
- AllowedRotations
- Portal（局部位置、方向、宽高、类型、高度）
- TopologySignature
- Clearance / Collision / Navigation 要求
- Objective / Reward / Trap / Enemy / Cover / Light / Prop Slots
- Weight / Cost

Presentation Set
- StableModuleId
- Soft Asset Reference
- PivotOffset / Scale
- SpawnPolicy（HISM / ISM / Actor）
- PresentationVersion
```

`GeneratedLevelPlan` 禁止保存 `/Game/Assets/SFCorridors/...` 路径，只保存整数 `StableModuleId`。SFCorridors 路径仅存在于 `Presentation Set`。以后更换同规格素材只替换表现绑定；若新素材尺寸或 Portal 契约不同，则新增 Catalog/Adapter/Layout Profile，但不改 Flow、难度和验证核心。

## 六、运行时与非工具性实现边界

- 生成代码位于 `Demo` Runtime 模块，不依赖 `UnrealEd`、Editor Subsystem 或 UE Experimental WFC 插件。
- 从空白承载关卡开始：快照难度和 Seed → 生成纯数据 Plan → 验证 → 实例化 → 等待碰撞/导航准备 → 开放玩家控制。
- DataAsset、模块资产和预计算的邻接兼容表是合法输入；最终关卡布局必须在每局 Runtime 现场求解。
- 首版先同步生成并测量真实耗时；纯数据和实例化已经分层，只有打包测试证明需要时再将纯数据求解移到工作线程。
- 求解期间不创建 Actor；失败或取消时不留下半成品。
- 同一生成签名由 `Seed + GeneratorAlgorithmVersion + DifficultyProfileVersion + FlowProfileVersion + ModuleCatalogVersion + PresentationVersion` 构成。
- 拓扑、布局、内容使用命名随机子流；候选项稳定排序，禁止依赖 `TMap/TSet` 遍历顺序保证复现。

## 七、状态 Owner 与数据契约

- `ARuntimeLevelGenerator`：一局生成状态唯一 Owner，状态为 Idle → Planning → Validating → Instantiating → Ready/Failed；这是粗粒度运行时状态：Planning 包含 Abstract、Socket/A*/WFC 与结构 Global Validation，Validating 专指 Presentation Binding/运行时提交前校验。默认无 Tick，通过函数、Delegate 和必要的异步完成回调推进。
- GameMode/GameState：只提供本局难度、Seed 和开始/完成流程，不持有 WFC 状态。
- 纯 C++ 生成器：负责 Progression、Topology、WFC/Socket、验证和确定性，不持有 UObject/Actor 生命周期。
- DataAsset：保存生成 Profile、逻辑 Module Catalog 和可替换 Presentation Set。
- Blueprint/关卡：只装配 DataAsset、必要复合模块和空白测试关卡，不承载权威生成规则。

主要数据对象：

- `FZeroEscapeGenerationRequest`
- `FZeroEscapeResolvedGenerationBudget`
- `FZeroEscapeProgressionPlan`
- `FZeroEscapeSpatialGraph`
- `FZeroEscapeObjectiveIntent`
- `FZeroEscapeLayoutRequest`
- `FZeroEscapeGeneratedLevelPlan`
- `FZeroEscapeGenerationValidationResult`
- `FZeroEscapeGenerationReport`

## 九、实施检查点与门禁

### 竖切 A：最小 SFCorridors 输入与纯数据契约

- 选择当前真正要生成的最小结构集，而不是先处理整个素材包；为这些模块填 Module Id、布局策略、Footprint、Pivot 修正、Portal 和表现引用。
- 同时完成 Request、Difficulty Resolver、Progression/Spatial Graph、稳定随机子流、K-of-N 和结构化报告。
- 缺少封口或测试结构时使用项目灰盒补位；第三方目录保持只读。

### 竖切 B：WFC + Socket + PIE 首次成图

- 先在有限 Grid 中嵌入主路和短支路，再预留一个特殊 Socket 模块；其开放入口作为 WFC 边界条件。
- 对最小规则模块集实现候选初始化、传播、最低熵选择、有限回溯和显式预算。
- 从空白承载关卡在 BeginPlay/显式 Generate 时求解；Plan 全部验证成功后才实例化。
- 第一目标是“同 Seed 可复现、不同 Seed 有差异、玩家能从 Start 走到 Exit、无重叠、失败不留半成品”，不是先做完整美术关卡。

### 竖切 C：流程扩展与真实折返验证

- 用 Flow/Profile 切换 EscapeOnly、Collect All、Collect K of N，以及目标的 Leaf/Transit/ForwardRejoin；布局求解器不随通关规则改写。
- 在实际几何上统计合法通关路线、连续折返距离、重复边比例和最晚目标完成进度；所有难度共享回头路硬上限。
- 接入短支路小房间、前向汇合房、可绕柱空间与奖励槽；陷阱和敌人仍保持关闭。

### 竖切 D：性能、导航与打包

- 固定回归 Seed + 100～300 个批量 Seed，记录成功率、失败分布、回溯次数、折返比例、生成/实例化/导航耗时 P50/P95。
- 相同生成签名复现；不同 Seed 有明显拓扑差异。
- Development/Shipping 从空白承载关卡完成 Runtime 生成，证明不依赖 Editor 工具；未来追猎者接入前再把动态导航作为硬门禁。
- 简单/普通/困难保持近似关键路线长度；困难提高统计意义上的复杂度和内容压力，而非要求每个单独 Seed 都严格单调。

## 十、止损条件

- 不建设通用 PCG 框架、不做无限流式地图、不做完整 3D 体素 WFC。
- 若 SFCorridors 规则模块无法可靠归一、WFC 失败/回溯成本过高，则宏观和整房间布局切换为 Socket 回溯；WFC 缩小到规则房间选择、走廊壳体或取消，不影响上层。
- 首版 Collect K of N 限制候选规模或采用有界状态搜索，避免组合爆炸。
- 当前不实现陷阱和敌人，只保留可关闭的 Planner 接口与 Slot；不把占位符冒充玩法完成。
- 未经用户再次确认，不修改 `Source/`、`Content/`、`Config/`、`Plugins/`、`.uproject` 或 `Build.cs`。

### 12.4 `Private/PCG/Data/ZeroEscapeLevelGenerationProfile.cpp`

```cpp
/**
 * @file ZeroEscapeLevelGenerationProfile.cpp
 * 职责：设置三档基线并拒绝非法配置，输出线程安全的纯数据快照。
 * 边界：不生成拓扑，不静默钳制，不访问世界或素材。
 * 状态 Owner：无额外状态。
 */
#include "PCG/Data/ZeroEscapeLevelGenerationProfile.h"

namespace
{
	constexpr int32 HardObjectiveLimit = 12;

	/** 校验闭区间排序及算法允许边界。 */
	bool IsRangeValid(
		const FZeroEscapeIntRange& Range,
		const int32 AllowedMin,
		const int32 AllowedMax)
	{
		return Range.IsOrdered()
			&& Range.Min >= AllowedMin
			&& Range.Max <= AllowedMax;
	}

	/** 校验单档难度的 K/N、槽位容量和非交叉旁路容量。 */
	bool IsDifficultyValid(
		const FZeroEscapeDifficultyDefinition& Definition,
		const FZeroEscapeSharedRouteConstraints& Shared)
	{
		if (!IsRangeValid(Definition.LeafBranchCount, 0, 16)
			|| !IsRangeValid(Definition.ForwardRejoinCount, 0, 16)
			|| !IsRangeValid(
				Definition.ObjectiveCandidateCount,
				1,
				Shared.MaxObjectiveCandidateCount)
			|| !IsRangeValid(
				Definition.RequiredObjectiveCount,
				1,
				Shared.MaxObjectiveCandidateCount))
		{
			return false;
		}

		// 确保任何独立解析出的 K/N 都满足 K <= N。
		if (Definition.RequiredObjectiveCount.Max
			> Definition.ObjectiveCandidateCount.Min)
		{
			return false;
		}

		const int32 GuaranteedInternalMainNodes =
			Shared.MainPathNodeCount.Min - 2;
		const int32 GuaranteedObjectiveLocations =
			GuaranteedInternalMainNodes
			+ Definition.LeafBranchCount.Min
			+ Definition.ForwardRejoinCount.Min;

		if (Definition.ObjectiveCandidateCount.Max
			> GuaranteedObjectiveLocations)
		{
			return false;
		}

		const int32 NonCrossingRejoinCapacity =
			(Shared.MainPathNodeCount.Min - 2) / 2;
		return Definition.LeafBranchCount.Max
				<= GuaranteedInternalMainNodes
			&& Definition.ForwardRejoinCount.Max
				<= NonCrossingRejoinCapacity;
	}
}

/** 写入简单、普通、困难三档默认预算。 */
UZeroEscapeLevelGenerationProfile::UZeroEscapeLevelGenerationProfile()
{
	// 三档共用 Shared.MainPathNodeCount，困难不通过拉长主路线制造难度。
	Easy.LeafBranchCount = FZeroEscapeIntRange(1, 1);
	Easy.ForwardRejoinCount = FZeroEscapeIntRange(0, 1);
	Easy.ObjectiveCandidateCount = FZeroEscapeIntRange(3, 4);
	Easy.RequiredObjectiveCount = FZeroEscapeIntRange(2, 2);

	Normal.LeafBranchCount = FZeroEscapeIntRange(2, 2);
	Normal.ForwardRejoinCount = FZeroEscapeIntRange(1, 2);
	Normal.ObjectiveCandidateCount = FZeroEscapeIntRange(5, 6);
	Normal.RequiredObjectiveCount = FZeroEscapeIntRange(3, 3);

	Hard.LeafBranchCount = FZeroEscapeIntRange(2, 3);
	Hard.ForwardRejoinCount = FZeroEscapeIntRange(2, 3);
	Hard.ObjectiveCandidateCount = FZeroEscapeIntRange(7, 8);
	Hard.RequiredObjectiveCount = FZeroEscapeIntRange(5, 5);
}

/** 完整校验后复制纯数据；失败时 OutSnapshot 保持默认空值。 */
bool UZeroEscapeLevelGenerationProfile::BuildSnapshot(
	FZeroEscapeGenerationProfileSnapshot& OutSnapshot,
	FZeroEscapeGenerationReport& OutReport) const
{
	OutSnapshot = FZeroEscapeGenerationProfileSnapshot();
	OutReport.Reset();
	OutReport.Stage = EZeroEscapeGenerationStage::Configuration;

	const bool bSharedPrimitiveValid = !ProfileId.IsNone()
		&& ProfileVersion > 0
		&& IsRangeValid(Shared.MainPathNodeCount, 5, 64)
		&& Shared.MaxLeafOneWayEdgeCount >= 1
		&& Shared.MaxLeafOneWayEdgeCount <= 4
		&& Shared.MaxRequiredRouteExtraEdgeCount >= 0
		&& Shared.MaxRequiredRouteExtraEdgeCount <= 32
		&& Shared.MaxObjectiveCandidateCount >= 1
		&& Shared.MaxObjectiveCandidateCount <= HardObjectiveLimit
		&& Shared.MaxValidationStateCount >= 1024
		&& Shared.MaxValidationStateCount <= 1048576
		&& Shared.MaxTopologyAttempts >= 1
		&& Shared.MaxTopologyAttempts <= 32
		&& Shared.MaxNodeDegree >= 4
		&& Shared.MaxNodeDegree <= 8;

	if (!bSharedPrimitiveValid
		|| !IsDifficultyValid(Easy, Shared)
		|| !IsDifficultyValid(Normal, Shared)
		|| !IsDifficultyValid(Hard, Shared))
	{
		OutReport.Failure = EZeroEscapeGenerationFailure::InvalidProfile;
		OutReport.Message = TEXT(
			"Generation Profile 非法：请检查共享路线约束、K/N、非交叉汇合容量和搜索状态预算。");
		return false;
	}

	const int32 MaxPotentialNodes = Shared.MainPathNodeCount.Max
		+ FMath::Max3(
			Easy.LeafBranchCount.Max + Easy.ForwardRejoinCount.Max,
			Normal.LeafBranchCount.Max + Normal.ForwardRejoinCount.Max,
			Hard.LeafBranchCount.Max + Hard.ForwardRejoinCount.Max);
	const int64 WorstCaseSearchStates =
		static_cast<int64>(MaxPotentialNodes)
		* (1LL << Shared.MaxObjectiveCandidateCount);
	if (WorstCaseSearchStates > Shared.MaxValidationStateCount)
	{
		OutReport.Failure = EZeroEscapeGenerationFailure::InvalidProfile;
		OutReport.ActualValue = static_cast<int32>(WorstCaseSearchStates);
		OutReport.LimitValue = Shared.MaxValidationStateCount;
		OutReport.Message = TEXT("Profile 的最坏情况精确搜索状态数超过共享预算。");
		return false;
	}

	OutSnapshot.ProfileId = ProfileId;
	OutSnapshot.ProfileVersion = ProfileVersion;
	OutSnapshot.Shared = Shared;
	OutSnapshot.Easy = Easy;
	OutSnapshot.Normal = Normal;
	OutSnapshot.Hard = Hard;
	return true;
}
```

```cpp
/**
 * @file ZeroEscapeGenerationRandom.h
 * 职责：按 Seed、算法版本、固定领域和 Attempt 派生相互隔离的随机子流。
 * 边界：不使用全局随机状态、FName 哈希或容器遍历顺序。
 * 状态 Owner：无；全部为纯值函数。
 */
#pragma once

#include "CoreMinimal.h"
#include "Math/RandomStream.h"

namespace ZeroEscape::LevelGeneration
{
	enum class ERandomDomain : uint32
	{
		Difficulty = 0xD1FF1C01U,
		Topology = 0x70F01061U,
		ObjectivePlacement = 0x0B1EC711U,
		Layout = 0x1A70A001U,
		Content = 0xC017E171U,
		Presentation = 0x9E53E171U
	};

	/** 对 32 位输入执行固定、可复现的无符号混合。 */
	inline uint32 Mix32(uint32 Value)
	{
		Value ^= Value >> 16;
		Value *= 0x7FEB352DU;
		Value ^= Value >> 15;
		Value *= 0x846CA68BU;
		Value ^= Value >> 16;
		return Value;
	}

	/** 每个阶段直接从签名派生子流；前一阶段多取一次随机数不会扰动后续阶段。 */
	inline FRandomStream MakeStream(
		const int32 MasterSeed,
		const int32 AlgorithmVersion,
		const ERandomDomain Domain,
		const int32 AttemptIndex)
	{
		uint32 Value = static_cast<uint32>(MasterSeed);
		Value ^= Mix32(static_cast<uint32>(AlgorithmVersion) * 0x9E3779B9U);
		Value ^= static_cast<uint32>(Domain);
		Value ^= Mix32(static_cast<uint32>(AttemptIndex) * 0x85EBCA6BU);
		return FRandomStream(static_cast<int32>(Mix32(Value) & 0x7FFFFFFFU));
	}
}
```

```cpp
		constexpr int32 GeneratorAlgorithmVersion = 1;

		/** 将单一失败写入结构化报告，不产生隐藏回退。 */
		void Fail(
			FZeroEscapeGenerationReport& Report,
			const EZeroEscapeGenerationStage Stage,
			const EZeroEscapeGenerationFailure Failure,
			const FString& Message,
			const int32 Actual = 0,
			const int32 Limit = 0,
			const int32 StableId = INDEX_NONE)
		{
			Report.bSuccess = false;
			Report.Stage = Stage;
			Report.Failure = Failure;
			Report.Message = Message;
			Report.ActualValue = Actual;
			Report.LimitValue = Limit;
			Report.RelatedStableId = StableId;
		}

		/** 用显式子流执行 Fisher-Yates，禁止使用全局随机状态。 */
		template <typename ElementType>
		void Shuffle(TArray<ElementType>& Values, FRandomStream& Stream)
		{
			for (int32 Index = Values.Num() - 1; Index > 0; --Index)
			{
				Values.Swap(Index, Stream.RandRange(0, Index));
			}
		}

		/** 按 NodeA < NodeB 添加无向规范边。 */
		void AddEdge(
			FZeroEscapeSpatialGraph& Graph,
			const int32 First,
			const int32 Second)
		{
			FZeroEscapeSpatialEdge& Edge = Graph.Edges.AddDefaulted_GetRef();
			Edge.NodeA = FMath::Min(First, Second);
			Edge.NodeB = FMath::Max(First, Second);
		}

		/** 判断拓扑角色是否满足本次目标放置策略。 */
		bool IsRoleAllowed(
			const EZeroEscapeObjectivePlacementPolicy Policy,
			const EZeroEscapeTopologyRole Role)
		{
			switch (Policy)
			{
			case EZeroEscapeObjectivePlacementPolicy::Any:
				return Role == EZeroEscapeTopologyRole::Transit
					|| Role == EZeroEscapeTopologyRole::Leaf
					|| Role == EZeroEscapeTopologyRole::ForwardRejoin;
			case EZeroEscapeObjectivePlacementPolicy::TransitOnly:
				return Role == EZeroEscapeTopologyRole::Transit;
			case EZeroEscapeObjectivePlacementPolicy::LeafOnly:
				return Role == EZeroEscapeTopologyRole::Leaf;
			case EZeroEscapeObjectivePlacementPolicy::ForwardRejoinOnly:
				return Role == EZeroEscapeTopologyRole::ForwardRejoin;
			case EZeroEscapeObjectivePlacementPolicy::ForwardProgressOnly:
				return Role == EZeroEscapeTopologyRole::Transit
					|| Role == EZeroEscapeTopologyRole::ForwardRejoin;
			default:
				return false;
			}
		}

		/** 按已解析拓扑预算计算目标策略理论上最多能提供的槽位数。 */
		int32 GetObjectiveCapacity(
			const EZeroEscapeObjectivePlacementPolicy Policy,
			const FZeroEscapeResolvedGenerationBudget& Budget)
		{
			const int32 TransitCount = Budget.MainPathNodeCount - 2;
			switch (Policy)
			{
			case EZeroEscapeObjectivePlacementPolicy::Any:
				return TransitCount + Budget.LeafBranchCount
					+ Budget.ForwardRejoinCount;
			case EZeroEscapeObjectivePlacementPolicy::TransitOnly:
				return TransitCount;
			case EZeroEscapeObjectivePlacementPolicy::LeafOnly:
				return Budget.LeafBranchCount;
			case EZeroEscapeObjectivePlacementPolicy::ForwardRejoinOnly:
				return Budget.ForwardRejoinCount;
			case EZeroEscapeObjectivePlacementPolicy::ForwardProgressOnly:
				return TransitCount + Budget.ForwardRejoinCount;
			default:
				return INDEX_NONE;
			}
		}

		/** 仅允许更换 Attempt 后确实可能变化的失败进入下一次尝试。 */
		bool IsRetryable(const EZeroEscapeGenerationFailure Failure)
		{
			return Failure
				== EZeroEscapeGenerationFailure::TopologyCapacityInsufficient
				|| Failure
					== EZeroEscapeGenerationFailure::RequiredRouteExtraEdgesExceeded;
		}

		/** 将固定难度枚举映射到快照字段，避免依赖 Map 遍历。 */
		const FZeroEscapeDifficultyDefinition* FindDifficulty(
			const EZeroEscapeDifficulty Difficulty,
			const FZeroEscapeGenerationProfileSnapshot& Profile)
		{
			switch (Difficulty)
			{
			case EZeroEscapeDifficulty::Easy: return &Profile.Easy;
			case EZeroEscapeDifficulty::Normal: return &Profile.Normal;
			case EZeroEscapeDifficulty::Hard: return &Profile.Hard;
			default: return nullptr;
			}
		}
	}

	/** 校验输入快照并按 Difficulty 随机域解析本局预算。 */
	bool FAbstractPlanGenerator::ResolveBudget(
		const FZeroEscapeGenerationRequest& Request,
		const FZeroEscapeGenerationProfileSnapshot& Profile,
		FZeroEscapeResolvedGenerationBudget& OutBudget,
		FZeroEscapeGenerationReport& OutReport)
	{
		OutReport.Stage = EZeroEscapeGenerationStage::BudgetResolution;
		const FZeroEscapeDifficultyDefinition* Definition =
			FindDifficulty(Request.Difficulty, Profile);

		if (Definition == nullptr || Request.FlowProfileId.IsNone()
			|| Request.FlowProfileVersion < 1 || Request.ModuleCatalogVersion < 0)
		{
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::InvalidRequest,
				TEXT("GenerationRequest 的难度或版本字段非法。"));
			return false;
		}

		const bool bSnapshotBoundaryValid = !Profile.ProfileId.IsNone()
			&& Profile.ProfileVersion > 0
			&& Profile.Shared.MainPathNodeCount.IsOrdered()
			&& Profile.Shared.MainPathNodeCount.Min >= 5
			&& Profile.Shared.MainPathNodeCount.Max <= 64
			&& Definition->LeafBranchCount.IsOrdered()
			&& Definition->LeafBranchCount.Min >= 0
			&& Definition->LeafBranchCount.Max <= 16
			&& Definition->ForwardRejoinCount.IsOrdered()
			&& Definition->ForwardRejoinCount.Min >= 0
			&& Definition->ForwardRejoinCount.Max <= 16
			&& Definition->ObjectiveCandidateCount.IsOrdered()
			&& Definition->ObjectiveCandidateCount.Min >= 1
			&& Definition->RequiredObjectiveCount.IsOrdered()
			&& Definition->RequiredObjectiveCount.Min >= 1
			&& Definition->RequiredObjectiveCount.Max
				<= Definition->ObjectiveCandidateCount.Min
			&& Profile.Shared.MaxTopologyAttempts >= 1
			&& Profile.Shared.MaxTopologyAttempts <= 32
			&& Profile.Shared.MaxNodeDegree >= 4
			&& Profile.Shared.MaxNodeDegree <= 8
			&& Profile.Shared.MaxObjectiveCandidateCount >= 1
			&& Profile.Shared.MaxObjectiveCandidateCount <= 12
			&& Definition->ObjectiveCandidateCount.Max
				<= Profile.Shared.MaxObjectiveCandidateCount
			&& Profile.Shared.MaxLeafOneWayEdgeCount >= 1
			&& Profile.Shared.MaxLeafOneWayEdgeCount <= 4
			&& Profile.Shared.MaxRequiredRouteExtraEdgeCount >= 0
			&& Profile.Shared.MaxRequiredRouteExtraEdgeCount <= 32
			&& Profile.Shared.MaxValidationStateCount >= 1024
			&& Profile.Shared.MaxValidationStateCount <= 1048576;
		if (!bSnapshotBoundaryValid)
		{
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::InvalidProfile,
				TEXT("传入的 Profile Snapshot 未通过生成器边界校验。"));
			return false;
		}

		FRandomStream Stream = MakeStream(
			Request.MasterSeed,
			GeneratorAlgorithmVersion,
			ERandomDomain::Difficulty,
			0);

		OutBudget = FZeroEscapeResolvedGenerationBudget();
		OutBudget.Shared = Profile.Shared;
		OutBudget.MainPathNodeCount =
			Profile.Shared.MainPathNodeCount.Resolve(Stream);
		OutBudget.LeafBranchCount = Definition->LeafBranchCount.Resolve(Stream);
		OutBudget.ForwardRejoinCount =
			Definition->ForwardRejoinCount.Resolve(Stream);

		const int32 CandidateCount =
			Definition->ObjectiveCandidateCount.Resolve(Stream);
		const int32 RequiredCount =
			Definition->RequiredObjectiveCount.Resolve(Stream);

		switch (Request.FlowRule)
		{
		case EZeroEscapeFlowRule::EscapeOnly:
			break;
		case EZeroEscapeFlowRule::CollectAll:
			OutBudget.ObjectiveCandidateCount = CandidateCount;
			OutBudget.RequiredObjectiveCount = CandidateCount;
			break;
		case EZeroEscapeFlowRule::CollectKOfN:
			OutBudget.ObjectiveCandidateCount = CandidateCount;
			OutBudget.RequiredObjectiveCount = RequiredCount;
			break;
		default:
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::InvalidRequest,
				TEXT("GenerationRequest 包含未支持的 FlowRule。"));
			return false;
		}

		if (OutBudget.RequiredObjectiveCount
			> OutBudget.ObjectiveCandidateCount)
		{
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::InvalidBudget,
				TEXT("解析后的 K 大于 N。"),
				OutBudget.RequiredObjectiveCount,
				OutBudget.ObjectiveCandidateCount);
			return false;
		}

		if (Request.FlowRule != EZeroEscapeFlowRule::EscapeOnly)
		{
			const int32 ObjectiveCapacity =
				GetObjectiveCapacity(Request.ObjectivePlacement, OutBudget);
			if (ObjectiveCapacity < OutBudget.ObjectiveCandidateCount)
			{
				Fail(OutReport, OutReport.Stage,
					EZeroEscapeGenerationFailure::InsufficientObjectiveLocations,
					TEXT("目标放置策略与本难度的 N/拓扑预算不兼容；请改用匹配的 Flow/Profile。"),
					ObjectiveCapacity,
					OutBudget.ObjectiveCandidateCount);
				return false;
			}

			const int32 PotentialNodeCount = OutBudget.MainPathNodeCount
				+ OutBudget.LeafBranchCount + OutBudget.ForwardRejoinCount;
			const int64 PotentialStateCount =
				static_cast<int64>(PotentialNodeCount)
				* (1LL << OutBudget.ObjectiveCandidateCount);
			if (PotentialStateCount > OutBudget.Shared.MaxValidationStateCount)
			{
				Fail(OutReport, OutReport.Stage,
					EZeroEscapeGenerationFailure::SearchBudgetExceeded,
					TEXT("解析后的图与 N 会超过精确搜索状态预算。"),
					static_cast<int32>(PotentialStateCount),
					OutBudget.Shared.MaxValidationStateCount);
				return false;
			}
		}

		return true;
	}

	/** 构造可复现的抽象空间图；失败不留下可实例化的半成品。 */
	bool FAbstractPlanGenerator::BuildSpatialGraph(
		const FZeroEscapeGenerationSignature& Signature,
		const FZeroEscapeResolvedGenerationBudget& Budget,
		const int32 AttemptIndex,
		FZeroEscapeSpatialGraph& OutGraph,
		FZeroEscapeGenerationReport& OutReport)
	{
		OutGraph = FZeroEscapeSpatialGraph();
		OutReport.Stage = EZeroEscapeGenerationStage::Topology;

		FRandomStream Stream = MakeStream(
			Signature.MasterSeed,
			Signature.GeneratorAlgorithmVersion,
			ERandomDomain::Topology,
			AttemptIndex);

		TArray<int32> Degree;
		Degree.Init(0, Budget.MainPathNodeCount);

		// 先构造 Start → Exit 主干；NodeId 与数组索引保持一致。
		for (int32 Index = 0; Index < Budget.MainPathNodeCount; ++Index)
		{
			FZeroEscapeSpatialNode& Node = OutGraph.Nodes.AddDefaulted_GetRef();
			Node.NodeId = Index;
			Node.ProgressIndex = Index;
			Node.Role = Index == 0
				? EZeroEscapeTopologyRole::Start
				: (Index == Budget.MainPathNodeCount - 1
					? EZeroEscapeTopologyRole::Exit
					: EZeroEscapeTopologyRole::Transit);
			OutGraph.MainPathNodeIds.Add(Index);

			if (Index > 0)
			{
				AddEdge(OutGraph, Index - 1, Index);
				++Degree[Index - 1];
				++Degree[Index];
			}
		}
		OutGraph.StartNodeId = 0;
		OutGraph.ExitNodeId = Budget.MainPathNodeCount - 1;

		// 一节点耳状旁路连接 i 与 i+2。只选同一奇偶组，区间不会交叉。
		const int32 PreferredParity = Stream.RandRange(0, 1);
		TArray<int32> RejoinAnchors;
		for (int32 Pass = 0; Pass < 2; ++Pass)
		{
			RejoinAnchors.Reset();
			const int32 FirstAnchor = 1 + ((PreferredParity + Pass) % 2);
			for (int32 Anchor = FirstAnchor;
				Anchor <= Budget.MainPathNodeCount - 3;
				Anchor += 2)
			{
				RejoinAnchors.Add(Anchor);
			}
			if (RejoinAnchors.Num() >= Budget.ForwardRejoinCount)
			{
				break;
			}
		}

		if (RejoinAnchors.Num() < Budget.ForwardRejoinCount)
		{
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::TopologyCapacityInsufficient,
				TEXT("主干没有足够的非交叉 ForwardRejoin 锚点。"),
				Budget.ForwardRejoinCount,
				RejoinAnchors.Num());
			return false;
		}

		Shuffle(RejoinAnchors, Stream);
		RejoinAnchors.SetNum(Budget.ForwardRejoinCount);
		RejoinAnchors.Sort();

		for (const int32 Anchor : RejoinAnchors)
		{
			const int32 NewNodeId = OutGraph.Nodes.Num();
			FZeroEscapeSpatialNode& Node = OutGraph.Nodes.AddDefaulted_GetRef();
			Node.NodeId = NewNodeId;
			Node.Role = EZeroEscapeTopologyRole::ForwardRejoin;
			Node.ProgressIndex = Anchor + 1;
			Node.AnchorNodeId = Anchor;
			Node.RejoinNodeId = Anchor + 2;

			Degree.Add(2);
			++Degree[Anchor];
			++Degree[Anchor + 2];
			AddEdge(OutGraph, Anchor, NewNodeId);
			AddEdge(OutGraph, NewNodeId, Anchor + 2);
		}

		// 当前叶支路固定深度 1；以后扩展深度仍受共享 OneWay 上限约束。
		TArray<int32> LeafAnchors;
		for (int32 NodeId = 1;
			NodeId < Budget.MainPathNodeCount - 1;
			++NodeId)
		{
			if (Degree[NodeId] < Budget.Shared.MaxNodeDegree)
			{
				LeafAnchors.Add(NodeId);
			}
		}
		Shuffle(LeafAnchors, Stream);

		if (LeafAnchors.Num() < Budget.LeafBranchCount)
		{
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::TopologyCapacityInsufficient,
				TEXT("节点度数上限下没有足够的 Leaf 锚点。"),
				Budget.LeafBranchCount,
				LeafAnchors.Num());
			return false;
		}

		LeafAnchors.SetNum(Budget.LeafBranchCount);
		LeafAnchors.Sort();
		for (const int32 Anchor : LeafAnchors)
		{
			const int32 NewNodeId = OutGraph.Nodes.Num();
			FZeroEscapeSpatialNode& Node = OutGraph.Nodes.AddDefaulted_GetRef();
			Node.NodeId = NewNodeId;
			Node.Role = EZeroEscapeTopologyRole::Leaf;
			Node.ProgressIndex = Anchor;
			Node.AnchorNodeId = Anchor;
			Node.OneWayDetourEdgeCount = 1;
			Degree.Add(1);
			++Degree[Anchor];
			AddEdge(OutGraph, Anchor, NewNodeId);
		}

		OutGraph.Edges.Sort(
			[](const FZeroEscapeSpatialEdge& A, const FZeroEscapeSpatialEdge& B)
			{
				return A.NodeA != B.NodeA ? A.NodeA < B.NodeA : A.NodeB < B.NodeB;
			});
		return true;
	}

	/** 在合法槽位中按整数进度带选择并规范排序目标。 */
	bool FAbstractPlanGenerator::BindObjectives(
		const FZeroEscapeGenerationRequest& Request,
		const FZeroEscapeGenerationSignature& Signature,
		const FZeroEscapeResolvedGenerationBudget& Budget,
		const FZeroEscapeSpatialGraph& Graph,
		const int32 AttemptIndex,
		FZeroEscapeProgressionPlan& OutProgression,
		FZeroEscapeGenerationReport& OutReport)
	{
		OutProgression = FZeroEscapeProgressionPlan();
		OutProgression.FlowRule = Request.FlowRule;
		OutProgression.CandidateObjectiveCount = Budget.ObjectiveCandidateCount;
		OutProgression.RequiredObjectiveCount = Budget.RequiredObjectiveCount;
		OutReport.Stage = EZeroEscapeGenerationStage::ObjectivePlacement;

		if (Request.FlowRule == EZeroEscapeFlowRule::EscapeOnly)
		{
			return true;
		}

		struct FCandidate
		{
			int32 NodeId = INDEX_NONE;
			int32 ProgressIndex = 0;
			int32 TieBreaker = 0;
		};

		FRandomStream Stream = MakeStream(
			Signature.MasterSeed,
			Signature.GeneratorAlgorithmVersion,
			ERandomDomain::ObjectivePlacement,
			AttemptIndex);

		TArray<FCandidate> Candidates;
		for (const FZeroEscapeSpatialNode& Node : Graph.Nodes)
		{
			if (IsRoleAllowed(Request.ObjectivePlacement, Node.Role))
			{
				FCandidate& Candidate = Candidates.AddDefaulted_GetRef();
				Candidate.NodeId = Node.NodeId;
				Candidate.ProgressIndex = Node.ProgressIndex;
				// 按稳定 NodeId 顺序消费子流；TieBreaker 只处理完全同分候选。
				Candidate.TieBreaker = Stream.RandRange(0, 0x3FFFFFFF);
			}
		}

		if (Candidates.Num() < Budget.ObjectiveCandidateCount)
		{
			Fail(OutReport, OutReport.Stage,
				EZeroEscapeGenerationFailure::InsufficientObjectiveLocations,
				TEXT("实际图中的目标槽位少于策略与预算要求；该错误不重试。"),
				Candidates.Num(),
				Budget.ObjectiveCandidateCount);
			return false;
		}

		// 按均匀进度目标做有界贪心，避免随机抽样把所有必需物集中在地图一端。
		for (int32 PickIndex = 0;
			PickIndex < Budget.ObjectiveCandidateCount;
			++PickIndex)
		{
			const int32 TargetNumerator =
				(PickIndex + 1) * (Budget.MainPathNodeCount - 1);
			const int32 Denominator = Budget.ObjectiveCandidateCount + 1;
			int32 BestIndex = INDEX_NONE;
			int64 BestError = MAX_int64;
			int32 BestTie = MAX_int32;

			for (int32 Index = 0; Index < Candidates.Num(); ++Index)
			{
				const int64 Error = FMath::Abs(
					static_cast<int64>(Candidates[Index].ProgressIndex) * Denominator
					- TargetNumerator);
				if (Error < BestError
					|| (Error == BestError && Candidates[Index].TieBreaker < BestTie)
					|| (Error == BestError && Candidates[Index].TieBreaker == BestTie
						&& Candidates[Index].NodeId < Candidates[BestIndex].NodeId))
				{
					BestIndex = Index;
					BestError = Error;
					BestTie = Candidates[Index].TieBreaker;
				}
			}

			const FZeroEscapeSpatialNode& Node =
				Graph.Nodes[Candidates[BestIndex].NodeId];
			FZeroEscapeObjectivePlacement& Placement =
				OutProgression.Objectives.AddDefaulted_GetRef();
			Placement.NodeId = Node.NodeId;
			Placement.Role = Node.Role;
			Placement.AnchorProgressIndex = Node.AnchorNodeId == INDEX_NONE
				? Node.ProgressIndex
				: Graph.Nodes[Node.AnchorNodeId].ProgressIndex;
			Placement.RejoinProgressIndex = Node.RejoinNodeId == INDEX_NONE
				? INDEX_NONE
				: Graph.Nodes[Node.RejoinNodeId].ProgressIndex;
			Placement.OneWayDetourEdgeCount = Node.OneWayDetourEdgeCount;
			Candidates.RemoveAtSwap(BestIndex, 1, EAllowShrinking::No);
		}

		OutProgression.Objectives.Sort(
			[](const FZeroEscapeObjectivePlacement& A,
				const FZeroEscapeObjectivePlacement& B)
			{
				return A.NodeId < B.NodeId;
			});
		for (int32 Index = 0; Index < OutProgression.Objectives.Num(); ++Index)
		{
			OutProgression.Objectives[Index].ObjectiveStableId = Index;
		}
		return true;
	}

	/** 编排预算、拓扑、目标与验证，并执行有界确定性重试。 */
	bool FAbstractPlanGenerator::Generate(
		const FZeroEscapeGenerationRequest& Request,
		const FZeroEscapeGenerationProfileSnapshot& Profile,
		FZeroEscapeAbstractLevelPlan& OutPlan,
		FZeroEscapeGenerationReport& OutReport)
	{
		OutPlan = FZeroEscapeAbstractLevelPlan();
		OutReport.Reset();

		FZeroEscapeResolvedGenerationBudget Budget;
		if (!ResolveBudget(Request, Profile, Budget, OutReport))
		{
			return false;
		}

		FZeroEscapeGenerationSignature Signature;
		Signature.MasterSeed = Request.MasterSeed;
		Signature.GeneratorAlgorithmVersion = GeneratorAlgorithmVersion;
		Signature.Difficulty = Request.Difficulty;
		Signature.FlowRule = Request.FlowRule;
		Signature.ObjectivePlacement = Request.ObjectivePlacement;
		Signature.FlowProfileId = Request.FlowProfileId;
		Signature.FlowProfileVersion = Request.FlowProfileVersion;
		Signature.TopologyProfileId = Profile.ProfileId;
		Signature.TopologyProfileVersion = Profile.ProfileVersion;
		Signature.ModuleCatalogVersion = Request.ModuleCatalogVersion;

		FZeroEscapeGenerationReport LastAttemptReport;
		for (int32 AttemptIndex = 0;
			AttemptIndex < Budget.Shared.MaxTopologyAttempts;
			++AttemptIndex)
		{
			FZeroEscapeAbstractLevelPlan Candidate;
			Candidate.Signature = Signature;
			Candidate.Budget = Budget;
			FZeroEscapeGenerationReport AttemptReport;
			AttemptReport.AttemptCount = AttemptIndex + 1;

			const bool bBuilt = BuildSpatialGraph(
				Signature, Budget, AttemptIndex,
				Candidate.SpatialGraph, AttemptReport);
			const bool bBound = bBuilt && BindObjectives(
				Request, Signature, Budget, Candidate.SpatialGraph,
				AttemptIndex, Candidate.Progression, AttemptReport);
			const bool bValid = bBound && FAbstractPlanValidator::Validate(
				Request, Candidate, AttemptReport);

			if (bValid)
			{
				AttemptReport.bSuccess = true;
				AttemptReport.Stage = EZeroEscapeGenerationStage::Completed;
				AttemptReport.Failure = EZeroEscapeGenerationFailure::None;
				OutPlan = MoveTemp(Candidate);
				OutReport = MoveTemp(AttemptReport);
				return true;
			}

			LastAttemptReport = MoveTemp(AttemptReport);
			if (!IsRetryable(LastAttemptReport.Failure))
			{
				OutReport = MoveTemp(LastAttemptReport);
				return false; // 配置、程序错误或搜索上限不会因换 Attempt 得到修复。
			}
		}

		OutReport = MoveTemp(LastAttemptReport);
		OutReport.LastAttemptFailure = OutReport.Failure;
		OutReport.Failure = EZeroEscapeGenerationFailure::AttemptsExhausted;
		OutReport.Message = FString::Printf(
			TEXT("%d 次确定性尝试均失败；最后原因为 %d。"),
			OutReport.AttemptCount,
			static_cast<int32>(OutReport.LastAttemptFailure));
		return false;
	}
}
```

```cpp
 * 边界：候选目标上限为 12，搜索必须服从显式状态预算。
 * 状态 Owner：全部搜索数组只存在于单次 Validate 调用中。
 */
#include "PCG/Validation/ZeroEscapeAbstractPlanValidator.h"

		constexpr int32 SupportedGeneratorAlgorithmVersion = 1;

		struct FRouteState
		{
			int32 NodeId = INDEX_NONE;
			uint32 CollectedMask = 0U;
		};

		/** 将验证失败写入当前 Attempt 的结构化报告。 */
		void Fail(
			FZeroEscapeGenerationReport& Report,
			const EZeroEscapeGenerationFailure Failure,
			const FString& Message,
			const int32 Actual = 0,
			const int32 Limit = 0,
			const int32 StableId = INDEX_NONE)
		{
			Report.bSuccess = false;
			Report.Stage = EZeroEscapeGenerationStage::ProgressionValidation;
			Report.Failure = Failure;
			Report.Message = Message;
			Report.ActualValue = Actual;
			Report.LimitValue = Limit;
			Report.RelatedStableId = StableId;
		}

		/** 复核目标角色是否满足请求策略。 */
		bool IsRoleAllowed(
			const EZeroEscapeObjectivePlacementPolicy Policy,
			const EZeroEscapeTopologyRole Role)
		{
			switch (Policy)
			{
			case EZeroEscapeObjectivePlacementPolicy::Any:
				return Role == EZeroEscapeTopologyRole::Transit
					|| Role == EZeroEscapeTopologyRole::Leaf
					|| Role == EZeroEscapeTopologyRole::ForwardRejoin;
			case EZeroEscapeObjectivePlacementPolicy::TransitOnly:
				return Role == EZeroEscapeTopologyRole::Transit;
			case EZeroEscapeObjectivePlacementPolicy::LeafOnly:
				return Role == EZeroEscapeTopologyRole::Leaf;
			case EZeroEscapeObjectivePlacementPolicy::ForwardRejoinOnly:
				return Role == EZeroEscapeTopologyRole::ForwardRejoin;
			case EZeroEscapeObjectivePlacementPolicy::ForwardProgressOnly:
				return Role == EZeroEscapeTopologyRole::Transit
					|| Role == EZeroEscapeTopologyRole::ForwardRejoin;
			default:
				return false;
			}
		}

		/** 计算已收集目标位数，不依赖平台 Intrinsic。 */
		int32 CountBits(uint32 Value)
		{
			int32 Count = 0;
			while (Value != 0U)
			{
				Value &= Value - 1U;
				++Count;
			}
			return Count;
		}

		/** 在单位边成本图上计算单源最短边数。 */
		void ComputeDistances(
			const TArray<TArray<int32>>& Adjacency,
			const int32 Source,
			TArray<int32>& OutDistances)
		{
			OutDistances.Init(INDEX_NONE, Adjacency.Num());
			TArray<int32> Queue;
			Queue.Reserve(Adjacency.Num());
			Queue.Add(Source);
			OutDistances[Source] = 0;

			for (int32 ReadIndex = 0; ReadIndex < Queue.Num(); ++ReadIndex)
			{
				const int32 Current = Queue[ReadIndex];
				for (const int32 Neighbor : Adjacency[Current])
				{
					if (OutDistances[Neighbor] == INDEX_NONE)
					{
						OutDistances[Neighbor] = OutDistances[Current] + 1;
						Queue.Add(Neighbor);
					}
				}
			}
		}

		/** 在 (NodeId, CollectedMask) 状态空间做有界精确 BFS。 */
		int32 FindRequiredRoute(
			const TArray<TArray<int32>>& Adjacency,
			const FZeroEscapeProgressionPlan& Progression,
			const int32 StartNodeId,
			const int32 ExitNodeId,
			const int32 MaxStateCount,
			int32& OutVisitedStateCount)
		{
			const int32 CandidateCount = Progression.Objectives.Num();
			const int32 MaskCount = 1 << CandidateCount;
			const int64 StateCount64 =
				static_cast<int64>(Adjacency.Num()) * MaskCount;
			if (StateCount64 > MaxStateCount || StateCount64 > MAX_int32)
			{
				return -2; // 与“无解”的 INDEX_NONE 分开。
			}

			TArray<uint32> ObjectiveBitByNode;
			ObjectiveBitByNode.Init(0U, Adjacency.Num());
			for (int32 Index = 0; Index < CandidateCount; ++Index)
			{
				ObjectiveBitByNode[Progression.Objectives[Index].NodeId]
					|= 1U << Index;
			}

			const int32 StateCount = static_cast<int32>(StateCount64);
			TArray<int32> Distances;
			Distances.Init(INDEX_NONE, StateCount);
			TArray<FRouteState> Queue;
			Queue.Reserve(StateCount);

			FRouteState Initial;
			Initial.NodeId = StartNodeId;
			Initial.CollectedMask = ObjectiveBitByNode[StartNodeId];
			Queue.Add(Initial);
			Distances[StartNodeId * MaskCount
				+ static_cast<int32>(Initial.CollectedMask)] = 0;

			for (int32 ReadIndex = 0; ReadIndex < Queue.Num(); ++ReadIndex)
			{
				const FRouteState Current = Queue[ReadIndex];
				const int32 CurrentStateIndex = Current.NodeId * MaskCount
					+ static_cast<int32>(Current.CollectedMask);
				const int32 CurrentDistance = Distances[CurrentStateIndex];
				++OutVisitedStateCount;

				if (Current.NodeId == ExitNodeId
					&& CountBits(Current.CollectedMask)
						>= Progression.RequiredObjectiveCount)
				{
					return CurrentDistance;
				}

				for (const int32 Neighbor : Adjacency[Current.NodeId])
				{
					const uint32 NextMask = Current.CollectedMask
						| ObjectiveBitByNode[Neighbor];
					const int32 NextStateIndex = Neighbor * MaskCount
						+ static_cast<int32>(NextMask);
					if (Distances[NextStateIndex] != INDEX_NONE)
					{
						continue;
					}

					Distances[NextStateIndex] = CurrentDistance + 1;
					FRouteState& Next = Queue.AddDefaulted_GetRef();
					Next.NodeId = Neighbor;
					Next.CollectedMask = NextMask;
				}
			}

			return INDEX_NONE;
		}
	}

	/** 先拒绝非法索引，再验证连通、目标和最短合法通关路线。 */
	bool FAbstractPlanValidator::Validate(
		const FZeroEscapeGenerationRequest& Request,
		const FZeroEscapeAbstractLevelPlan& Plan,
		FZeroEscapeGenerationReport& OutReport)
	{
		OutReport.Stage = EZeroEscapeGenerationStage::ProgressionValidation;
		const FZeroEscapeSpatialGraph& Graph = Plan.SpatialGraph;
		const FZeroEscapeResolvedGenerationBudget& Budget = Plan.Budget;
		const FZeroEscapeGenerationSignature& Signature = Plan.Signature;

		if (Signature.MasterSeed != Request.MasterSeed
			|| Signature.Difficulty != Request.Difficulty
			|| Signature.FlowRule != Request.FlowRule
			|| Signature.ObjectivePlacement != Request.ObjectivePlacement
			|| Signature.FlowProfileId != Request.FlowProfileId
			|| Signature.FlowProfileVersion != Request.FlowProfileVersion
			|| Signature.ModuleCatalogVersion != Request.ModuleCatalogVersion
			|| Signature.GeneratorAlgorithmVersion
				!= SupportedGeneratorAlgorithmVersion
			|| Signature.TopologyProfileId.IsNone()
			|| Signature.TopologyProfileVersion < 1)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidRequest,
				TEXT("Plan Signature 与本次 GenerationRequest 或算法/Profile 版本不一致。"));
			return false;
		}

		if (Graph.Nodes.IsEmpty()
			|| !Graph.Nodes.IsValidIndex(Graph.StartNodeId)
			|| !Graph.Nodes.IsValidIndex(Graph.ExitNodeId)
			|| Graph.StartNodeId == Graph.ExitNodeId)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
				TEXT("空间图没有合法且不同的 Start/Exit。"));
			return false;
		}

		for (int32 Index = 0; Index < Graph.Nodes.Num(); ++Index)
		{
			const FZeroEscapeSpatialNode& Node = Graph.Nodes[Index];
			if (Node.NodeId != Index
				|| (Node.Role == EZeroEscapeTopologyRole::Start
					&& Index != Graph.StartNodeId)
				|| (Node.Role == EZeroEscapeTopologyRole::Exit
					&& Index != Graph.ExitNodeId))
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("NodeId 或 Start/Exit 唯一角色不符合规范。"),
					Node.NodeId, Index, Node.NodeId);
				return false;
			}
		}

		if (Graph.MainPathNodeIds.Num() != Budget.MainPathNodeCount)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
				TEXT("MainPathNodeIds 数量与预算不一致。"),
				Graph.MainPathNodeIds.Num(), Budget.MainPathNodeCount);
			return false;
		}
		const int32 ExpectedNodeCount = Budget.MainPathNodeCount
			+ Budget.LeafBranchCount + Budget.ForwardRejoinCount;
		if (Graph.Nodes.Num() != ExpectedNodeCount
			|| Graph.StartNodeId != 0
			|| Graph.ExitNodeId != Budget.MainPathNodeCount - 1)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
				TEXT("节点总数或主干 Start/Exit 首尾与预算不一致。"),
				Graph.Nodes.Num(), ExpectedNodeCount);
			return false;
		}

		int32 ActualLeafCount = 0;
		int32 ActualForwardRejoinCount = 0;
		for (const FZeroEscapeSpatialNode& Node : Graph.Nodes)
		{
			ActualLeafCount += Node.Role == EZeroEscapeTopologyRole::Leaf ? 1 : 0;
			ActualForwardRejoinCount +=
				Node.Role == EZeroEscapeTopologyRole::ForwardRejoin ? 1 : 0;
		}
		if (ActualLeafCount != Budget.LeafBranchCount
			|| ActualForwardRejoinCount != Budget.ForwardRejoinCount)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
				TEXT("Leaf/ForwardRejoin 实际数量与预算不一致。"));
			return false;
		}

		for (int32 Index = 0; Index < Graph.MainPathNodeIds.Num(); ++Index)
		{
			const EZeroEscapeTopologyRole ExpectedRole = Index == 0
				? EZeroEscapeTopologyRole::Start
				: (Index == Graph.MainPathNodeIds.Num() - 1
					? EZeroEscapeTopologyRole::Exit
					: EZeroEscapeTopologyRole::Transit);
			if (Graph.MainPathNodeIds[Index] != Index
				|| Graph.Nodes[Index].Role != ExpectedRole
				|| Graph.Nodes[Index].ProgressIndex != Index)
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("主干 ID、角色和 ProgressIndex 必须从 Start 到 Exit 规范排序。"),
					Graph.MainPathNodeIds[Index], Index);
				return false;
			}
		}

		if (Graph.Nodes[Graph.StartNodeId].Role != EZeroEscapeTopologyRole::Start
			|| Graph.Nodes[Graph.ExitNodeId].Role != EZeroEscapeTopologyRole::Exit)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
				TEXT("Start/Exit 节点角色与 ID 不一致。"));
			return false;
		}

		TArray<TArray<int32>> Adjacency;
		Adjacency.SetNum(Graph.Nodes.Num());
		FZeroEscapeSpatialEdge Previous;
		for (int32 EdgeIndex = 0; EdgeIndex < Graph.Edges.Num(); ++EdgeIndex)
		{
			const FZeroEscapeSpatialEdge& Edge = Graph.Edges[EdgeIndex];
			const bool bEndpointValid = Graph.Nodes.IsValidIndex(Edge.NodeA)
				&& Graph.Nodes.IsValidIndex(Edge.NodeB);
			const bool bSortedAfterPrevious = EdgeIndex == 0
				|| Previous.NodeA < Edge.NodeA
				|| (Previous.NodeA == Edge.NodeA && Previous.NodeB < Edge.NodeB);

			if (!bEndpointValid || Edge.NodeA >= Edge.NodeB || !bSortedAfterPrevious)
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("边必须有效、无自环、无重复，并按 (NodeA, NodeB) 严格排序。"),
					EdgeIndex, Graph.Edges.Num());
				return false;
			}
			Adjacency[Edge.NodeA].Add(Edge.NodeB);
			Adjacency[Edge.NodeB].Add(Edge.NodeA);
			Previous = Edge;
		}

		for (int32 NodeId = 0; NodeId < Adjacency.Num(); ++NodeId)
		{
			Adjacency[NodeId].Sort();
			const FZeroEscapeSpatialNode& Node = Graph.Nodes[NodeId];
			if (Adjacency[NodeId].Num() > Budget.Shared.MaxNodeDegree)
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("节点度数超过共享上限。"),
					Adjacency[NodeId].Num(), Budget.Shared.MaxNodeDegree, NodeId);
				return false;
			}

			if ((Node.Role == EZeroEscapeTopologyRole::Start
					|| Node.Role == EZeroEscapeTopologyRole::Exit
					|| Node.Role == EZeroEscapeTopologyRole::Transit)
				&& (Node.AnchorNodeId != INDEX_NONE
					|| Node.RejoinNodeId != INDEX_NONE
					|| Node.OneWayDetourEdgeCount != 0))
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("Start/Exit/Transit 不得携带分支来源元数据。"),
					0, 0, NodeId);
				return false;
			}

			if (Node.Role == EZeroEscapeTopologyRole::Leaf
				&& (Adjacency[NodeId].Num() != 1
					|| !Graph.Nodes.IsValidIndex(Node.AnchorNodeId)
					|| !Adjacency[NodeId].Contains(Node.AnchorNodeId)
					|| Node.RejoinNodeId != INDEX_NONE
					|| Node.OneWayDetourEdgeCount < 1
					|| Node.OneWayDetourEdgeCount
						> Budget.Shared.MaxLeafOneWayEdgeCount))
			{
				Fail(OutReport,
					EZeroEscapeGenerationFailure::LeafDetourLimitExceeded,
					TEXT("Leaf 结构或单程边数超过所有难度共用的上限。"),
					Node.OneWayDetourEdgeCount,
					Budget.Shared.MaxLeafOneWayEdgeCount,
					NodeId);
				return false;
			}

			if (Node.Role == EZeroEscapeTopologyRole::ForwardRejoin
				&& (Adjacency[NodeId].Num() != 2
					|| !Graph.Nodes.IsValidIndex(Node.AnchorNodeId)
					|| !Graph.Nodes.IsValidIndex(Node.RejoinNodeId)
					|| !Adjacency[NodeId].Contains(Node.AnchorNodeId)
					|| !Adjacency[NodeId].Contains(Node.RejoinNodeId)
					|| Node.OneWayDetourEdgeCount != 0
					|| Graph.Nodes[Node.AnchorNodeId].ProgressIndex
						>= Graph.Nodes[Node.RejoinNodeId].ProgressIndex))
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("ForwardRejoin 必须明确连接较早锚点和较晚汇合点。"),
					0, 0, NodeId);
				return false;
			}
		}

		for (int32 MainIndex = 1;
			MainIndex < Graph.MainPathNodeIds.Num();
			++MainIndex)
		{
			if (!Adjacency[MainIndex - 1].Contains(MainIndex))
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::InvalidGraph,
					TEXT("相邻主干节点之间缺少必需边。"),
					0, 0, MainIndex);
				return false;
			}
		}

		TArray<int32> StartDistances;
		ComputeDistances(Adjacency, Graph.StartNodeId, StartDistances);
		for (int32 NodeId = 0; NodeId < StartDistances.Num(); ++NodeId)
		{
			if (StartDistances[NodeId] == INDEX_NONE)
			{
				Fail(OutReport, EZeroEscapeGenerationFailure::DisconnectedGraph,
					TEXT("存在从 Start 不可达的节点。"), 0, 0, NodeId);
				return false;
			}
		}

		const FZeroEscapeProgressionPlan& Progression = Plan.Progression;
		if (Progression.FlowRule != Request.FlowRule
			|| Progression.CandidateObjectiveCount != Progression.Objectives.Num()
			|| Progression.CandidateObjectiveCount != Budget.ObjectiveCandidateCount
			|| Progression.RequiredObjectiveCount != Budget.RequiredObjectiveCount)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidBudget,
				TEXT("Progression Plan 的 Flow 或 K/N 与请求和预算不一致。"));
			return false;
		}

		if (Request.FlowRule == EZeroEscapeFlowRule::EscapeOnly)
		{
			OutReport.BaselineRouteEdgeCount = StartDistances[Graph.ExitNodeId];
			OutReport.RequiredRouteEdgeCount = OutReport.BaselineRouteEdgeCount;
			if (!Progression.Objectives.IsEmpty()
				|| Progression.RequiredObjectiveCount != 0)
			{
				Fail(OutReport,
					EZeroEscapeGenerationFailure::InvalidObjectivePlacement,
					TEXT("EscapeOnly 不得包含目标候选或收集要求。"));
				return false;
			}
			return true;
		}

		if (Progression.Objectives.Num() > Budget.Shared.MaxObjectiveCandidateCount
			|| Progression.RequiredObjectiveCount < 1
			|| Progression.RequiredObjectiveCount > Progression.Objectives.Num())
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::InvalidBudget,
				TEXT("目标规模或 K/N 超出精确搜索边界。"));
			return false;
		}

		TArray<bool> SeenNodes;
		SeenNodes.Init(false, Graph.Nodes.Num());
		int32 PreviousObjectiveNodeId = INDEX_NONE;
		for (int32 ObjectiveIndex = 0;
			ObjectiveIndex < Progression.Objectives.Num();
			++ObjectiveIndex)
		{
			const FZeroEscapeObjectivePlacement& Objective =
				Progression.Objectives[ObjectiveIndex];
			const bool bNodeIndexValid =
				Graph.Nodes.IsValidIndex(Objective.NodeId);
			const FZeroEscapeSpatialNode* SourceNode = bNodeIndexValid
				? &Graph.Nodes[Objective.NodeId]
				: nullptr;
			const int32 ExpectedAnchorProgress = SourceNode == nullptr
				? INDEX_NONE
				: (SourceNode->AnchorNodeId == INDEX_NONE
					? SourceNode->ProgressIndex
					: Graph.Nodes[SourceNode->AnchorNodeId].ProgressIndex);
			const int32 ExpectedRejoinProgress = SourceNode == nullptr
				|| SourceNode->RejoinNodeId == INDEX_NONE
				? INDEX_NONE
				: Graph.Nodes[SourceNode->RejoinNodeId].ProgressIndex;
			if (!bNodeIndexValid
				|| Objective.NodeId == Graph.StartNodeId
				|| Objective.NodeId == Graph.ExitNodeId
				|| SeenNodes[Objective.NodeId]
				|| Objective.NodeId <= PreviousObjectiveNodeId
				|| Objective.ObjectiveStableId != ObjectiveIndex
				|| Objective.Role != SourceNode->Role
				|| Objective.AnchorProgressIndex != ExpectedAnchorProgress
				|| Objective.RejoinProgressIndex != ExpectedRejoinProgress
				|| Objective.OneWayDetourEdgeCount
					!= SourceNode->OneWayDetourEdgeCount
				|| !IsRoleAllowed(Request.ObjectivePlacement, Objective.Role))
			{
				Fail(OutReport,
					EZeroEscapeGenerationFailure::InvalidObjectivePlacement,
					TEXT("目标节点非法、重复、未规范排序或不满足拓扑角色策略。"),
					0, 0, Objective.ObjectiveStableId);
				return false;
			}
			SeenNodes[Objective.NodeId] = true;
			PreviousObjectiveNodeId = Objective.NodeId;
		}

		OutReport.BaselineRouteEdgeCount = StartDistances[Graph.ExitNodeId];
		OutReport.VisitedValidationStateCount = 0;
		const int32 RequiredRoute = FindRequiredRoute(
			Adjacency,
			Progression,
			Graph.StartNodeId,
			Graph.ExitNodeId,
			Budget.Shared.MaxValidationStateCount,
			OutReport.VisitedValidationStateCount);

		if (RequiredRoute == -2)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::SearchBudgetExceeded,
				TEXT("(NodeId, CollectedMask) 精确搜索超过状态预算。"));
			return false;
		}
		if (RequiredRoute == INDEX_NONE)
		{
			Fail(OutReport, EZeroEscapeGenerationFailure::ProgressionNoSolution,
				TEXT("不存在收集足够目标后到达出口的路线。"));
			return false;
		}

		OutReport.RequiredRouteEdgeCount = RequiredRoute;
		OutReport.RequiredRouteExtraEdgeCount =
			RequiredRoute - OutReport.BaselineRouteEdgeCount;

		if (OutReport.RequiredRouteExtraEdgeCount
			> Budget.Shared.MaxRequiredRouteExtraEdgeCount)
		{
			Fail(OutReport,
				EZeroEscapeGenerationFailure::RequiredRouteExtraEdgesExceeded,
				TEXT("最短合法通关路线的额外边数超过所有难度共用上限。"),
				OutReport.RequiredRouteExtraEdgeCount,
				Budget.Shared.MaxRequiredRouteExtraEdgeCount);
			return false;
		}

		return true;
	}
}
```

> `RequiredRouteExtraEdgeCount = 收集足够目标并到出口的最短路线 - 直达出口最短路线`。它能约束“为了过关额外绕了多少”，但还不能完整描述连续原路折返；Checkpoint 2 获得几何路径后，再增加“实际米数、重复边米数、最长连续折返米数”和导航可达验证。

## 十三、V2.1 混合生成方案与拟实现代码（已吸收评审）

### 13.1 先澄清三个概念

“完成素材契约后，下一批代码才会进入”在 V1 中表达得过于绝对。V2 的准确含义是：

- SFCorridors 从现在起就是首个正式素材实现，不是临时候选。
- WFC、Socket、Flow、运行时 Actor 的接口和代码可以现在一起设计。
- 在真正进入 PIE 实例化某个模块前，只要求该模块自己的 Footprint、Pivot、Portal、碰撞和表现引用已填写并通过校验；不要求先把整个素材包审完。
- 未来换成同尺寸同 Portal 的素材，只换 Presentation Profile；若几何规格也变化，则新增一套 Module Catalog，但 Progression、K-of-N、难度和验证核心不改。

`K of N` 不是布局算法，而是通关规则：

| 规则 | 含义 | 示例 |
|---|---|---|
| Escape Only | 到出口即可通关 | 当前最小灰盒流程 |
| Collect All | N 个目标全部完成，等价于 K=N | 三个房间都必须到达 |
| Collect K of N | N 个候选中任意完成 K 个 | 10 个材料拿到任意 6 个 |

顺序目标只作未来概念，首版不把它放进 `BlueprintType` 枚举或 DataAsset 下拉框。等独立状态机、校验和测试真正实现时再新增，避免“策划可选但必然失败”。

K-of-N 只影响 Progression Plan 与可解性搜索。目标房可以是短死路、主路经过房或前向汇合房，具体比例由 Flow Profile 配置；WFC 和 Socket 不知道“材料”是什么，只接收入口、占地和拓扑角色约束。

### 13.2 外部方案中实际借鉴的部分

- [mxgmn/WaveFunctionCollapse](https://github.com/mxgmn/WaveFunctionCollapse) 提供 Simple-Tiled WFC 的核心循环：最低熵选择、按权重 Observe、邻接传播和矛盾检测；仓库为 MIT，但本项目只借鉴算法结构，不复制其 C# 代码。
- UE 5.7 的 [Experimental Wave Function Collapse](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/PluginIndex/WaveFunctionCollapse) 和本机引擎源码可作为 UE 数据表达参考，但本机 `WaveFunctionCollapse.uplugin` 明确是 `Editor` 模块并依赖 `UnrealEd`，不能成为 Runtime 方案依赖。
- [Dungeon Architect Snap Grid Flow](https://docs.dungeonarchitect.dev/unreal/snap-grid-flow/sgf-introduction/) 的可取之处是“Flow Graph 先定语义，再用固定 Chunk、多格 Module 和 Door 进行拼接”；本项目实现更小的自有版本，不购买或依赖该插件。
- [BenPyton Procedural Dungeon](https://benpyton.github.io/ProceduralDungeon/guides/Introduction) 证明了“主关卡保留、运行时虚拟生成、验证后再加载房间、房间数据保存 Bounds/Doors”的成熟方向；其当前 GitHub 版本是 CeCILL-C/Fab 多许可证，本项目不复制其源码。
- UE 官方 PCG Framework 确实支持 [Runtime Generation](https://dev.epicgames.com/documentation/unreal-engine/using-pcg-generation-modes-in-unreal-engine?lang=ja)，但 V2 不把官方 PCG Graph 作为权威关卡求解器；以后可用它做房间内部散布和装饰。
- 重复结构实例化遵循 UE 官方 [Instanced Static Mesh](https://dev.epicgames.com/documentation/en-us/unreal-engine/instanced-static-mesh-component-in-unreal-engine) 方向；交互物、门和玩法 Actor 仍单独生成。

### 13.3 最终采用的混合顺序

```text
Generation Request
  Seed + 单局固定 Difficulty + Flow Profile
        |
        v
Progression / Spatial Graph
  主干 + 短叶支路 + 前向汇合 + K-of-N Objective Intents
        |
        v
Graph-to-Grid Skeleton
  先保证 Start -> Exit 与目标拓扑，不让 WFC 自由改写流程
        |
        v
Socket Reservation
  先放 Start/Exit/Objective/Special 模块并占用多格 Footprint
        |
        v
Deterministic A* Skeleton
  在未占用粗网格中连接已选 Portal
  将路径转成相邻 Cell 的 Required Portal Mask
        |
        v
Bounded Simple-Tiled WFC
  只填有限走廊带与规则小房间
  Initialize -> Observe -> Propagate -> bounded Backtrack
        |
        v
Global Validation
  重叠、Portal、连通、K-of-N、真实路线与折返指标
        |
        v
Runtime Instantiation
  Plan 成功后批量生成结构，再生成少量玩法 Actor
```

选择“Socket 预留在前、A* 落实必需连接、WFC 填充在后”的原因是：大厅、楼梯和目标房占地大且约束强，先固定它们能显著减少 WFC 盲目坍缩后的大规模推翻。A* 只保证每条抽象边能落到粗网格，不选择最终美术模块；WFC 负责规则走廊/小房间在边界约束下的局部组合，并可在受限区域内增加短环路。

A* 连边顺序固定为：主路径边 → 必需目标边 → Forward-Rejoin/可选短环边；同级再按 `StableEdgeId` 排序。后加的奖励房或新 Flow 不能因遍历容器顺序而改写已有主路。

### 13.4 WFC 的具体实现边界

V2 使用 **Simple-Tiled WFC**，不使用从示例图片学习 N×N Pattern 的 Overlapping Model。每个可旋转模块先展开为稳定 Variant：

```text
Variant
- StableVariantId
- StableModuleId
- QuarterTurns
- Weight
- 四向 Portal Signature
- Allowed Region / Topology Tags
```

WFC 初始化时不是“所有格子允许所有模块”，而是先把格子分为 `Outside | ActiveWfc | ReservedSocket`，只为 `ActiveWfc` 创建 Domain，再叠加硬约束：

1. `ActiveWfc Region` 由 A* 有序路径 Cell 与 Profile 明确批准的局部扩展/短环 Cell 构成，数量不得超过 `MaxWfcActiveCells`；不默认铺满整个 `20×20` Grid。
2. Active Region 外边界必须闭合；`Outside` 和 `ReservedSocket` 不进入 WFC Cell 数组、不入传播队列。
3. Graph-to-Grid Skeleton 要求的方向必须开放，禁止的方向必须闭合。
4. 特殊 Socket 模块不通过“空 Domain 邻居”传播；而是把边界入口的 `ConnectorTypeId + WidthClass + HeightLayer` 写入相邻 Active Cell 的 `MustMatchSignature`。
5. WFC Variant 的四向 `ConnectorSignature` 是权威相容依据；4-bit Open Mask 只是预筛。开口必须在相反方向上同时匹配 Type/Width/Height，闭口只与闭口相容。

核心循环：

1. 首版使用 MRV：选择候选数大于 1 且候选最少的 Cell；并列时先按 Stable Cell Id 排序，再使用 Layout 子流选择。这样避免浮点 Shannon Entropy 破坏跨平台复现；以后需要权重熵时再用固定点或预计算值。
2. 在传播稳定点保存完整 Domain 快照与本层 Untried Variant；按整数权重选择一个 Variant，并通过候选删除事件移除同 Cell 其他候选。
3. 使用删除事件队列和四向 Support Count 传播；某候选在一个 Active 邻接方向的支持数归零时才移除。
4. 任一 Cell 候选变为 0 时发生 Contradiction。
5. 从最近仍有 Untried Variant 的稳定快照恢复，重建 Support Count 后尝试下一候选；达到 `MaxWfcBacktracks`、`MaxWfcObservations`、`MaxWfcSupportUpdates`、快照/累计复制预算、`MaxTotalWorkUnits` 或 `MaxLayoutAttempts` 后返回结构化失败，不无限换 Seed。

为避免 WFC 产生“局部都接得上、全局却走不通”，主路线 Cell 及其 Required Portal 在进入 WFC 前已经固定；WFC 完成后仍重新从 Start 做 Flood Fill，并对实际 Portal Graph 运行流程验证。WFC 熵值和回溯次数只用于诊断，不作为游戏难度指标。

### 13.5 Socket 的具体实现边界

每个 Socket 至少保存：

```text
StableSocketId
CellOffset
LocalTransform
Direction
ConnectorTypeId / DisplayType
WidthClass / HeightLayer
ConnectionPolicy = Required | Optional | Sealable
```

候选放置流程：

1. 按“合法候选最少”的 Required Graph Node/Socket 优先处理。
2. 过滤拓扑角色、Footprint、Connector Type、方向、层高和旋转。决策与哈希使用整数 `ConnectorTypeId`，`DisplayType` 只用于 DataAsset 可读性。
3. 全部布局都在 Generator Local 空间求解，用 `CandidateModuleLocal = SourcePortalInModule.Inverse() * MakeOpposedPortalFrame(TargetPortalInGenerator)` 对齐；世界 Transform 只在 Presentation 实例化时合成。正式实现必须先用单位测试验证 UE 的 Transform 乘法顺序。
4. 以离散 Occupied Cells 做第一层重叠检查，再以配置的 Local Bounds/Clearance 做第二层检查。
5. 成功后登记新开放 Socket；失败则尝试下一个稳定排序后的候选。
6. Required Socket 全部连接后，Optional Socket 可以关闭；Sealable Socket 必须找到显式 Cap，不能留下可见洞口。
7. Socket DFS 同样受 `MaxSocketBacktracks` 与候选预算限制，失败时返回 Node、Module、Socket 和实际冲突范围。

对 SFCorridors 的首版映射建议：

| 角色 | 当前素材候选 | 布局策略 |
|---|---|---|
| 直行小房/走廊 | `SM_Room_Pass` | WFC 单格 Variant |
| 左/右转 | `SM_Room_LeftTurn`、`SM_Room_RightTurn` | WFC 单格 Variant/旋转变体 |
| 三岔 | `SM_Room_T` | WFC 单格 Variant |
| 走廊壳体 | `SM_SideWalls`、`SM_Corridor_Segment` | WFC 输出后的表现组合，是否单格由实测决定 |
| Hub/大厅 | `SM_hub`、`SM_largeHall` | 多格 Socket |
| 楼梯 | `SM_stairs` | 跨 HeightLayer Socket；首个单层 PIE 可暂时禁用 |
| 封口 | SFCorridors 合适墙/门或项目灰盒 | Cap |

这里不填写未经实测的厘米数字。数值属于 `DA_ModuleCatalog_SFCorridors`，而不是 C++ 常量。

### 13.6 难度与未来流程如何保持可扩展

所有难度共享：

- 关键路线成本/基准时长区间。
- 叶支路单程上限、最长连续折返和重复边比例上限。
- 候选目标 N 的算法安全上限。
- WFC/Socket/搜索时间与状态预算。

难度 Profile 只改变：

- 有意义的选择节点密度、ForwardRejoin 数和分支角色配额。
- K/N、目标分布进度带以及可选奖励密度。
- 已真正接入后才启用的 Trap/Enemy Planner 预算。

因此困难可以要求更多材料，但同时把更多目标放到主路/前向汇合路径，并减少无意义空走廊，使合法通关路线仍落在共同时间区间。当前没有追猎者、陷阱或多敌人时，对应 Planner 不创建假数据，也不参与难度评分。

### 13.7 必须分层验证的指标

```text
Configuration
  K/N、版本、模块 ID、Portal、权重、预算合法

Abstract Graph
  主干规范、全节点/目标可达、最大度数、角色容量

Progression
  (NodeId, CollectedMask) 有界最短路；N 首版上限 12

Layout
  Footprint/Bounds 不重叠、Required Socket 全连接、WFC 无空 Domain

Geometry
  Portal World Transform 对齐、Start 到 Exit 实际连通、无越界

Experience
  最短合法通关成本、重复边成本、最长连续折返、
  最晚必需目标完成进度、困难复杂度分布
```

K-of-N 的精确状态是 `(CurrentNodeId, CollectedObjectiveMask)`。到达 Exit 且 `PopCount(Mask) >= K` 才成功；`CollectAll` 等价于 `K=N`，`EscapeOnly` 不创建目标 Mask。所有 N 个候选目标仍必须可达，不能把“不是必需的目标”生成到无效区域。

```cpp
bool UZeroEscapeModuleCatalog::IsConfigured(FString& OutError) const
{
    if (CatalogVersion < 1 ||
        CellSize.X <= 0.0 || CellSize.Y <= 0.0 || CellSize.Z <= 0.0)
    {
        OutError = TEXT("Invalid catalog version or cell size.");
        return false;
    }

    TSet<int32> StableModuleIds;
    for (const FZeroEscapeModuleDefinition& Module : Modules)
    {
        if (Module.StableModuleId < 0 ||
            StableModuleIds.Contains(Module.StableModuleId) ||
            Module.Weight <= 0 ||
            Module.Footprint.X <= 0 ||
            Module.Footprint.Y <= 0 ||
            Module.Footprint.Z <= 0 ||
            !IsFiniteValidBounds(Module.LocalBounds) ||
            (Module.AllowedQuarterTurnsMask & 0xF) == 0 ||
            (Module.AllowedQuarterTurnsMask & ~0xF) != 0 ||
            (Module.LayoutPolicy == EZeroEscapeLayoutPolicy::WfcSingleCell &&
             Module.Footprint != FIntVector(1, 1, 1)))
        {
            OutError = FString::Printf(
                TEXT("Invalid or duplicate module id: %d"),
                Module.StableModuleId);
            return false;
        }

        TSet<int32> SocketIds;
        for (const FZeroEscapeModulePortal& Portal : Module.Portals)
        {
            if (Portal.StableSocketId < 0 ||
                Portal.ConnectorTypeId < 0 ||
                Portal.WidthClass <= 0 ||
                Portal.LocalTransform.ContainsNaN() ||
                !Portal.LocalTransform.GetScale3D().Equals(
                    FVector::OneVector, KINDA_SMALL_NUMBER) ||
                !PortalFrameMatchesCardinalDirection(Portal) ||
                (Module.LayoutPolicy ==
                     EZeroEscapeLayoutPolicy::WfcSingleCell &&
                 (Portal.Direction == EZeroEscapeCardinalDirection::Up ||
                  Portal.Direction == EZeroEscapeCardinalDirection::Down)) ||
                (Portal.Policy == EZeroEscapeSocketPolicy::Sealable &&
                 Portal.ClosureModuleId < 0) ||
                SocketIds.Contains(Portal.StableSocketId))
            {
                OutError = FString::Printf(
                    TEXT("Invalid portal in module id: %d"),
                    Module.StableModuleId);
                return false;
            }
            SocketIds.Add(Portal.StableSocketId);
        }
        StableModuleIds.Add(Module.StableModuleId);
    }

    if (!ValidateClosureReferencesAndRequiredRoles(
            Modules, StableModuleIds, OutError))
    {
        return false;
    }

    // 决策阶段会复制到数组并按 StableModuleId 排序；
    // 这里的 TSet 仅用于唯一性查询，不参与随机顺序。
    return true;
}
```

`ValidateClosureReferencesAndRequiredRoles` 二遍检查 Closure Id 确实指向规格相容的 Cap，Start/Exit 至少各有一个模块与对应 Gameplay Anchor，所有 Anchor Id 在模块内唯一、Transform 有限且无缩放。首版 `CompletionRule` 只有 EscapeOnly/CollectAll/CollectKOfN，不暴露未实现选项。

Presentation 校验必须保证每个会进入结构 Plan 的 Logical Module 都有且只有一个有效绑定；`DecorationOnly` 可以缺省。StaticMesh 策略不允许只填 ActorClass，Actor 策略不允许两个引用都为空。实际 Mesh 经 `PivotCorrection` 后的 Bounds 还必须落在 Catalog Bounds 容差内；HISM 分组键包含 Mesh、CollisionProfileName 和 `bCanEverAffectNavigation`，不得把不同碰撞/导航策略合并。

首个竖切只绑定少量必需结构，因此 Presentation Profile 先使用硬资源引用，确保 Cook 和 PIE 行为明确；若后续素材量与加载时间实测证明需要，再把这一层独立迁移到软引用和异步预载，不改布局 Plan。所有随机、排序和 Plan Hash 使用整数 Stable Id；`FName` 只作 Flow 选择或编辑器显示，禁止直接参与 Seed 派生和原始内存 Hash。Socket 占格与相容性使用 `CellOffset/ConnectorTypeId`，浮点 `LocalTransform` 只做实例对齐和容差校验。

```cpp
static uint32 Mix32(uint32 Value)
{
    Value ^= Value >> 16;
    Value *= 0x7FEB352Du;
    Value ^= Value >> 15;
    Value *= 0x846CA68Bu;
    Value ^= Value >> 16;
    return Value;
}

FRandomStream FGenerationCore::MakeRandomStream(
    int32 MasterSeed,
    int32 AlgorithmVersion,
    ERandomDomain Domain,
    int32 AttemptIndex)
{
    uint32 Value = Mix32(static_cast<uint32>(MasterSeed));
    Value = Mix32(Value ^ static_cast<uint32>(AlgorithmVersion));
    Value = Mix32(Value ^ static_cast<uint32>(Domain));
    Value = Mix32(Value ^ static_cast<uint32>(AttemptIndex));
    // 显式保留 31 位，不依赖超出 int32 正范围的转换行为。
    return FRandomStream(
        static_cast<int32>(Value & 0x7FFFFFFFu));
```

K-of-N 使用有界状态 BFS；首版抽象边成本统一为 1，几何完成后再用 Dijkstra 计算真实距离：

```cpp
namespace
{
using FObjectiveMask = uint32;
static_assert(
    ZeroEscape::GenerationLimits::MaxObjectiveCandidates < 32,
    "FObjectiveMask requires every objective to fit in uint32.");

struct FProgressionState
{
    int32 NodeIndex = INDEX_NONE; // 只是连续索引，不是 StableNodeId。
    FObjectiveMask CollectedMask = 0;

    friend bool operator==(
        const FProgressionState& A,
        const FProgressionState& B)
    {
        return A.NodeIndex == B.NodeIndex &&
            A.CollectedMask == B.CollectedMask;
    }

    friend uint32 GetTypeHash(const FProgressionState& State)
    {
        return HashCombineFast(
            GetTypeHash(State.NodeIndex),
            GetTypeHash(State.CollectedMask));
    }
};

bool IsFlowSatisfied(
    EZeroEscapeCompletionRule Rule,
    FObjectiveMask Mask,
    int32 RequiredCount,
    int32 CandidateCount)
{
    const int32 Count = FPlatformMath::CountBits(Mask);
    switch (Rule)
    {
    case EZeroEscapeCompletionRule::EscapeOnly:
        return true;
    case EZeroEscapeCompletionRule::CollectAll:
        return Count == CandidateCount;
    case EZeroEscapeCompletionRule::CollectKOfN:
        return Count >= RequiredCount;
    default:
        return false; // 防御非法序列化值。
    }
}
}

bool FGenerationCore::ValidateProgression(
    const FAbstractLevelPlan& Plan,
    int32 MaxSearchStates,
    FZeroEscapeGenerationReport& OutReport)
{
    if (Plan.Objectives.Num() >
        ZeroEscape::GenerationLimits::MaxObjectiveCandidates)
    {
        OutReport.Stage = EZeroEscapeGenerationStage::Progression;
        OutReport.Failure =
            EZeroEscapeGenerationFailure::ObjectiveLimitExceeded;
        return false;
    }

    // 先一次性把外部 Stable Id 映射为连续索引；
    // 后续所有数组访问和 BFS State 只使用 Dense Index。
    TMap<int32, int32> NodeIndexByStableId;
    if (!BuildDenseNodeIndex(
            Plan.Nodes, NodeIndexByStableId, OutReport))
    {
        OutReport.Stage = EZeroEscapeGenerationStage::Progression;
        OutReport.Failure = EZeroEscapeGenerationFailure::InvalidGraph;
        return false;
    }

    const int32* StartNodeIndex =
        NodeIndexByStableId.Find(Plan.StartStableNodeId);
    const int32* ExitNodeIndex =
        NodeIndexByStableId.Find(Plan.ExitStableNodeId);
    if (StartNodeIndex == nullptr || ExitNodeIndex == nullptr)
    {
        OutReport.Stage = EZeroEscapeGenerationStage::Progression;
        OutReport.Failure = EZeroEscapeGenerationFailure::InvalidGraph;
        return false;
    }

    TArray<FObjectiveMask> ObjectiveMaskByNodeIndex;
    ObjectiveMaskByNodeIndex.Init(0, Plan.Nodes.Num());
    for (int32 Index = 0; Index < Plan.Objectives.Num(); ++Index)
    {
        const int32* NodeIndex = NodeIndexByStableId.Find(
            Plan.Objectives[Index].StableNodeId);
        if (NodeIndex == nullptr)
        {
            OutReport.Stage = EZeroEscapeGenerationStage::Progression;
            OutReport.Failure =
                EZeroEscapeGenerationFailure::InvalidGraph;
            return false;
        }
        ObjectiveMaskByNodeIndex[*NodeIndex] |=
            (FObjectiveMask{1} << Index);
    }

    TArray<TArray<int32>> Adjacency;
    if (!BuildDenseAdjacency(
            Plan, NodeIndexByStableId, Adjacency, OutReport))
    {
        OutReport.Stage = EZeroEscapeGenerationStage::Progression;
        OutReport.Failure = EZeroEscapeGenerationFailure::InvalidGraph;
        return false;
    }

    TQueue<FProgressionState> Open;
    TSet<FProgressionState> Visited;
    Open.Enqueue({
        *StartNodeIndex,
        ObjectiveMaskByNodeIndex[*StartNodeIndex] });

    FProgressionState State;
    while (Open.Dequeue(State))
    {
        if (Visited.Contains(State))
        {
            continue;
        }
        Visited.Add(State);

        if (Visited.Num() > MaxSearchStates)
        {
            OutReport.Stage = EZeroEscapeGenerationStage::Progression;
            OutReport.Failure =
                EZeroEscapeGenerationFailure::SearchBudgetExceeded;
            return false;
        }

        if (State.NodeIndex == *ExitNodeIndex &&
            IsFlowSatisfied(
                Plan.CompletionRule,
                State.CollectedMask,
                Plan.RequiredObjectiveCount,
                Plan.Objectives.Num()))
        {
            return AreAllCandidateObjectivesReachable(
                Plan,
                NodeIndexByStableId,
                Adjacency,
                OutReport);
        }

        for (const int32 NeighborIndex : Adjacency[State.NodeIndex])
        {
            Open.Enqueue({
                NeighborIndex,
                State.CollectedMask |
                    ObjectiveMaskByNodeIndex[NeighborIndex] });
        }
    }

    OutReport.Stage = EZeroEscapeGenerationStage::Progression;
    OutReport.Failure =
        EZeroEscapeGenerationFailure::ProgressionNoSolution;
    return false;
}
```

这里冻结为“Stable Id 只做身份，Dense Index 只做数组访问”；不允许再以“实际数据应该连续”作为前提。
`BuildDenseNodeIndex` 先复制并按 `StableNodeId` 升序排列，再分配 `0..Num-1`；`BuildDenseAdjacency` 对每个邻接数组也按对方 Stable Id 排序。`TMap/TSet` 只做查询，不直接驱动随机或遍历决策。
Objective Mask 统一使用 `FObjectiveMask = uint32` 和 `FPlatformMath::CountBits`；WFC Domain 的 `CountCandidates` 只封装 `TBitArray::CountSetBits()`。`MaxObjectiveCandidates` 是具名常量，只有 UPROPERTY 的 `ClampMax="12"` 因 UHT 元数据必须保留字符串字面量，Catalog/Profile 校验仍以具名常量为权威上限。

### 13.12 拟实现代码：Socket、A* 骨架与有限 WFC

首版不隐式收缩普通二度节点，先保留每个原始 `StableNodeId` 的可追踪映射：

- Start、Exit、Objective/特殊能力节点、度数不为 2 的分叉/汇合节点是 **Strong Anchor**：`EmbedAbstractNodes` 先分配离散 Grid Anchor，`PlaceRequiredSocketModules` 必须为它们选到具备所需 Portal/Gameplay Anchor 的模块。
- 无特殊能力的普通二度 MainPath/Transit 节点是 **Route Anchor**：只预约一个必经 Grid Cell，由 A* 的 Ordered Cells 与 WFC 最终 Placement 回填。
- `FGraphAnchorPlacement` 在布局期间允许 `StablePlacementId = INDEX_NONE`，但在 Finalize 后每个原始 Node 都必须转成 `FZeroEscapeNodePlacementBinding`。日后若为性能收缩二度链，也必须保留 `OriginalNodeId → Edge/OrderedCellIndex` 反向映射，不允许丢失 Flow 语义。

```cpp
bool FLayoutSolver::Solve(
    const FLayoutRequest& Request,
    const FModuleCatalogSnapshot& Catalog,
    const FZeroEscapeSolverBudgets& Budgets,
    int32 MasterSeed,
    FZeroEscapeGeneratedLevelPlan& OutPlan,
    FZeroEscapeGenerationReport& OutReport)
{
    OutPlan = {};
    if (Request.AbstractPlan == nullptr ||
        Request.CellSize.X <= 0.0 ||
        Request.CellSize.Y <= 0.0 ||
        Request.GridExtent.X <= 0 ||
        Request.GridExtent.Y <= 0 ||
        Request.AStarStraightStepCost <= 0 ||
        Request.AStarTurnPenalty < 0)
    {
        OutReport.Stage = EZeroEscapeGenerationStage::Configuration;
        OutReport.Failure =
            EZeroEscapeGenerationFailure::InvalidConfiguration;
        return false;
    }

    FDeterministicWorkBudget WorkBudget(Budgets.MaxTotalWorkUnits);

    for (int32 Attempt = 0; Attempt < Budgets.MaxLayoutAttempts; ++Attempt)
    {
        OutReport.AttemptIndex = Attempt;
        OutReport.AttemptsExecuted = Attempt + 1;
        FPlacementState PlacementState;
        FRandomStream SocketRandom = FGenerationCore::MakeRandomStream(
            MasterSeed, GAlgorithmVersion,
            ERandomDomain::SocketLayout, Attempt);

        if (!EmbedAbstractNodes(
                Request,
                Budgets,
                WorkBudget,
                PlacementState,
                OutReport))
        {
            RecordAttemptFailure(Attempt, OutReport);
            continue;
        }

        if (!PlaceRequiredSocketModules(
                Request,
                Catalog,
                SocketRandom,
                Budgets.MaxSocketBacktracks,
                Budgets.MaxSocketCandidateChecks,
                WorkBudget,
                PlacementState,
                OutReport))
        {
            RecordAttemptFailure(Attempt, OutReport);
            continue;
        }

        TArray<FGridConstraint> Constraints;
        TArray<FRoutedGraphEdge> RoutedEdges;
        if (!RouteGraphEdgesWithAStar(
                *Request.AbstractPlan,
                PlacementState,
                Budgets,
                WorkBudget,
                Constraints,
                RoutedEdges,
                OutReport))
        {
            if (OutReport.Failure ==
                EZeroEscapeGenerationFailure::SearchBudgetExceeded)
            {
                RecordAttemptFailure(Attempt, OutReport);
                return false;
            }
            RecordAttemptFailure(Attempt, OutReport);
            continue;
        }

        TArray<FTileVariant> Variants;
        FCompatibilityTable Compatibility;
        if (!BuildWfcVariantsAndCompatibility(
                Catalog, Variants, Compatibility, OutReport))
        {
            RecordAttemptFailure(Attempt, OutReport);
            continue;
        }

        TArray<int32> VariantByCell;
        FRandomStream WfcRandom = FGenerationCore::MakeRandomStream(
            MasterSeed, GAlgorithmVersion,
            ERandomDomain::WfcLayout, Attempt);

        if (!SolveWfc(
                Constraints,
                Variants,
                Compatibility,
                WfcRandom,
                Budgets,
                Request.bRequireEffectiveWfcChoice,
                WorkBudget,
                VariantByCell,
                OutReport))
        {
            if (OutReport.Failure ==
                    EZeroEscapeGenerationFailure::WfcBudgetExceeded ||
                OutReport.Failure ==
                    EZeroEscapeGenerationFailure::WfcNoEffectiveChoice)
            {
                RecordAttemptFailure(Attempt, OutReport);
                return false;
            }
            RecordAttemptFailure(Attempt, OutReport);
            continue;
        }

        if (!FinalizeConnectedOrClosedSockets(
                Catalog,
                PlacementState,
                VariantByCell,
                OutReport))
        {
            RecordAttemptFailure(Attempt, OutReport);
            continue;
        }

        FZeroEscapeGeneratedLevelPlan CandidatePlan;
        ExportPlacedModulesAndSemanticBindings(
            Request,
            Catalog,
            PlacementState,
            RoutedEdges,
            Variants,
            VariantByCell,
            CandidatePlan);

        if (ValidateGlobalLayout(
                *Request.AbstractPlan,
                Catalog,
                CandidatePlan,
                OutReport))
        {
            OutPlan = MoveTemp(CandidatePlan);
            OutReport.Stage = EZeroEscapeGenerationStage::None;
            OutReport.Failure = EZeroEscapeGenerationFailure::None;
            OutReport.Message.Reset();
            return true;
        }
        RecordAttemptFailure(Attempt, OutReport);
    }

    // 汇总错误明确表示“有限尝试已耗尽”；最后一次具体原因仍保存在
    // LastAttemptFailure，全部原因保存在稳定排序的 AttemptFailureCounts。
    OutReport.Failure =
        EZeroEscapeGenerationFailure::LayoutAttemptsExhausted;
    OutReport.Message = TEXT("All bounded layout attempts failed.");
    return false;
}
```

`RecordAttemptFailure` 在每个 `continue/预算返回` 前更新 `LastAttemptFailure`，并对 `AttemptFailureCounts` 做 `(Stage, Failure)` 线性查找后按枚举值稳定排序；它不使用 `TMap` 输出，也不逐 Seed 刷屏。单次 Report 因而同时保留“最终为何停止”和“各类失败出现几次”。批量 100～300 Seed Harness 再按同一枚举键聚合计数。

特殊模块先按 Socket 对齐，并建立 `AbstractNodeId → FGraphAnchorPlacement`；再由 A* 在粗 Grid 中为每个 `AbstractEdgeId` 产生 `FRoutedGraphEdge::OrderedCells`。A* 只走未被多格模块占用的 Cell，且严格使用整数成本。状态键冻结为 `(Cell, IncomingDirection)`：下一步的转向代价只依赖入射方向；`TurnCount` 当前只是诊断和平局项，不是硬约束，因此不进入 Key。若未来增加 `MaxTurns` 一类硬约束，必须把 TurnCount 纳入状态键，而不能沿用本版剪枝。邻居固定按 N/E/S/W 展开，Open 平局规则为 `FScore → GScore → TurnCount → IncomingDirection → Y → X`，并受 `MaxAStarExpandedStates/MaxAStarRouteAttempts/MaxTotalWorkUnits` 限制。

```cpp
const bool bTurns =
    Current.Key.IncomingDirection != INDEX_NONE &&
    Current.Key.IncomingDirection != NextDirection;
const int64 TentativeG =
    Current.GScore + int64(Request.AStarStraightStepCost) +
    (bTurns ? Request.AStarTurnPenalty : 0);
const int32 TentativeTurns =
    Current.TurnCount + (bTurns ? 1 : 0);

// Manhattan 启发只计算必付的直行成本；忽略非负转向惩罚仍可采纳。
const int64 Heuristic =
    int64(ManhattanDistance(NextCoordinate, GoalCoordinate)) *
    int64(Request.AStarStraightStepCost);

// 同一 (Cell, IncomingDirection) 只接受字典序更优的 (G, Turns)。
// 完全相同则保留先到 Parent，避免容器顺序影响路径。
if (TentativeG < Existing.GScore ||
    (TentativeG == Existing.GScore &&
     TentativeTurns < Existing.TurnCount))
{
    Existing.GScore = TentativeG;
    Existing.FScore = TentativeG + Heuristic;
    Existing.TurnCount = TentativeTurns;
    Existing.ParentRecordIndex = CurrentRecordIndex;
}
```

每条路径把相邻 Active Cell 的方向写成 `MustMatchSignature`；外围写成 `MustBeClosed`。路径 Cell 只能在抽象图明确的 Junction 共享，其他共享一律拒绝。A* 保证必需连接，WFC 在有限 Active Region 内选具体 Variant；完成后 `RoutedGraphEdge` 转换为实际 `OrderedPlacementIds`，供几何 Flow 二次验证。

`ExportPlacedModulesAndSemanticBindings` 不只导出 Mesh Transform：它必须为每个原 Abstract Node 写 `NodeBinding`，为每条 Edge 写 `EdgeRouteBinding`，为每个 Objective 选中唯一的 `Objective Gameplay Anchor`，并为每对实际开口写唯一 `PortalConnection`。`ValidateGlobalLayout` 从 `PortalConnections` 重建权威几何图，再检查 EdgeRoute 映射、K-of-N、真实路程与折返；不会只因抽象图可解就通过。任一 Portal 同时被两条 Connection 占用、既 Connected 又 Closed，或 Finalize 后仍无状态，都是结构错误。

WFC 初始化先构建按坐标稳定排序的 Active Cell、四向 Dense Neighbor Index 和一元约束后的 Domain，再一次性建立支持计数。`Outside/ReservedSocket` 不拥有 Domain；它们只通过相邻 Active Cell 的方向约束影响候选。任何 BitArray/Support Array 分配之前，先检查 `ActiveCellCount <= 256`、`VariantCount <= 64`，并用 `int64` 检查 `ActiveCellCount * VariantCount * 4` 不溢出 `int32`。Catalog 同时拒绝重复的 `(StableModuleId, QuarterTurns)` 结果，防止“两个索引、同一个实际模块姿态”伪造选择空间。

```cpp
enum class EPropagationResult : uint8
{
    Stable,
    Contradiction,
    BudgetExceeded
};

bool RemoveVariant(
    FWfcState& State,
    int32 CellIndex,
    int32 VariantIndex,
    TQueue<FRemovedVariantEvent>& OutRemoved,
    FZeroEscapeGenerationReport& OutReport)
{
    FWfcCell& Cell = State.Cells[CellIndex];
    if (!Cell.AllowedVariants[VariantIndex])
    {
        return true;
    }

    Cell.AllowedVariants[VariantIndex] = false;
    --Cell.RemainingCandidateCount;
    ++OutReport.Metrics.WfcVariantRemovalCount;
    OutRemoved.Enqueue({CellIndex, VariantIndex});
    return Cell.RemainingCandidateCount > 0;
}

EPropagationResult PropagateRemovedVariants(
    FWfcState& State,
    const FCompatibilityTable& Compatibility,
    TQueue<FRemovedVariantEvent>& Removed,
    const FZeroEscapeSolverBudgets& Budgets,
    FDeterministicWorkBudget& InOutWorkBudget,
    FZeroEscapeGenerationReport& OutReport)
{
    FRemovedVariantEvent Event;
    while (Removed.Dequeue(Event))
    {
        const FWfcCell& Source = State.Cells[Event.CellIndex];
        for (int32 Direction = 0; Direction < 4; ++Direction)
        {
            const int32 NeighborIndex =
                Source.NeighborCellIndices[Direction];
            if (NeighborIndex == INDEX_NONE)
            {
                continue;
            }

            FWfcCell& Neighbor = State.Cells[NeighborIndex];
            const int32 Opposite = GetOppositeDirection(Direction);
            for (const int32 NeighborVariant :
                 Compatibility.GetSupportedNeighbors(
                     Event.VariantIndex, Direction))
            {
                // 每个实际检查都进入全局预算，不能只按“看过一个邻格”计费。
                if (!InOutWorkBudget.TryConsume(1))
                {
                    return EPropagationResult::BudgetExceeded;
                }
                if (!Neighbor.AllowedVariants[NeighborVariant])
                {
                    continue;
                }

                FWfcSupportCount& Support =
                    Neighbor.SupportCountByVariantDirection[
                        NeighborVariant * 4 + Opposite];
                check(Support != NoActiveNeighbor && Support > 0);
                if (!InOutWorkBudget.TryConsume(1))
                {
                    return EPropagationResult::BudgetExceeded;
                }
                --Support;
                ++OutReport.Metrics.WfcSupportUpdateCount;
                if (OutReport.Metrics.WfcSupportUpdateCount >
                    Budgets.MaxWfcSupportUpdates)
                {
                    return EPropagationResult::BudgetExceeded;
                }

                if (Support == 0)
                {
                    if (!InOutWorkBudget.TryConsume(1))
                    {
                        return EPropagationResult::BudgetExceeded;
                    }
                    if (!RemoveVariant(
                            State,
                            NeighborIndex,
                            NeighborVariant,
                            Removed,
                            OutReport))
                    {
                        return EPropagationResult::Contradiction;
                    }
                }
            }
        }
    }
    return EPropagationResult::Stable;
}
```

`BuildOrRebuildSupportCounts` 的确定顺序冻结为 Cell Y/X → Variant Stable Id → N/E/S/W → Neighbor Variant Stable Id。它先根据当前 Domain 计算全部 `[Variant, Direction]` 支持数，方向没有 Active 邻格时写 `NoActiveNeighbor`；再把支持数为 0 的候选统一交给 `RemoveVariant`，最后调用上面的删除事件传播。初始化和每次快照恢复都走同一函数。每个兼容项检查、支持数递减和候选删除都实际消耗 `MaxTotalWorkUnits`，每个真实递减另受 `MaxWfcSupportUpdates` 限制；`CollapseByRemovingOtherVariants` 与初始化的零支持删除也按每个候选逐项计费，因此重建和观察都不能绕开预算。

完整 Domain 快照保留为首版正确性基线，但现在有明确内存账本：

```cpp
int64 MeasureDecisionNestedBytes(const FWfcDecision& Decision)
{
    int64 Bytes = Decision.StableState.Domains.GetAllocatedSize();
    for (const TBitArray<>& Domain : Decision.StableState.Domains)
    {
        Bytes += Domain.GetAllocatedSize();
    }
    Bytes += Decision.UntriedVariants.GetAllocatedSize();
    return Bytes;
}

int64 EstimateDecisionNestedBytesBeforeCopy(
    const FWfcState& State,
    int32 CellIndex)
{
    // SnapshotDomains 固定 Reserve(Cells.Num())，每个目标 BitArray
    // 精确 Init 到源 NumBits。按源已分配字节逐项向 16 对齐并留固定余量，
    // 先形成保守上界；实现测试会断言实测值不超过这个上界。
    int64 Bytes = Align(
        int64(State.Cells.Num()) * sizeof(TBitArray<>), int64(16));
    for (const FWfcCell& Cell : State.Cells)
    {
        Bytes += Align(
            int64(Cell.AllowedVariants.GetAllocatedSize()), int64(16));
    }
    Bytes += Align(
        int64(State.Cells[CellIndex].AllowedVariants.GetAllocatedSize()),
        int64(16));
    return Bytes + 256; // 固定 allocator/accounting 余量，不参与随机。
}

enum class ESnapshotCaptureResult : uint8
{
    Success,
    BudgetExceeded,
    InvariantViolation
};

ESnapshotCaptureResult TryCaptureStableDecision(
    const FWfcState& State,
    const TQueue<FRemovedVariantEvent>& Removed,
    int32 CellIndex,
    const FZeroEscapeSolverBudgets& Budgets,
    int64& InOutLiveSnapshotBytes,
    FWfcDecision& OutDecision,
    FZeroEscapeGenerationReport& OutReport)
{
    check(Removed.IsEmpty()); // 只允许快照传播稳定点。
    OutDecision.CellIndex = CellIndex;

    const int64 MaxLiveBytes =
        int64(FMath::Min(
            Budgets.MaxWfcSnapshotMemoryMB,
            ZeroEscape::GenerationLimits::FirstPassMaxWfcSnapshotMemoryMB)) *
        1024 * 1024;
    const int64 MaxCopiedBytes =
        int64(FMath::Min(
            Budgets.MaxWfcCumulativeSnapshotCopyMB,
            ZeroEscape::GenerationLimits::
                FirstPassMaxWfcCumulativeSnapshotCopyMB)) *
        1024 * 1024;
    const int64 ConservativeBytes =
        EstimateDecisionNestedBytesBeforeCopy(State, CellIndex);
    if (InOutLiveSnapshotBytes + ConservativeBytes > MaxLiveBytes ||
        OutReport.Metrics.WfcCumulativeSnapshotCopyBytes +
            ConservativeBytes > MaxCopiedBytes)
    {
        return ESnapshotCaptureResult::BudgetExceeded;
    }

    SnapshotDomains(State, OutDecision.StableState.Domains);
    OutDecision.UntriedVariants =
        State.Cells[CellIndex].AllowedVariants;
    OutDecision.NestedResidentBytes =
        MeasureDecisionNestedBytes(OutDecision);
    if (OutDecision.NestedResidentBytes > ConservativeBytes)
    {
        OutDecision = {}; // Shipping 中也释放临时快照，不能只靠 check。
        return ESnapshotCaptureResult::InvariantViolation;
    }

    const int64 NextLive =
        InOutLiveSnapshotBytes + OutDecision.NestedResidentBytes;
    const int64 NextCopied =
        OutReport.Metrics.WfcCumulativeSnapshotCopyBytes +
        OutDecision.NestedResidentBytes;
    if (NextLive > MaxLiveBytes || NextCopied > MaxCopiedBytes)
    {
        OutDecision = {};
        return ESnapshotCaptureResult::InvariantViolation;
    }
    InOutLiveSnapshotBytes = NextLive;
    OutReport.Metrics.WfcCumulativeSnapshotCopyBytes = NextCopied;
    OutReport.Metrics.WfcPeakSnapshotBytes = FMath::Max(
        OutReport.Metrics.WfcPeakSnapshotBytes, NextLive);
    return ESnapshotCaptureResult::Success;
}
```

恢复快照时先根据源 Domain 的已分配容量保守估算复制量并检查累计上限，通过后才复制，再把实测字节加入 `WfcCumulativeSnapshotCopyBytes`；随后清空失败分支的删除队列、恢复所有 Domain/RemainingCandidateCount，并从恢复后的 Domain 确定性重建 Support Count。Decision 栈会在求解前一次性 `Reserve(MaxWfcObservationCount)`，其固定外层容量计入 `LiveSnapshotBytes`；Pop 只减去该 Frame 的嵌套 Domain/Untried 内存，不假装 TArray 容量已经释放。首版绝不快照/恢复旧 Support Count，也不允许恢复 Domain 后沿用失败分支的计数。

求解循环保留同一 Decision Frame 直到它的全部备选真正耗尽，避免旧拟稿“一弹栈就丢掉同层剩余选择”的歧义：

```cpp
bool FLayoutSolver::SolveWfc(
    const TArray<FGridConstraint>& Constraints,
    const TArray<FTileVariant>& Variants,
    const FCompatibilityTable& Compatibility,
    FRandomStream& Random,
    const FZeroEscapeSolverBudgets& Budgets,
    bool bRequireEffectiveWfcChoice,
    FDeterministicWorkBudget& InOutWorkBudget,
    TArray<int32>& OutVariantByCell,
    FZeroEscapeGenerationReport& OutReport)
{
    ResetWfcAttemptMetrics(OutReport.Metrics);
    const int32 ActiveCellCount = CountActiveCells(Constraints);
    const int32 MaxActiveCells = FMath::Min(
        Budgets.MaxWfcActiveCells,
        ZeroEscape::GenerationLimits::FirstPassMaxWfcActiveCells);
    const int32 MaxVariants = FMath::Min(
        Budgets.MaxWfcVariants,
        ZeroEscape::GenerationLimits::FirstPassMaxWfcVariants);
    const int64 SupportSlotCount =
        int64(ActiveCellCount) * int64(Variants.Num()) * 4;
    if (Budgets.MaxWfcObservationCount < 1 ||
        Budgets.MaxWfcSnapshotMemoryMB < 1 ||
        Budgets.MaxWfcCumulativeSnapshotCopyMB < 1 ||
        ActiveCellCount < 1 || Variants.Num() < 1)
    {
        return FailInvalidWfcConfiguration(OutReport);
    }
    if (ActiveCellCount > MaxActiveCells ||
        Variants.Num() > MaxVariants ||
        SupportSlotCount > MAX_int32)
    {
        return FailWfcBudget(OutReport);
    }
    FString CompatibilityError;
    if (!Compatibility.IsConfigured(Variants, CompatibilityError))
    {
        OutReport.Stage = EZeroEscapeGenerationStage::WfcLayout;
        OutReport.Failure =
            EZeroEscapeGenerationFailure::InvalidConfiguration;
        OutReport.Message = MoveTemp(CompatibilityError);
        return false;
    }
    OutReport.Metrics.WfcActiveCellCount = ActiveCellCount;
    OutReport.Metrics.WfcVariantCount = Variants.Num();

    FWfcState State;
    TQueue<FRemovedVariantEvent> Removed;
    if (!InitializeDomainsAndDenseNeighbors(
            Constraints, Variants, State, OutReport))
    {
        return false;
    }
    EPropagationResult Result = BuildOrRebuildSupportCounts(
        State,
        Compatibility,
        Removed,
        Budgets,
        InOutWorkBudget,
        OutReport);
    if (Result == EPropagationResult::BudgetExceeded)
    {
        return FailWfcBudget(OutReport);
    }
    if (Result == EPropagationResult::Contradiction)
    {
        return FailWfcNoSolution(OutReport);
    }

    // 在首次稳定传播后、第一次观察前记录真实选择空间。
    MeasureInitialChoiceSpace(State, Variants, OutReport.Metrics);

    const int64 MaxLiveSnapshotBytes =
        int64(FMath::Min(
            Budgets.MaxWfcSnapshotMemoryMB,
            ZeroEscape::GenerationLimits::FirstPassMaxWfcSnapshotMemoryMB)) *
        1024 * 1024;
    const int32 MaxSimultaneousDecisionDepth = FMath::Min(
        ActiveCellCount, Budgets.MaxWfcObservationCount);
    const int64 EstimatedDecisionStackBytes =
        int64(MaxSimultaneousDecisionDepth) * sizeof(FWfcDecision);
    if (EstimatedDecisionStackBytes > MaxLiveSnapshotBytes)
    {
        return FailWfcBudget(OutReport);
    }
    TArray<FWfcDecision> Decisions;
    Decisions.Reserve(MaxSimultaneousDecisionDepth);
    int64 LiveSnapshotBytes = Decisions.GetAllocatedSize();
    if (LiveSnapshotBytes > MaxLiveSnapshotBytes)
    {
        return FailWfcBudget(OutReport);
    }
    OutReport.Metrics.WfcPeakSnapshotBytes = LiveSnapshotBytes;

    for (;;)
    {
        if (Result == EPropagationResult::BudgetExceeded)
        {
            return FailWfcBudget(OutReport);
        }

        while (Result == EPropagationResult::Contradiction)
        {
            ++OutReport.Metrics.WfcContradictionCount;
            while (!Decisions.IsEmpty() &&
                   CountCandidates(
                       Decisions.Last().UntriedVariants) == 0)
            {
                LiveSnapshotBytes -=
                    Decisions.Last().NestedResidentBytes;
                Decisions.Pop(EAllowShrinking::No);
            }
            if (Decisions.IsEmpty())
            {
                return FailWfcNoSolution(OutReport);
            }

            // 只有真的准备恢复并尝试另一个候选，才算一次 Backtrack；
            // 若栈已空，上面已经完整证明无解，不能误报预算耗尽。
            if (OutReport.Metrics.WfcObservationCount >=
                    Budgets.MaxWfcObservationCount ||
                ++OutReport.Metrics.WfcBacktrackCount >
                    Budgets.MaxWfcBacktracks)
            {
                return FailWfcBudget(OutReport);
            }

            FWfcDecision& Retry = Decisions.Last();
            const EPropagationResult RestoreResult =
                RestoreDomainsAndRebuildSupportCounts(
                    Retry.StableState,
                    State,
                    Compatibility,
                    Removed,
                    Budgets,
                    InOutWorkBudget,
                    OutReport);
            if (RestoreResult == EPropagationResult::BudgetExceeded)
            {
                return FailWfcBudget(OutReport);
            }
            if (RestoreResult == EPropagationResult::Contradiction)
            {
                return FailWfcStateInvariant(OutReport);
            }

            const int32 Alternative = ChooseWeightedVariant(
                Retry.UntriedVariants, Variants, Random);
            Retry.UntriedVariants[Alternative] = false;
            ++OutReport.Metrics.WfcObservationCount;
            Result = CollapseByRemovingOtherVariants(
                State,
                Retry.CellIndex,
                Alternative,
                Removed,
                Compatibility,
                Budgets,
                InOutWorkBudget,
                OutReport);
        }

        if (Result == EPropagationResult::BudgetExceeded)
        {
            return FailWfcBudget(OutReport);
        }

        const int32 CellIndex =
            ChooseMinimumRemainingValueCell(State.Cells, Random);
        if (CellIndex == INDEX_NONE)
        {
            OutReport.Metrics.bHadEffectiveWfcChoice =
                OutReport.Metrics.WfcInitialChoiceCellCount > 0 &&
                OutReport.Metrics.WfcInitialAlternativeCount > 0 &&
                OutReport.Metrics.WfcObservationCount > 0;
            if (bRequireEffectiveWfcChoice &&
                !OutReport.Metrics.bHadEffectiveWfcChoice)
            {
                return FailWfcNoEffectiveChoice(OutReport);
            }
            return ExportCollapsedVariants(
                State.Cells, OutVariantByCell, OutReport);
        }

        // 先预检 Observation；否则会为一个注定超预算的分支复制快照。
        if (OutReport.Metrics.WfcObservationCount >=
            Budgets.MaxWfcObservationCount)
        {
            return FailWfcBudget(OutReport);
        }

        FWfcDecision Decision;
        const ESnapshotCaptureResult CaptureResult =
            TryCaptureStableDecision(
                State,
                Removed,
                CellIndex,
                Budgets,
                LiveSnapshotBytes,
                Decision,
                OutReport);
        if (CaptureResult == ESnapshotCaptureResult::BudgetExceeded)
        {
            return FailWfcBudget(OutReport);
        }
        if (CaptureResult == ESnapshotCaptureResult::InvariantViolation)
        {
            return FailWfcStateInvariant(OutReport);
        }
        Decisions.Add(MoveTemp(Decision));
        ++OutReport.Metrics.WfcDecisionFrameCount;
        OutReport.Metrics.WfcPeakDecisionDepth = FMath::Max(
            OutReport.Metrics.WfcPeakDecisionDepth,
            Decisions.Num());

        FWfcDecision& Current = Decisions.Last();
        const int32 Chosen = ChooseWeightedVariant(
            Current.UntriedVariants, Variants, Random);
        Current.UntriedVariants[Chosen] = false;
        ++OutReport.Metrics.WfcObservationCount;
        Result = CollapseByRemovingOtherVariants(
            State,
            CellIndex,
            Chosen,
            Removed,
            Compatibility,
            Budgets,
            InOutWorkBudget,
            OutReport);
    }
}
```

上面的 `bRequireEffectiveWfcChoice` 来自本次 `FLayoutRequest` 快照。`MeasureInitialChoiceSpace` 统计初始稳定 Domain 中的 Choice Cell、总额外候选数与最大 Domain；`WfcObservationCount` 统计首次选择和回溯重选在内的每一次实际 Collapse，`WfcDecisionFrameCount` 只统计创建过多少稳定点快照。WFC 指标在每个 Layout Attempt 开始时由 `ResetWfcAttemptMetrics` 清零，因此 `WfcCumulativeSnapshotCopyBytes` 也明确指“当前 Layout Attempt 内累计”；失败分布另由 `AttemptFailureCounts` 跨 Attempt 聚合，避免用前一次 Observation 误判本次真实选择。普通生产 Profile 允许某个合法 Seed 得到唯一解，但必须在 Report 中明确 `bHadEffectiveWfcChoice=false`；专门的 PIE/算法验收 Profile 打开硬门槛，无真实选择就返回 `WfcNoEffectiveChoice`。所有 `FailWfc...` helper 都同时填写 `Stage=WfcLayout`、Failure 与可读 Message；稳定快照恢复后若重建出矛盾则是 `SolverInvariantViolation`，不能伪装成普通无解。首个灰盒 Catalog 必须提供至少两个 Connector Signature 相同但 `(StableModuleId, QuarterTurns)` 不同的真实结果，并在 20 个固定 Seed 中证明二者都至少被选中过一次。

完整快照是 V2.1 首版基线，不立即换 Trail。256 Cell × 64 Variant 的纯 Domain 位载荷每层只有 `256 × 8 B = 2 KiB`，即使 256 层的纯位载荷也约 512 KiB；真正要实测的是 256 个 `TBitArray` 小分配、外层数组和重复恢复的 allocator/复制成本，因此仍保留 16 MiB 实时硬上限与 64 MiB 累计复制上限。8 MiB 是占实时上限 50% 的提前预警，按当前理论规模不应轻易触发。

只有满足任一条件才另起 `AlgorithmVersion` 评审增量 Trail：产品需求确实超过 256 个 Active Cell 或 64 个 Variant；**完整跑完 300 个固定 Seed** 后峰值快照达到 8 MiB；目标机 packaged Development 的“快照复制 + Support 重建”P95 超过 2 ms；或 WFC 阶段 P95 超过 16.7 ms。切换时必须增加 Snapshot/Trail 同 Seed Canonical Layout Hash 对照和多层回溯 Oracle 测试，不能原地改变已发布算法版本。

```cpp
bool AZeroEscapeRuntimeLevelGenerator::GenerateFromRequest(
    const FZeroEscapeGenerationRequest& Request)
{
    if (bGenerationInProgress)
    {
        // 拒绝重入；不排队，也不覆盖当前 State/Report/Plan/实例。
        return false;
    }

    // Guard 必须覆盖所有可能 Broadcast 的失败分支，包括空 DataAsset。
    TGuardValue<bool> GeneratingGuard(
        bGenerationInProgress, true);

    // 一次请求被接受后，旧场景与旧 Plan 立即失效；PIE Harness
    // 必须已经把 Pawn 移回 Staging。失败时不会出现“旧场景+新失败状态”。
    ClearGeneratedSceneInternal();
    LastReport = {};
    State = EZeroEscapeRuntimeGenerationState::Planning;

    FZeroEscapeGenerationReport Report;
    if (GeneratedRoot == nullptr ||
        !LevelGen::IsFiniteUnitScaleTransform(
            GeneratedRoot->GetComponentTransform()))
    {
        Report.Stage = EZeroEscapeGenerationStage::Configuration;
        Report.Failure =
            EZeroEscapeGenerationFailure::InvalidConfiguration;
        Report.Message = TEXT(
            "GeneratedRoot world transform must be finite and unit scale.");
        FinishGeneration(false, Report);
        return false;
    }

    if (GenerationProfile == nullptr ||
        ModuleCatalog == nullptr ||
        PresentationProfile == nullptr)
    {
        Report.Stage = EZeroEscapeGenerationStage::Configuration;
        Report.Failure =
            EZeroEscapeGenerationFailure::InvalidConfiguration;
        Report.Message = TEXT("Generation assets are not configured.");
        FinishGeneration(false, Report);
        return false;
    }

    FString Error;
    if (!GenerationProfile->IsConfigured(Error) ||
        !ModuleCatalog->IsConfigured(Error) ||
        !PresentationProfile->IsConfigured(
            *ModuleCatalog, Error))
    {
        Report.Stage = EZeroEscapeGenerationStage::Configuration;
        Report.Failure =
            EZeroEscapeGenerationFailure::InvalidConfiguration;
        Report.Message = MoveTemp(Error);
        FinishGeneration(false, Report);
        return false;
    }

    // UObject/DataAsset 只在游戏线程读取一次，算法只拿值快照。
    LevelGen::FGenerationProfileSnapshot ProfileSnapshot;
    LevelGen::FModuleCatalogSnapshot CatalogSnapshot;
    LevelGen::BuildGenerationSnapshot(
        *GenerationProfile, ProfileSnapshot);
    LevelGen::BuildCatalogSnapshot(
        *ModuleCatalog, CatalogSnapshot);

    LevelGen::FAbstractLevelPlan AbstractPlan;
    if (!LevelGen::FGenerationCore::BuildAbstractPlan(
            Request,
            ProfileSnapshot,
            AbstractPlan,
            Report))
    {
        FinishGeneration(false, Report);
        return false;
    }

    LevelGen::FLayoutRequest LayoutRequest;
    LayoutRequest.CellSize = CatalogSnapshot.CellSize;
    LayoutRequest.AbstractPlan = &AbstractPlan;
    LayoutRequest.GridExtent =
        LevelGen::ResolveGridExtent(
            ProfileSnapshot, Request.Difficulty);
    LayoutRequest.AStarStraightStepCost =
        ProfileSnapshot.SharedRouteConstraints.AStarStraightStepCost;
    LayoutRequest.AStarTurnPenalty =
        ProfileSnapshot.SharedRouteConstraints.AStarTurnPenalty;
    LayoutRequest.bRequireEffectiveWfcChoice =
        ProfileSnapshot.bRequireEffectiveWfcChoice;

    FZeroEscapeGeneratedLevelPlan Plan;
    if (!LevelGen::FLayoutSolver::Solve(
            LayoutRequest,
            CatalogSnapshot,
            ProfileSnapshot.SolverBudgets,
            Request.Seed,
            Plan,
            Report))
    {
        FinishGeneration(false, Report);
        return false;
    }

    Plan.Signature = LevelGen::BuildGenerationSignature(
        Request,
        LevelGen::GAlgorithmVersion,
        *GenerationProfile,
        *ModuleCatalog,
        *PresentationProfile);
    Plan.CanonicalAbstractHash =
        LevelGen::ComputeCanonicalAbstractHash(AbstractPlan);
    Plan.CanonicalLayoutHash =
        LevelGen::ComputeCanonicalLayoutHash(Plan);
    // Layout Hash 只哈希排序后的 Stable Id、GridOrigin、
    // QuarterTurns、Node/Edge Binding 与 Portal Connection；
    // 不哈希 FTransform 原始内存，也不包 PresentationVersion。

    State = EZeroEscapeRuntimeGenerationState::Validating;
    if (!LevelGen::ValidatePresentationBindings(
            Plan, *PresentationProfile, Report))
    {
        FinishGeneration(false, Report);
        return false;
    }

    State = EZeroEscapeRuntimeGenerationState::Instantiating;
    if (!InstantiateValidatedPlan(Plan, Report))
    {
        ClearGeneratedSceneInternal(); // 不保留半成品或 LastPlan。
        FinishGeneration(false, Report);
        return false;
    }

    LastPlan = MoveTemp(Plan);

    // 当前无追猎者时，Ready 只表示碰撞场景提交成功。
    // 未来启用导航后在这里转 WaitingForNavigation，
    // 由导航完成 Delegate/Timer + 超时推进，仍不启用 Tick。
    FinishGeneration(true, Report);
    return true;
}
```

`InstantiateValidatedPlan` 把成员数组视为当前实例化事务的 rollback 集：对象一创建成功就登记，而不是等 Register/AddInstances/FinishSpawning 全部完成后才登记；只有所有 Binding 全部提交成功才把 Plan 移入 `LastPlan`。自动化故障注入点覆盖 NewObject、Register、AddInstances、SpawnDeferred、FinishSpawning 前后，任一点失败都由调用方 Internal Clear 回滚为零实例。首版 Actor Binding 只允许经过项目审查、Construction Script 不生成无 Owner 外溢 Actor 的包装类；否则继续使用 HISM/组件组合。若实现时确实要在 Construction/BeginPlay 前注入更多玩法上下文或生成子 Actor，再新增项目自有 `AZeroEscapeGeneratedModuleActor` 基类，让所有子对象进入同一 Owner/rollback 契约；当前首个结构竖切不为单一假设提前创建该类。

清理与完成必须显式，不依赖 Tick：

```cpp
bool AZeroEscapeRuntimeLevelGenerator::ClearGeneratedScene()
{
    if (bGenerationInProgress)
    {
        return false;
    }

    ClearGeneratedSceneInternal();
    State = EZeroEscapeRuntimeGenerationState::Idle;
    return true;
}

void AZeroEscapeRuntimeLevelGenerator::ClearGeneratedSceneInternal()
{
    for (AActor* Actor : GeneratedActors)
    {
        if (IsValid(Actor))
        {
            Actor->Destroy();
        }
    }
    GeneratedActors.Reset();

    for (UHierarchicalInstancedStaticMeshComponent* Component :
         GeneratedHismComponents)
    {
        if (IsValid(Component))
        {
            Component->DestroyComponent();
        }
    }
    GeneratedHismComponents.Reset();
    LastPlan = {};
}

void AZeroEscapeRuntimeLevelGenerator::FinishGeneration(
    bool bSuccess,
    const FZeroEscapeGenerationReport& Report)
{
    LastReport = Report;
    State = bSuccess
        ? EZeroEscapeRuntimeGenerationState::Ready
        : EZeroEscapeRuntimeGenerationState::Failed;

    // 此处 GeneratingGuard 仍为 true。监听者可以查询结果，但回调中
    // Generate/Clear 都会被拒绝，不能制造 Ready + 空场景或递归生成。
    OnGenerationFinished.Broadcast(bSuccess, LastReport);
}

void AZeroEscapeRuntimeLevelGenerator::EndPlay(
    const EEndPlayReason::Type EndPlayReason)
{
    ClearGeneratedSceneInternal();
    Super::EndPlay(EndPlayReason);
}
```

生命周期契约冻结为：忙碌期间 `Generate/GenerateFromRequest/ClearGeneratedScene` 都返回 `false`，不排队也不改当前操作；一个新请求被接受后旧结果立即失效；实例化中途任一点失败都先写结构化 Instantiation 报告，再调用 Internal 清理，最终为 `Failed + 空 Plan + 零生成实例`；公开 Clear 可重复调用，两次都成功且保持 `Idle + 空 Plan`。首版全同步流程使用栈上 Guard；只要出现导航等待、工作线程求解或跨帧分批实例化中的任一种，整个操作就必须改由持久、递增的 Operation Token + 状态机管理。所有回调提交前核对 Token；EndPlay 先使 Token 失效、取消相关 Timer/Delegate，再清理实例并丢弃迟到结果。

首个 PIE 分两步，避免把“地图算法”和“尚未实现的通关玩法”混为一件事：

#### PIE-A：结构闭环

- `Flow = EscapeOnly`，固定 Seed。
- SFCorridors 最小 WFC 集：Pass、LeftTurn、RightTurn、T。
- 一个实际完成适配的 Special Socket 模块；优先在 `hub` 与 `largeHall` 中选通过 Bounds/Portal/碰撞检查的一个。若两者都需要大量修整，先用项目自有灰盒 Special Wrapper 证明 Socket 链路，SFCorridors 仍是主要走廊与房间素材，不修改第三方 Mesh。
- 一个视觉、碰撞都可靠的 Cap；SFCorridors 没有合适件时使用项目灰盒 WallCap。
- 空白承载关卡在生成边界外保留一块不会被清理的 Staging Platform 与 PlayerStart。`BP_RuntimeGenerationTestHarness` 先让 Pawn 留在 Staging，等 `OnGenerationFinished(true)` 后查询 `PlayerSpawnAnchorInstanceId`，以 Sweep/Teleport 安全移到生成 Start，再从 Start 走到 Exit。
- 手动重生成前，Harness 必须先把 Pawn 送回 Staging，再调 `Clear/Generate`，避免删除玩家脚下的实例地板。

通过条件：

- 不依赖 `UnrealEd`、UE Experimental WFC 或 Editor 工具。
- 同 Seed 重生成不累计 Actor/Component，Plan/Transform 一致。
- 验收 Profile 必须令 `bHadEffectiveWfcChoice=true`：初始传播后至少一个 Cell 有两个不同实际结果、实际发生 Observation，并在 20 个固定 Seed 中让双 Variant 两侧都至少命中一次；否则 PIE-A 硬失败为 `WfcNoEffectiveChoice`，不能只凭调用过函数宣称 WFC 已实现。
- 所有模块无重叠，所有 Portal 为 Connected 或 Closed，所有开口在画面和碰撞上都封闭。
- 故意破坏邻接或 Closure 时在预算内失败，场景不留下半成品。

#### PIE-B：流程数据承载验证

- 使用 `DrawDebugSphere`/编号文字可视化 Objective Anchor，不引入伪装成正式收集物的 Actor。
- 三个 Objective Intent 分别绑定 Transit、ShortLeaf、ForwardRejoin。
- 三个位置都可达；程序举取 3 种“任意两个”组合，在实际 Portal Graph 上证明每组都能完成并到 Exit。
- Leaf 单程距离与最长连续折返不超过共享上限；ForwardRejoin 拿到目标后可以继续向前。
- 这一阶段只证明空间、Objective Binding 和 Flow 数据可承载未来 `Collect 2 of 3`，不声称玩家已能交互收集，也不声称正式材料、出口解锁或 UI 已实现。若要验证真实收集，必须新建独立 GameFlow/Debug Objective 实施范围，不在本轮暗中加入。

导航边界：

- 当前没有追猎者，PIE-A 不把动态 NavMesh 当作“地图出现”的阻塞门槛，但仍检查玩家碰撞和可行走净空。
- 接入第一个追猎者前，Recast NavMesh 必须使用 `RuntimeGeneration = Dynamic`；`DynamicModifiersOnly` 不能为新结构生成完整导航。
- 生成 Actor 的状态应区分 `Instantiating`、`WaitingForNavigation` 与 `Ready`；通过导航完成 Delegate 或 Timer + 超时推进，禁止 Tick。
- 若代码直接调用 `UNavigationSystemV1`，实施清单再增加 `NavigationSystem` 私有依赖；本轮仍不修改 `Demo.Build.cs`。

性能和确定性：

- 首版同步、有界地执行纯数据生成，分别记录 Abstract、Socket、A*、WFC、Validation、Instantiation 毫秒数。
- 算法分支只使用确定性工作预算：活跃 WFC Cell 上限、各阶段局部上限和跨 Socket/A*/WFC/Validation 的 `MaxTotalWorkUnits`；避免多层重试的乘法爆炸。“证明无解”与“预算耗尽”分别返回 `WfcNoSolution` / `WfcBudgetExceeded`。
- 墙钟时间只做观测和紧急取消，不能参与正常随机分支，否则不同机器可能生成不同结果。
- 在确定目标机和关卡开始遮罩/转场后，用 packaged Development 先预热 10 次，再跑 100～300 个固定 Seed，输出各阶段 P50/P95、峰值快照、累计复制与失败分类；Trail 判定单独要求完整 300 Seed。这些数值是实施验收数据，不写进算法分支。
- **纯数据主线程阻塞**：P95 `<= 16.7 ms` 无条件保持同步；`16.7～33.3 ms` 只有在既定开始转场完全遮蔽、且端到端目标通过时才可同步验收，否则先优化，仍超 16.7 ms 就评审工作线程；优化后仍 `> 33.3 ms` 且不能遮蔽时，工作线程评审为强制门禁，不得直接验收。
- **实例化主线程阻塞**：工作线程不能解决 Spawn/HISM 卡顿。若实例化发生在可见帧，任一固定批次必须 `<= 16.7 ms`；若 packaged P95 超出或无法被开始转场完全遮蔽，则改为按固定 Module/Instance 数量分批提交（禁止按墙钟决定批量），并用持久 Operation Token/状态机替代栈上 Guard。若全程由已确认的阻塞式开始转场遮蔽，首版允许一次性提交，但仍记录 Instantiation P50/P95。
- **端到端加载延迟**：从接受请求到 Ready 的 P95 `<= 250 ms` 是待目标机与转场确定后的暂定产品目标，不代替上面两个单项门槛，也不是现在声称已经达到的指标。
- 若未来异步，只把值类型的 Abstract/Socket/A*/WFC/Validation 放入工作线程；UObject、Mesh、World、Spawn、HISM、Debug 和 NavMesh 始终留在游戏线程。相同输入的同步/异步 Canonical Abstract/Layout Hash 必须完全一致，提交结果还要核对 Operation Token。
