# 2026-08-12 追猎者预判跑跳攻击收口

## 今日目标

- 把追猎者主攻击收口为“中距离预判跑跳下砸 + 近距离斧击兜底”。
- 玩家持续跑动时，追猎者能够主动封锁其前方落点，而不是到达旧攻击距离后原地挥空。
- 攻击具有可读的起手、一次性落点锁定、命中/落空和恢复窗口，不采用持续空中追踪。

## 核心循环

1. 距离大于跑跳上限时继续追击。
2. 进入跑跳距离且攻击可用时，按玩家速度预测短时间后的落点并锁定。
3. 播放全身跑跳攻击 Montage；在离地时刻由 `CharacterMovement` 发起抛物线位移。
4. 落地时做范围查询，命中则提交伤害和短时站立冲击；命中与落空均进入恢复。
5. 距离过近时改用现有斧击 Montage，并通过前方球形 Sweep 结算命中。
6. 冷却中继续追击，不再站在旧攻击距离等待。

## C++、蓝图与数据边界

- `UPursuerAttackComponent`：唯一管理攻击阶段、预测落点、起跳、命中去重、计时器、恢复与取消。
- `APursuerAIController`：只做目标与距离决策，不拥有攻击冷却状态。
- `APursuerCharacter`：装配攻击组件，并把现有受击中断入口转交给组件。
- `UPursuerConfig` / `DA_Pursuer`：保存近战、跑跳、伤害、命中范围、预判和恢复参数。
- 蓝图和资产只做 Montage、动画及 Source Profile 装配；不在 Blueprint EventGraph 编写攻击逻辑，不修改 AnimBP 图。

## 参数首版

- 近战范围约 220 cm；跑跳攻击约 220–650 cm。
- 预判时间约 0.35 秒，只在起跳前计算一次。
- 跑跳飞行时间约 0.65 秒；落地范围约 160 cm。
- 跑跳伤害高于近战；命中反馈使用短时站立冲击，不冒充 Heavy Impact。
- 恢复约 0.75 秒；冷却期间恢复追击。
