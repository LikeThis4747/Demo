## 目标

保留现有 `GameMode -> GameplayPopulator -> 纯值 PlacementPolicy -> PlacementPlan -> Spawn` 架构和机关总量，将普通机关的“类型权重后均匀选点 + 全局最小间距”替换为可复现的上下文加权选择，使机关自然形成强弱不同的组合簇与空白段，并把一格刺轮正式接入 Population。

## 已确认规则

- Easy / Normal / Hard 的机关密度保持 `26 / 28 / 30` 每百玩法格，不用总量差异代替难度设计。
- 只排除技术非法候选：流程点、越界、安装条件失败、永久堵路、实体或运行包络重叠。
- 首版不做跨类型同格复合；组合按通行图上的前后相邻判定。现有单组双 Actor 地刺仍视为一处机关。
- 所有合法单独机关、同类型连续和不同类型组合均保留非零概率。
- 分数使用有界 log2 权重：各信号映射到 `[-1, 1]` 后乘强度相加，最终权重为 `2^Score`；首轮 `MaxAbsLog2Score=5`。
- 选择顺序仍为“类型 -> 锚点 -> 方向/路线”，但类型权重读取每类最佳三个不同锚点的上下文分数，回写强度 `0.5`，不得按候选数量累加。
- 刺轮与冲锤为强奖励、刺轮与地刺为中奖励、单独刺轮为轻度降权；组合表对放置顺序对称。512 Seed 首轮统计已把初值从 `+2.0 / +1.0 / -0.25` 收敛为 `+3.0 / +2.25 / -0.5`，仍保留非零 solo。
- 两个机关的图距离定义为“各自占用格之间的最短通行边数”；同格为 `0`、前后相邻格为 `1`。组合要求距离恰好为 `1`，组归属要求距离不大于首轮组半径 `3`。
- 机关组按整栋通行图距离维护；多层楼梯按真实通行边数计算，不使用空间直线距离。
- 组目标压力由难度、距终点进度、Seed 派生的区域起伏和组锚点抖动组成，不把所有组补到相同压力。
- 同类机关的速度和运动规律继续由各自 DataAsset 统一管理。首轮只给 Population 刺轮写入归一化相位；地刺与冲锤保持当前启动方式。
- Population 刺轮只使用现有三条一格路线，Actor 原点位于该格格心，完整占用一个普通格。连续两格刺轮由两个相邻的一格刺轮 Actor 形成，各自拥有独立但可复现的路线与相位。
- 官方资产回读确认：一格路线控制点最大偏移为 `0.32` 格；在 `600 cm` 格宽和 `65 cm` Hurt Radius 下，运行包络距格心最大约 `257 cm < 300 cm`，可安全按单格占用处理。
- 资源继续使用独立随机域和现有总预算，但读取机关组诊断，在高压力组靠近玩家进入侧的安全邻格提高权重；资源调参不得洗牌机关。
- 玩家 `CharacterMovement.MaxWalkSpeed` 统一为 `400 cm/s`。Populator 由当前正式玩家的实际 Class 取得 UE 类默认对象（Class Default Object，CDO）上的名义速度，Policy 用 `LogicalTileSizeCm / MaxWalkSpeed` 得到单格代表性时长；不读会被 Stop/Slow 改写的实例瞬时值或 Velocity，也不在评分中写死 `400`。

## 评分通道与职责

| 通道 | 只负责什么 | 首版处理 |
|---|---|---|
| 位置 | 机关与拓扑是否匹配 | 发射器转角加成、直廊低权重；其他类型保留中性或已有安装条件 |
| 进度 | 形成整体递增强度 | 使用玩家出生点到 Exit 的图距离归一化进度 |
| 组压力 | 决定继续成簇还是转入空白 | 放入后接近本组变化目标时加权，超载后快速降权 |
| 组合 | 表达具体机关协同 | 对称组合表；刺轮强/中组合使用已确认数值 |
| 多样性 | 抑制全局长时间重复 | 只查看最近少量已接受机关，轻度降权，不否决同类型连续 |
| 诊断 | 标识严重过载并服务资源 | 不重复计算常规危险；严重档才额外降权并提高资源支持优先级 |

每秒通行压力和受击惩罚保留为两个独立可调输入；基础压力只计算一次：`每秒通行压力 × 单格代表性时长 + 受击惩罚`。组压力再派生严重程度，禁止重复放大同一危险。

## 初始调参值（必须经 Seed Sweep 和 PIE 收敛）

- 基础类型权重，顺序为地刺 / 冲锤 / 发射器 / 刺轮：Easy `5/3/2/1`，Normal `3/3/3/2`，Hard `2/3/5/3`。
- 在 `600 cm` 格宽、`400 cm/s` 玩家名义速度下，基础压力保持：摆锤 `3.0`、地刺 `2.0`、冲锤 `3.0`、发射器 `1.0`、刺轮 `0.5`。
- 为保持上述基线，每秒通行压力初值依次为 `1.333333 / 0.666667 / 1.333333 / 0.333333 / 0.166667`，再加受击后果 `1.0 / 1.0 / 1.0 / 0.5 / 0.25`。刺轮基线 `0.5` 仍表示其单独占用组预算较低；`DA_SpikeWheelStandingImpact` 保持只读。
- 组合压力增量建议：刺轮+冲锤 `1.0`、刺轮+地刺 `0.5`；该值只估算难度，不等于组合奖励。
- 组目标压力建议：Easy 从 `3.0` 递增到 `4.5`，Normal 从 `4.0` 到 `6.0`，Hard 从 `5.0` 到 `7.5`；区域起伏和锚点抖动各不超过 `1.0`。
- 最近类型观察窗口建议 `4`，重复类型最多贡献 `-0.5`；同类型紧邻仍可由组合通道获得正奖励。
- `TypeContextStrength=0.5` 和 `SoloWheelLog2Contribution=-0.5` 是后续 PIE 重点调参项。组合绝对频率不足时先提高前者；零散刺轮过多时先降低后者，不通过抬高刺轮基础压力破坏组合预算。

## 已知限制与第二步候选

- 当前地刺与冲锤的 `BeginPlay` 没有使用随机数：二者都从固定安全阶段启动，因此不是“同 Seed 随机错相”的问题；相同放置/Spawn 顺序下关系基本稳定。
- 但 Population 不能显式控制二者相位，首版也不会精确求解地刺/冲锤的时间窗口。组压力只是可调近似值，严重档诊断不能宣称是严格的“通过余量”。
- 如果首轮 PIE 证明同步启动导致组合过易、或细小生成时序差异影响手感，第二步再为地刺和冲锤增加生成前 `Phase01` 配置；不得在本轮暗中扩展。

## 自动验证

- 同一 Seed、难度、Profile 和玩家名义速度生成的机关类型、锚点、方向、刺轮路线 Seed、相位及资源完全一致。
- `0/NaN/Infinity` 玩家速度必须原子失败；在固定单机关夹具中，`200/400/800 cm/s` 的实际组压力必须依次下降，且受击后果部分保持不变。
- 只改资源参数时机关层完全不变；只改某类候选数量时类型基础概率不被候选数量吞没。
- 每个刺轮只声明自己的一个占用格；相邻两个刺轮允许生成但不得同格。路线 Seed 和相位必须因锚点不同而独立且可复现。
- 自动校验三条一格路线的控制点加 Hurt Radius 不越过单格边界；若刺轮路线 DataAsset 后续改到越界，Population 配置应明确失败而不是继续按单格占用生成。
- 构造固定图夹具验证：两个机关占用相邻格时图距离精确为 `1`，刺轮+相邻冲锤/地刺必定被判入同组并获得对应组合分；距离 `2` 时仍可同组但不获得紧邻组合分。
- 在机关目标至少 `8` 且存在足够合法配对候选的 Normal 固定夹具中，对固定 512 Seed 统计：平均每局至少 `1` 个刺轮组合，至少 `60%` 的 Seed 出现刺轮组合，并满足刺轮+冲锤频率高于刺轮+地刺；这些是首轮调参门槛，不适用于候选不足的小地图。
- 单独刺轮仍必须出现，但另行统计绝对数量与占全部刺轮的比例；零散刺轮过多时优先调低单独刺轮贡献。
- 组目标压力在相同进度也存在 Seed 派生差异；跨楼梯邻近按图距离归组；机关分布存在簇与空白而非恢复等距。
- Easy / Normal / Hard 目标密度仍为 `26/28/30`，无流程点放置、物理重叠、非法 Class 或异常欠填。
- Development Editor 构建和完整 `Demo.PCG.Population`、相关 `Demo.PCG` Automation 通过。

## 体验反馈补充：空白段与高厅灯光

- 用户反馈部分长走廊同时缺少机关和资源，追猎压力下没有决策点；确认不把“最大空白长度”改成生成硬约束。
- 在现有机关位置分和资源支持分中各增加一个有界、非零的路线覆盖奖励：机关偏向远离已有机关，资源偏向远离已有机关与资源。所有合法候选仍有概率被选择，偶发安静段继续允许。
- 机关覆盖强度首轮为 `0.5 log2`，避免压过刺轮组合；资源覆盖强度为 `1.0 log2`。三档资源密度由 `10` 小幅提高为 `12 / 100`，机关密度不变。
- 正式高厅配方增加两盏顶灯。共享 LampA Blueprint 的 RectLight 默认 Static 保持不动；PCG 生成路径已有局部 Movable 覆盖，避免影响第三方蓝图的手摆或烘焙用途。
- 自动验证以固定 Seed 集的累计最长空白段改善为门槛，不增加逐 Seed 的最大长度拒绝条件。
