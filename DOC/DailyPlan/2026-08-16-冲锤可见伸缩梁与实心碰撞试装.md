# 2026-08-16 冲锤可见伸缩梁与实心碰撞试装

## 目标

- 保留冲锤现有运动、Heavy 强度与周期，只修复外观和碰撞职责不一致。
- 锤头不再依赖空心/复杂美术网格碰撞，角色不能钻进锤头或固定冲杆。
- 伸缩结构只存在于墙面到锤头之间，墙后不会出现长杆或碰撞体。

## 最小实现

1. 现有 `RamBody` 继续作为唯一 Heavy 锤头，并把 Pawn 响应改为实心阻挡。
2. 锤头、旧固定冲杆、外壳和预警灯的美术网格统一关闭碰撞；旧固定冲杆隐藏。
3. 在冲锤 C++ 内新增一段可见长方形金属梁和一只简单盒碰撞：
   - 长度等于当前伸出距离；
   - 固定起点是墙前 Actor 原点，中心位于当前长度的一半；
   - 横截面为锤头碰撞的 90%，视觉与碰撞共同更新；
   - 只阻挡 Pawn 与 PhysicsBody，不触发 Heavy，不影响导航；
   - 完全缩回时隐藏并关闭碰撞。
4. Blueprint 只为新增可见梁装配 Engine Cube 与现有金属材质；不修改第三方网格资产。

## 验收

- 完全缩回时墙后没有伸缩梁或碰撞。
- 25%、50%、100% 伸出时，梁只覆盖墙面到锤头后方，外观与简单碰撞重合。
- 玩家不能进入锤头内部，也不能从锤头后方钻入机构。
- 收回时站在锤头外侧不会被拖进墙；Heavy、冲程、速度与周期保持原样。
- 本轮只做 C++ 构建、Blueprint 编译保存和短 PIE smoke，最终视觉与卡模效果由用户验收。

## 当前验证

- `DemoEditor Win64 Development` 完整构建成功，Blueprint 编译并保存成功。
- 官方 MCP 运行回读确认：伸缩梁实例取得 Engine Cube 与现有金属材质；梁长会随当前伸出距离在约 `200 cm` 到 `450 cm` 间变化，隐藏阻挡盒同步更新。
- 锤头复杂美术碰撞已关闭，现有 `RamBody` 简单盒体负责 Heavy 与 Pawn 实心阻挡；旧固定冲杆已隐藏且不再碰撞。
- 未改运动周期、冲程、Heavy 强度、DataAsset、角色或 PCG。最终画面、收回挤压和玩家钻入边界由用户直接 PIE 验收。

## 风险与下一步
