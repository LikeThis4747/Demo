# 2026-08-13 制导投射物与磁力投掷物轻受击收口

## 目标

- 制导投射物第一次有效命中玩家时，触发 `Slow` 与明显、可恢复的上半身局部物理表现。
- 磁力箱子砸追猎者时，保留现有 `Stop + 三方向受击动画`，并用最低可见强度改善局部物理表现。
- 只允许一次有限参数 A/B；若仍不明显，停止扩写物理代码并转入 `Stop + 玩家受击动画` 回退路线。

## 已确认行为

- 制导投射物：玩家 `Slow 0.40s / SpeedMultiplier 0.55 / 不播动画 / 允许局部物理`。
- 磁力箱子：追猎者保持现有 `Stop 0.60s / 播动画 / 允许局部物理`。
- 有效来源冲量不再从零表现开始；由来源 Profile 配置最低归一化强度。
- `NormalImpulse` 缺失或过小时，制导投射物使用自身 DataAsset 的策划保底强度。
- 局部物理按头、躯干、左臂、右臂选受力 Body；施力点使用受限的真实命中点，不再固定为骨骼中心。
