# 2026-07-27 PCG 室内光源最小实现

## 目标与范围

- 在运行时 WFC 场景中生成 HydroLab 原始顶灯，缓解封闭场景过暗与天花板漏光闪烁。
- 约每两个有效逻辑格一盏，Start 所在格必有灯。
- 本步只修改四个现有 PCG C++ 文件和项目自有 Presentation DataAsset；不修改 WFC、第三方素材、Level0、测试 Harness 或小地图。

## 文件与资产

- `Source/Demo/Public/PCG/ZeroEscapeGenerationAssets.h`：灯开关、Actor 类、格中心修正 Transform。
- `Source/Demo/Private/PCG/ZeroEscapeGenerationAssets.cpp`：启用时执行 fail-closed 配置校验。
- `Source/Demo/Public/PCG/ZeroEscapeRuntimeLevelGenerator.h`：灯 Actor 事务状态与私有生成入口。
- `Source/Demo/Private/PCG/ZeroEscapeRuntimeLevelGenerator.cpp`：奇偶格选灯、Spawn、失败与清理回滚。
- `/Game/ZeroEscape/Generation/Presentation/DA_Presentation_SciFiHydroLab`：绑定原始 LampA 与 `Roll=180°`。

## 实施步骤

1. 给现有 Presentation Profile 增加且只增加三项灯具表现配置。
2. 对有效格统计两组棋盘奇偶性，选择较少组；平局选 Start 组，必要时额外补 Start。
3. 在规范逻辑格中心、天花板 Pivot 高度生成原始灯 Blueprint，并立即登记到回滚数组。
4. 将灯 Actor 纳入 Clear、重生成、失败与 EndPlay 的现有事务清理。
5. 用户关闭 UE 后构建；重开后配置并保存 DataAsset。

## 验证与回退

- 不运行自动化测试；用户在正常主视口 PIE 检查 Seed 12345 与至少一个不同 Seed。
- 检查灯数约为有效格一半、直路大致隔格布灯、Start 有灯、重新生成无残留，并观察亮度、阴影和性能。
- 任一步失败由现有实例化事务清空 HISM 与已登记灯 Actor；可通过 DataAsset 的 `bSpawnCeilingLights` 关闭功能。
- UE 构建与 DataAsset 装配完成后仍标记“待用户验收”，不提前宣称完成。
