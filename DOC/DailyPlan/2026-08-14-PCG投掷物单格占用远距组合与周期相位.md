# 2026-08-14 PCG 投掷物单格占用、远距组合与周期相位

## 目标

- 发射器只占挂载所在的一格，正前方一格不再被当作机关/资源硬冲突区。
- 提高发射器出现倾向，并优先选择转角及与其他机关相隔 2～3 格的配合位置。
- PCG 生成的摆锤、地刺、冲锤、刺轮不再同拍启动；相同公开 Seed 必须稳定重放。

## 硬边界与软目标

| 类型 | 规则 | 实现方式 |
|---|---|---|
| 硬边界 | 发射器自身挂载格不能与另一处内容重叠 | 只把锚点写入既有占用集合 |
| 硬边界 | 发射方向必须是合法开放相邻格，且不能直接覆盖玩家、追猎者或 Exit | 保留既有候选构造检查 |
| 软目标 | 转角更适合发射器 | 合法候选增加 `1.5 log2` 权重，不归零其他位置 |
| 软目标 | 发射器与其他机关形成远距配合 | 复用现有 3 格机关组；1 格不加分、2 格加 `0.75`、3 格加 `1.5` |
| 软目标 | 同组周期机关错相 | 摆位结束后从四个确定性候选相位中择优分散；任何结果都接受 |

## 最小实现

- 不新增组件、Actor、求解器、管理器或 DataAsset。
- 在现有 Population 评分中增加发射器组合项；组合缺失不拒绝候选，也不增加地图重试。
- 在现有 Population 摆位结果中携带内部相位，延迟生成周期机关时于 `BeginPlay` 前注入。
- 地刺与冲锤只改变第一轮安全等待时长；摆锤只改变初始角度/切向速度；刺轮复用既有相位入口。手摆 Actor 保持原行为。
- 正式 `DA_Population_Default` 的 Easy/Normal/Hard 发射器权重设为 `3/4/6`，转角奖励 `1.5`，远距组合奖励 `1.5`、组合压力 `0.5`。

## 验收

- 定向 Demo 模块构建通过。
- Population 自动化覆盖一格占用、远距组合、相位分散和同 Seed 重放。
- L_Game 用同一公开 Seed 连续生成两次，布局哈希、机关计数与相位一致；无 Population 失败或相位配置回退。
- 玩家次日验收实际机关节奏、投掷物密度及组合观感。
