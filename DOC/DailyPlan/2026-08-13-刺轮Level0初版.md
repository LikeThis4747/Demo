# 2026-08-13 刺轮 Level0 初版实施计划

## 目标

在 Level0 放置一个项目自有刺轮，沿 DataAsset 中配置的 1～3 格轨迹持续循环；本次房间展示使用一格实例。命中玩家时通过现有 `ICharacterImpactReceiver` 提交一次 Stop，并用局部门禁保护伤害与轻受击不连续触发。

## 范围

- 新增 `Source/Demo/Public/Actors/Hazards/SpikeWheelHazard.h`
- 新增 `Source/Demo/Private/Actors/Hazards/SpikeWheelHazard.cpp`
- 新增 `Source/Demo/Public/Data/Hazards/SpikeWheelHazardTuningData.h`
- 新增 `Source/Demo/Private/Data/Hazards/SpikeWheelHazardTuningData.cpp`
- 新增 `/Game/ZeroEscape/Hazards/Physics/BP_SpikeWheelHazard`

- 新增 `/Game/ZeroEscape/Hazards/Physics/FX/M_SpikeWheel_Sparks_Forge`
- 新增 `/Game/ZeroEscape/Hazards/Physics/FX/P_SpikeWheel_Sparks_Forge`
- 新增 `/Game/ZeroEscape/Physics/Impact/DA_SpikeWheelStandingImpact`
- 修改 `/Game/Levels/Level0`，只放置一个一格测试实例

不修改 PCG/Population、玩家、追猎者、现有机关或第三方素材；不实现追踪、销毁、物理破坏、多刺轮协同和受击动画。

## 实施步骤

1. 实现 `USpikeWheelHazardTuningData`：保存 1～3 格轨迹模板、运动/碰撞参数、伤害和轻受击来源，并严格校验非法配置。
2. 实现 `ASpikeWheelHazard`：构建样条、闭环/折返移动、视觉自转、Pawn Overlap、一次 Stop/伤害和局部再次命中门禁。
3. 完成 Development Editor C++ 构建；不带编译错误进入资产阶段。
4. 用官方 UE5.8 MCP 创建 DataAsset 和 Blueprint；Blueprint 只装配 `SM_SawBlade`、相对姿态和循环音效，不写玩法逻辑。
5. 在 Level0 独立空房间放置一个一格实例，编译、保存、回读并运行 PIE。
6. 根据用户反馈把轮心降至地面，仅露上半圆；补充三种一格轨迹，并装配项目自有的红黄打铁火星粒子副本，不修改第三方原资产。

## 验证

- 配置非法时机关明确停用，不静默钳制或兜底。
- 一格展示路线保持在声明足迹内；总配置仍覆盖 1～3 格。基础 Seed 混入实例所在逻辑格坐标，不同实例可稳定产生模板/镜像/方向/起始相位变化。
- 一次完整重叠只提交一次 Stop 和一次伤害；停留、重复组件 Overlap 与快速重新进入不造成连击。
- 玩家完全离开且超过门禁时间后，下次接触可以再次命中。
- 刺轮不阻挡 Pawn、不影响导航；追猎者来源映射为 None。
- 轮体只露上半圆；火花集中在接地点附近，并呈亮黄橙核心、橙红尾部的金属火星颜色。
- C++ 构建、Blueprint 编译保存、资产/Level0 回读与 PIE 日志分别记录；最终手感待用户验收。

## 回退边界

- C++、五个新增资产与 Level0 单实例可分别回退。
- 若资产装配或路线手感失败，不扩展 Population 或修改现有机关；先停在 Level0 调整既有轨迹数据。
- 若实现需要超出四个 C++ 文件或触及排除文件，暂停并重新征得用户确认。
