## 1. 目标

在 `Level0` 灰盒里做出一个**追猎者**：感知玩家 → 持续寻路追击 → 进入攻击距离播放攻击蒙太奇 → 冷却 → 回追。**全程纯动画，不涉及物理受击**（物理受击为第二步）。

## 2. 已确认决策

| 项 | 决策 |
|---|---|
| 骨架 | 官方 **Manny**（SKM_Manny），玩家/敌人共用受击系统时用组件而非共用类（第二步） |
| AI | **纯 C++ 状态机**（AIController），不用行为树；Timer 驱动，默认关 Tick |
| 感知 | 第一步用**距离 + 可选视线检测**（C++ 自算），AIPerception 延后 |
| 抽象 | 只做 `APursuerCharacter` 一个具体类，**不做 EnemyBase**；能力走组件、参数走 DataAsset |
| 攻击 | 表现与后果分离：动画 Notify 只发"攻击生效"事件，第一步不结算伤害 |

## 3. Level0 现状（MCP 已探查，2026-07-24）

- 当前关卡：`/Game/Levels/Level0`。
- 已有：PlayerStart、Floor、4 个磁力道具（MagneticProp_05/20/45/70kg）、PCG 手搭的 L600 走廊 + Room900 房间、灯光/雾/天空。

## 4. C++ 代码规划（分块落盘顺序）

严格遵循 Public/Private 镜像、文件头职责/边界注释、DataAsset 驱动、默认关 Tick、不硬编码资源路径（对齐 `ZeroEscapeCharacter` 风格）。

### 块1：`Demo.Build.cs`（修改）
增加依赖：`AIModule`、`NavigationSystem`、`GameplayTasks`。

### 块2：`Source/Demo/Public/Data/PursuerConfig.h`
`UPursuerConfig : UPrimaryDataAsset`，字段（初值待方案定）：
- `MaxWalkSpeed`（移速）
- `SenseRadius`（察觉半径）
- `LoseSightRadius`（丢失半径，滞后于察觉，防抖）
- `bUseLineOfSight`（是否做视线检测）+ `SightTraceChannel`
- `AttackRange`（进入攻击的距离）
- `AttackCooldown`（攻击冷却秒数）
- `AttackMontage`（`TSoftObjectPtr<UAnimMontage>`，软引用）
- `AcceptanceRadius`（MoveTo 到点容差）
- `ThinkInterval`（状态机 Timer 周期，替代 Tick）

### 块3：`Source/Demo/Public/Characters/PursuerCharacter.h` + `Private/.../PursuerCharacter.cpp`
- 继承 `ACharacter`，默认关 Tick，`AIControllerClass = APursuerAIController`，`AutoPossessAI = PlacedInWorldOrSpawned`。
- 持有 `UPursuerConfig* Config`（EditDefaultsOnly）。
- 构造时按 Config 缺省值配移动组件（若 Config 为空则用安全默认并报错日志）。
- 提供 `PlayAttackMontage()`（加载软引用蒙太奇并播放）、`GetConfig()`。
- 不含任何 AI 决策。

### 块4：`Source/Demo/Public/AI/PursuerAIController.h` + `Private/AI/PursuerAIController.cpp`
- 继承 `AAIController`。
- `OnPossess`：读取被控角色 Config，启动 `ThinkInterval` 的 Timer（`Think()`）。
- `Think()` 状态机：
  - 找玩家（`UGameplayStatics::GetPlayerPawn`）。
  - 算距离；可选 `LineOfSight` 检测。
  - 距离 > 察觉半径 → Idle（不追）。
  - 察觉半径内且 > 攻击距离 → `MoveToActor` 追击。
  - ≤ 攻击距离且不在冷却 → 停止移动、`PlayAttackMontage()`、进入冷却。
  - 冷却中 → 保持面向玩家，冷却结束回追。
- 默认关 Tick，全部靠 Timer；`OnUnPossess` 清理 Timer。

## 6. 验收标准（第一步）

- 追猎者在 NavMesh 上稳定追击玩家，绕障不卡死。
- 攻击距离触发蒙太奇并正确冷却回追。
- 全程无物理受击（第二步内容）；参数全走 DataAsset；默认关 Tick；无硬编码路径。
