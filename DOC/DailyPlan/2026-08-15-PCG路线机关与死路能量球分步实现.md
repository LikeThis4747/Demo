# 2026-08-15 PCG 路线、机关与死路能量球分步实现

## 已确认目标

- 用软路线提示和坍缩后图评分，减少长直、锯齿、无意义一格凸起与单一 L 型路线。
- 用有界 log2 权重改善机关覆盖、发射器远距配合、刺轮组合和资源支持，不将质量偏好升成硬禁止。
- 识别有长度、有转弯、不反客为主的奖励支线，在最终端点放置独立能量光团。

## 实施边界

- 保留现有“二维 WFC → 跨层 Plan → 纯值 Population → Spawn”架构；不新建房间/走廊 ID 系统、通用 Manager 或新生产 C++ 文件。
- 硬约束仅限几何/拓扑合法、连通、同格/操作包络冲突、玩家/追猎者/Exit/光团端点保护、Class/Transform/Actor 预算和原子回滚。
- 所有路线质量、支线 3/4/5 中心值、长直/一格凸起、机关覆盖、类型/组合/压力/多样性与资源支持都是软评分。
- 光团本轮只做确定性放置、可读原型与 Spawn；不做能量数值、行走充能、Exit 百分比或 HUD。

## 检查点 A1：坍缩前软引导

1. 在 Generation DataAsset 增加软开口强度、奖励支线长度与早停阈值。
2. 按方向感知最短路生成主路/支线开口偏好；超长直线平方增费，每格反向的锯齿额外增费。
3. 偏好只乘合法 OpeningMask 的正权重，不 Ban 候选；兜底使用独立 salt。
4. 关闭 Editor 完整构建，迁移/回读 Generation Profile，运行 WFC 自动化。

## 检查点 A2：图分析、选优与奖励支线

1. 仅在每棵 WFC 成功树后分析一次；不进入叶验收 `BuildRouteMetrics`。
2. 提取稳定主路 Run、合理转弯、锯齿、长直、度 1/2 支线和可绕过主路边。
3. `OrdinaryDeficit` 仍第一比较；其余密度/主路/支线/替代路/伪凸起量化为整数 micros，质量达 `0.82` 可早停。
4. Planner 先保护候选支线选玩家出生点；若容量不足则回退原出生规则，再过滤冲突支线，不令软目标引发整栋失败。
5. 最终 RewardBranches 进 Plan/Hash，`ZE_PCG_RESULT` schema `6→7`。

## 检查点 B：机关与普通资源

1. 类型比例写为 Easy `5/3/3/2`、Normal `4/4/4/2`、Hard `3/6/4/4`。
2. 把“机关处数/100 格”迁移为“预算单位/100 格”；摆锤/地刺/冲锤/发射器/刺轮成本为 `10/10/10/7/5` 个十分之一单位，初值 `22.0/23.5/24.5`。
3. 机关覆盖从图距离 4 开始按 `0.35x+0.03x²` 增长，单通道上限 `+3 log2`；无已接受机关时为 0。
4. 发射器组合奖励为图距离 `1/2/3+ = 0.25/1.0/1.75`；压力诊断保持按组半径归一。
5. 奖励支线接近区只把正组合 log2 乘 `1.2`；负贡献和压力不放大。
6. 删除普通资源之间图距离 3 硬间距，保留同格/机关占用冲突。

## 检查点 C：死路能量光团

1. 在 Plan 增加独立 `EnergyOrbPlacements` 和 `EnergyOrbs`，不混入 `ResourcePlacements/ResourceStats`。
2. 每条最终 RewardBranch 端点确定性放一个光团，不消费 HazardRng/ResourceRng；前后 Actor 预算都计入。
3. Populator 完整接入名称、Class、加载、Transform、AppendLayer、Spawn 和日志。
4. 原型资产仅有可读 Emissive 光团、低成本 PointLight 和 OverlapOnlyPawn 碰撞，默认无 Tick，不做爆炸表现。

## 验证与回退

- 每个检查点独立 commit；A1 不改善候选分布则不进 A2，A2 结构/性能不达标则不进 B/C。
- 自动化覆盖：软提示不 Ban、同 Seed 稳定、软分析每成功树一次、支线/死路不变式、覆盖限幅下组合仍有效、资源可相邻、随机域隔离、光团统计/预算/Class 失败原子性。
- 性能记录每层 WFC 树数、软分析调用数、整栋 P50/P95；平均 WFC 树数不超基线 `+0.25`，整栋 P95 不超 `2×`。
- 完整构建后重开 Editor，用官方 UE5.8 MCP 迁移/编译/保存/回读 DataAsset 与 Blueprint，最后运行代表 Seed 与多 Seed PIE；仍保留用户玩家手感验收。
