# 2026-08-17 右下角资源与操作 HUD

## 目标

在现有 Canvas 准星之外，新增一个轻量 UMG 局内 HUD，固定在右下角，显示：

- 鼠标左键：投掷
- 鼠标右键：按住吸取
- E：赋能爆炸
- 爆裂次数：当前可用次数 / 最大次数
- 蓝色爆炸充能进度
- 红色生命进度

本轮不扩展目标、出口方向、追猎者警告或独立教学关。

## 文件与资产范围

- `Source/Demo/Public/GameFlow/ZeroEscapePlayerController.h`
- `Source/Demo/Private/GameFlow/ZeroEscapePlayerController.cpp`
- `Source/Demo/Public/UI/ZeroEscapeGameplayHUDWidget.h`
- `Source/Demo/Private/UI/ZeroEscapeGameplayHUDWidget.cpp`
- `/Game/ZeroEscape/GameFlow/BP_ZeroEscapePlayerController`
- `/Game/ZeroEscape/UI/WBP_GameplayHUD`（新建）

现有 `AZeroEscapeHUD` 的 Canvas 准星保持不变。蓝色条按当前磁力系统的爆炸充能进度处理，避免新增一套独立能量玩法。

## 实施步骤

1. 用 UMG 创建右下角安全区面板、操作键帽、爆裂次数文本、蓝色 ProgressBar 和红色 ProgressBar。
2. 增加薄的 `UZeroEscapeGameplayHUDWidget`，以低频 Timer 读取现有 HealthComponent 与 ElectromagneticGrabComponent，不新增能量组件或常驻玩法 Tick。
3. 在现有 PlayerController 中增加最小的 Gameplay Widget 创建入口，并在 Blueprint 默认值中指定新 Widget。
4. 编译 Widget/Blueprint，保存资产，回读默认值和控件树。
5. 构建 DemoEditor Development，并做一次 `L_Game` PIE smoke；画面和手感由用户最终验收。

## 验收与回退

- HUD 在右下角安全区内，不遮挡准星。
- 生命、爆裂次数和充能进度可读取，Widget/Blueprint 无编译错误。
- 暂停菜单和结算菜单仍可正常打开；若遮挡关系不理想，仅调整 Widget 可见性或层级，不改玩法逻辑。
- 若运行中 UMG 纯读绑定更新不及时，只补最小事件更新，不新增能量组件或常驻玩法 Tick。
