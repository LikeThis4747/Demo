## 编辑器装配步骤（正式构建完成并重开编辑器后）

2026-09-16 15:47 正式构建已成功。重新打开工程载入新 DLL 后即可查找新增原生节点。先不要运行 PIE：新代码要求配置树，尚未装配时会明确报错且不会启动 AI。

1. 内容浏览器进入 `/Game/ZeroEscape/Enemies`，新建文件夹 `AI`。在其中右键 → 人工智能（Artificial Intelligence）→ 黑板（Blackboard），命名 `BB_Pursuer`。
2. 打开黑板，依次创建键：`TargetActor` 为对象（Object），展开键类型并把基类（Base Class）设为 `Actor`；`CanCloseAttack` 和 `CanJumpAttack` 均为布尔（Bool）。三个键均不勾选实例同步（Instance Synced），确保不同追猎者各自判断。保存。
3. 同目录右键 → 人工智能 → 行为树（Behavior Tree），命名 `BT_Pursuer`。打开后在细节（Details）中的黑板资产（Blackboard Asset）选择 `BB_Pursuer`。
4. 从 ROOT 拉线创建选择器（Selector），节点名可设为“追逐玩家”。右键此选择器 → 添加服务（Add Service），搜索 `Pursuer`，添加 `Pursuer: Update Context`（C++ 类 `BTService_PursuerContext`）。周期自动读取 DA 的 ThinkInterval，不需要另设节点 Interval。
5. 在选择器下面从左至右连接三个任务：`Pursuer: Attack`、`Pursuer: Attack`、`Pursuer: Chase Player`。第一个攻击节点名设“普攻”，Jump Attack 不勾；第二个设“大跳”，Jump Attack 勾选。节点水平位置决定执行优先级，确保普攻最左、大跳居中、追击最右。
6. 右键“普攻”→ 添加装饰器（Add Decorator）→ 黑板（Blackboard），设置 Blackboard Key=`CanCloseAttack`、Key Query=`Is Set`、Notify Observer=`On Result Change`、Observer Aborts=`Lower Priority`。
7. “大跳”加同类黑板装饰器，只有 Blackboard Key 改为 `CanJumpAttack`，其他设置相同。追击不加装饰器，不加 Wait。两个攻击装饰器不能设为 Self 或 Both：起手后条件变 false 是正常现象，不能因此取消自身攻击。
8. 保存两个资产。打开现有 `/Game/ZeroEscape/Enemies/DA_Pursuer`，在“追猎者|AI”把 Behavior Tree 指向 `BT_Pursuer` 并保存。此资源属性也可在用户完成建树后由 AI 通过官方 MCP 装配。

```text
ROOT
└─ Selector
   ├─ Service: Pursuer: Update Context
   ├─ 普攻：Pursuer: Attack（Jump Attack=false）
   │  └─ CanCloseAttack Is Set；Observer Aborts=Lower Priority
   ├─ 大跳：Pursuer: Attack（Jump Attack=true）
   │  └─ CanJumpAttack Is Set；Observer Aborts=Lower Priority
   └─ Pursuer: Chase Player
```
