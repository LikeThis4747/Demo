# 2026-08-16 机关伤害与难度生命最简接入

## 已确认目标

- 摆锤 30、冲锤 30、制导推进机关 15，均只对玩家结算。
- 玩家正式生命为简单 800、普通 600、困难 400；当前开启调试覆盖，三档均为 1000。
- 所有数值必须可在既有机关 DataAsset 或 GameMode 蓝图默认值中调整，命中逻辑不写死数值。

## 最简实现

- 三种机关 Tuning 类型增加 `Damage`，由实际接触路径读取。
- 摆锤和冲锤通过 Heavy 真实接触提交一次伤害；准备阶段不扣血。
- 制导推进机关首次真实阻挡玩家时结算一次伤害，追猎者不结算。
- GameMode 按本局难度初始化玩家 HealthComponent；调试覆盖开关默认开启。
- 不新增伤害框架、不处理追猎者死亡、不修改 HUD。

## 验证边界

- 用户要求快速完成并明确取消自动化测试与 PIE。
- 仅执行必要 C++ 编译检查；资产使用新增 C++ 默认值，下次编辑器重载后可直接在现有资产中调整。
