# 2026-08-14 刺轮 Stop 受击动画接通计划

## 目标

在不修改玩家动画资产、角色蓝图、刺轮 C++、AI、碰撞、导航与路线的前提下，让刺轮现有的 Light Stop 播放玩家三方向受击动画。

## 唯一功能改动

- 修改 `/Game/ZeroEscape/Physics/Impact/DA_SpikeWheelStandingImpact`。
- `PlayerReaction.bPlayReactionAnimation: false -> true`。
- 保持 `PlayerReaction.Result=Stop`、`DurationSeconds=0.7`、`SpeedMultiplier=0`、`bApplyPhysicalReaction=false`。
- 保持 `PursuerReaction.Result=None`，不播放动画、不应用物理反应。

## 明确排除

- 不修改 `DA_PlayerStandingImpact`、三条玩家动画、AnimBP 或玩家蓝图。
- 不修改刺轮 C++、伤害 `20`、重复命中锁 `1.0 s`、轨迹、火星、声音或 Level0 布局。
- 不增加追猎者类型特判；当前 None 反应、无阻挡碰撞与不影响导航的合同保持。

## 风险与处理

- 三条动画长度约为 `1.60 / 1.03 / 1.77 s`，长于 `0.7 s` Stop。首轮保持短 Stop，让动画在恢复控制时淡出；若现场明显硬切，只记录并返回讨论，不擅自延长控制时间或修改全局动画参数。
- 当前只有正面、左侧、右侧三向，背后命中沿用正面反应；本增量不扩展第四方向。

## 验证

1. 官方 UE5.8 MCP 回读 DataAsset：只允许动画开关变化，其余 Player/Pursuer 字段保持。
2. Blueprint Warning-as-error 编译并保存；确认资产非 Dirty。
3. Level0 PIE 从正面、左侧、右侧各命中一次：立即 Stop、播放对应动画、约 `0.7 s` 恢复、每次只扣 `20`。
4. 持续接触不重复结算；完全离开且超过 `1.0 s` 后可再次命中。
5. 追猎者经过刺轮时不停止、不受伤、不播动画、不打断攻击与寻路；刺轮继续不阻挡 Pawn、不影响 NavMesh。
6. 用户最终验收动作方向、截断观感与控制时长。

## 实施结果

- 已完成唯一功能改动：`PlayerReaction.bPlayReactionAnimation` 由 `false` 改为 `true`，未修改玩家动画、角色蓝图、刺轮代码、路线、伤害、重复命中锁、AI、碰撞或导航。
- 官方 MCP 最终回读：玩家仍为 `Stop / 0.7 s / SpeedMultiplier=0 / Physical=false`；追猎者仍为 `None / Animation=false / Physical=false`；资产保存后非 Dirty。
- `BP_SpikeWheelHazard` Warning-as-error 编译通过；`Demo.Physics.CharacterImpact.DataValidationContract` 与 `Demo.Physics.CharacterImpact.SourceProfileContract` 共 `2/2` 通过、无警告。
- 运行时边界回读保持：`HurtZone` 为 `QueryOnly`、Pawn `Overlap`、`bCanEverAffectNavigation=false`、`bDynamicObstacle=false`。因此本增量不阻挡 AI，也不改变 NavMesh。
- 2026-08-14 用户已在 Level0 现场确认刺轮受击动画正常播放。动画截断观感如需微调，另行讨论，不在本次增量中扩展范围。
