## 目标与完成边界

在 `/Game/Levels/Level0` 的既有高厅内实现一个始终运行的物理摆锤：Chaos 负责重力、约束、碰撞和动量交换；机关只在穿过最低点且速度不足时施加有限补能。模拟刚体无须标签、质量或速度门槛即可改变摆锤的摆幅、相位和有限侧摆。

本轮完成边界：

1. C++、DataAsset、Blueprint 和一个 Level0 实例形成最小可玩闭环；
2. 显式关闭 UE 5.8 Twist/Cone 默认 Soft Constraint，使用 23° 主轴硬角限位；
3. 先以补能 0 测量 3 分钟自由摆损失，再填写只覆盖被动损失的最小补速；
4. 完成构建、蓝图编译/保存、资产回读、PIE 和用户手感验收；
5. 不接入 PCG，不在摆锤内复制角色受击逻辑，不修改第三方素材。

## 验证与停止条件

- C++ 完整构建成功，新增蓝图为 UpToDate，DataAsset 数值和父类字段经官方 MCP 回读一致。
- 无干扰时补能后运行 3 分钟不逐步耗停、不过度增能；反向碰撞的减速至少保留到下一次完整摆动。

- 若同帧 `TeleportPhysics` 未形成 18° 初始释放，只在实测失败后改为下一物理帧释放。
- 若构建被 Live Coding 占用，直接请用户关闭 Live Coding 或编辑器，不写绕行脚本。
- 若官方 UE MCP 连接失败，立即停止 Blueprint/DataAsset/Level0 写入，由用户决定重连或允许本地 MCP 兜底。
