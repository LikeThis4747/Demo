# PCG + 物理玩法 Idea 当日评审（2026-07-20）

> 用途：记录命题发布后首轮发散与筛选。所有方向均为候选，尚未立项；按需读取，不加入 AI 启动上下文。

## 1. 命题与项目约束

- UE 3D 单机 Demo，工期约三周，C++ 优先。
- PCG 必须运行时生成完整场景关卡，不能只是散布资源或随机敌人。
- 物理可以基于 Chaos，但必须有自研求解、控制、传播或验证层，不能把 UE 现成功能直接当技术点。
- 游戏必须形成目标、失败、成长和重玩理由，不能只是技术展示。
- 资源应低模、模块化、风格统一，尽量只使用一套主环境资产。

## 2. 评分方法

每项满分 5 分，`综合`不是机械平均，额外考虑三周交付风险。

| 指标 | 含义 |
|---|---|
| 乐趣 | 是否容易形成持续操作、风险收益和重玩动力 |
| PCG | PCG 是否真正生成关卡并明显改变每局体验 |
| 物理 | 自研物理辨识度及其与玩法的结合程度 |
| 可做 | 三周内完成最小完整体验的可行性，越高越安全 |
| 省资源 | 美术、动画、关卡手工制作压力，越高越省 |

## 4. 今日全部方向评审

### A. 飞行与空气动力

#### A1. 螺旋桨飞机

- 参考游戏：`Microsoft Flight Simulator`、`War Thunder`、`IL-2 Sturmovik`、`Kerbal Space Program`。
- 物理技术：分布式气动面、迎角、失速、螺旋桨推力/扭矩、滑流、动态重心和结构损伤。
- PCG体验：生成峡谷、风场、航线和任务，再按飞机能量包线验证可飞性。
- 评价：原始技术上限高，但题材成熟、资源需求大；没有损伤或风场特色时容易被认为是普通飞行模拟。
- 评分：乐趣 3.5 / PCG 3.5 / 物理 4.5 / 可做 2.0 / 省资源 2.5 / 综合 **3.3**。

#### A2. 五气动面翼装原型

- 参考游戏/项目：`JUMP Wingsuit Simulator`、`Mount Wingsuit`、`Laya's Horizon`、`Superflight`、`Steep`。
- 物理技术：左/右臂翼、左/右腿翼和躯干分别计算局部风速、迎角、升阻力与力矩；输入改变姿态而非直接改变速度。
- PCG体验：生成三维地形和风场，并根据滑翔比、转弯半径与能量包线验证路线。
- 评价：适合做物理原型，资源压力低；单独作为游戏仍容易退化成“随机峡谷躲墙”。
- 评分：乐趣 3.0 / PCG 4.0 / 物理 4.5 / 可做 3.5 / 省资源 4.5 / 综合 **3.7**。

#### A3. 翼装空中狩猎

- 参考游戏：`Superflight`、`Luftrausers`、`The Falconeer`、`Control`、`Shadow of the Colossus`。
- 设想：以高度和速度作为资源，通过俯冲、掠过、尾流、展开震荡和磁力投掷攻击目标。
- PCG体验：生成风场、敌人/舰队路线、大型目标和风险收益分支。
- 用户评价：当前战斗动作缺少直接、可信的乐趣。
- 结论：低优先级保留；除非找到更强的一分钟循环，否则不实现。
- 评分：乐趣 2.5 / PCG 4.0 / 物理 4.5 / 可做 2.5 / 省资源 3.5 / 综合 **3.2**。

### B. 力场、重力与碰撞

#### B1. 磁力废品战斗

- 参考游戏：`Control`、`Half-Life 2`、`Just Cause 3`、`Instruments of Destruction`。
- 物理技术：磁场、极性、力场叠加、物体聚合、动能损伤、反磁力移动和碎片管理。
- PCG体验：生成完整立体战区、物理资源、敌人、陷阱和可达平台。
- 评价：场景物体能同时成为弹药、防御和移动资源；目前仍需解决“吸起再扔”的单调性。
- 评分：见当前短名单。

#### B2. 重力重构空间站

- 参考游戏：`Exo One`、`Hardspace: Shipbreaker`、`Portal 2`、`Prey`。
- 物理技术：局部重力场、物体状态管理、轨迹/可达区域近似和重力切换稳定控制。
- PCG体验：舱室图语法、重力节点和任务拓扑，并通过抽象搜索验证可行路线。
- 评价：技术结合自然，但偏解谜；PCG很难保证谜题质量，因此不作为当前首选。
- 评分：乐趣 3.5 / PCG 4.0 / 物理 4.0 / 可做 3.5 / 省资源 4.5 / 综合 **3.7**。

#### B3. 碰撞弹射地牢

- 参考游戏：`Creature in the Well`、`Peggle`、`Rock of Ages`。
- 物理技术：高速连续碰撞、反弹材料、预测轨迹、容错辅助和连锁评分。
- PCG体验：生成房间图、反弹面、敌人和机关因果链，用轨迹采样验证可命中序列。
- 评价：反馈强、资源省、验证相对可控；技术规模不如复杂仿真，但最容易完成。
- 评分：见当前短名单。

### C. 绳索、身体与运输

#### C1. Snake Pass 式多段身体

- 参考游戏：`Snake Pass`、`Rain World`、`Carrion`、`Octodad`。
- 物理技术：多刚体链、约束、接触摩擦、身体曲线推进、重量分布和物理骨架跟随。
- PCG体验：按身体长度、黏附、缠绕与支撑能力生成路线。
- 评价：技术实现不简单，但原作核心动词仍主要是移动、缠绕和攀爬；技术复杂不等于玩法丰富。
- 评分：乐趣 3.0 / PCG 3.5 / 物理 4.5 / 可做 2.5 / 省资源 3.5 / 综合 **3.4**。

#### C2. 多绞盘深渊回收

- 参考游戏：`Hardspace: Shipbreaker`、`SnowRunner`、`Mars First Logistics`、`Heavenly Bodies`、`Uncharted 4`。
- 物理技术：PBD/Verlet 绳索、碰撞缠绕、动态接触点、摩擦、张力传播、多绳载荷和绞盘功率限制。
- PCG体验：生成设施/洞穴、锚点、目标质量、障碍、环境流和回收路线。
- 评价：比单纯抓钩更有深度，运输与临场事故有潜力；多绳碰撞和稳定性调试风险高。
- 评分：乐趣 4.0 / PCG 4.0 / 物理 4.5 / 可做 2.5 / 省资源 4.0 / 综合 **3.8**。

#### C3. 漂浮岛货运

- 参考游戏：`Poly Bridge`、`World of Goo`、`Besiege`、`Death Stranding`。
- 物理技术：浮力/升力近似、结构张力图、稳定性评估、断绳与载荷传播。
- PCG体验：生成岛群、连接图、质量和资源预算，并验证可行运输顺序。
- 评价：技术边界清楚、视觉资源省，但可能偏解谜和慢节奏。
- 评分：乐趣 3.5 / PCG 4.0 / 物理 4.0 / 可做 3.5 / 省资源 4.5 / 综合 **3.7**。

#### C4. 布娃娃救援队

- 参考游戏：`Human: Fall Flat`、`Gang Beasts`、`Heave Ho`、`Wobbledoll`。
- 物理技术：主动布娃娃、关节马达、姿态目标、抓取稳定、跌倒恢复。
- PCG体验：按抓取、摆荡、搬运和协同能力生成障碍段。
- 评价：失败反馈有趣，但单机缺少多人互坑的天然乐趣，角色控制调试成本高。
- 评分：乐趣 3.5 / PCG 3.5 / 物理 4.5 / 可做 2.5 / 省资源 3.5 / 综合 **3.4**。

### D. 结构、机械与地形

#### D1. 程序化灾难拆除

- 参考游戏：`Teardown`、`Instruments of Destruction`、`Hardspace: Shipbreaker`、`Red Faction: Guerrilla`、`Besiege`。
- 物理技术：支撑关系图、载荷传播、连接应力、渐进损伤和倾倒预测。
- PCG体验：生成结构、弱点、任务与安全拆除路线。
- 用户评价：PCG难以生成精密、稳定、可进入、可拆且坍塌有趣的建筑。
- 结论：降级。模块拼接可以实现，但会牺牲建筑可信度；完整运行时验证超出工期。
- 评分：乐趣 4.0 / PCG 2.5 / 物理 4.5 / 可做 2.0 / 省资源 3.0 / 综合 **3.1**。

#### D2. 程序化攻城试验场

- 参考游戏：`Besiege`、`Instruments of Destruction`、`Angry Birds`。
- 物理技术：标准模块的支撑图、冲击能量、渐进失稳和坍塌评分。
- PCG体验：由有限城堡模块生成目标，验证武器至少能命中一个弱点。
- 评价：比任意建筑拆除可控，观赏反馈强；仍需避免变成发射一次后只看动画。
- 评分：乐趣 4.0 / PCG 3.5 / 物理 4.0 / 可做 3.0 / 省资源 3.5 / 综合 **3.6**。

#### D3. 程序化桥梁救援

- 参考游戏：`Poly Bridge`、`Bridge Constructor Portal`、`Death Stranding`。
- 物理技术：杆件轴力/弯曲近似、应力可视化、渐进损伤与结构失效图。
- PCG体验：生成地形、支撑点、缺口和材料预算，并验证理论可行结构。
- 评价：最稳妥，但题材常见且明显偏工程解谜。
- 评分：乐趣 3.0 / PCG 4.0 / 物理 4.0 / 可做 4.0 / 省资源 4.0 / 综合 **3.7**。

#### D4. 程序化矿洞与坍塌

- 参考游戏：`Deep Rock Galactic`、`Noita`、`SteamWorld Dig`。
- 物理技术：体素/SDF、岩层支撑传播、爆破影响、块体聚合和按需刚体化。
- PCG体验：洞穴、矿脉、支撑与返程路线生成。
- 评价：PCG结合优秀，但动态网格、碰撞和性能风险过高，只能做有限可挖区域。

- 参考游戏：`BeamNG.drive`、`Rigs of Rods`、`SnowRunner`、`Wreckfest`、`Expeditions`。
- 物理技术：节点梁车架、塑性形变、断裂、轮胎接地、地面沉陷和载荷传递。
- PCG体验：生成灾区地形、运输任务、救援点和适配车辆能力的路线。

### E. 材料、压力与灾害

- PCG体验：生成工厂管网、材料源、事故和目标通路。
- 评价：技术辨识度很高，但完整三维材料模拟不可控；只能采用 3D 表现、2.5D 求解。

- PCG体验：生成舱室图、管网、事故源和撤离路线。

### F. 肉鸽化的新方向

#### F1. 物理法术构筑肉鸽

- 参考游戏：`Noita`、`Magicka`、`Control`、`Fictorum`、`Mages of Mystralia`、`Risk of Rain 2`。
- 核心：用“目标选择 + 物理操作 + 触发条件”组合技能，例如吸引、排斥、减重、增摩擦、焊接、断开、施加扭矩。
- PCG体验：根据玩家构筑生成物体供给、材料组合、空间和敌人，使不同物理能力有实际应用机会。
- 物理技术：统一操作符、事件链、力场叠加、对象标签、组合稳定性和性能预算。
- 评价：最接近 3D `Noita` 的系统精神，构筑和世界使用同一套规则；必须限制首版操作符和触发器数量。
- 评分：见当前短名单。

#### F2. 模块机械生命肉鸽

- 参考游戏：`Besiege`、`Trailmakers`、`Cogmind`、`Captain Forever`、`Rain World`。
- 核心：击败敌人后拆取轮子、腿、抓取臂、武器、配重和弹簧关节，安装后真实改变质量、重心、惯量和接触能力。
- PCG体验：依据当前机器能力生成地形、战斗空间、任务和可选捷径。
- 物理技术：模块连接图、质量/惯量重算、关节控制、载荷传播、部件损伤和脱落。
- 评价：肉鸽升级肉眼可见，物理代价天然形成取舍；需用固定插槽和少量部件控制实现规模。
- 评分：见当前短名单。

#### F3. 物理变异生物肉鸽

- 参考游戏：`Snake Pass`、`Rain World`、`Carrion`、`Spore`、`Octodad`。
- 核心：身体长度、黏性、刚性、弹性、触手和配重随构筑变化，并改变穿越与战斗方式。
- PCG体验：根据身体能力生成狭缝、液体、攀附面、缠绕柱和奖励区域。
- 物理技术：多段身体、肌肉/关节控制、接触感知、断裂和动态骨架表现。
- 评价：独特但控制器和动画风险很高，容易重复 `Snake Pass` 的“技术复杂、玩法单一”问题。
- 评分：乐趣 4.0 / PCG 4.0 / 物理 5.0 / 可做 1.5 / 省资源 3.5 / 综合 **3.5**。

#### F4. 物理灾害生存肉鸽

- 参考游戏：`Noita`、`Spelunky 2`、`Barotrauma`、`Oxygen Not Included`、`Streets of Rogue`。
- 核心：每一区域由重力、压力、进水、热量、磁场或坍塌中的两种灾害组合；玩家构筑改变隔离、转移和利用灾害的能力。
- PCG体验：生成灾害源、传播网络、资源和撤离路线。
- 物理技术：有限状态传播、场叠加、房间网络、动态质量与结构响应。
- 评价：环境本身就是敌人，AI需求低；必须只选择两套能深入联动的灾害系统。
- 评分：见当前短名单。

#### F5. 运动型物理肉鸽

- 参考游戏：`Descenders`、`Trials`、`Lonely Mountains: Downhill`、`Hades`。
- 核心：一条命通过程序化路线，每个节点加入运输、撞击、拖拽、动态重力或易碎目标，而不只是竞速。
- PCG体验：生成路线图、运动段、任务和风险捷径，并按当前运动能力验证。
- 物理技术：动量控制、接触面采样、悬挂/弹性、质量与摩擦构筑。
- 评价：完成概率最高，但需要额外机制与 `Descenders` 区分。
- 评分：见当前短名单。

## 5. 肉鸽与物理的结合标准

不合格的结合：随机地图、随机敌人、伤害/射速/暴击数值升级，物理只负责碰撞表现。

合格的结合至少满足两项：

1. 构筑改变质量、重心、摩擦、弹性、连接、力场或身体结构。
2. 同一构筑同时产生能力和物理副作用。
3. PCG理解玩家当前物理能力并生成适用问题。
4. 环境、敌人和玩家使用一致的物理规则。
5. 玩家能利用规则组合产生非脚本化结果。

## 6. 下一轮建议

暂不立项。下一轮只为以下三个方向各写一页“一分钟核心循环”，避免继续无限发散：

1. **物理法术构筑肉鸽**：重点验证操作符组合是否真的好玩，而非只展示碎片。
2. **模块机械生命肉鸽**：重点验证安装部件后质量、重心和操控变化是否形成有趣取舍。
3. **物理灾害生存肉鸽**：重点从压力、重力、热量、磁场中只选两种最值得联动的系统。
