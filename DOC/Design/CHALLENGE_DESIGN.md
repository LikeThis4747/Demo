# 《零号逃亡》挑战性设计：追猎者压力与机关关卡

> 状态：正式策划案，2026-08-13 立案。本案是 `GAME_DESIGN.md` 与 `ENEMY_DESIGN.md` 的挑战性专题展开。
>
> 本案回答一个问题：为什么当前游戏有明显无聊感，以及在剩余工期内如何解决。
>
> 本文只记录设计目标、玩家可感知规则、参数化要求与工期评估。类结构、AI 实现、寻路方案、碰撞方案和验证步骤在方案确认后写入对应 `DOC/DailyPlan/`。
>
> **本案修订 `ENEMY_DESIGN.md` 3.1 的感知规则**：追猎者不再依赖丢失半径放弃追击。该文件其余设定继续有效。
>
> 命名说明：「持续追击」「遭遇组」「战术地形」「次级威胁」均为本项目内部命名，不是 UE 官方概念、标准算法或行业通用术语。

---

## 1. 无聊感的三个根因

### 1.1 根因一：追猎者会追丢（最严重）

机关的压力**不来自机关本身，而来自「你没有时间处理它」**。

追猎者一旦追丢，玩家可以停下、观察机关周期、从容绕行。此时地图上有 4 种还是 15 种机关都一样——**全部降级为静态装饰**。

这条会吞掉所有内容扩充的收益，因此必须最先解决。

### 1.2 根因二：机关放在可绕开的位置

玩家的成本是「绕一下」，收益是「完全免疫」，这个交换永远划算。

**关键区分：机关的威胁强度不由伤害决定，由是否可回避决定。** 一个 5 点伤害的不可回避机关，比一个 50 点伤害的可绕开机关更有存在感。

### 1.3 根因三：全局最小间距把机关打散成孤立点

孤立的机关只产生单一决策（绕 / 不绕），玩家两秒内解决完。

组合的机关产生复合决策，才构成挑战。而 2026-08-12 验收的全局最小间距（间距 2）从机制上排除了组合的可能——它保证了每个机关都是孤立的。

## 2. 追丢问题：先分清两种「丢失」

这是本案最重要的一处设计区分。

当前系统把两件完全不同的事混为一谈：

| 事实 | 当前系统的解读 | 应有的解读 |
|---|---|---|
| 玩家跑远了 | 「我不知道你在哪了」→ 放弃追击 | 「你暂时安全了」→ 继续推进 |
| 玩家被机关掩护 | 同上 | 同上 |

**玩家利用机关和地形换来的收益，应该体现为「距离」，而不是「让猎手遗忘你」。**

一旦「距离拉开」被翻译成「感知丢失」，玩家的每一次成功操作都会导致压力**永久消失**，而不是**暂时缓解**。这就是无聊感的直接来源。

### 2.1 结论：采用持续追击

**你的倾向是对的，采纳。** 追猎者始终知道玩家的大致位置，不使用丢失半径放弃追击。

理由：

1. **迷宫天然让视线丢失过于容易。** 多层结构、转角、走廊、机关遮挡，玩家不需要任何技巧就能断开视线。把「断开视线」作为脱离条件，等于把逃脱做成了免费操作。
2. **这是逃亡游戏，猎手放弃就没有游戏了。** 压力源必须持续存在，否则一局会退化为「触发追击 → 随便拐两个弯 → 安全散步到出口」。
3. **它使玩家的物理手段第一次有真实价值。** 当追猎者不会遗忘时，「击倒它换 5 秒」变成一个可量化、可依赖的收益。
4. **它让机关摆放产生意义。** 玩家必须在被持续追赶的状态下处理机关，机关才有压力。

### 2.2 玩家的收益改为体现在距离与时间

持续追击不等于无法逃脱。玩家依然可以获得安全，但形式变了：

| 玩家操作 | 收益 |
|---|---|
| 磁力物命中追猎者 | 短暂迟滞，拉开数米 |
| 引它进机关 / 高动能命中 | 击倒 + 起身，数秒完整窗口 |
| 走位、绕环路、上下楼 | 它需要绕行的时间 |
| 全程奔跑 | 距离缓慢缩短，但仍有可控余量 |

**玩家追求的不再是「甩掉它」，而是「现在还剩多少余量」。** 这才是逃亡游戏应有的紧张感。

### 2.3 机关对追猎者的正确作用：延迟，不遗忘

你的观察准确——对 AI 来说通过机关比玩家更难。这不应该被当作缺陷修掉，而应该成为玩家的奖励。

机关作用于追猎者时，三种可能后果里只有前两种可以接受：

| 后果 | 是否接受 | 说明 |
|---|---|---|
| 伤害它 / 击倒它 | **接受** | 这正是「奖励玩家利用机关」 |
| 迫使它绕路、延长它的路径 | **接受** | 时间成本就是玩家的收益 |
| 让它忘记玩家位置 | **不接受** | 压力永久消失，玩法崩塌 |

**因此设计规则是：追猎者承受机关的全部后果，但不因此终止追击。**

这条规则的额外好处是实现简单：不需要让 AI 理解机关周期、计算安全时机或规划避让路线（这在剩余工期内做不到），只需要它在受到机关影响后继续朝玩家推进。

### 2.4 持续追击的必要补偿：玩家必须能感知威胁位置

**这一条是持续追击能否成立的前提，不是可选项。**

如果追猎者永不放弃，而玩家又不知道它在哪，结果不是紧张，而是持续焦虑与疲劳——玩家无法判断「我现在安全吗」，也就无法做任何决策。

必须同时提供：

| 补偿 | 作用 |
|---|---|
| **追猎者脚步声 + 距离衰减** | 玩家通过听觉判断远近与方向。当前第三人称视角下追猎者从背后或墙后接近时玩家零信息来源 |
| 击倒 / 迟滞的明确反馈 | 让玩家确认「我换到了时间」 |
| 玩家血量显示 | 判断还能承受几次失误 |

**没有听觉信息，持续追击会从「压迫感」变成「折磨」。** 因此音效不是打磨项，而是本案的实施前提。

### 2.5 必须保留的兜底

持续追击去掉了「放弃」这个状态，因此需要防止另一类问题：

- **卡住检测**：追猎者长时间无法接近玩家（寻路失败、被几何卡住、被机关反复击倒在同一位置）时，必须有恢复手段，否则它会永久缺席；
- **开局宽限**：一局开始时应有一段距离或延迟，让玩家建立空间认知，而不是开局即贴身；
- **难度分档**：Easy 可保留较慢的推进速度或较长的受击恢复，Hard 则更紧迫。

## 3. 多追猎者与可击杀追猎者的评估

你提出的第二个方案：一局多个追猎者，允许被机关或磁力物打死。

### 3.1 我的判断：不建议在剩余工期内做，但你的真实需求应该满足

**风险评估：**

| 风险 | 说明 |
|---|---|
| 难度不可控 | 玩家只有磁力，没有闪避或格挡。两个追猎者同时进入攻击距离时，玩家几乎没有解 |
| 调参成本高 | 数量、刷新、分布、互相干扰的平衡需要大量试玩，剩余工期无法覆盖 |
| AI 互相干扰 | 两个体积较大的 AI 在窄走廊里会互相阻挡、抢占同一路径点 |
| 与既定范围冲突 | `ENEMY_DESIGN.md` 明确「三周只做一种高完成度追猎者」，且「追猎者难以被直接消灭」是核心定位 |
| 削弱压力源 | 可被击杀的猎手在被击杀后压力归零，需要刷新机制补偿，进一步增加复杂度 |

### 3.2 但你的需求是合理的：玩家需要「能解决东西」的正反馈

当前玩家的全部物理操作只能换来延迟，永远无法「解决」任何威胁。这确实缺少一类正反馈。

这个需求仍适合由次级威胁或可破坏物满足，而不是改造主追猎者；但当前刺轮已经收敛为固定路线机关，不能再把早期“可击杀小怪”设想写成已实现能力：

| 角色 | 定位 | 可否击杀 |
|---|---|---|
| 追猎者（唯一） | 持续压力源，不可解决，只能延迟 | **否** |
| 当前刺轮（见 4.2） | 固定路线组合机关 | **否；当前不提供击杀合同** |
| 独立可破坏次级威胁 | 后续候选 | 尚未立项 |

当前版本先通过磁力资源、爆裂投掷和机关组合提供“思考后降低风险”的正反馈；若试玩仍明显缺少“彻底清除威胁”的满足感，再为独立对象立项。主压力源仍保持不可消除，逃亡主题不变。

### 3.3 若仍要做多追猎者，最低成本形态

如果试玩后确认必须要多个，建议采用**按楼层分配**：每层至多一个追猎者，不跨层追击。

优点：避免同时围攻，天然分散压力，玩家上下楼即换对手，也复用了已有的多层结构。缺点是跨层追逐的连续压迫感会减弱。

**此形态仍属工期外候选，不在本案实施范围。**

## 4. 机关内容扩充

### 4.1 评估结论汇总

评估标准：实现成本、是否不可回避、是否与物理系统相关、与现有机关的区分度。

| 候选 | 成本 | 不可回避 | 物理关联 | 结论 |
|---|---|---|---|---|
| **刺轮（固定路线滚动威胁）** | 低 | 中 | 已接入站立受击 | **已实现，作为组合放大器接入 Population** |
| **压力板触发现有机关** | 低 | — | 强 | **强烈推荐，零新机关** |
| **悬挂重物（一次性掉落）** | 低 | 中 | 强 | 有时间则做 |
| 低摩擦区域 | 低 | 中 | 中 | 仅在「战术地形」定位下做 |
| 激光 | 中 | 中 | 弱 | **砍掉** |

### 4.2 刺轮

**当前定位：沿一格内固定轨迹滚动的可读地面机关，自身压力低，主要用于压缩相邻地刺或冲锤的走位空间。**

玩家可感知规则：
- 移动速度和运动规律由统一 DataAsset 管理，不追踪玩家；
- Population 只随机一格路线、镜像、方向和归一化相位；
- 接触造成伤害并触发当前站立 Stop 反馈；
- 单独出现合法但轻微降权，与冲锤相邻为强奖励，与地刺相邻为中奖励。

追踪玩家、被击毁或被磁力物打偏属于早期候选方向，**不是当前已确认实现合同**；后续若重新立项必须单独评估，不得据本文误判为已落地能力。

### 4.3 压力板触发现有机关

**这一项价值高于任何单个新机关，因为它翻转了全部现有机关的性质。**

当前四类机关都是周期自动，玩家只能被动躲避。增加区域触发模式后：

| | 周期自动（现状） | 触发式 |
|---|---|---|
| 玩家关系 | 被动躲避 | **可主动利用** |
| 战术空间 | 无 | 引诱追猎者踩上去 |
| 与物理系统关系 | 无 | 磁力物也可触发 |

玩家第一次有理由**主动接近**机关，而不是永远绕开。这直接服务于「奖励玩家利用机关攻击追猎者」这一目标。

### 4.4 悬挂重物

天花板悬挂重物，玩家投掷打断悬挂使其砸落。真实 Chaos 落体，可复用现有 HeavyImpact。

与压力板同一设计方向：**让玩家成为机关的使用者，而不只是受害者。** 一次性掉落比持续摆动实现更简单，视觉冲击强，适合演示。

### 4.5 低摩擦区域：必须重新定位

**直接作为障碍会产生高挫败感**——在追逐中让玩家失去控制，玩家会认为「我不是因为决策失误而死」。

但有一个翻转使它成立：

> **低摩擦对追猎者的惩罚大于对玩家的惩罚。**

追猎者的主攻击是助跑跳跃与冲撞，高速直线运动在低摩擦地面会明显失控、滑过头、撞墙；而玩家速度更低且可主动减速。磁力物在低摩擦地面也会滑行很远，可形成远距离送物体的玩法。

**因此它应作为「战术地形」设计：玩家学会把追猎者引到滑面上。** 必须与其他机关或地形组合（滑面尽头有东西），不做纯滑走廊。

技术前提：角色移动不直接受 Physical Material 摩擦影响，需通过角色移动参数实现，实施前需验证成本。

### 4.6 砍掉激光

单纯「跳过去的激光」与地刺重复，不产生新决策。

它有价值的形态是「可被物体阻挡的视线威胁」（玩家用铁板当盾牌穿过，实现 `GAME_DESIGN.md` 2.4 的移动掩体），但需要扫射逻辑、阻挡判定与视觉资产，且**与现有发射器机关生态位重叠**——发射器已经是远程威胁。

**想要掩体玩法，用「发射器 + 沿途磁力箱」的组合摆放即可实现，成本为零。**

## 5. 机关摆放规则：本案最高杠杆项

**不新增任何机关，只改摆放，即可显著提升挑战性。** 这一节优先于第 4 节的所有新机关。

### 5.1 原则一：成组遭遇 + 空旷呼吸

取消全局统一最小间距，不再用“组内/组间两档硬距离”替代它。机关按最终通行图的最短边数动态归组；组目标压力由难度、距终点进度、Seed 派生的区域起伏和组锚点抖动组成。基础压力使用“每秒通行压力 × 逻辑格宽/玩家名义 `MaxWalkSpeed` + 受击后果”计算一次。压力不足时鼓励补足、接近目标时最容易继续成组、超载后快速降权，但合法候选始终保持非零概率。

节奏来自变化目标压力与加权抽样，而不是强行切段：弱组、强组和空白会随 Seed 形成。全图均匀密度既不紧张也不放松，**空旷段的作用是让遭遇段显得可怕。**

### 5.2 原则二：位置有偏好，不是位置白名单

机关在难以绕开的走廊、门口、转角和楼梯接口更有价值，因此获得正向位置贡献；但不能把“通常更好”写成“只有这里允许”。

PCG 根据当前通行图与空间类型评分：

| 位置 | 权重倾向 | 理由 |
|---|---|---|
| 走廊、门口、楼梯接口 | **加权** | 难绕开，更能迫使玩家判断时机 |
| 转角 | 对发射器等信息型机关加权 | 形成观察与反应压力 |
| 开阔区域 | 通常降权但不禁止 | 单独机关仍可能形成空间选择 |
| 死胡同内部与入口 | 结合资源诊断加权 | 形成高风险高回报 |

**同一个机关放在走廊还是大厅，威胁强度差一个数量级。这是零成本的强度提升。**

首版实现只把已经有可靠几何依据的“发射器转角”写入机关位置评分；走廊、门口、楼梯接口和死胡同仍是后续调参方向，不在本轮伪装成已实现通道。机关组的安全进入侧只提供给资源层加权。

### 5.3 原则三：一组内的机关约束不同维度

好的组合让机关限制**不同**的东西，玩家必须同时满足：

| 组合 | 机关 A 约束 | 机关 B 约束 | 玩家必须 |
|---|---|---|---|
| 地刺 + 冲锤 | 时间（等刺降下） | 空间（贴墙躲锤） | 同时算时机与站位 |
| 摆锤 + 窄门 | 节奏（等摆锤过） | 通路唯一 | 掌握周期且不能久等 |
| 发射器 + 磁力箱 | 弹道（暴露即被击） | 提供掩体 | 用箱子挡或当移动掩体 |
| 刺轮 + 冲锤 | 压缩等待位置 | 高命中惩罚 | 提前观察并选择通过时机 |
| 刺轮 + 地刺 | 压缩等待位置 | 限制移动区域 | 在有限空间内精确走位 |

首版把刺轮 + 冲锤设为强奖励、刺轮 + 地刺设为中奖励，solo 刺轮只轻微降权且始终可出现。同类型连续不是天然坏组合，也不能硬排除；它由独立的多样性和组压力贡献控制。

### 5.4 原则四：可读性是质量评分与验收项

一转弯就是高惩罚机关容易造成随机死亡感，因此可读性必须参与验收；但首版不设置固定“机关前最小可读距离”硬门槛。当前代码只实现发射器转角位置贡献、组压力过载降权，并把安全进入侧输出给资源层；更精细的前方视野评分留待实测证明必要后再加。

当前正式玩家 `CharacterMovement.MaxWalkSpeed` 已确认为 `400 cm/s`。Population 在开局由真实玩家的实际 Class 取得 UE 类默认对象（Class Default Object，CDO）上的名义值，作为通行时间和通行压力的纯值输入；不读取会被受击改写的实例瞬时值或 Velocity，也不在 Policy 中硬编码 `400`。

### 5.5 原则五：死胡同 = 光球 + 入口机关

配合 `ENDGAME_GAMEPLAY_DESIGN.md` 的光球玩法：死胡同末端可放光球，入口机关获得组合位置偏好，而不是强制模板。

> 进去容易，出来时机关和追猎者同时在门口。

死胡同只有一个出口，这个风险结构由几何形状自动成立。机关阶段输出组压力和安全进入侧，资源阶段读取该诊断提高支持概率；两层随机域独立，调资源不能洗牌机关。

### 5.6 零成本的内容丰富度：组合即新关卡

几个已有机关的特定组合，玩家会感知为不同的关卡类型。组合由评分鼓励，不做“必须生成”的硬模板：

| 组合 | 玩家感知 |
|---|---|
| 窄走廊 + 地刺 + 两侧冲锤 | 精准通过挑战 |
| 高厅 + 摆锤 + 出口窄门 | 节奏门 |
| 直走廊 + 发射器 + 沿途磁力箱 | 掩体推进 |
| 死胡同 + 光球 + 入口冲锤 | 宝箱陷阱 |
| 低摩擦段 + 尽头冲锤 | 刹不住的死亡滑道 |

**内容丰富度的感知主要来自组合数量，而非机关种类数量。** 四种机关的有意义组合远多于四种。

## 6. 参数化要求

以下必须可调，便于试玩后快速收敛，不得硬编码：

| 参数 | 说明 |
|---|---|
| 感知模式开关 | 持续追击 / 有限感知。保留开关便于对比调试与难度分档 |
| 追猎者推进速度（按难度） | 必须高于玩家基础速度，否则压力不成立 |
| 追猎者受机关影响后的恢复时间 | 这是玩家收益的直接度量 |
| 卡住检测阈值与恢复方式 | 防止追猎者永久缺席 |
| 开局宽限距离或时间 | 避免开局贴身 |
| 有界 log2 评分范围 | 控制合法候选最大权重差，不让软贡献变成隐性硬过滤 |
| 类型上下文回写强度 | 每类只读取最佳三个不同锚点，避免候选数量扭曲类型概率 |
| 机关组图半径 | 控制哪些机关共同累计压力；不是硬间距 |
| 玩家名义地面速度 | 由正式玩家实际 Class 的默认 `MaxWalkSpeed` 提供，用于计算代表性单格通行时间 |
| 起点/终点目标压力与 Seed 起伏 | 产生整体递增但不趋同的组强度 |
| 组压力超载曲线 | 防止高压组合无限堆叠，但保持非零概率 |
| 刺轮组合贡献 | 刺轮+冲锤强奖、刺轮+地刺中奖、solo 轻微降权 |
| 资源支持权重 | 读取组诊断；资源随机域必须与机关随机域独立 |
| 刺轮速度、路线与相位 | 速度/规律由 DataAsset 统一；Population 只随机一格路线和归一化相位 |

### 7.2 止损顺序

1. 低摩擦区域；

4. 压力板触发；
5. **不得放弃**：持续追击、机关摆放规则、音效前提三项、打包。

### 7.3 明确不做

| 项 | 理由 |
|---|---|

## 8. 优先级判断原则

若 8/13 只能完成一件事，做**持续追击改造**。
若能完成两件，加**机关摆放规则改造**。

这两项不增加任何新内容，但会让**已经完成的四类机关、既有摆放、磁力系统与 HeavyImpact 全部产生压力**；而新增一种机关只增加一种体验。

**当前项目的瓶颈不是内容数量，而是现有内容没有产生压力。**

## 9. 未确定事项

- 持续追击下追猎者是否需要「大致方向」而非「精确位置」，以保留少量玩家操作空间；
