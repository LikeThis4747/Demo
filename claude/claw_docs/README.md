# claw_docs

Claw 远程阅读、分析代码后输出的详细代码分析文档目录。

- 面向**人（项目作者）**阅读，不是给 AI 看的精简审计。内容尽量详细：架构 → 模块 → 文件 → 具体实现。
- 与 `claude/reviews/`（给写代码 AI 看的精简审计）区分：reviews 只列问题和优先级，claw_docs 讲清楚"代码是怎么组织、每个文件干什么、关键逻辑怎么跑的"。
- 每份文档命名 `YYYY-MM-DD-主题.md`，文件头注明分析日期与代码 git 基线。
