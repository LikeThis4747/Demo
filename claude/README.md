# AI 工作区

这里存放 AI 自己创建的任务卡、交接、辅助脚本和临时产物，不存放游戏权威数据或长期项目事实。

- `tasks/active/`：正在执行的任务卡。
- `tasks/archive/`：完成后归档的任务卡。
- `handoffs/`：跨 AI/会话交接。
- `scripts/`：可复用辅助脚本。
- `scratch/`：随时可清理的临时文件。
- `artifacts/`：临时报告和输出。
- `templates/`：任务与交接模板。
- `reviews/`：AI 代码审计结论；实现/修改代码前先查（索引见 `reviews/README.md`）。

详细规则见 `DOC/AI_WORK_GUIDELINES/AI_WORKFLOW.md`。
