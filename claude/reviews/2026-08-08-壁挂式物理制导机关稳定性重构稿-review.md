## 2. 阻塞交付（落盘前必须定）

### B1. `MaximumPoweredSpeed` 关机线用总速度、油门用前向速度，余量偏小，转向时会误熄火
§7.3 `TryCalculateControlCommand`（稿 647-652）：`TotalSpeed = BodyVelocity.Size()`，`TotalSpeed >= MaximumPoweredSpeed` 即 `return false` → `FinishPoweredPhase("control command became invalid")`。而油门用前向投影 `ForwardSpeed`（669-675）。本方案靠 AddTorque 转姿态、推力沿 +Z，转向时惯性速度不跟转，产生**侧向速度分量**，使 `TotalSpeed > ForwardSpeed`。建议值 `Target 650 / Max 800 / Band 150`，关机余量仅 150 cm/s，急转 + P 控制超调时，`ForwardSpeed` 尚未达标 `TotalSpeed` 就可能撞 800 熄火下坠。
处理：关机线也按 `ForwardSpeed` 判定，或对侧向速度单独设更宽阈值，或拉大Max 与 Target 间距。此点决定飞行是否稳定，必须先定。

### B2. `IsConfigured` 必须整体重写，而非“新增关系检查”
§5.2 只给了新增关系检查，但现有 `ThrustGuidedHazardTuningData.cpp:22-42` 的 `IsFinite` 块与 44-117 的逐字段范围检查仍引用将删除的 `ThrustStrength`、`TargetLeadTimeSeconds`、`MaximumGimbalAngleDegrees`、`MaximumGimbalRateDegreesPerSecond`，且缺新字段（`MaximumPoweredAcceleration`、`TargetPoweredSpeed`、`MaximumPoweredSpeed`、`SpeedControlBand`、`Coasting*Damping`、`MaximumAngularAcceleration` 等）的有限值/范围校验。若只“追加”，会残留对已删成员的引用（编译失败）或漏校验新字段。稿件应改写成完整的字段增删清单。

## 3. 高回报（落盘前顺手做）

### H1（已核实，不采纳简化）. 保留真实惯量换算
UE5.8 当前源码已核实：`FBodyInstance::GetBodyInertiaTensor()` 返回局部质量空间惯量，`GetMassSpaceToWorldSpace()` 返回世界质心和惯量朝向；`UPrimitiveComponent::AddTorqueInRadians(..., bAccelChange=true)` 的官方注释明确表示把输入当作角加速度且质量不再生效。因此不能把 `bAccelChange=true` 写成“引擎自动处理惯量”，它是更游戏化但会绕开本稿坚持的质量/惯量语义。保留 §7.4 的“期望角加速度 → 质量空间 → 乘惯量 → 世界物理转矩”并以 `bAccelChange=false` 施加；实施时仍需通过 Demo 编译和运行日志验证有限值。

### H2. 出生净空检查能否挡住“炮管/外壳”取决于 Launcher BP 碰撞设置
§6.3 用 `OverlapBlockingTestByChannel(..., ECC_PhysicsBody, ...)` 且注释“故意不忽略 Launcher”。但现有 Launcher 外壳 `HousingVisualRoot` 是纯 `USceneComponent`（`ThrustGuidedHazardLauncher.cpp:31`）无碰撞，`TriggerVolume` 是 QueryOnly 且只 Overlap Pawn。若 `BP_ThrustGuidedHazardLauncher` 没有对 `ECC_PhysicsBody` 返回 Block 的外壳网格，这段检查对炮管形同虚设，只能检出墙体。建议在 §2 现场事实补一条 Launcher BP 外壳碰撞回读结论，别把“不忽略 Launcher”当成既定保护。

### H3. 每帧设 `ThrustStrength` 的 Tick 时序未在稿中确认保留
现有靠 `Thruster->AddTickPrerequisiteActor(this)` + `TG_PrePhysics`（`.cpp:78,109`）保证 Actor 先tick 设力、Thruster 后 tick 施力。新稿改为每帧只改 `ThrustStrength`（§7.3）并在 Actor Tick 内 `AddTorqueInRadians`。稿件应明确保留 `TG_PrePhysics` 与该前置依赖，否则 `ThrustStrength` 可能延迟一帧、AddTorque 需在 PrePhysics 内累积才正确。
