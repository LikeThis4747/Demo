# PCG 机关候选位泊松盘拒绝采样方案（讨论稿）

- 日期：2026-08-11
- 状态：待用户确认；不是实施计划
- 范围：只规划摆锤、冲锤、制导/预判抛射机关的 PCG 选位与生成
- 明确不做：本轮不改机关行为、初始相位、触发方式、伤害、表现、Level0 或正式 UE 资产

## 1. 结论

采用“有限合法候选位上的泊松盘拒绝采样”：

1. Runtime PCG 完成整栋布局和导航验收后，把最终纯空间 Plan 只读交给 Population。
2. Population 先按每种机关的真实空间需求生成合法候选位。
3. 根据整栋总可走格数计算本局期望机关总数，只做一次随机取整，不设置每层配额或固定全图上限。
4. 将候选位按独立随机流打乱；依次检查它与已接受机关之间的最短通行路线距离。
5. 达到最小间距就接受，否则拒绝；达到本局目标数或候选耗尽后停止。
6. 候选耗尽时允许少生成，不偷偷缩小间距，也不把正常的“地图放不下更多”当作整局失败。

这里参考的是 Poisson-disk / dart throwing 的“任意两个样本至少相距半径 r”条件。项目实现是在已有离散候选位和整栋通行图上使用拒绝采样，不是照搬 Bridson 在连续平面上生成新点的 active-list 加速算法，也不另造算法名称。

## 2. 已核对的当前事实

| 项目事实 | 当前真实情况 | 对方案的影响 |
|---|---|---|
| 正式 PCG 高厅 | `HighCeilingRoom_Level0_1x2`，两个相邻的 600 cm 逻辑可走格 | 高厅中心只产生摆锤候选；不是 2×2 高厅 |
| 整栋规模 | 20×12 逻辑网格，600 cm/格，2～4 层；难度定义总可走格约 72～160 | 用整栋总可走格数换算期望机关数 |
| 当前 Population | 只有地刺和磁性物体；仍使用 `OneEveryNCells + MaxCount` | 新机关单独使用新分布设置，先不强制重写旧规则 |
| 当前候选查询 | 只返回普通 WFC 格 Transform，缺少坐标、结构、开口和完整通行图 | 需要一个只读最终 Plan 快照，不能靠 Transform 猜拓扑 |
| 摆锤摆位合同 | Actor 根在地面；当前 DA 为支点高 610 cm、摆长 520 cm、目标摆幅 79°；Actor 局部 X 为铰链轴 | 放在 1×2 高厅中心，让局部 Y/摆动平面沿房间长轴；必须实测硬限位净距 |
| 冲锤摆位合同 | Actor 原点是完全缩回的锤头中心；局部 +X 伸出 450 cm；当前实例根高 100 cm | 任意普通格只要有可安装的封闭墙面即可产候选，不限直走廊 |
| 发射器摆位合同 | 局部 +X 是中性炮向；Trigger 中心在前方 600 cm，半尺寸 500×260×140 cm；当前实例根高 150 cm | 只要求墙后有迎面可走方向和前方空间；拐角、T 口、死端均可成为候选 |
| 开局顺序 | GameMode 先放玩家、追猎者和出口，再调用 Population | 可以精确排除实际占用格，不需要 blanket 排除所有相邻格 |

## 3. 策划控制参数

第一版只保留真正影响策划结果的参数：

| 参数 | 含义 | 建议首轮值 | 说明 |
|---|---|---:|---|
| `ExpectedHazardsPer100WalkableCells` | 每 100 个整栋可走格期望出现多少个三类机关 | 8.0 | 72～160 格地图约得到 6～13 个；只是首轮校准起点 |
| `MinimumRouteSpacingTiles` | 两个机关影响格之间允许的最短通行图距离 | 2 | 不是“每 2 格强制放一个”；只拒绝相邻挤在一起的结果 |
| `BatteringRamWeight` | 合法墙面同时支持两类机关时，冲锤相对权重 | 1.0 | 只控制类型构成，不增加或减少总数 |
| `GuidedLauncherWeight` | 同上，发射器相对权重 | 1.0 | 发射器仍只会出现在满足迎面条件的位置 |
| 冲锤装配偏移 | 以墙内表面和朝内方向为基准的局部位置 | `(50,0,100) cm` | X=50 让缩回锤头回到墙内侧，Z=100 对齐当前实例 |
| 发射器装配偏移 | 同一墙面基准下的局部位置 | `(0,0,150) cm` | 对齐当前两个 Level0 实例 |

不增加以下控制：每层最大数量、连续走廊最多一个、全图固定上限、每隔 N 格强制放置、不同机关各自一套最小半径、柏林噪声密度图。以后只有 Seed Sweep 和玩家实测证明一个参数不够用时，才补新的策划维度。

本局目标数：

```text
Expected = TotalWalkableCells × ExpectedHazardsPer100WalkableCells / 100
Target   = floor(Expected) + 一次按小数部分概率进行的随机进位
```

例：100 格、密度 8.0 时目标是 8；104 格时期望 8.32，同一 Seed 下稳定得到 8 或 9。实际数量可因合法候选不足或最小间距拒绝而低于目标。

## 4. 合法候选位

“候选是否合法”与“候选是否被泊松采中”分开。前者只处理机关能不能合理装在那里，后者才处理全图密度和间距。

| 机关 | 候选来源 | 朝向 | 影响/占用格 | 不额外添加的限制 |
|---|---|---|---|---|
| 摆锤 | 每个 `Kind == HighCeilingRoom` 且满足当前 1×2 合同的结构中心 | 铰链局部 X 沿短轴，摆动平面局部 Y 沿两格长轴 | 高厅的两个可走格 | 不按楼层限量，不用 DefinitionId 字符串猜类型 |
| 冲锤 | 任意普通可走格的每一面封闭墙 | 局部 +X 从墙面指向格内 | 当前普通格 | 不要求直走廊；拐角、T 口、死端都可放；十字口没有墙面，自然没有候选 |
| 制导/预判抛射 | 普通格封闭墙面，且该墙朝内方向对应一个开放边，前方相邻格可走并适合进入 Trigger | 局部 +X 从墙面沿玩家迎面路线 | 安装格 + 前方第一个格 | 不限定“只能转角”；直段尽头、拐角腿、T 口和死端只要能正面遇到都可放 |

共同的硬合法性检查：

- 影响格不能包含玩家出生格、追猎者出生格或 Exit 格；只排除真实占用范围，不 blanket 排除它们所有相邻格。
- 不在楼梯、楼梯净空或高厅上层 clearance 中生成普通墙面机关。
- Transform 必须有限、旋转规范、Scale 固定为 `(1,1,1)`。
- 同一机关自己的运动/触发包围必须落在它声明的影响格和正式模块净空内。
- 被选机关的影响格加入 `ClaimedCells`，后续地刺/磁性物体不再占用同一逻辑格；这只是防止穿插，不是密度配额。

## 5. 距离定义

最小半径使用“玩家实际可走图上的最短路线格数”，不用三维欧氏距离：

- 两个不同楼层但 XY 重叠的位置，不会因为垂直距离很近而被错误排斥。
- 隔着墙看起来很近、实际要绕很远的两处可以同时存在。
- 高厅摆锤用两个高厅格作为影响节点；发射器用安装格和前方触发格；冲锤用自身格。
- 两个候选的距离取两组影响节点之间的最短通行距离。

Plan 已有普通格 OpeningMask、结构 InternalConnections 和 Openings，足以在 Population 内重建同一张无向通行图。整栋上限仅 960 个地址，首版在每次接受机关后做一次多源 BFS 即可，不需要 Bridson 连续空间的背景网格或更复杂的加速结构。

## 6. 拒绝采样流程

```text
读取最终 Plan 和 Population 设置
  -> 重建整栋通行图
  -> 生成并稳定排序全部合法候选（楼层/坐标/墙向）
  -> 用专用 HazardPopulation 随机域计算目标数并打乱候选
  -> 先处理高厅摆锤语义（见第 11 节待确认项）
  -> 依随机顺序考察普通墙面候选
       -> 与已接受影响节点的最短路线距离 >= MinimumRouteSpacingTiles：接受
       -> 否则：拒绝并继续下一个
       -> 同一墙面同时允许冲锤/发射器时，再按两项权重选类型
  -> 达到 Target 或候选耗尽
  -> 生成所选 Actor；任一实际 Spawn 失败则沿用现有原子回滚
```

性质：

- 每个合法候选都有因随机顺序而被选中的机会。
- 输出满足最小间距，但为了控制近似总量，达到 Target 就停止，因此不声称得到“最大化/饱和”的泊松盘点集。
- 同一生成 Seed、同一生成 Plan、同一 Population Profile 必须得到同一位置和类型。
- 使用独立随机子流，新增机关不会仅因多消费随机数就把旧地刺和磁性物体全部洗牌。

## 7. 与现有 Population 的关系

第一版不删除也不改名现有 `FZeroEscapePlacementRule`，地刺和磁性物体继续使用旧的 `OneEveryNCells + MaxCount`。新机关增加独立的 `HazardPlacement` 设置与选位路径：

1. 先选定并生成三类大型机关，取得 `ClaimedCells`。
2. 再执行旧规则；只从其普通格候选中去掉已被大型机关占用的格。
3. 旧规则之间原有语义暂不扩大重构，避免本次接入顺手改掉已经工作的内容。

这能让大型机关获得稳定空间，同时让现有小型内容填剩余空位。

## 8. 失败与降级

| 情况 | 处理 |
|---|---|
| 没有高厅 | 正常为 0 个摆锤，不判失败 |
| 某类候选为 0 | 由其他合法类型继续填目标；没有可替代类型时实际数量降低 |
| 最小间距导致无法达到 Target | 保留已接受结果并记录 `actual < target`；不缩小半径、不换 Seed、不让整局失败 |
| 配置非法、类加载失败、Plan/图不自洽 | Population 失败并原子清理本次已生成对象 |
| 任一 Actor Spawn 失败 | 沿用当前 Population 原子回滚 |
| 机关生成后自身因资产装配非法而 Disabled | 记录为资产/装配错误，不能伪装成正常的候选不足 |

建议日志至少输出：Seed、总可走格、目标数、三类候选数、实际三类数量、间距拒绝数、特殊格拒绝数、是否候选耗尽。

## 10. 验证计划

### 纯值/自动化

- 1×2 高厅只产一个中心摆锤候选，旋转后仍沿长轴摆动。
- 冲锤覆盖死端、拐角、直段和 T 口所有有墙面的位置；不再错误限定直走廊。
- 发射器覆盖能迎面进入的转角腿/T 口/直段尽头，不接受背后无墙或前方不可走的位置。
- 任意两处实际接受机关的通行图距离均不小于配置半径。
- 72、104、132、160 可走格的目标数按密度线性变化且只随机取整一次。
- 候选不足或半径过大时成功返回较少结果；配置非法时明确失败。
- 同 Seed/Plan/Profile 完全复现；不同随机域不扰动 WFC 和旧 Population 随机序列。
- 玩家、追猎者、Exit 只按实际影响格排除，不误删整圈邻居。

### Seed Sweep

- 先跑小批代表 Seed，再跑项目既有规模的批量 Seed。
- 统计 `target/actual`、各机关数量、各层机关数量、最小实际路线距离、候选耗尽率。
- “各层数量”只作为观察指标；第一版不据此强制每层配额。只有大量 Seed 持续出现整层空白，才讨论新的软分布策略。

### UE 资产/运行

- Blueprint/DataAsset 回读、编译、保存；Actor Transform 保持单位缩放。
- 检查摆锤 79° 目标摆幅和 84° 硬限位在正式 1×2 高厅长轴方向的墙面净距。
- 检查冲锤全行程、发射器 Trigger 与炮口不会穿入正式模块墙体。
- Population 生成后重新验证玩家与追猎者可通过、动态导航没有被外壳意外切断。
- 玩家实测关注：地图是否仍有明显大片空白、机关是否经常连续挤在一起、预警是否可读、总体难度是否过高。

## 11. 需要用户确认的一项策划语义

推荐：**每个满足当前 1×2 空间合同的高厅优先放 1 个摆锤，并计入同一个全图 Target；剩余数量再由普通墙面机关填。**

理由：高厅是稀有、专用空间，若把它和数量很多的墙面候选完全等概率混洗，高厅经常会空着；计入总量又不会让摆锤额外抬高整局密度。高厅摆锤仍作为已接受点参与最小路线间距，附近普通机关会被正常拒绝。

备选：高厅摆锤也和所有墙面候选完全等概率参与抽样。这样算法最对称，但出现高厅却没有摆锤的概率会明显更高。

除这一项外，当前方案不需要再增加强制数量或每层规则。

## 12. 参考

- Robert Bridson, *Fast Poisson Disk Sampling in Arbitrary Dimensions*, SIGGRAPH 2007：Poisson-disk 最小距离条件，以及对经典 dart throwing 的高效连续空间实现。
- Alejandro Parada-Mayorga et al., *Blue-Noise Sampling on Graphs*, IEEE TSIPN 2019：在图节点上用最短路径距离描述样本间隔的相关研究。项目只借用“图距离比欧氏距离更符合拓扑”这一点，不实现论文的图信号优化算法。
