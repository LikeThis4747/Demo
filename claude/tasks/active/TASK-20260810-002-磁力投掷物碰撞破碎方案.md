## 关键决策

- 完整 Static Mesh 保持到合格命中，下一帧才生成 GC 替身；Geometry Collection 不参与抓取。
- `UMagneticObjectComponent` 是 Hit 通知、CCD、临时碰撞身份和恢复快照的唯一 Owner。
- Light 窗口仍为 2.5 秒；破碎监听最晚 8 秒结束，避免长期潜伏后随机碎裂。
- 最小破碎冲量默认 1000 kg·cm/s；低于门槛不消费。
- 碎片 ObjectType 为 PhysicsBody，但仅 Block WorldStatic/WorldDynamic，Ignore Pawn/Camera/PhysicsBody；不触发受击、不可抓取、不影响导航。
- `SafetyLifetimeSeconds = 6s`，大于 Remove On Break 最长 3 秒并保留 3 秒异常余量。
- Build.cs 只追加 `GeometryCollectionEngine`，不新增 `Chaos`。

## 风险与回退

- 最大技术风险是 Light 与破碎重复控制同一个 Hit/CCD 状态；修订版已通过共享正式投掷事务消除双 Owner。
- 高速薄墙隧穿由共享事务现有 CCD 负责，并纳入贴墙、斜射薄墙和近地投掷验证。
- 替身 Spawn 失败时保留原 Actor、完整 Disarm、转为 `BreakFailed`，不循环报错。
- 碎片碰撞若仍干扰角色或其他道具，只在 `AMagneticFractureActor` 的单点碰撞契约中调，不在 BP 建第二份配置。
- 最小回退只撤掉破碎组件、替身 Actor 和接线；现有抓取与 Light 链保持不变。
