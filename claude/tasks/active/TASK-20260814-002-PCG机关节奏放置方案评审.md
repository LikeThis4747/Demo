## 阻塞、风险与下一步

- 当前阻塞：无工程阻塞；只待用户现场手感验收，未经验收不把玩法质量标记为完成。
- 风险：原案“附近疲劳值越高、权重越低”在全局抽样下实际会继续推散机关，不能独立形成簇；统一“通过余量”与一次性发射器、物理摆锤、不同路线长度的刺轮不兼容；任意同格复合机关也超出当前逻辑格占用契约。
- 讨论补充：现有 Population 是 `GameMode -> Populator -> 纯值 PlacementPolicy -> PlacementPlan -> Spawn` 的分层结构；普通机关采用“先按难度权重选可行类型，再在该类型内均匀选候选和方向”，资源使用独立随机域并在机关之后规划。
- 映射建议：保留原案的多项信号，但先区分硬过滤、类型选择、候选位置、遭遇状态和诊断；位置类信号先映射到 `[-1, 1]`，再在对数权重空间有界相加并 Softmax 抽样，避免原始乘积的零值、量纲与极端放大问题。
- 评审补充：类型上下文修正成立，但不能只看“全图是否已有周期机关”；应从每类可行候选的最佳少量上下文分数聚合出类型倍率，避免恢复候选数量偏差。固定钟形目标确会造成组压力趋同，目标应由进度趋势和按 `Seed + 组锚点` 派生的确定性变化共同产生。
- 相位边界：同类机关固定周期、实例只变相位是合理设计原则，但当前地刺/冲锤在 `BeginPlay` 固定启动，摆锤是受碰撞扰动的 Chaos 自由摆，发射器一次性触发；刺轮在 `BeginPlay` 自选路线、镜像、方向和相位，且不同路线长度在固定速度下周期不同。真正接入相位需要扩展 PlacementPlan、Populator 的预 BeginPlay 初始化和各机关接口，不能声称只改 Policy。
- 用户确认：刺轮保持统一移动速度和可读运动规律；不同路线只随机归一化路线相位，不为统一绝对周期而按路线长度改变速度。
- 用户确认：刺轮与冲锤组合为强奖励，刺轮与地刺组合为中等奖励；刺轮单独出现始终允许，只做轻微降权，组合关系不得升级为硬约束。
- 用户确认：首版暂不考虑同格复合机关；组合关系按通行路径上的前后相邻格判定。同格机关不进入本轮候选枚举、评分与验收范围。
- 用户确认：玩家名义地面速度调整为 `400 cm/s`。Population 由正式玩家的实际 Class 读取 UE 类默认对象（Class Default Object，CDO）上的 `CharacterMovement.MaxWalkSpeed` 作为纯值输入，不在 Policy 中写死 `400`，也不读取会被 Stop/Slow 改写的实例瞬时值或 Velocity。
- 用户确认：接受完整 Population 总览；首版只为 Population 生成的刺轮接通归一化随机相位，暂不重构地刺与冲锤的启动相位接口。后续修正为首版刺轮只占一格并只使用现有一格路线；连续两格刺轮由两个相邻的一格 Actor 分别放置。
- 一格占用资产依据：官方 MCP 回读 `DA_SpikeWheelHazard_Default`，三条一格路线控制点最大轴向偏移 `0.32` 格；`TileSize=600 cm`、`HurtRadius=65 cm`，运行包络最大约 `257 cm`，小于半格 `300 cm`。
- 核心选择循环：每轮先为各类型的全部合法候选计算有界对数分数；以该类型最佳少量候选的聚合分修正基础类型权重，再抽类型；随后在已选类型内按候选权重抽位置/路线变体。刺轮与其他机关的配对奖励同时进入类型上下文和候选位置分数，单独刺轮只轻微降权、绝不归零。
- 首版合同：Population 每个刺轮只占一个普通格并从现有三条一格路线中确定性选取；冲锤或地刺占用与刺轮前后相邻的通行格时获得强/中奖励。连续刺轮按两个相邻的一格 Actor 处理；同格/运行范围重叠仍属技术硬冲突。
- 调参收敛：初始 `+2.0 / +1.0 / -0.25` 在 512 Seed 下零散刺轮偏多；遵循奖励主导原则，首轮改为刺轮+冲锤 `+3.0`、刺轮+地刺 `+2.25`、无优选搭档 `-0.5`。统计为强 `690`、中 `329`、无优选搭档 `297`、完全单独 `260`，`493/512` Seed 出现组合；类型上下文仍以 `0.5` 强度回写。
- 相位首版建议：仅为 Population 生成的刺轮写入 `Seed + 锚点 + 朝向` 派生的路线种子与 `0..1` 归一化相位；闭环映射一圈，开放路线映射完整往返周期；速度继续由现有刺轮 DataAsset 唯一管理。Level0 手放实例不提供规划配置时保持旧行为。
- 距离合同：两个机关的距离取双方占用格之间的最短通行边数；同格为 `0`、相邻格为 `1`。紧邻组合要求距离 `1`，机关组要求距离不大于组半径 `3`；自动化必须覆盖刺轮+相邻冲锤/地刺的同组与组合得分。
- 频率合同：除组合相对顺序外，Normal 的足量候选固定夹具还要验证平均每局至少一个刺轮组合、至少 `60%` Seed 出现刺轮组合；单独刺轮绝对数量单独记录，偏多时优先调整单独降权而非基础压力。
- 相位已知限制：当前地刺与冲锤都从固定安全阶段启动，源码未使用随机相位；首版关系基本稳定但 Population 无法主动错开/对齐，组压力只作近似诊断。显式相位配置列为第二步候选，不扩入首版。
- 文档同步范围：正式实施时除 `HAZARD_PLACEMENT_RULES.md` 和 `DOC/README.md` 外，还必须同步 `DOC/Design/CHALLENGE_DESIGN.md` 第 5 节的旧两级间距、硬窄点、同类型必坏和固定可读距离表述。
- 资源首版建议：机关阶段输出纯值组记录，资源仍用独立随机域和 `10/100` 总预算，只对高压力组进入侧的安全格加权；不允许资源进入刺轮占用格，也不把资源当作无解组合的补丁。
- 资源数据流：资源随机域可继续独立，但语义应读取机关阶段产出的纯值组诊断；若资源是通关必需，则它成为硬可行性合同，预算不足时应回退当前组而不能仅靠软加权或换 Seed。
