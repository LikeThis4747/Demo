## 已核验事实

- 当前正式高厅是 `HighCeilingRoom_Level0_1x2`。
- 项目正式设计把磁力物定义为逃脱、投掷、压制和防御所需的核心物理资源，并要求危险与资源分别通过生成验证。
- 现有 `AZeroEscapeGameplayPopulator` 已承担统一 Owner、Actor 登记和原子回滚，适合作为唯一填充总控，不需要再建两个 Manager。
- 官方 UE5.8 MCP 本轮连接正常，已回读 `/Game/ZeroEscape/Generation/Population/DA_Population_Default`：
  - 地刺：旧规则约每 4 个候选一处、最多 8 处、每处两个、间距 300 cm、仅直道、避开出生/出口邻格、Z=0。
  - 磁力物：旧规则约每 4 个候选一处、最多 8 处、每处一个、不限直道、不避开邻格、Z=50 cm。
- 旧 `FZeroEscapePlacementRule` 在 C++ 中只被 Profile、GameplayPopulator、旧预算 Policy 和对应测试消费，可在实现时直接替换。
- 三个新增机关的 Blueprint/Class 已存在；本任务只规划 PCG 选位，不修改其行为、伤害或表现。

## 稳定架构决策

- [x] 空间生成、流程对象、玩法填充保持清晰分工；Population 只消费最终 Plan。
- [x] Population 内部分成机关阶段与资源阶段，但仍是一套 Actor/Profile/Policy/Spawn 事务。
- [x] 机关层包含摆锤、地刺、冲锤、制导发射器；资源层当前只包含磁力物。
- [x] 机关层先执行；资源层只避让机关实际操作范围，不能抢机关配额或合法点。
- [x] 两层分别使用有限候选位置上的泊松盘式图距离拒绝采样。
- [x] 使用 `HazardPopulationPlacement` 与 `ResourcePopulationPlacement` 两个确定性随机域；资源调参不能洗牌机关。
- [x] 高厅摆锤为结构必放内容并计入机关目标。
- [x] 不增加每层配额、每类硬上限、动态 Director、通用注册表、策略 UObject、每类采样器或新 Manager。
- [x] 不继续保留泛化 `bStraightCorridorOnly`；地刺按实际资产覆盖和进入方向枚举合法候选。
- [x] 主路线资源空窗首轮纳入 Seed Sweep 观测；没有稳定“追逐区”语义和阈值前，不先建分区配额框架。
- [x] 用户确认可以按分层架构继续进入正式实施规划。
- [x] 普通机关改为“类型先、位置后”的加权采样，避免候选多的地刺/冲锤吞掉发射器稀缺位置；不增加每类保底。
- [x] 密度面积使用普通格与高厅可走格，楼梯仅作为图连接；跨层冲突只使用实际操作格。
- [x] 玩家、追猎者、Exit 只按实际占用/操作范围避让，不保留泛化邻格开关。
- [x] 资源候选空间足够大，不增加 `MinimumResourcesPerMap` 第二数量控制；低于密度目标记录回归告警，但不让整轮 Population 失败。
- [x] 资源先按整栋通行图的泊松间距选锚点格，再在格内扣除真实占地半径的安全矩形中均匀随机 X/Y，不再固定地板中心；本轮不额外改变磁力物朝向。
- [x] 用户确认 Population 支持 Easy/Normal/Hard 分档；只分密度、间距和普通机关权重，资产 Class 与装配数据全难度共享，三档初值可先相同。
- [ ] 用户确认实现级数据结构、失败语义和验证范围。
- [ ] 候选统计后确定两层初始密度、间距、磁力物占地半径和普通机关权重。
