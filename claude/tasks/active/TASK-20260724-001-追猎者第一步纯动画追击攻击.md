## 目标与验收

- 目标：用官方 Manny 骨架，在 Level0 灰盒里做出一个**追猎者**：能感知玩家、持续追击、进入攻击距离后播放攻击蒙太奇并冷却回追。**全程纯动画，不涉及任何物理受击**（物理受击属第二步）。
- 验收：
  - 追猎者能感知玩家并在 NavMesh 上持续寻路追击。
  - 进入攻击距离播放攻击蒙太奇，冷却结束后继续追。
  - 玩家跑远/绕柱时追猎者重新寻路，不卡死。
  - 全部参数走 DataAsset，默认关 Tick，无硬编码资源路径。
- 非目标：不做物理受击/失衡/倒地（第二步）；不做真实伤害判定（攻击 Notify 只发事件，先不结算后果）；不做 EnemyBase 父类；不接 PCG 运行时 NavMesh 重建；不找/导入敌人美术资产。

## 架构原则（承接讨论结论）

- **抽象能力（组件/数据）趁早，抽象继承树延后**：第一步只做 `APursuerCharacter` 一个具体类，不做 EnemyBase；能力用组件、参数用 DataAsset。
- **AI 用 C++ 状态机**，不用行为树：逻辑简单（察觉→追→到距离→攻击→冷却→回追），C++ 更省更可控，符合项目"能 C++ 尽量 C++"，也绕开 MCP 行为树短板。
- **默认关 Tick**：AI 状态机用 Timer 驱动。
- **攻击表现与后果分离**：动画 Notify 只发"攻击生效"事件，不把伤害/击退写死在 Notify（为第二步和多种追猎者复用留口）。
