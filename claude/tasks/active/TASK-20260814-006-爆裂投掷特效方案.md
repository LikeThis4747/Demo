## 只读审计结论

- `BP_MagneticProp` 的可见刚体为 `StaticMeshComponent`，支持 UE 的 Overlay Material；可以用项目自建的透明无光照材质覆盖整件道具，利用材质 `Time/Sine` 自行闪烁，不增加 Tick。
- 持有阶段已有 `OnExplosionModeChanged`，事件携带精确持有刚体；正式投掷阶段由 `UMagneticObjectComponent::ArmThrownImpact/DisarmThrownImpact` 管理；真实爆炸点已在 `TriggerExplosion(ExplosionOrigin)` 收口。
- UE Niagara 插件提供 `/Niagara/DefaultAssets/Templates/Systems/SimpleExplosion`，说明为 sprite core、速度对齐火花和定向网格；项目另有可候选的火焰、火花与蒸汽/烟雾 Cascade 资源，但目前没有项目自有的手榴弹 Niagara System。
- 官方 MCP 可创建完整闪红材质、复制资产和装配引用；本地 MCP 也未提供 Niagara 发射器堆栈编辑动作。因此可全自动完成“自建红色闪烁 Overlay + 复用爆炸模板/现有烟雾组合 + 运行时接入”的 Demo 第一版，但从零精雕 Niagara 的发射器层、曲线和渲染器仍需要人工在 Niagara Editor 中调整。
