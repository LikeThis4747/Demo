# 机关设计深化：陷阱的三条通用原则

> 日期：2026-08-13
> 性质：设计讨论稿。确认后并入 `DOC/Design/CHALLENGE_DESIGN.md` 第 4 节。
> 出发问题：低摩擦如何成为合理玩法；压力板+冲锤为何「感觉不对劲」；如何防止玩家无视机关。
> 命名说明：「斗牛结构」「陷阱资源化」「刹不住」为本项目内部命名，不是 UE 官方概念或行业术语。

## 一、三条原则（同时回答你的三个问题）

你的三个疑问其实是同一个问题的三个侧面。先给原则，再逐个套用。

### 原则一：陷阱必须默认对玩家构成不可绕开的威胁

这条直接回答你问题 3 的担忧「玩家直接无视跑过去怎么办」。

| 陷阱性质 | 玩家行为 | 结果 |
|---|---|---|
| 只对 AI 有害 | **无视它** | 你做的东西白费 |
| 对玩家有害但可绕开 | **绕开它** | 同样白费 |
| **对玩家有害且不可绕开** | **必须学会处理** | 学会之后自然发现能用它打 AI ✓ |

**关键因果：玩家不是因为「这个陷阱能打 AI」才去研究它，而是因为「我必须过这里」才被迫理解它，理解之后才发现能用。**

所以设计顺序永远是：先让它威胁玩家，再让它可被玩家利用。反过来做必然失败。

### 原则二：诱饵必须是玩家自己

这条回答你说的「感觉不对劲」——我认为你的不适感来源很明确：

> 在「玩家跑过去、站安全区、等 AI 踩板」这个设计里，**玩家是安全的旁观者。**

玩家没有承担风险，没有做出有难度的操作，只是看 AI 犯错。这是「AI 很笨」的体验，不是「我很强」的体验。

**正确结构：玩家必须自己站在危险位置，才能把 AI 引进来。风险共担。**

这就是斗牛：斗牛士必须站在牛的冲锋线上，红布才有意义。站在栅栏后面挥红布，没有人会觉得精彩。

### 原则三：触发与生效之间必须有可反应的时间差，且玩家能躲、AI 不能躲

这条回答你的「靠近就触发 = 100% 命中或不命中」。

问题不在触发方式，在于**触发即生效**。只要中间插入一段有明确视听预警的延迟：

- 玩家：获得反应窗口，躲开是技巧
- 追猎者：我们不给它避让逻辑，它会继续朝玩家推进，因此大概率被命中

**「玩家能躲、AI 不能躲」这个不对称本身就是玩法。** 不需要复杂设计，只需要预警期。

而且这条同时解决了「固定周期太平庸」——不是靠周期制造威胁，而是靠玩家自己触发后的反应检定。

## 二、压力板 + 冲锤：斗牛结构

### 2.1 你的顾虑与修正

你说「除非压力板就设置在冲锤的攻击路线的地板上，否则根本打不中玩家」——**这句话本身就是正确答案。**

压力板**必须**在冲锤的攻击路线上。这不是妥协，这是设计要求。

因为只有这样，才满足原则一（玩家踩上去会被砸，不可无视）和原则二（玩家必须站在危险位置才能引 AI）。

### 2.2 画面感

> 一条两米宽的走廊，唯一通路。地面中段有一块明显的金属压板，磨得发亮。压板正上方的侧壁里，收着一根液压冲锤。
>
> 你踩上压板。**咔——** 液压泵开始加压，锤头从墙里探出半截，蓄势待发。你有大约一秒。
>
> **第一次，你不知道会发生什么。** 你站在那里看，锤子砸出来，把你钉在对面墙上。
>
> **第二次，你学会了：** 踩上去就往前冲，锤子在你身后砸空。
>
> **第三次，你有了别的想法。** 追猎者在你身后十米。你踩上压板，但这次不跑——你站在原地，等它。
>
> 锤头探出。追猎者冲进走廊，直奔你。八米、五米、三米。
>
> 你在最后一刻侧滚闪开。液压锤砸出来，正中它的胸口，把它轰进走廊尽头的墙里。
>
> 但如果你早跑了半秒,它还没进来,锤子砸空——液压泵要十秒才能重新加压。而它已经到你面前了。

### 2.3 这个设计为什么成立

| 要求 | 如何满足 |
|---|---|
| 不可无视 | 压板在唯一通路上，踩上去就触发 |
| 不是 100% 命中 | 有约一秒预警期，玩家可以跑掉 |
| 玩家承担风险 | 想引 AI 就必须自己站在锤击线上当诱饵 |
| 有技巧上限 | 闪开时机决定成败：早了打空，晚了自己被砸 |
| 失败可理解 | 「我跑早了」或「我跑晚了」，不是随机死亡 |
| AI 不需要智能 | 它只管朝玩家推进，不需要理解陷阱 |

**最关键的一点：玩家的技巧体现在「敢等多久」。** 这是一个纯粹的胆量与时机检定，没有任何隐藏信息，失败完全归因于自己的判断。

### 2.4 补充：冷却是风险的一部分

砸空之后需要一段较长的重新加压时间。这让「赌一把」有真实代价——不是「打空了再来一次」，而是「打空了这个陷阱这段时间内没了，而它就在你面前」。

## 三、悬挂重物：陷阱转化为资源

### 3.1 直接回应「玩家会无视」

按原则一处理：**重物挂在必经窄点正上方，玩家从下方通过时锁链断裂。**

它不是「一个你可以选择打落的道具」，而是「一个你经过就会掉的不稳定威胁」。

但这里有个真正的设计问题：**掉过一次就没了，玩家来不及利用。**

### 3.2 解法：两段式 + 落地后变资源

这是我认为这个机关最有价值的部分。

**第一段（威胁）**：玩家从下方通过 → 锁链断裂声 → 重物开始明显摇晃 → 约 1.5 秒后掉落。玩家必须加速通过或退回。

**第二段（资源）**：重物落地后，成为一个**重型磁力物**——比铁桶重得多，可以被吸取、持有、投掷。

于是这个机关经历了：

```
悬挂威胁 → 玩家必须处理 → 掉落 → 变成玩家最重的武器
```

### 3.3 画面感

> 走廊上方悬着一个铸铁配重块，比人还大。锁链已经锈断了一半。
>
> 你跑过它下方。**嘎啦——** 锁链绷断，头顶传来沉重的摇晃声。你本能地加速冲出，配重块砸在你身后的地面上，整条走廊震了一下，灰尘从天花板落下来。
>
> 现在它躺在地上。你回头看了它一眼。
>
> 追猎者的脚步声从转角传来。你伸手把配重块吸起来——它太重了，悬在你身前时你只能慢慢走，视野被它挡住一半。
>
> 但当追猎者从转角冲出来的那一刻，你把这一吨铁砸了出去。

**这比任何"打落陷阱砸中AI"的设计都好**，因为它把一次性陷阱变成了持续可用的资源，而且天然带着"重物拖累移动"的取舍。

### 3.4 进阶用法自然涌现

玩家熟练后会发现更多玩法，我们不需要专门设计：

- 不去下面走，先用投掷物打落锁链，节省风险
- 引追猎者从下方通过，让它自己触发（它不知道躲）
- 把落地的配重块留在原地当路障，或搬到别处备用

**这些都是玩家自己发明的，不需要我们编排。** 好机制的标志就是它能生出设计者没想到的用法。

### 3.5 与摆锤的区分

摆锤是「持续周期威胁」，悬挂重物是「一次性威胁 + 永久资源」。两者生态位不同，不重复。

## 四、低摩擦：不要做「滑倒」，做「刹不住」

### 4.1 「滑倒」是错误目标

你问「滑倒要怎么做，是否要额外动画」——我的建议是**不要做滑倒**，三个理由：

| 问题 | 说明 |
|---|---|
| 需要动画 | 倒地 + 起身动画，成本高 |
| 玩家失控 | 追逐中失去控制是高挫败设计，玩家会认为「我不是因为决策失误而死」 |
| 无技巧空间 | 滑倒是一个二元结果，没有「做得好」和「做得更好」的区别 |

### 4.2 正确目标：能转向，但不能减速

| | 滑倒 | 刹不住 |
|---|---|---|
| 玩家状态 | 倒地，失去控制 | **站着，仍能转向** |
| 受限的能力 | 全部 | **只有减速** |
| 动画成本 | 需要倒地+起身 | **零，正常跑步动画** |
| 玩家感受 | 被剥夺 | 被挑战 |
| 技巧空间 | 无 | 进入速度、转向时机 |

**「不能减速」是一个纯粹的能力限制，不是失控。** 玩家仍然完全掌握方向，只是必须提前规划。

### 4.3 画面感：滑道必须有终点和岔路

低摩擦本身不构成玩法。它必须与地形组合：

> 走廊地面突然变成漏满油的钢板。你看得见前方十五米是尽头——一面墙，墙前是一排地刺。
>
> 而在滑道中段，右侧有一个岔路口。
>
> 你必须在滑行中精确地在岔口转向。冲太快会滑过岔口撞上地刺；但慢慢进入的话，追猎者就跟上来了。
>
> 你选择全速冲进去，在岔口前一刻猛地右转——擦着墙角滑进侧道。
>
> 身后追猎者也冲进了滑道。它比你重、比你快，而且它不会转向——它的冲撞攻击在油面上完全失控。它笔直滑过岔口，撞进那排地刺里。

### 4.4 对追猎者的不对称惩罚

这是低摩擦的真正价值：

- **玩家**速度较低、可主动减速、会规划路线
- **追猎者**主攻击是助跑跳跃与冲撞，高速直线运动在低摩擦地面必然失控、滑过头、撞墙

**所以低摩擦是天然对玩家有利的战术地形**，玩家学会「把它引到油面上」就是掌握了这个机关。

附带：磁力物在低摩擦地面会滑行很远，可以形成「远距离送物体」的用法。

### 4.5 但我必须诚实指出它的真实成本

**低摩擦的成本不在技术上，在关卡结构上。**

技术上很便宜（不需要动画，只需调整角色移动的地面摩擦与制动参数，不涉及 Physical Material）。

但它要求 PCG 生成一个特定结构：**足够长的直线滑道 + 明确的尽头危险 + 中段的岔路**。

这三者同时满足的格子组合，在当前 WFC 生成中不能保证出现，可能需要新的房间模板或放置约束。**这个成本高于机关本身。**

### 4.6 我的建议

**低摩擦排在最后，且只在有富余时间时做。** 若要做，采用最低成本形态：

> 滑道 = 一段直走廊 + 尽头是转角（不是岔路，就是普通的 90 度转角）

玩家滑过头就撞墙（轻微伤害 + 短暂停顿），追猎者滑过头撞墙则失衡。不需要岔路，不需要尽头放地刺，**利用 WFC 本来就会生成的「直走廊接转角」结构**即可。

这样成本降到最低，虽然戏剧性弱于 4.3 的画面，但保留了「不对称惩罚」这个核心。

## 五、修正后的优先级

原则一是筛子：**能否做到「对玩家不可绕开的威胁」，决定一个机关值不值得做。**

| 机关 | 不可绕开 | 玩家承担风险 | 有反应窗口 | 关卡结构成本 | 结论 |
|---|---|---|---|---|---|
| **压力板 + 冲锤** | ✅ 压板在唯一通路 | ✅ 必须当诱饵 | ✅ 约一秒预警 | **低**（直走廊即可） | **最推荐** |
| **悬挂重物** | ✅ 挂在必经点上方 | ✅ 必须从下方过 | ✅ 1.5 秒摇晃 | **低**（走廊上方） | **推荐** |
| 刺轮 | ✅ 会追你 | — | ✅ 可被打翻 | **无**（自己移动） | 推荐 |
| 低摩擦 | ✅ 铺满通路 | ✅ 自己也会滑 | ✅ 可提前减速 | **高**（需要特定地形） | 最后做 |

**压力板+冲锤和悬挂重物都只需要「一段走廊」这个 WFC 必然会生成的结构，这是它们优先级最高的原因。**

## 六、一个共同的收尾要求

三个机关都需要同一件事才能成立：**玩家必须能看懂它。**

- 压力板：踩上去要有明确的加压声 + 锤头探出的视觉预警
- 悬挂重物：锁链断裂声 + 明显摇晃 + 地面阴影
- 低摩擦：地面材质必须一眼可辨（油污 / 结冰）

**没有这些，三个机关全部退化为随机死亡。** 这再次说明音效与特效是玩法前提，不是打磨——它们决定了机关是「挑战」还是「不公平」。

## 七、需要制作人决策

1. **压力板 + 冲锤采用斗牛结构吗？**（压板在锤击线上、有约一秒预警、砸空后长冷却）这是我认为最值得做的一个。
2. **悬挂重物是否采用「落地后变重型磁力物」？** 这一条把一次性陷阱变成持续资源，我认为是它成立的关键。
3. **低摩擦是否降到最后、并采用「直走廊 + 转角」的最低成本形态？** 或者直接砍掉，把时间留给前两个。
4. **预警时间是否需要按难度调整？**（Easy 更长）我倾向不做，保持单一手感更容易调好。
