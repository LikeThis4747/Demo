## 一、同意拆分，但阶段一缺一块

你的拆分判断正确：光球与爆裂投掷不可分，「攒能量总要有事能做」是对的。

但**只做阶段一，会撞上和现在完全一样的问题**：

```
当前规则：跑到出口就赢
  → 玩家最优策略：直线冲刺
    → 死胡同是主动绕路（增加路程 = 增加被追上次数）
      → 理性玩家不会去拿光球
        → 光球和爆裂投掷都用不上
```

这正是我们这轮讨论的起点：**东西做好了，但玩家没有理由用。**

即使速度关系改成追猎者更快，玩家被迫应战时也会用**普通磁力箱**（沿路都有，今天验收的 Population 放了 13 个），而不会专门绕进死胡同换一个更强的手段。绕路的成本是确定的，爆裂的收益是不确定的。

**换句话说：阶段二（守场）不是阶段一的锦上添花，而是阶段一的「用途」。** 依赖方向和直觉相反。

---

## 二、解法：让光球同时是钥匙和弹药

不需要把守场提前。只加一条规则：

> **出口需要 N 个光球才能开启。**

同时保留光球的原用途。于是光球有两个互斥的消耗路径：

| 用途 | 效果 |
|---|---|
| **交给出口** | 计入开门进度（例如 3 个开门） |
| **就地消耗** | 换一次爆裂投掷（保命 / 击倒追猎者） |

**这一条同时解决三件事：**

1. **光球从「可选」变「必需」** — 玩家必须进死胡同，死胡同的风险回报结构才真正成立
2. **产生真正的资源两难** — 这是全案最有价值的一处张力
3. **省掉了做「沿途目标」的工作** — 我上午报告里的 P0-2（目标链）本来要新做目标 Actor、交互、计数；现在光球一个 Actor 同时承担「钥匙」和「弹药」两个职责

### 那个两难长什么样

> 你手上有 2 个光球，出口需要 3 个。
>
> 前面走廊里追猎者正朝你冲过来，你身边只有一个空油桶。
>
> 你可以用光球换一次爆裂——把它掀翻在地，稳稳走过去。但那样你就只剩 1 个，还得再进两个死胡同。
>
> 或者你硬着头皮用油桶砸它一下，赌能挤过这个走廊。

**这就是「弹药经济」**，和生化危机决定「这只丧尸值不值得开枪」是同一个结构。它不需要任何新系统，只是同一个资源的两条消耗路径。

而且它自动产生难度曲线：玩家越接近开门，手上的救命资源越少——**终局压力自然升高**，不需要人为编排。

## 三、阶段一（含出口锁）的完整闭环

```
开局：追猎者略快于你，被追上是必然，不是意外
  │
  ├─ 主路线：通往出口，沿途有普通磁力箱（普通手段）
  │
  └─ 死胡同：光球
       ├─ 收益：一枚钥匙，或一次爆裂
       └─ 风险：唯一出口可能被堵，要用物理脱身
  │
出口：需 3 枚光球
  ├─ 不足 → 门锁着，必须继续找
  └─ 集满 → 撤离，胜利
  │
全程决策：这枚光球留着开门，还是现在花掉保命？
```

**这个闭环不依赖守场，可独立交付。** 守场变成纯粹的加分项——它会让终局从「走进出口」升级为一场硬仗，但没有它游戏也是完整的。

这样你的优先级判断就成立了：**先做 1（含出口锁），2 看时间。**

## 五、关于阶段二你列的特效

你提到「关门特效、终点充能特效、按机关读条」。有一处要提醒：

**「按机关读条」不要做成持续读条**（那是我 v1 被你否掉的东西）。启动装置应该是**瞬时**的——按一下，门落下，倒计时开始。难点在守住 30 秒，不在按按钮那 2 秒。

其余两项特效方向没问题，但它们属于 L4，建议和「撞击音效 / 追猎者脚步声 / 爆炸特效」放在同一天一起做，不要分散。

## 六、今天必须先完成的三项前提

阶段一的验证依赖这三项，它们优先于光球：

1. **Recast 验证** — PCG 生成后 NavMesh 建不起来则追猎者不动，光球和爆裂都无法验证。全项目唯一单点故障
2. **速度关系修正** — 追猎者必须追得上，否则「被追上是必然」这个前提不成立，光球依然没用
3. **跳跃攻击收口** — 代码已落盘未提交，需构建与验收。没有真实威胁，爆裂投掷无从谈起

**这三项不过，阶段一做完也看不出效果。**

## 八、需要制作人确认

1. **接受「出口需 N 个光球」这条追加规则吗？** 这是阶段一能否独立成立的关键，0.25 天。
2. **出口需要几个光球？** 建议 3 个。同时死胡同光球总量建议 5~6 个，让玩家有 2~3 个的余量可以花在爆裂上——**这个余量就是两难的空间**，太少则不敢花，太多则没压力。
3. **一次爆裂消耗几个光球？** 建议 1 个，让「花掉」的决策频繁发生。若设为 2 个则爆裂太重，玩家永远不敢用。
4. **光球是即时计入还是要带回出口？** 建议**即时计入**（碰到就+1）。若要求带回，会和「手只能拿一个」冲突，且增加搬运逻辑，4 天内不划算。
5. **是否接受砍掉物理轻受击？**（v3 第六节的建议仍然有效）
