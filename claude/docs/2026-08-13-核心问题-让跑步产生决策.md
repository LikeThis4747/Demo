# 核心问题：让「跑」本身产生决策

> 日期：2026-08-13
> 性质：设计讨论稿。取代前两版机关讨论中关于「压力板」「悬挂重物」的方案。
> 触发：制作人指出「周期机关 + 诱导落点冲锤已经实现了」「最大的问题是玩家一直跑就行了」。
> 命名说明：「堵塞物」「障碍即资源」「强制停留点」为本项目内部命名，不是 UE 官方概念或行业术语。

---

## 一、先承认：我上一版没有提供新东西

制作人的判断正确。「周期机关放窄点 + AI 不避让」和「诱导跳跃落点」——现有的循环冲锤已经实现了这两件事：追猎者本来就会撞上冲锤，玩家本来就可以在冲锤前停留吸引它。

我把已经存在的东西重新描述了一遍，没有解决任何问题。

**真正的问题不在机关种类，也不在机关摆放，而在于：玩家没有任何理由停下来。**

---

## 二、为什么「一直跑」是最优解

这是一个数学结论，不是玩家偏好：

| 行为 | 成本 | 收益 |
|---|---|---|
| **一直跑** | **零** | 接近胜利 |
| 停下来拿资源 | 时间 + 被追上的风险 | 一个可能用不上的箱子 |
| 停下来打 AI | 时间 + 风险 | 换来时间——**但我本来就在跑，不需要额外时间** |
| 停下来利用机关 | 时间 + 风险 | 同上 |

**关键矛盾：玩家停下来战斗的收益是「时间」，而玩家停下来的成本也是「时间」。这笔交易永远不划算。**

这解释了为什么增加机关种类、改进机关摆放都无效——**所有这些设计都试图让玩家「主动选择」停下来，而在当前结构下停下来永远是亏的。**

### 光球方案的局限

我之前提的光球（`ENDGAME_GAMEPLAY_DESIGN.md` 阶段一）也是同一类设计：它是**可选的诱惑**。

玩家的行为会变成「跑到死胡同拿光球 → 跑到出口」。仍然是跑，只是路线变长了。光球解决了「玩家为什么进死胡同」，但没有解决「玩家为什么停下来」。

**诱惑无法对抗「跑」的零成本。只有强制可以。**

---

## 三、解法：从「可选诱惑」改为「强制停留」

### 核心设计：堵塞物 —— 障碍即资源

在走廊、门口等必经窄点，放置**堵住通路的重型磁力物**。

玩家必须用磁力把它拽开才能通过。

```
玩家冲到窄点 → 路被堵住 → 必须停下 → 用磁力拽开（需要时间）
   → 追猎者逼近 → 拽开的瞬间，手上多了一个重物
   → 选择：扔掉继续跑 / 转身砸它 / 带着走
```

### 为什么这个设计解决了根本问题

| 问题 | 如何解决 |
|---|---|
| 玩家不会停下来 | **不是选择，是必须** |
| 停下来没有收益 | **停下来的产出就是武器** |
| 玩家会无视机关 | **无法无视，路被堵着** |
| 需要新机关系统 | **不需要，磁力系统已完整实现** |
| 不够物理 | **这是纯物理玩法：用磁力搬开重物** |

**最关键的一点：障碍本身就是武器。** 玩家清障碍这个动作，同时完成了「被迫停留」和「获得资源」，两件事合成一个操作。

### 画面感

> 你冲进走廊，前面的门半开着，一个沉重的铁柜卡在门缝里。过不去。
>
> 你停下来，用磁力抓住铁柜。它很重，拽动需要一秒多，柜子在门框上刮出刺耳的声音。
>
> 身后的脚步声越来越近。你能听见它已经拐过了上一个转角。
>
> 柜子被拽出来的瞬间，路通了。它悬在你身前——你现在手上有一个几十公斤的铁柜，而追猎者在你身后五米。
>
> 你可以立刻扔掉它冲过去，赌自己跑得比它快。
>
> 或者转身，把这个柜子砸在它脸上。
>
> 又或者带着它走——但那样你的速度会慢下来，视野被挡住一半。

### 由此产生的持续决策

清开障碍后，玩家手上有一个重物，每次都要重新决定：

| 选择 | 代价 | 收益 |
|---|---|---|
| 扔掉继续跑 | 失去武器 | 保持最高速度 |
| 转身砸 AI | 消耗武器 + 承担停留风险 | 数秒安全距离 |
| 带着走 | **持续减速** | 遇到威胁时手上有东西 |

**这三个选择在每个堵塞点都会重新出现一次。** 这就是「跑的过程中产生决策」——不需要玩家主动寻找战斗，战斗机会自己送上门。

---

## 四、关于悬挂重物：建议砍掉

你的质疑是对的，而且是决定性的：

> 玩家为什么不直接用资源物投掷，或者干脆什么都不管直接往前跑？

**因为它需要玩家「多做一步」，而多做的那一步没有必要性。**

任何「玩家可以选择触发」的机关都会撞上同一堵墙：只要不触发也能过去，玩家就不会触发。

**堵塞物没有这个问题，因为它不是「可以触发的机关」，而是「必须处理的障碍」。**

建议用堵塞物完全替代悬挂重物。两者提供的体验（获得重型武器）相同，但堵塞物是强制的，悬挂重物是可选的。

---

## 五、还有一个更基础的问题：玩家不知道往哪跑

这一条独立于机关设计，但可能是无聊感的另一个来源。

**项目没有小地图，出口位置未知。** 因此玩家的「一直跑」实际上是「一直瞎逛」——他不是在做「走哪条路」的决策，而是在随机试探。

这会造成两种糟糕体验：

1. **迷路**：反复经过同一区域，找不到出口，追猎者一直在后面
2. **决策消失**：迷宫的分支路线失去意义，因为玩家无法判断哪条更好

**没有方向感，任何路线设计都无法被玩家感知。** 玩家不会觉得「我选了危险的近路」，只会觉得「我随便拐了个弯」。

### 低成本解法

不需要做小地图，只需要给出方向：

| 方案 | 成本 | 效果 |
|---|---|---|
| 出口方向的光柱 / 远处可见的高亮标识 | 低 | 玩家始终知道大方向 |
| HUD 边缘的方向指示箭头 | 低 | 同上，更精确 |
| 出口低频音效（远距离可闻） | 低 | 符合项目的听觉设计方向 |

**建议至少做一个。** 有了方向感之后：

- 玩家的移动从「瞎逛」变成「朝目标推进」；
- 迷宫的绕路才被感知为绕路；
- 死胡同才被感知为风险（因为玩家知道自己偏离了方向）；
- **堵塞物的停留成本才有意义**（我知道出口就在那边，但我被堵住了）。

这一项的性价比可能高于任何一个机关。

## 六、修正后的优先级

| 项 | 开发量 | 解决什么 | 优先级 |
|---|---|---|---|
| **追猎者速度 > 玩家 + 持续追击** | 参数 + 少量逻辑 | 「跑」不再安全 | **最高** |
| **堵塞物（障碍即资源）** | 低（复用磁力系统） | 「跑」被强制中断，且产出武器 | **最高** |
| **出口方向指示** | 低 | 「跑」有方向，决策可被感知 | **高** |
| 持有重物减速 | 参数 | 让「带着走」有真实代价 | 高 |
| 光球 + 爆裂 | 中 | 死胡同价值 + 玩家能力 | 中 |
| 刺轮 | 低 | 可击杀的正反馈 | 中 |
| ~~悬挂重物~~ | — | **砍掉**，被堵塞物替代 | — |
| ~~压力板~~ | — | **砍掉** | — |
| ~~低摩擦~~ | — | **砍掉** | — |

### 这四项组合起来的效果

```
追猎者更快 → 一直跑会被追上，必须偶尔处理它
堵塞物     → 强制停留，且每次停留都产出一个武器
持物减速   → 带着武器跑有代价，形成持续取舍
方向指示   → 玩家知道自己在朝哪跑，路线选择有意义
```

**四项都不是新玩法系统，全部是给现有系统加约束。** 而它们合起来直接解决「玩家一直跑就行了」。

---

## 七、堵塞物的设计要求

若采纳，以下几点需在实施方案中明确：

1. **必须保证可解**：堵塞物必须能被玩家的磁力可靠抓取，不能因为卡在几何里而无法移动，否则会造成死局；
2. **数量控制**：不是每个窄点都堵，否则会变成烦人的开门模拟器。建议按难度控制每局数量；
3. **清开后保持通畅**：玩家把它扔到别处后，该通路应保持可通行，不要求玩家再次处理；
4. **追猎者能否通过堵塞物**：建议追猎者可以直接推开或撞开（体型与力量设定合理），避免它被永久挡住；这同时意味着堵塞物不能被玩家当作封路手段；
5. **拽取时间**：需要足够长以形成压力，但不能长到让玩家必然被追上。这是核心调参项。

## 八、需要制作人决策

1. **接受「堵塞物 = 障碍即资源」作为解决「一直跑」的主方案吗？** 我认为这是本次讨论里唯一真正解决该问题的设计。
2. **确认砍掉悬挂重物、压力板、低摩擦？** 三者都属于「玩家可以选择不理会」的机关。
3. **是否加出口方向指示？** 这一项独立于机关，但可能是无聊感的另一个主要来源。
4. **堵塞物是否需要多种形态？**（铁柜 / 管道 / 集装箱）我建议首版只做一种，用现有静态网格，把时间留给表现层。
