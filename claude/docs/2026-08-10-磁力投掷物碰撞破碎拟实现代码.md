# 磁力投掷物碰撞破碎——拟实现代码

> 状态：2026-08-10 讨论稿；Geometry Collection 资产原型已完成并由用户做过一次落地破碎测试，尚未授权把本稿写入 Source、Blueprint 或关卡。
>
> 本稿只记录下一阶段准备实施的代码与资产接线。当前工作区还有制导机关任务的并行 C++、Blueprint、DataAsset 和 Level0 改动；该任务收口并重新完成全工作区 Git 基线门禁前，不得实施本文代码。
>
> `Unarmed / Armed / BreakQueued / Consumed / BreakFailed` 是本项目拟使用的内部状态名，不是 UE 官方概念；直白含义分别是“不会碎”“正式投掷后等待首次命中”“已经命中、等待安全替换”“原物体已消耗”“替身失败、保留原物体”。

## 1. 本轮结论

第一阶段只完成这一条闭环：

```text
完整 Static Mesh 磁力物
    -> 玩家成功抓取时取消旧破碎资格
    -> 只有 ThrowHeldObject 正式投掷才武装
    -> 第一次 Blocking Hit 只登记一次
    -> 下一帧生成 Geometry Collection 替身
    -> 替身继承当前 Transform、线速度和角速度
    -> 显式 CrumbleActiveClusters
    -> Remove On Break 清除碎片
    -> 替身成功后才销毁完整磁力物
```

本轮明确不做：

- 不让 Geometry Collection 参与拉取、持有或 Physics Handle。
- 不新增 `AttackProjectileBody` 等碰撞通道。
- 不修改 `FindBestCandidate()` 的 `PhysicsBody` 查询。
- 不用 `AttackProjectile` Actor Tag 保存破碎资格。
- 不给碎片附加 `UMagneticObjectComponent`，碎片不能再次抓取。
- 不实现“大磁力物生成可再次使用的小磁力物”；这属于 P1。
- 首轮不额外施加爆炸式径向冲量；先保留原碰撞的真实能量，若 PIE 证明碎块抱团，再单独增加有上限的微弱分离冲量。
- 不顺带修复现有 `AttackProjectile` Tag 的局部 `FTimerHandle`；它是另一个既存生命周期问题，不影响本文独立破碎资格。


## 3. 时序硬约束

### 3.1 重新抓取必须先取消资格

`GrabCandidate()` 当前在函数开头保存角阻尼、Pawn 碰撞和 Camera 碰撞。拟新增的 `TryDisarmForGrab()` 必须放在这些快照之前：

```text
TryDisarmForGrab
    -> HeldComponent / HeldMagneticObject 赋值
    -> 保存阻尼和碰撞快照
    -> 修改持有期碰撞
    -> PhysicsHandle Grab
```

不能只保证“在 `PhysicsHandle->GrabComponentAtLocation()` 之前”，否则未来若破碎资格修改了可快照字段，旧投掷状态可能被保存并在释放时恢复。

### 3.2 正式投掷才武装

武装顺序固定为：

```text
保存待投掷 Body 与破碎组件
    -> 计算目标速度
    -> ReleaseHeldObject(true)
    -> 确认 Body 仍有效且投掷方向非零
    -> ArmForFormalThrow
    -> AddImpulse
    -> 保留既有 AttackProjectile Tag 逻辑
```

普通右键松手、安全释放和重冲击中断都不会调用 `ArmForFormalThrow()`。

### 3.3 命中回调不立即销毁

第一次有效 Hit 只做三件事：

1. `Armed -> BreakQueued`，同一物理步中的后续 Hit 全部忽略。
2. 恢复武装前的 Hit 通知配置。
3. 用成员 `FTimerHandle` 安排下一帧替换。

下一帧再读取碰撞后的 Transform 与速度。这样追猎者或玩家的同帧碰撞监听仍能看到原 Actor 和原 `AttackProjectile` Tag。

### 3.4 命中后、替换前禁止重新抓取

`TryDisarmForGrab()` 返回 `bool`：

- `Unarmed`：允许抓取。
- `Armed`：先取消资格，再允许抓取。
- `BreakQueued / Consumed`：拒绝抓取，防止替换前一帧重新建立 Physics Handle。
- `BreakFailed`：允许抓取，但本 Actor 不再尝试破碎。

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

/**
 * @file MagneticThrowBreakComponent.h
 * 职责：保存单个磁力道具“正式投掷后首次命中破碎”的资格，并安全完成完整物体到碎片替身的事务。
 * 边界：不计算抓取或投掷速度，不控制目标受击，不让 Geometry Collection 进入 Physics Handle。
 * 状态 Owner：本组件独占 Unarmed、Armed、BreakQueued、Consumed 与 BreakFailed 状态。
 */

#pragma once

#include "Components/ActorComponent.h"
#include "CoreMinimal.h"
#include "Engine/EngineTypes.h"
#include "TimerManager.h"

#include "MagneticThrowBreakComponent.generated.h"

class AMagneticFractureActor;
class UPrimitiveComponent;

/** 只管理正式投掷资格和一次性碎片替换，不参与玩家抓取状态机。 */
UCLASS(ClassGroup = (Magnetism), meta = (BlueprintSpawnableComponent))
class DEMO_API UMagneticThrowBreakComponent final : public UActorComponent
{
	GENERATED_BODY()

public:
	UMagneticThrowBreakComponent();

	/** 正式投掷释放完成后武装；配置、Body 或状态不合法时保持原行为并返回 false。 */
	bool ArmForFormalThrow(UPrimitiveComponent* ThrownBody);

	/** 必须在抓取组件保存任何物理快照前调用；返回 false 表示命中已经提交，禁止重新抓取。 */
	bool TryDisarmForGrab(UPrimitiveComponent* CandidateBody);

protected:
	virtual void BeginPlay() override;
	virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;

private:
	enum class EThrowBreakState : uint8
	{
		Unarmed,
		Armed,
		BreakQueued,
		Consumed,
		BreakFailed
	};

	/** 只接受已武装根刚体的第一次 Blocking Hit。 */
	UFUNCTION()
	void HandleBodyHit(
		UPrimitiveComponent* HitComponent,
		AActor* OtherActor,
		UPrimitiveComponent* OtherComponent,
		FVector NormalImpulse,
		const FHitResult& Hit);

	/** 下一帧读取碰撞后状态并创建碎片替身；成功后才销毁 Owner。 */
	void ProcessQueuedBreak();

	/** 恢复武装前的刚体 Hit 通知设置，保证取消资格和所有结束路径可回退。 */
	void RestoreHitNotification();

	/** 进入不可重试失败态，保留完整磁力物并输出一次明确错误。 */
	void EnterBreakFailed(const TCHAR* Reason);

	/** 项目自有碎片替身类；空值时本组件停用，不使用硬编码资产路径兜底。 */
	UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Category = "磁力|破碎", meta = (AllowPrivateAccess = "true"))
	TSubclassOf<AMagneticFractureActor> FractureActorClass;

	/** BeginPlay 从 Owner 根组件解析出的唯一模拟刚体。 */
	UPROPERTY(Transient)
	TObjectPtr<UPrimitiveComponent> MonitoredBody;

	FTimerHandle BreakTimer;
	EThrowBreakState State = EThrowBreakState::Unarmed;
	bool bPreviousHitNotification = false;
	bool bHitNotificationOverridden = false;
	bool bConfigurationValid = false;
};
```

### 5.2 `MagneticThrowBreakComponent.cpp`

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

/**
 * @file MagneticThrowBreakComponent.cpp
 * 职责：实现正式投掷资格、首次 Blocking Hit 去重和下一帧碎片替换。
 * 边界：不改变碰撞通道、对象类型或目标受击 Tag；失败时不删除完整物体。
 * 状态 Owner：所有破碎资格和替换阶段只在本组件内写入。
 */

#include "Components/Magnetism/MagneticThrowBreakComponent.h"

#include "Actors/Magnetism/MagneticFractureActor.h"
#include "Components/PrimitiveComponent.h"
#include "Engine/World.h"
#include "GameFramework/Actor.h"
#include "Kismet/GameplayStatics.h"
#include "PhysicsEngine/BodyInstance.h"

DEFINE_LOG_CATEGORY_STATIC(LogZeroEscapeMagneticBreak, Log, All);

UMagneticThrowBreakComponent::UMagneticThrowBreakComponent()
{
	PrimaryComponentTick.bCanEverTick = false;
}

void UMagneticThrowBreakComponent::BeginPlay()
{
	Super::BeginPlay();

	AActor* OwnerActor = GetOwner();
	MonitoredBody = IsValid(OwnerActor)
		? Cast<UPrimitiveComponent>(OwnerActor->GetRootComponent())
		: nullptr;

	if (!IsValid(MonitoredBody) || !MonitoredBody->IsSimulatingPhysics())
	{
		UE_LOG(
			LogZeroEscapeMagneticBreak,
			Error,
			TEXT("%s 的磁力破碎组件要求 Owner 根组件为模拟物理的 PrimitiveComponent，功能已停用。"),
			*GetNameSafe(OwnerActor));
		return;
	}

	if (!FractureActorClass)
	{
		UE_LOG(
			LogZeroEscapeMagneticBreak,
			Error,
			TEXT("%s 尚未指定 FractureActorClass，正式投掷仍可进行，但不会破碎。"),
			*GetNameSafe(OwnerActor));
		return;
	}

	MonitoredBody->OnComponentHit.AddDynamic(
		this,
		&UMagneticThrowBreakComponent::HandleBodyHit);
	bConfigurationValid = true;
}

void UMagneticThrowBreakComponent::EndPlay(
	const EEndPlayReason::Type EndPlayReason)
{
	if (UWorld* World = GetWorld())
	{
		World->GetTimerManager().ClearTimer(BreakTimer);
	}
	BreakTimer.Invalidate();
	RestoreHitNotification();

	if (IsValid(MonitoredBody))
	{
		MonitoredBody->OnComponentHit.RemoveDynamic(
			this,
			&UMagneticThrowBreakComponent::HandleBodyHit);
	}
	MonitoredBody = nullptr;

	Super::EndPlay(EndPlayReason);
}

bool UMagneticThrowBreakComponent::ArmForFormalThrow(
	UPrimitiveComponent* ThrownBody)
{
	if (!bConfigurationValid
		|| State != EThrowBreakState::Unarmed
		|| !IsValid(ThrownBody)
		|| ThrownBody != MonitoredBody
		|| !ThrownBody->IsSimulatingPhysics())
	{
		return false;
	}

	bPreviousHitNotification =
		ThrownBody->BodyInstance.bNotifyRigidBodyCollision;
	bHitNotificationOverridden = true;
	ThrownBody->SetNotifyRigidBodyCollision(true);
	State = EThrowBreakState::Armed;
	return true;
}

bool UMagneticThrowBreakComponent::TryDisarmForGrab(
	UPrimitiveComponent* CandidateBody)
{
	if (!IsValid(CandidateBody) || CandidateBody != MonitoredBody)
	{
		return true;
	}

	if (State == EThrowBreakState::BreakQueued
		|| State == EThrowBreakState::Consumed)
	{
		return false;
	}

	if (State == EThrowBreakState::Armed)
	{
		RestoreHitNotification();
		State = EThrowBreakState::Unarmed;
	}

	return true;
}

void UMagneticThrowBreakComponent::HandleBodyHit(
	UPrimitiveComponent* HitComponent,
	AActor* /*OtherActor*/,
	UPrimitiveComponent* /*OtherComponent*/,
	FVector /*NormalImpulse*/,
	const FHitResult& Hit)
{
	if (State != EThrowBreakState::Armed
		|| HitComponent != MonitoredBody
		|| !Hit.bBlockingHit)
	{
		return;
	}

	State = EThrowBreakState::BreakQueued;
	RestoreHitNotification();

	UWorld* World = GetWorld();
	if (!IsValid(World))
	{
		EnterBreakFailed(TEXT("缺少有效 World，无法安排碎片替换。"));
		return;
	}

	BreakTimer = World->GetTimerManager().SetTimerForNextTick(
		this,
		&UMagneticThrowBreakComponent::ProcessQueuedBreak);
}

void UMagneticThrowBreakComponent::ProcessQueuedBreak()
{
	BreakTimer.Invalidate();
	if (State != EThrowBreakState::BreakQueued)
	{
		return;
	}

	AActor* OwnerActor = GetOwner();
	UWorld* World = GetWorld();
	if (!IsValid(OwnerActor)
		|| !IsValid(World)
		|| !IsValid(MonitoredBody)
		|| !FractureActorClass)
	{
		EnterBreakFailed(TEXT("替换执行时 Owner、World、根刚体或替身类失效。"));
		return;
	}

	const FTransform SpawnTransform = MonitoredBody->GetComponentTransform();
	const FVector LinearVelocity =
		MonitoredBody->GetPhysicsLinearVelocity();
	const FVector AngularVelocityRadians =
		MonitoredBody->GetPhysicsAngularVelocityInRadians();

	AMagneticFractureActor* FractureActor =
		World->SpawnActorDeferred<AMagneticFractureActor>(
			FractureActorClass,
			SpawnTransform,
			OwnerActor->GetOwner(),
			OwnerActor->GetInstigator(),
			ESpawnActorCollisionHandlingMethod::AlwaysSpawn);

	if (!IsValid(FractureActor))
	{
		EnterBreakFailed(TEXT("SpawnActorDeferred 未能创建碎片替身。"));
		return;
	}

	if (!FractureActor->InitializeFracture(
		LinearVelocity,
		AngularVelocityRadians))
	{
		FractureActor->Destroy();
		EnterBreakFailed(TEXT("碎片替身缺少有效 Geometry Collection 配置。"));
		return;
	}

	AActor* FinishedActor = UGameplayStatics::FinishSpawningActor(
		FractureActor,
		SpawnTransform);
	if (!IsValid(FinishedActor))
	{
		EnterBreakFailed(TEXT("碎片替身未能完成生成。"));
		return;
	}

	State = EThrowBreakState::Consumed;
	OwnerActor->Destroy();
}

void UMagneticThrowBreakComponent::RestoreHitNotification()
{
	if (bHitNotificationOverridden && IsValid(MonitoredBody))
	{
		MonitoredBody->SetNotifyRigidBodyCollision(
			bPreviousHitNotification);
	}

	bPreviousHitNotification = false;
	bHitNotificationOverridden = false;
}

void UMagneticThrowBreakComponent::EnterBreakFailed(const TCHAR* Reason)
{
	RestoreHitNotification();
	State = EThrowBreakState::BreakFailed;

	UE_LOG(
		LogZeroEscapeMagneticBreak,
		Error,
		TEXT("%s 磁力物破碎替换失败：%s 原物体已保留，本实例不再重试。"),
		*GetNameSafe(GetOwner()),
		Reason != nullptr ? Reason : TEXT("未知原因"));
}
```

### 6.2 `MagneticFractureActor.cpp`

```cpp
// Copyright Epic Games, Inc. All Rights Reserved.

/**
 * @file MagneticFractureActor.cpp
 * 职责：配置短命 Geometry Collection、继承速度并在物理代理可用后显式解簇。
 * 边界：碎片移除节奏来自 Geometry Collection 的 Remove On Break 数据；本类只提供 Actor 级安全寿命。
 * 状态 Owner：初始化和激活只执行一次，不使用 Tick。
 */

#include "Actors/Magnetism/MagneticFractureActor.h"

#include "Engine/World.h"
#include "GeometryCollection/GeometryCollectionComponent.h"
#include "GeometryCollection/GeometryCollectionSimulationTypes.h"

DEFINE_LOG_CATEGORY_STATIC(LogZeroEscapeMagneticFracture, Log, All);

AMagneticFractureActor::AMagneticFractureActor()
{
	PrimaryActorTick.bCanEverTick = false;

	FractureBody = CreateDefaultSubobject<UGeometryCollectionComponent>(
		TEXT("FractureBody"));
	SetRootComponent(FractureBody);

	FractureBody->SetMobility(EComponentMobility::Movable);
	FractureBody->bEnableDamageFromCollision = false;
	FractureBody->bAllowRemovalOnSleep = false;
	FractureBody->bAllowRemovalOnBreak = true;
}

bool AMagneticFractureActor::InitializeFracture(
	const FVector& SourceLinearVelocity,
	const FVector& SourceAngularVelocityRadians)
{
	if (!IsValid(FractureBody)
		|| !IsValid(FractureBody->GetRestCollection()))
	{
		return false;
	}

	FractureBody->bEnableDamageFromCollision = false;
	FractureBody->bAllowRemovalOnSleep = false;
	FractureBody->bAllowRemovalOnBreak = true;
	FractureBody->InitialVelocityType =
		EInitialVelocityTypeEnum::Chaos_Initial_Velocity_User_Defined;
	FractureBody->InitialLinearVelocity = SourceLinearVelocity;
	FractureBody->InitialAngularVelocity = SourceAngularVelocityRadians;
	bInitialized = true;
	return true;
}

void AMagneticFractureActor::BeginPlay()
{
	Super::BeginPlay();

	if (!bInitialized || !IsValid(FractureBody))
	{
		UE_LOG(
			LogZeroEscapeMagneticFracture,
			Error,
			TEXT("%s 未通过 InitializeFracture 完成初始化，已销毁无效替身。"),
			*GetNameSafe(this));
		Destroy();
		return;
	}

	SetLifeSpan(SafetyLifetimeSeconds);
	if (UWorld* World = GetWorld())
	{
		ActivationTimer = World->GetTimerManager().SetTimerForNextTick(
			this,
			&AMagneticFractureActor::ActivateFracture);
	}
}

void AMagneticFractureActor::EndPlay(
	const EEndPlayReason::Type EndPlayReason)
{
	if (UWorld* World = GetWorld())
	{
		World->GetTimerManager().ClearTimer(ActivationTimer);
	}
	ActivationTimer.Invalidate();

	Super::EndPlay(EndPlayReason);
}

void AMagneticFractureActor::ActivateFracture()
{
	ActivationTimer.Invalidate();
	if (IsValid(FractureBody))
	{
		FractureBody->CrumbleActiveClusters();
	}
}
```

### 7.4 `ElectromagneticGrabComponent.cpp`——正式投掷入口

现有速度算法、普通释放和 Tag 逻辑保持不变，只把 Actor 与破碎组件引用提升到释放前：

```cpp
void UElectromagneticGrabComponent::ThrowHeldObject()
{
	UPrimitiveComponent* ComponentToThrow = HeldComponent.Get();
	if (!IsConfigurationReady()
		|| !IsValid(ComponentToThrow)
		|| !IsHoldingObject())
	{
		return;
	}

	const UMagneticObjectComponent* MagneticObject =
		HeldMagneticObject.Get();
	const float SpeedMultiplier = IsValid(MagneticObject)
		? MagneticObject->ThrowSpeedMultiplier
		: 1.0f;
	const FVector CenterOfMass = ComponentToThrow->GetCenterOfMass();
	const FVector ThrowDirection =
		(CalculateAimPoint() - CenterOfMass).GetSafeNormal();
	const FVector DesiredVelocity =
		ThrowDirection * TuningData->ThrowSpeed * SpeedMultiplier;
	const FVector ExistingVelocity =
		ComponentToThrow->GetPhysicsLinearVelocity();

	AActor* ProjectileActor = ComponentToThrow->GetOwner();
	UMagneticThrowBreakComponent* BreakComponent =
		IsValid(ProjectileActor)
			? ProjectileActor->FindComponentByClass<UMagneticThrowBreakComponent>()
			: nullptr;

	ReleaseHeldObject(true);

	if (IsValid(ComponentToThrow) && !ThrowDirection.IsNearlyZero())
	{
		if (IsValid(BreakComponent))
		{
			BreakComponent->ArmForFormalThrow(ComponentToThrow);
		}

		ComponentToThrow->AddImpulse(
			DesiredVelocity - ExistingVelocity,
			NAME_None,
			true);

		// 以下保留现有 AttackProjectile Tag 与既有清理 Timer，
		// 不让该 Tag 控制破碎资格。
		if (IsValid(ProjectileActor))
		{
			ProjectileActor->Tags.AddUnique(
				DemoHitTags::AttackProjectile());
			// ...现有 Tag Timer 原样保留...
		}
	}
}
```

## 9. 失败与回退

| 情况 | 行为 |
|---|---|
| 磁力物没有 `MagneticThrowBreak` | 保持当前可重复使用磁力物行为 |
| `FractureActorClass` 未配置 | 正式投掷照常；不武装破碎，并输出一次错误 |
| 拉取、持有、普通放下、自动释放时碰撞 | 状态不是 `Armed`，完全忽略 |
| 正式投掷后重新抓取 | 在任何抓取快照之前恢复 Hit 通知并回到 `Unarmed` |
| 同一物理步多次 Hit | 第一次立即进入 `BreakQueued`；后续全部忽略 |
| Hit 后、替换前尝试抓取 | `TryDisarmForGrab()` 返回 false，不建立 Physics Handle |
| deferred spawn 失败 | 原物体保留并进入 `BreakFailed`，不循环重试 |
| 替身缺少 RestCollection | 销毁本次无效替身，原物体保留并进入 `BreakFailed` |
| Remove On Break 异常 | Actor 级 4 秒安全寿命最终清理替身 |

## 11. P1 保留一块可再次投掷的小磁力物

P0 验收后，扩展点放在 `ProcessQueuedBreak()` 的替换成功路径，而不是把 Geometry Collection 的某个骨骼改造成磁力物：

```text
大磁力物命中
    -> 生成短命 Geometry Collection 表现
    -> 额外生成独立的小磁力 Actor
    -> 小磁力 Actor 仍由 StaticMesh + MagneticObject + MagneticThrowBreak 组成
    -> 小磁力 Actor 正式投掷命中后按 P0 彻底消耗
```

可重用资源始终是完整、稳定的 Static Mesh 刚体；Geometry Collection 始终只负责短暂碎片表现。
