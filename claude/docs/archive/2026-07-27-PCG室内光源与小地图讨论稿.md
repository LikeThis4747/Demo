# PCG 室内光源与小地图讨论稿

> 当前结论：室内光源已确认并进入最小实现；小地图留到光源 PIE 通过后的独立检查点。

## 1. 已采用的光源方案

- 直接生成 HydroLab 原始 `BP_HydroLab_LampA`，不复制其 RectLight、颜色、强度、半径或材质参数。
- 灯具绑定属于项目自有 Presentation Profile，因此未来更换素材只需改 DataAsset；WFC 不知道具体灯 Blueprint。
- 对当前四方向方格，按 `(GridX + GridY) % 2` 分为两组，选择格数较少的一组；平局选择 Start 所在组。若较少组不含 Start，再补 Start 一盏。
- 48～72 个有效格预计约 24～37 盏灯。相邻有效格的奇偶性必不同，所以未放灯的格至少与一个候选灯格相邻；当前不需要 BFS、灯距参数、路线分析或随机抽样。
- 灯位固定在逻辑格中心与 `CeilingPivotZCm`，再应用素材修正 Transform；LampA 当前修正为零平移、`Roll=180°`。

## 2. 数据与代码边界

### Presentation Profile

项目自有资产：`/Game/ZeroEscape/Generation/Presentation/DA_Presentation_SciFiHydroLab`

- `bSpawnCeilingLights`：临时关闭或启用本套表现的顶灯。
- `CeilingLightActorClass`：当前绑定 `/Game/Assets/SciFiHydroLab/Blueprints/BP_HydroLab_LampA`。
- `CeilingLightCellTransform`：灯具 Pivot 相对规范逻辑格中心的修正；当前为 `Roll=180°`、单位缩放。

### Generator

- HISM 完成后生成灯 Actor。
- Actor Spawn 成功后立即写入 `GeneratedLightActors`，以复用现有事务回滚。
- Clear、重新生成、失败和 EndPlay 都先销毁灯 Actor，再清空 Plan。
- 不新增类、组件、目录、测试系统或日志 schema 字段。

- 不再增加 `MaxDistanceToLightTiles`。
- 不再做多源 BFS、Start/Exit/房间必选集合或“最远未覆盖格补灯”。
- 不增加 `FZeroEscapeInteriorLightingBinding` 包装结构；三项当前必要属性直接放在现有 Presentation Profile。
- 不在本步增加地图快照、坐标换算或 HUD 代码；小地图重新单独确认。
