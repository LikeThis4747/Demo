## 0. Review 结论先行

### 0.1 本稿建议实现的最小闭环

1. 机关只向命中 Actor 提交 `FHeavyImpactRequest`，不接触 Character、Mesh、AI、Camera 或 Physics Control。
2. 玩家和追猎者实现同一个 `IHeavyImpactReceiver`，把请求转交给同一个 `UHeavyImpactResponseComponent`。
3. 组件冻结 AnimBP 当前输出、停止 CharacterMovement、让 Mesh 保持世界姿势脱离 Capsule，并把 `pelvis` 以下 Physics Body 全部切为 Simulated。
4. Physics Control **不创建 World-space Control，不设置任何线性位置强度**；只创建刚体父子之间的 Parent-space 角驱动。骨盆没有世界控制，所以脚和身体都不会被钉在原地。
5. 组件在命中点施加一次有上限的冲量；之后的飞行、身体翻转、墙面二次碰撞和落地全部交给 Chaos。
6. 直立 Actor/Capsule 关闭碰撞并只跟随 pelvis 的位置，不继承 pelvis 的 Pitch/Roll；玩家相机因此能跟上身体但不会跟着翻滚。
7. 角速度异常时立即销毁本次角控制，退化为自由 Ragdoll；落地且连续低速或达到最大超时后，第一版回到受击前测试位置并恢复所有状态。

### 0.2 相比正式 Plan 的一项建议变更

正式 Plan 原先列了两套 `UPhysicsControlAsset`（PCA）。本稿建议**效果原型首版先不创建 PCA**，改用项目 DataAsset 保存每套骨架的 limb/骨骼和角驱动参数，再直接调用 UE5.8 官方 API：

- `GetLimbBonesFromSkeletalMesh`
- `CreateControlsFromLimbBones`
- `CreateBodyModifiersFromLimbBones`
- `SetControlDatas`
- `SetBodyModifierDatas`
- `DestroyControls` / `DestroyBodyModifiers`

理由不是自造框架，而是当前真实工程有一个冲突：追猎者现有局部 Physics Control 已经为同一组身体创建 Body Modifier；若首版又常驻创建一套 PCA Body Modifier，两套记录会在每个 PrePhysics Tick 争夺同一刚体的 `Kinematic/Simulated` 状态。动态临时创建方案可以：

- 重击前先暂停并精确销毁局部受击创建的记录；
- 重击只在活动期间创建一套返回明确 Names 的临时记录；
- 重击结束后精确销毁，再恢复局部受击；
- 不使用 `DestroyAllControlsAndBodyModifiers()`，不会误删其他模块状态；
- 少做两套二进制 PCA，先把时间用在“是否真的好看”的验证上。

如果原型证明效果成立，再把稳定参数迁入 PCA Profile；这不改变 `FHeavyImpactRequest` 或角色接口。

### 0.3 首版冲量所有权

本稿默认采用可预测的单次交接：**锤头仍由 Chaos 运动，但角色初始击飞冲量由机关通过 `FHeavyImpactRequest` 明确提交。** 首次接管时不再让锤头对角色身体额外传一遍完整物理冲量。

- 好处：不会因身体从 Kinematic 切到 Simulated 的时序而得到双倍冲量；摆锤和冲锤可以使用同一标定单位。
- 仍然是物理结果：冲量之后的全身轨迹、关节姿势和环境二次碰撞全部由物理决定。
- `bImpulseAlreadyAppliedByPhysics` 只为“身体已经在重击模拟中，又发生第二次真实刚体接触”保留。
- 若用户要求首次接触必须由锤头与人体刚体直接交换动量，需要增加前置触发体的“提前接管”阶段；不在本稿暗中加入。

## 3. 运行时所有权与顺序

```text
机关/重物
  └─ IHeavyImpactReceiver::TryApplyHeavyImpact(Request)
       └─ 玩家/追猎者 Adapter
            └─ UHeavyImpactResponseComponent（唯一重击状态 Owner）
                 ├─ 暂停 CharacterMovement / 冻结动画目标
                 ├─ 临时创建 Parent-space Controls + Body Modifiers
                 ├─ Mesh 脱离 Capsule，全身 Simulated
                 ├─ 一次冲量 → Chaos 环境结果
                 ├─ PostPhysics 跟随/安全/稳定判断
                 └─ 精确销毁临时 Physics Control 对象并恢复快照
```

追猎者的现有局部受击不与重击并行：

```text
Pursuer Adapter 收到首个 Heavy 请求
  → PhysicsControlHitResponse.SuspendForHeavyImpact()
  → HeavyImpactResponse.TryApplyHeavyImpact()
  → HeavyImpact 结束 Delegate
  → PhysicsControlHitResponse.ResumeAfterHeavyImpact()
```

/**
 * @file HeavyImpactTypes.h
 * 职责：定义机关、玩家和 AI 共享的重冲击请求、接收结果、运行状态与短时碰撞 ID 去重。

/** 机关提交的 V1 重冲击合同；所有向量均为世界空间。 */
USTRUCT(BlueprintType)
struct DEMO_API FHeavyImpactRequest
{
	GENERATED_BODY()

	/** 只有 Heavy 进入全身物理；Light 由角色现有普通受击路径解释。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	EHeavyImpactLevel Level = EHeavyImpactLevel::Heavy;

	/** 施加给身体的世界空间冲量，单位 kg*cm/s；接收端还会做最终安全钳制。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	FVector WorldImpulse = FVector::ZeroVector;

	/** 世界空间命中点；用于 AddImpulseAtLocation 产生合理转动。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	FVector ImpactPoint = FVector::ZeroVector;

	/** 可选命中 Physics Body 骨骼；不存在时安全回退到角色 DataAsset 的 pelvis。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	FName HitBone;

	/** 机关或重物 Actor，仅用于日志与归因；接收端不反向调用。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	TObjectPtr<AActor> SourceActor = nullptr;

	/** 实际产生事件的 Primitive Component；可空。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	TObjectPtr<UPrimitiveComponent> SourceComponent = nullptr;

	/** 来源在接触时的世界速度，单位 cm/s；首版只记录，不据此二次计算冲量。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	FVector SourceVelocity = FVector::ZeroVector;

	/** 同一次摆动/冲撞共享一个非零 ID，用于去除多刚体和多 Hit 回调。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	FGuid ImpactId;

	/** 仅当身体已处于重击模拟且 Chaos 已传递本次冲量时为 true。 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Heavy Impact")
	bool bImpulseAlreadyAppliedByPhysics = false;

	/** 只校验合同本身的有限值、非零冲量和有效 ID；角色/骨骼配置由组件另行校验。 */
	bool IsStructurallyValid(FString& OutError) const
	{
		if (!ImpactId.IsValid())
		{
			OutError = TEXT("ImpactId 必须是有效的非零 FGuid。");
			return false;
		}
		if (WorldImpulse.ContainsNaN() || WorldImpulse.IsNearlyZero())
		{
			OutError = TEXT("WorldImpulse 必须是有限且非零的世界空间冲量。");
			return false;
		}
		if (ImpactPoint.ContainsNaN() || SourceVelocity.ContainsNaN())
		{
			OutError = TEXT("ImpactPoint 与 SourceVelocity 不能包含 NaN/Inf。");
			return false;
		}
		OutError.Reset();
		return true;
	}
};

/** 事件驱动的短时 ID 窗口；只在收到请求时清理，不引入常驻 Tick。 */
class DEMO_API FHeavyImpactIdWindow final
{
public:
	/** 新 ID 返回 true；窗口内重复 ID 返回 false；时间回退时自动清空。 */
	bool TryRemember(
		const FGuid& ImpactId,
		double NowSeconds,
		double WindowSeconds,
		int32 MaximumEntries)
	{
		if (NowSeconds < LastObservedTime)
		{
			RecentIds.Reset();
		}
		LastObservedTime = NowSeconds;

		for (auto It = RecentIds.CreateIterator(); It; ++It)
		{
			if (NowSeconds - It.Value() > WindowSeconds)
			{
				It.RemoveCurrent();
			}
		}

		if (RecentIds.Contains(ImpactId))
		{
			return false;
		}

		RecentIds.Add(ImpactId, NowSeconds);
		while (RecentIds.Num() > MaximumEntries)
		{
			FGuid OldestId;
			double OldestTime = TNumericLimits<double>::Max();
			for (const TPair<FGuid, double>& Entry : RecentIds)
			{
				if (Entry.Value < OldestTime)
				{
					OldestTime = Entry.Value;
					OldestId = Entry.Key;
				}
			}
			RecentIds.Remove(OldestId);
		}
		return true;
	}

	/** 关卡/Owner 生命周期结束时清空窗口。 */
	void Reset()
	{
		RecentIds.Reset();
		LastObservedTime = 0.0;
	}

private:
	TMap<FGuid, double> RecentIds;
	double LastObservedTime = 0.0;
};

	if (!bConfigurationReady)
	{
		UE_LOG(LogHeavyImpact, Error, TEXT("%s 重冲击配置无效：%s"),
			*GetNameSafe(GetOwner()), *Error);
	}
	SetComponentTickEnabled(false);
}

void UHeavyImpactResponseComponent::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
	RestoreInternal(EHeavyImpactEndReason::EndPlay, false);
	ImpactIdWindow.Reset();
	Super::EndPlay(EndPlayReason);
}

void UHeavyImpactResponseComponent::ForceRestore(const EHeavyImpactEndReason Reason)
{
	RestoreInternal(Reason, true);
}

bool UHeavyImpactResponseComponent::ValidateRuntimeConfiguration(FString& OutError) const
{
	const ACharacter* Character = Cast<ACharacter>(GetOwner());
	if (!IsValid(Character) || !IsValid(ControlledMesh)
		|| !IsValid(PhysicsControl) || !IsValid(TuningData))
	{
		OutError = TEXT("Owner 必须是 Character，并显式注入 Mesh、PhysicsControl 与 TuningData。");
		return false;
	}

	if (ControlledMesh != Character->GetMesh() || !IsValid(ControlledMesh->GetPhysicsAsset()))
	{
		OutError = TEXT("ControlledMesh 必须是 Owner 的 Character Mesh，且必须有 Physics Asset。");
		return false;
	}
	if (ControlledMesh->bBlendPhysics)
	{
		OutError = TEXT("V1 只支持入场时 bBlendPhysics=false 的角色，避免覆盖其他全身混合系统。");
		return false;
	}

	if (!TuningData->IsConfigured(OutError))
	{
		return false;
	}

	if (!ControlledMesh->GetBodyInstance(TuningData->PelvisBone))
	{
		OutError = FString::Printf(TEXT("Physics Asset 不含 pelvis Body：%s。"),
			*TuningData->PelvisBone.ToString());
		return false;
	}

	for (const FHeavyImpactLimbSetup& Limb : TuningData->Limbs)
	{
		if (ControlledMesh->GetBoneIndex(Limb.StartBone) == INDEX_NONE)
		{
			OutError = FString::Printf(TEXT("Skeleton 不含 Limb StartBone：%s。"),
				*Limb.StartBone.ToString());
			return false;
		}
	}
	for (const FName Bone : TuningData->NoEnvironmentCollisionBones)
	{
		if (!ControlledMesh->GetBodyInstance(Bone))
		{
			OutError = FString::Printf(TEXT("Physics Asset 不含免环境碰撞 Body：%s。"),
				*Bone.ToString());
			return false;
		}
	}

	OutError.Reset();
	return true;
}

EHeavyImpactRequestResult UHeavyImpactResponseComponent::TryApplyHeavyImpact(
	const FHeavyImpactRequest& Request)
{
	if (!bConfigurationReady)
	{
		return EHeavyImpactRequestResult::RejectedDisabled;
	}
	if (Request.Level == EHeavyImpactLevel::Light)
	{
		return EHeavyImpactRequestResult::IgnoredLight;
	}
	if (State == EHeavyImpactResponseState::TakingOver
		|| State == EHeavyImpactResponseState::Restoring)
	{
		return EHeavyImpactRequestResult::RejectedBusy;
	}

	FString Error;
	if (!Request.IsStructurallyValid(Error))
	{
		UE_LOG(LogHeavyImpact, Warning, TEXT("%s 拒绝重击：%s"),
			*GetNameSafe(GetOwner()), *Error);
		return EHeavyImpactRequestResult::RejectedInvalid;
	}

	const float RequestedMagnitude = Request.WorldImpulse.Size();
	if (RequestedMagnitude < TuningData->MinimumAcceptedImpulse)
	{
		return EHeavyImpactRequestResult::RejectedInvalid;
	}

	const UWorld* World = GetWorld();
	if (!World || !ImpactIdWindow.TryRemember(
		Request.ImpactId,
		World->GetTimeSeconds(),
		TuningData->DuplicateWindowSeconds,
		TuningData->MaximumRememberedImpactIds))
	{
		return EHeavyImpactRequestResult::IgnoredDuplicate;
	}

	if (IsHeavyImpactActive())
	{
		// 活动中的身体已经 Simulated：真实重物接触可只提交记录而不补第二次冲量。
		if (!Request.bImpulseAlreadyAppliedByPhysics)
		{
			ApplyRequestImpulse(Request);
		}
		// 只重置稳定窗口，不重置本次会话硬超时；不同 ImpactId 不能无限续命。
		StableElapsed = 0.0f;
		return EHeavyImpactRequestResult::AcceptedAdditionalImpact;
	}

	// V1 不声称能够追认“此前身体还是 Kinematic 时”已经发生的 Chaos 动量传递。
	if (Request.bImpulseAlreadyAppliedByPhysics)
	{
		return EHeavyImpactRequestResult::RejectedInvalid;
	}

	return BeginNewSession(Request)
		? EHeavyImpactRequestResult::AcceptedNewSession
		: EHeavyImpactRequestResult::RejectedSetup;
}

bool UHeavyImpactResponseComponent::CaptureOwnerSnapshot()
{
	ACharacter* Character = Cast<ACharacter>(GetOwner());
	UCharacterMovementComponent* Movement = Character ? Character->GetCharacterMovement() : nullptr;
	UCapsuleComponent* Capsule = Character ? Character->GetCapsuleComponent() : nullptr;
	UPhysicsAsset* PhysicsAsset = IsValid(ControlledMesh) ? ControlledMesh->GetPhysicsAsset() : nullptr;
	if (!Character || !Movement || !Capsule || !PhysicsAsset)
	{
		return false;
	}

	OwnerSnapshot = FOwnerSnapshot();
	OwnerSnapshot.MeshAttachParent = ControlledMesh->GetAttachParent();
	OwnerSnapshot.MeshAttachSocket = ControlledMesh->GetAttachSocketName();
	OwnerSnapshot.MeshRelativeTransform = ControlledMesh->GetRelativeTransform();
	OwnerSnapshot.ActorTransform = Character->GetActorTransform();
	OwnerSnapshot.ActorMinusPelvis =
		Character->GetActorLocation() - ControlledMesh->GetBoneLocation(TuningData->PelvisBone);
	OwnerSnapshot.MovementVelocity = Movement->Velocity;
	OwnerSnapshot.MovementMode = Movement->MovementMode;
	OwnerSnapshot.CustomMovementMode = Movement->CustomMovementMode;
	OwnerSnapshot.MeshCollision = ControlledMesh->GetCollisionEnabled();
	OwnerSnapshot.MeshObjectType = ControlledMesh->GetCollisionObjectType();
	OwnerSnapshot.MeshResponses = ControlledMesh->GetCollisionResponseToChannels();
	OwnerSnapshot.bMeshGenerateOverlapEvents = ControlledMesh->GetGenerateOverlapEvents();
	OwnerSnapshot.CapsuleCollision = Capsule->GetCollisionEnabled();
	OwnerSnapshot.bPauseAnims = ControlledMesh->bPauseAnims;
	OwnerSnapshot.bBlendPhysics = ControlledMesh->bBlendPhysics;

	for (const TObjectPtr<USkeletalBodySetup>& BodySetup : PhysicsAsset->SkeletalBodySetups)
	{
		if (!IsValid(BodySetup))
		{
			continue;
		}
		FBodyInstance* Body = ControlledMesh->GetBodyInstance(BodySetup->BoneName);
		if (!Body)
		{
			return false;
		}

		FBodySnapshot& Snapshot = OwnerSnapshot.Bodies.AddDefaulted_GetRef();
		Snapshot.BoneName = BodySetup->BoneName;
		Snapshot.CollisionEnabled = Body->GetCollisionEnabled();
		Snapshot.PhysicsBlendWeight = Body->PhysicsBlendWeight;
		Snapshot.bWasSimulating = Body->IsInstanceSimulatingPhysics();
		Snapshot.bUseCCD = Body->bUseCCD;
	}

	OwnerSnapshot.bValid = !OwnerSnapshot.Bodies.IsEmpty();
	return OwnerSnapshot.bValid;
}

bool UHeavyImpactResponseComponent::CreateOwnedPhysicsControlObjects()
{
	// 首版明确把该 Character 上的 PhysicsControl 视为串行资源；追猎者 Adapter 必须先暂停局部受击。
	if (!PhysicsControl->GetAllControlNames().IsEmpty()
		|| !PhysicsControl->GetAllBodyModifierNames().IsEmpty())
	{
		UE_LOG(LogHeavyImpact, Error,
			TEXT("%s 的 PhysicsControl 仍有其他运行时记录，拒绝重击接管。"),
			*GetNameSafe(GetOwner()));
		return false;
	}

	TArray<FPhysicsControlLimbSetupData> Setups;
	Setups.Reserve(TuningData->Limbs.Num());
	for (const FHeavyImpactLimbSetup& Source : TuningData->Limbs)
	{
		FPhysicsControlLimbSetupData& Dest = Setups.AddDefaulted_GetRef();
		Dest.LimbName = Source.LimbName;
		Dest.StartBone = Source.StartBone;
		Dest.bIncludeParentBone = Source.bIncludeParentBone;
		Dest.bCreateWorldSpaceControls = false;
		Dest.bCreateParentSpaceControls = true;
		Dest.bCreateBodyModifiers = true;
	}

	const TMap<FName, FPhysicsControlLimbBones> LimbBones =
		PhysicsControl->GetLimbBonesFromSkeletalMesh(ControlledMesh, Setups);
	if (LimbBones.Num() != Setups.Num())
	{
		return false;
	}

	FPhysicsControlData BaseControl;
	BaseControl.bEnabled = TuningData->bEnablePoseControl;
	BaseControl.LinearStrength = 0.0f;
	BaseControl.LinearDampingRatio = 1.0f;
	BaseControl.LinearExtraDamping = 0.0f;
	BaseControl.MaxForce = 0.0f;
	BaseControl.AngularStrength = 1.0f; // 创建后立即按 limb 覆盖；非零仅避免非法中间值。
	BaseControl.AngularDampingRatio = 1.0f;
	BaseControl.MaxTorque = 1.0f;
	BaseControl.LinearTargetVelocityMultiplier = 0.0f;
	BaseControl.AngularTargetVelocityMultiplier = 0.0f;
	BaseControl.bUseSkeletalAnimation = true;
	BaseControl.bDisableCollision = true;
	BaseControl.bOnlyControlChildObject = false;
	BaseControl.bUseAccelerationDriveMode = true;

	// 创建阶段保持 Kinematic；全部记录齐全后再显式、同步地切全身 Simulated。
	const FPhysicsControlModifierData BaseModifier(
		EPhysicsMovementType::Kinematic,
		ECollisionEnabled::QueryAndPhysics,
		1.0f,
		0.0f,
		EPhysicsControlKinematicTargetSpace::OffsetInBoneSpace,
		false,
		true);

	FPhysicsControlNames AllControls;
	FPhysicsControlNames AllModifiers;
	const TMap<FName, FPhysicsControlNames> LimbControls =
		PhysicsControl->CreateControlsFromLimbBones(
			AllControls, LimbBones, EPhysicsControlType::ParentSpace, BaseControl);
	const TMap<FName, FPhysicsControlNames> LimbModifiers =
		PhysicsControl->CreateBodyModifiersFromLimbBones(
			AllModifiers, LimbBones, BaseModifier);

	// 先取得所有权数组；后续任一步失败也能只清理本次对象。
	OwnedControlNames = AllControls.Names;
	OwnedBodyModifierNames = AllModifiers.Names;

	for (int32 SetupIndex = 0; SetupIndex < TuningData->Limbs.Num(); ++SetupIndex)
	{
		const FHeavyImpactLimbSetup& Setup = TuningData->Limbs[SetupIndex];
		const FPhysicsControlLimbBones* Bones = LimbBones.Find(Setup.LimbName);
		const FPhysicsControlNames* Controls = LimbControls.Find(Setup.LimbName);
		const FPhysicsControlNames* Modifiers = LimbModifiers.Find(Setup.LimbName);
		if (!Bones || !Controls || !Modifiers
			|| Bones->BoneNames.IsEmpty()
			|| (TuningData->bEnablePoseControl && Controls->Names.IsEmpty())
			|| Modifiers->Names.Num() != Bones->BoneNames.Num())
		{
			DestroyOwnedPhysicsControlObjects();
			return false;
		}

		FLimbRuntime& Runtime = LimbRuntimes.AddDefaulted_GetRef();
		Runtime.SetupIndex = SetupIndex;
		Runtime.BodyBones = Bones->BoneNames;
		Runtime.ControlNames = Controls->Names;
		Runtime.BodyModifierNames = Modifiers->Names;

		FPhysicsControlData LimbControl = BaseControl;
		LimbControl.bEnabled = TuningData->bEnablePoseControl;
		LimbControl.AngularStrength = Setup.AngularStrength;
		LimbControl.AngularDampingRatio = Setup.AngularDampingRatio;
		LimbControl.MaxTorque = Setup.MaximumTorque;
		if (!Runtime.ControlNames.IsEmpty()
			&& !PhysicsControl->SetControlDatas(Runtime.ControlNames, LimbControl, true, false))
		{
			DestroyOwnedPhysicsControlObjects();
			return false;
		}

		for (int32 BodyIndex = 0; BodyIndex < Runtime.BodyBones.Num(); ++BodyIndex)
		{
			BodyBoneToModifierName.Add(
				Runtime.BodyBones[BodyIndex], Runtime.BodyModifierNames[BodyIndex]);
		}
	}

	return !OwnedBodyModifierNames.IsEmpty()
		&& (!TuningData->bEnablePoseControl || !OwnedControlNames.IsEmpty());
}

bool UHeavyImpactResponseComponent::BeginNewSession(const FHeavyImpactRequest& Request)
{
	if (!CaptureOwnerSnapshot() || !CreateOwnedPhysicsControlObjects())
	{
		DestroyOwnedPhysicsControlObjects();
		OwnerSnapshot = FOwnerSnapshot();
		return false;
	}

	ACharacter* Character = CastChecked<ACharacter>(GetOwner());
	UCharacterMovementComponent* Movement = Character->GetCharacterMovement();
	UCapsuleComponent* Capsule = Character->GetCapsuleComponent();

	SetState(EHeavyImpactResponseState::TakingOver);
	OnHeavyImpactStarted.Broadcast(Request);
	if (State != EHeavyImpactResponseState::TakingOver)
	{
		// Delegate 中发生 UnPossessed/EndPlay 等强制恢复时，不继续写已经归还的身体状态。
		return false;
	}

	Movement->StopMovementImmediately();
	Movement->DisableMovement();
	Capsule->SetCollisionEnabled(ECollisionEnabled::NoCollision);

	ControlledMesh->bPauseAnims = true;
	ControlledMesh->DetachFromComponent(FDetachmentTransformRules::KeepWorldTransform);
	ControlledMesh->SetCollisionObjectType(ECC_PhysicsBody);
	ControlledMesh->SetCollisionEnabled(ECollisionEnabled::QueryAndPhysics);
	ControlledMesh->SetCollisionResponseToAllChannels(ECR_Ignore);
	ControlledMesh->SetCollisionResponseToChannel(ECC_WorldStatic, ECR_Block);
	ControlledMesh->SetCollisionResponseToChannel(ECC_WorldDynamic, ECR_Block);
	ControlledMesh->SetCollisionResponseToChannel(ECC_PhysicsBody, ECR_Block);
	ControlledMesh->SetGenerateOverlapEvents(false);

	ControlledMesh->SetAllBodiesBelowSimulatePhysics(TuningData->PelvisBone, true, true);
	ControlledMesh->SetAllBodiesBelowPhysicsBlendWeight(TuningData->PelvisBone, 1.0f, false, true);

	const FPhysicsControlModifierData SimulatedModifier(
		EPhysicsMovementType::Simulated,
		ECollisionEnabled::QueryAndPhysics,
		1.0f,
		1.0f,
		EPhysicsControlKinematicTargetSpace::OffsetInBoneSpace,
		false,
		true);
	if (!PhysicsControl->SetBodyModifierDatas(
		OwnedBodyModifierNames, SimulatedModifier, true, false))
	{
		RestoreInternal(EHeavyImpactEndReason::SetupFailed, true);
		return false;
	}

	for (const FBodySnapshot& Snapshot : OwnerSnapshot.Bodies)
	{
		if (FBodyInstance* Body = ControlledMesh->GetBodyInstance(Snapshot.BoneName))
		{
			Body->SetUseCCD(true);
		}
	}

	const FPhysicsControlModifierData NoCollisionModifier(
		EPhysicsMovementType::Simulated,
		ECollisionEnabled::NoCollision,
		1.0f,
		1.0f,
		EPhysicsControlKinematicTargetSpace::OffsetInBoneSpace,
		false,
		true);
	for (const FName Bone : TuningData->NoEnvironmentCollisionBones)
	{
		if (FBodyInstance* Body = ControlledMesh->GetBodyInstance(Bone))
		{
			Body->SetCollisionEnabled(ECollisionEnabled::NoCollision);
		}
		if (const FName* ModifierName = BodyBoneToModifierName.Find(Bone))
		{
			PhysicsControl->SetBodyModifierData(*ModifierName, NoCollisionModifier);
		}
	}

	FBodyInstance* Pelvis = ControlledMesh->GetBodyInstance(TuningData->PelvisBone);
	if (!Pelvis || !Pelvis->IsInstanceSimulatingPhysics())
	{
		RestoreInternal(EHeavyImpactEndReason::SetupFailed, true);
		return false;
	}

	SimulationElapsed = 0.0f;
	StableElapsed = 0.0f;
	UnsafeAngularElapsed = 0.0f;
	bControlsAbandoned = false;
	SetState(EHeavyImpactResponseState::Simulating);
	SetComponentTickEnabled(true);
	ApplyRequestImpulse(Request);
	return true;
}

FName UHeavyImpactResponseComponent::ResolveImpactBone(const FName RequestedBone) const
{
	return !RequestedBone.IsNone() && ControlledMesh->GetBodyInstance(RequestedBone)
		? RequestedBone
		: TuningData->PelvisBone;
}

void UHeavyImpactResponseComponent::ApplyRequestImpulse(const FHeavyImpactRequest& Request)
{
	const FVector AppliedImpulse = Request.WorldImpulse.GetClampedToMaxSize(
		TuningData->MaximumAppliedImpulse);
	ControlledMesh->AddImpulseAtLocation(
		AppliedImpulse, Request.ImpactPoint, ResolveImpactBone(Request.HitBone));

	UE_LOG(LogHeavyImpact, Log,
		TEXT("%s HeavyImpact id=%s impulse=%s bone=%s source=%s"),
		*GetNameSafe(GetOwner()),
		*Request.ImpactId.ToString(),
		*AppliedImpulse.ToCompactString(),
		*ResolveImpactBone(Request.HitBone).ToString(),
		*GetNameSafe(Request.SourceActor));
}

void UHeavyImpactResponseComponent::TickComponent(
	const float DeltaTime,
	const ELevelTick TickType,
	FActorComponentTickFunction* ThisTickFunction)
{
	Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
	if (State != EHeavyImpactResponseState::Simulating
		&& State != EHeavyImpactResponseState::FreeFallback
		&& State != EHeavyImpactResponseState::Settling)
	{
		return;
	}

	SimulationElapsed += DeltaTime;
	FollowPelvis(DeltaTime);
	if (!IsHeavyImpactActive())
	{
		return;
	}
	UpdateSafetyAndStability(DeltaTime);
}

void UHeavyImpactResponseComponent::FollowPelvis(const float DeltaTime)
{
	AActor* Owner = GetOwner();
	FBodyInstance* Pelvis = ControlledMesh->GetBodyInstance(TuningData->PelvisBone);
	if (!Owner || !Pelvis)
	{
		RestoreInternal(EHeavyImpactEndReason::Forced, true);
		return;
	}

	const FVector Desired = Pelvis->GetUnrealWorldTransform().GetLocation()
		+ OwnerSnapshot.ActorMinusPelvis;
	if (Desired.ContainsNaN())
	{
		RestoreInternal(EHeavyImpactEndReason::Forced, true);
		return;
	}
	const FVector Current = Owner->GetActorLocation();
	const FVector Next = FVector::DistSquared(Current, Desired)
		> FMath::Square(TuningData->MaximumPelvisFollowLag)
		? Desired
		: FMath::VInterpTo(Current, Desired, DeltaTime, TuningData->PelvisFollowInterpSpeed);

	// 只移动直立 Actor 锚点；不把 ragdoll 的 Pitch/Roll 传给 Capsule/Camera。
	Owner->SetActorLocation(Next, false, nullptr, ETeleportType::TeleportPhysics);
}

bool UHeavyImpactResponseComponent::IsPelvisGrounded() const
{
	const UWorld* World = GetWorld();
	const FBodyInstance* Pelvis = ControlledMesh->GetBodyInstance(TuningData->PelvisBone);
	if (!World || !Pelvis)
	{
		return false;
	}

	const FVector Start = Pelvis->GetUnrealWorldTransform().GetLocation();
	const FVector End = Start - FVector::UpVector * TuningData->GroundProbeDistance;
	FCollisionObjectQueryParams Objects;
	Objects.AddObjectTypesToQuery(ECC_WorldStatic);
	Objects.AddObjectTypesToQuery(ECC_WorldDynamic);
	FCollisionQueryParams Params(SCENE_QUERY_STAT(HeavyImpactGroundProbe), false, GetOwner());
	FHitResult Hit;
	return World->LineTraceSingleByObjectType(Hit, Start, End, Objects, Params);
}

void UHeavyImpactResponseComponent::UpdateSafetyAndStability(const float DeltaTime)
{
	float MaxLinearSpeed = 0.0f;
	float MaxAngularSpeed = 0.0f;
	for (const FBodySnapshot& Snapshot : OwnerSnapshot.Bodies)
	{
		const FVector LinearVelocity =
			ControlledMesh->GetPhysicsLinearVelocity(Snapshot.BoneName);
		const FVector AngularVelocity =
			ControlledMesh->GetPhysicsAngularVelocityInDegrees(Snapshot.BoneName);
		if (LinearVelocity.ContainsNaN() || AngularVelocity.ContainsNaN())
		{
			RestoreInternal(EHeavyImpactEndReason::Forced, true);
			return;
		}
		MaxLinearSpeed = FMath::Max(MaxLinearSpeed, LinearVelocity.Size());
		MaxAngularSpeed = FMath::Max(MaxAngularSpeed, AngularVelocity.Size());
	}

	if (!bControlsAbandoned && MaxAngularSpeed > TuningData->FreeFallbackAngularSpeed)
	{
		UnsafeAngularElapsed += DeltaTime;
		if (UnsafeAngularElapsed >= TuningData->FreeFallbackDelaySeconds)
		{
			EnterFreeFallback();
		}
	}
	else
	{
		UnsafeAngularElapsed = 0.0f;
	}

	if (SimulationElapsed >= TuningData->MaximumSimulationSeconds)
	{
		RestoreInternal(EHeavyImpactEndReason::TimedOut, true);
		return;
	}

	const bool bCanSettle = SimulationElapsed >= TuningData->MinimumSimulationSeconds
		&& MaxLinearSpeed <= TuningData->StableLinearSpeed
		&& MaxAngularSpeed <= TuningData->StableAngularSpeed
		&& IsPelvisGrounded();
	if (!bCanSettle)
	{
		StableElapsed = 0.0f;
		SetState(bControlsAbandoned
			? EHeavyImpactResponseState::FreeFallback
			: EHeavyImpactResponseState::Simulating);
		return;
	}

	StableElapsed += DeltaTime;
	SetState(EHeavyImpactResponseState::Settling);
	if (StableElapsed >= TuningData->StableWindowSeconds)
	{
		RestoreInternal(EHeavyImpactEndReason::Settled, true);
	}
}

void UHeavyImpactResponseComponent::EnterFreeFallback()
{
	if (bControlsAbandoned)
	{
		return;
	}
	bControlsAbandoned = true;
	if (!OwnedControlNames.IsEmpty())
	{
		PhysicsControl->DestroyControls(OwnedControlNames, true, false);
		OwnedControlNames.Reset();
	}
	for (FLimbRuntime& Runtime : LimbRuntimes)
	{
		Runtime.ControlNames.Reset();
	}
	SetState(EHeavyImpactResponseState::FreeFallback);
	UE_LOG(LogHeavyImpact, Warning, TEXT("%s 重冲击角速度异常，降级为自由物理。"),
		*GetNameSafe(GetOwner()));
}

void UHeavyImpactResponseComponent::DestroyOwnedPhysicsControlObjects()
{
	if (IsValid(PhysicsControl))
	{
		if (!OwnedControlNames.IsEmpty())
		{
			PhysicsControl->DestroyControls(OwnedControlNames, true, false);
		}
		if (!OwnedBodyModifierNames.IsEmpty())
		{
			PhysicsControl->DestroyBodyModifiers(OwnedBodyModifierNames, true, false);
		}
	}
	OwnedControlNames.Reset();
	OwnedBodyModifierNames.Reset();
	BodyBoneToModifierName.Reset();
	LimbRuntimes.Reset();
}

void UHeavyImpactResponseComponent::RestoreInternal(
	const EHeavyImpactEndReason Reason,
	const bool bBroadcast)
{
	if (State == EHeavyImpactResponseState::Restoring)
	{
		return;
	}
	if (State == EHeavyImpactResponseState::Inactive && !OwnerSnapshot.bValid)
	{
		DestroyOwnedPhysicsControlObjects();
		SetComponentTickEnabled(false);
		return;
	}

	SetState(EHeavyImpactResponseState::Restoring);
	SetComponentTickEnabled(false);

	ACharacter* Character = Cast<ACharacter>(GetOwner());
	UCapsuleComponent* Capsule = Character ? Character->GetCapsuleComponent() : nullptr;
	UCharacterMovementComponent* Movement = Character ? Character->GetCharacterMovement() : nullptr;
	if (IsValid(ControlledMesh))
	{
		for (const FBodySnapshot& Snapshot : OwnerSnapshot.Bodies)
		{
			ControlledMesh->SetPhysicsLinearVelocity(
				FVector::ZeroVector, false, Snapshot.BoneName);
			ControlledMesh->SetPhysicsAngularVelocityInDegrees(
				FVector::ZeroVector, false, Snapshot.BoneName);
		}
		if (IsValid(TuningData))
		{
			ControlledMesh->SetAllBodiesBelowSimulatePhysics(TuningData->PelvisBone, false, true);
		}
	}

	// 必须先删临时 Modifier，避免下一次 PrePhysics 又把刚体切回 Simulated。
	DestroyOwnedPhysicsControlObjects();

	if (Character && OwnerSnapshot.bValid)
	{
		// 正式 Plan 的首版验收只观察击飞/落地，随后回到受击前测试起点；不伪装成“已完成起身”。
		Character->SetActorTransform(
			OwnerSnapshot.ActorTransform, false, nullptr, ETeleportType::TeleportPhysics);
	}

	if (IsValid(ControlledMesh) && OwnerSnapshot.bValid)
	{
		if (USceneComponent* Parent = OwnerSnapshot.MeshAttachParent.Get())
		{
			ControlledMesh->AttachToComponent(
				Parent,
				FAttachmentTransformRules::KeepRelativeTransform,
				OwnerSnapshot.MeshAttachSocket);
		}
		ControlledMesh->SetRelativeTransform(OwnerSnapshot.MeshRelativeTransform);

		for (const FBodySnapshot& Snapshot : OwnerSnapshot.Bodies)
		{
			if (FBodyInstance* Body = ControlledMesh->GetBodyInstance(Snapshot.BoneName))
			{
				Body->SetCollisionEnabled(Snapshot.CollisionEnabled);
				Body->SetUseCCD(Snapshot.bUseCCD);
				Body->PhysicsBlendWeight = Snapshot.PhysicsBlendWeight;
				ControlledMesh->SetBodySimulatePhysics(
					Snapshot.BoneName, Snapshot.bWasSimulating);
			}
		}

		ControlledMesh->SetCollisionObjectType(OwnerSnapshot.MeshObjectType);
		ControlledMesh->SetCollisionResponseToChannels(OwnerSnapshot.MeshResponses);
		ControlledMesh->SetCollisionEnabled(OwnerSnapshot.MeshCollision);
		ControlledMesh->SetGenerateOverlapEvents(OwnerSnapshot.bMeshGenerateOverlapEvents);
		ControlledMesh->bPauseAnims = OwnerSnapshot.bPauseAnims;
		ControlledMesh->bBlendPhysics = OwnerSnapshot.bBlendPhysics;
	}

	if (Capsule && OwnerSnapshot.bValid)
	{
		Capsule->SetCollisionEnabled(OwnerSnapshot.CapsuleCollision);
	}
	if (Movement && OwnerSnapshot.bValid)
	{
		Movement->SetMovementMode(
			OwnerSnapshot.MovementMode, OwnerSnapshot.CustomMovementMode);
		Movement->Velocity = OwnerSnapshot.MovementVelocity;
	}

	OwnerSnapshot = FOwnerSnapshot();
	SimulationElapsed = 0.0f;
	StableElapsed = 0.0f;
	UnsafeAngularElapsed = 0.0f;
	bControlsAbandoned = false;
	SetState(EHeavyImpactResponseState::Inactive);
	if (bBroadcast)
	{
		OnHeavyImpactEnded.Broadcast(Reason);
	}
}

void UHeavyImpactResponseComponent::SetState(const EHeavyImpactResponseState NewState)
{
	State = NewState;
}

#### 4.2.1 这段主体代码在 review 时必须挑的四个点

1. **冲量时序**：首个请求只有显式 `AddImpulseAtLocation` 一条路径；活动中真实接触才允许 `bImpulseAlreadyAppliedByPhysics=true`，因此不把两份动量叠加。
2. **位置自由度**：所有 Control 都是 `ParentSpace` 且 `LinearStrength=0`；pelvis 没有世界锚点，脚也没有单独控制，所以整体可被击飞。
3. **恢复不是效果完成**：首版按已确认 Plan 回到测试起点，故不会保留最终游戏位移，也没有起身表现。它只用于快速判断“起飞—翻转—撞墙—落地”是否值得继续投入。
4. **物理表现无法由单测证明**：API 编译通过、状态恢复正确，仍不等于好看；必须用真实 Physics Asset 做空地、靠墙、斜向上冲量 A/B。

#### 4.2.2 已知编译/运行风险，不在实现时偷偷绕过

- `FBodyInstance::PhysicsBlendWeight` 当前 UE5.8 是公开字段，但若项目最终编译配置禁止直接访问，改为组件级恢复并把“角色入场前全部为 0”列为显式前置条件，不能静默漏恢复。
- UE5.8 引擎源码已确认 `SetBodyModifierData` 返回 `bool`，`FBodyInstance::GetUnrealWorldTransform()` 可从 const Body 调用；首次真实编译仍需验证本项目 include 边界，但不允许借编译修复改变物理模型。
- `ImpactPoint` V1 假定来自真实接触点。若机关提交远离身体的点，会产生不合理力矩；集成验收必须记录 `ImpactPoint` 与命中 Body 的距离，若确有错误再新增可审计钳制字段，不先硬编码魔法距离。
- 当前恢复会发生“物理落地后直接回测试起点”的可见跳变，这是首版明确非目标，不把它包装成成品。只有物理段通过后，才讨论保留最终位移与物理/动画起身。

Review 注意：`FHeavyImpactIdWindow` 放在共享 Types Header 是为了纯值自动化测试；如果审查认为不应暴露，可改为 Private Pimpl，但会增加一个内部文件和析构样板。

#include "Data/Physics/HeavyImpactTuningData.h"

bool UHeavyImpactTuningData::IsConfigured(FString& OutError) const
{
	if (PelvisBone.IsNone() || Limbs.IsEmpty())
	{
		OutError = TEXT("PelvisBone 不能为空，Limbs 至少需要一个区域。");
		return false;
	}
	if (MinimumAcceptedImpulse <= 0.0f || MaximumAppliedImpulse < MinimumAcceptedImpulse)
	{
		OutError = TEXT("MaximumAppliedImpulse 必须 >= MinimumAcceptedImpulse > 0。");
		return false;
	}
	if (MaximumSimulationSeconds <= MinimumSimulationSeconds
		|| StableWindowSeconds <= 0.0f
		|| DuplicateWindowSeconds <= 0.0f
		|| MaximumRememberedImpactIds < 4)
	{
		OutError = TEXT("重击时间窗口或去重容量配置非法。");
		return false;
	}
	if (StableLinearSpeed <= 0.0f || StableAngularSpeed <= 0.0f
		|| GroundProbeDistance <= 0.0f
		|| FreeFallbackAngularSpeed <= StableAngularSpeed
		|| FreeFallbackDelaySeconds < 0.0f
		|| PelvisFollowInterpSpeed <= 0.0f
		|| MaximumPelvisFollowLag <= 0.0f)
	{
		OutError = TEXT("速度、落地探测、FreeFallback 或 pelvis 跟随参数非法。");
		return false;
	}

	TSet<FName> LimbNames;
	TSet<FName> StartBones;
	for (const FHeavyImpactLimbSetup& Limb : Limbs)
	{
		if (Limb.LimbName.IsNone() || Limb.StartBone.IsNone())
		{
			OutError = TEXT("每个 Limb 都必须填写 LimbName 与 StartBone。");
			return false;
		}
		if (LimbNames.Contains(Limb.LimbName) || StartBones.Contains(Limb.StartBone))
		{
			OutError = FString::Printf(TEXT("LimbName 或 StartBone 重复：%s / %s。"),
				*Limb.LimbName.ToString(), *Limb.StartBone.ToString());
			return false;
		}
		if (bEnablePoseControl && (Limb.AngularStrength <= 0.0f
			|| Limb.AngularDampingRatio < 0.0f
			|| Limb.MaximumTorque <= 0.0f))
		{
			OutError = FString::Printf(TEXT("%s 的角强度和最大扭矩必须大于 0。"),
				*Limb.LimbName.ToString());
			return false;
		}
		LimbNames.Add(Limb.LimbName);
		StartBones.Add(Limb.StartBone);
	}

	TSet<FName> NoCollisionBones;
	for (const FName Bone : NoEnvironmentCollisionBones)
	{
		if (Bone.IsNone() || NoCollisionBones.Contains(Bone))
		{
			OutError = TEXT("NoEnvironmentCollisionBones 不能包含空名或重复骨骼。");
			return false;
		}
		NoCollisionBones.Add(Bone);
	}

	OutError.Reset();
	return true;
}

## 7. Increment 1：现有局部 Physics Control 的所有权收紧

### 7.1 为什么不能直接让两套 Body Modifier 并存

当前 `UPhysicsControlHitResponseComponent` 在 BeginPlay 为追猎者同一 Mesh 创建常驻 Body Modifier；重击若再给相同 Body 创建第二份 Modifier，两份记录会在 Physics Control 的 PrePhysics 阶段反复写 `Kinematic/Simulated`、Collision 与 Blend Weight。首版不赌写入顺序，采用明确的串行交接：

```text
局部受击 Active
  └─ Heavy 首次请求 → 局部组件恢复活动肢体 → 精确销毁自己创建的 Names → Suspended
       └─ 重击组件创建临时 Names、全身模拟
            └─ 重击恢复 → 精确销毁临时 Names → 局部组件重新创建自己的 Names
```

	const FHeavyImpactRequest& Request)

	if (!IsValid(HeavyImpactResponse) || !IsValid(PhysicsControlHitResponse))
	{
		return EHeavyImpactRequestResult::RejectedDisabled;
	}
	if (Request.Level == EHeavyImpactLevel::Light)

		return EHeavyImpactRequestResult::IgnoredLight;

	if (!bWasAlreadyActive && !PhysicsControlHitResponse->SuspendForHeavyImpact())
	{
		PhysicsControlHitResponse->ResumeAfterHeavyImpact();

		|| Result == EHeavyImpactRequestResult::AcceptedAdditionalImpact;

	{
		PhysicsControlHitResponse->ResumeAfterHeavyImpact();
	}
	return Result;
}

## 12. 机关输入与 PCG 并行合同

### 12.1 机关侧只允许出现的依赖

摆锤/冲锤文件只 include：

```cpp
#include "Interfaces/HeavyImpactReceiver.h"
#include "Physics/HeavyImpactTypes.h"
```

示意调用如下；这段属于机关任务 review，不由本任务落盘：

```cpp
void APhysicalHammer::SubmitHeavyImpact(
	AActor* HitActor,
	UPrimitiveComponent* HitComponent,
	const FHitResult& Hit,
	const FVector& NormalImpulse)
{
	if (!IsValid(HitActor)
		|| !HitActor->GetClass()->ImplementsInterface(UHeavyImpactReceiver::StaticClass()))
	{
		return;
	}

	FHeavyImpactRequest Request;
	Request.Level = EHeavyImpactLevel::Heavy;
	Request.SourceVelocity = HitComponent->GetPhysicsLinearVelocityAtPoint(Hit.ImpactPoint);
	FVector PushDirection = Request.SourceVelocity.GetSafeNormal();
	if (PushDirection.IsNearlyZero())
	{
		PushDirection = -Hit.ImpactNormal;
	}
	Request.WorldImpulse = PushDirection * NormalImpulse.Size() * ImpactTransferScale;
	Request.ImpactPoint = Hit.ImpactPoint;
	// 该示例回调属于锤头，目标 Skeletal Mesh 的 Body 是 BoneName；MyBoneName 是锤头自身。
	Request.HitBone = Hit.BoneName;
	Request.SourceActor = this;
	Request.SourceComponent = HitComponent;
	Request.ImpactId = CurrentSwingImpactId; // 每次有效摆动生成一次，同摆多回调复用。
	Request.bImpulseAlreadyAppliedByPhysics = false;

	IHeavyImpactReceiver::Execute_TryApplyHeavyImpact(HitActor, Request);
}
```

V1 推荐原型语义：锤仍由 Chaos 驱动，但首次接触时角色此前为 Kinematic，所以接收端使用这份显式冲量完成一次接管，不再声称同一帧存在完整双向动量守恒。这个选择的目的，是先验证角色物理表现，而不是同时承担“机关预触发 + 角色预接管 + 精确动量交换”三项风险。

如果用户明确要求第一次撞击也必须完全由锤—身体直接交换动量，则改为单独的预接管版本：

```text
锤头前置窄 Trigger 进入
  → 用同一 ImpactId 请求 Prepare（只接管、暂不施力）
  → 下一次 PrePhysics 前角色已 Simulated
  → 锤头真实碰撞直接传递动量
  → OnHit 用同一 ID、bImpulseAlreadyAppliedByPhysics=true 只记录，不补冲量
```

这需要给 V1 合同增加可审计的 Prepare 阶段或单独接口，不能偷偷把 `bImpulseAlreadyAppliedByPhysics` 在 Kinematic 首撞上设为 true。

### 12.2 PCG 不需要知道物理受击内部

PCG 只负责生成已配置好的摆锤/冲锤 Actor。机关的类型、调参、扫掠包围盒和接口实现随 Actor/其 DataAsset 走，不让 PCG 查询 Character Component 或骨骼。

PCG 侧最终需要提供的是空间约束，不是物理代码：

- 锤头完整扫掠体积不得与墙体、门框和其他机关初始重叠；
- 命中方向前方需要一段可观察的飞行/落地区域，首轮验收建议至少覆盖一次 3～6m 级位移的镜头空间，但最终数值由实测冲量决定；
- 落地区不能直接连到无返回的关卡外或 PCG 未封闭空洞；
- 同一区域多个重击机关的活动体积不能让角色持续被不同 `ImpactId` 无限续时；
- 追猎者恢复到测试起点后应仍在 NavMesh；玩家恢复点不能落进机关当前扫掠体积。

这些约束由机关/PCG Plan 拥有。本任务只冻结 `FHeavyImpactRequest + IHeavyImpactReceiver`，不修改 Level0 或任何 PCG 资产。

## 13. 预期画面、失败画面与“有没有技术收益”的判断

### 13.1 目标画面

以摆锤从角色右侧打中胸肩为例：

1. 命中瞬间不是播一段固定侧向受击，而是胸肩先获得冲量，骨盆和整个人随后一起离地。
2. 身体在空中保留“活人本能绷紧”的轮廓：躯干没有完全折叠，头颈和四肢有滞后，但不是硬直木板。
3. 脚没有锚定，角色确实横向飞出；镜头跟着身体总体位置走，但地平线不随身体翻滚。
4. 若撞墙，先接触墙的一侧被压回并改变整体旋转；同一冲量在空地与墙边会自然产生不同结果。
5. 落地后身体仍受重力和碰撞影响，速度连续下降；首版稳定后直接回测试起点，明确不是成品起身。

这更接近用户提到的“GTA 被车撞，但不是完全瘫软”的方向：动量和环境决定大运动，有限物理驱动只约束难看姿态。这里的实现机制是本项目方案，不把“GTA 方案”当成已知源码事实。

### 13.2 一眼判失败的画面

| 失败画面 | 可能原因 | 第一检查项 |
|---|---|---|
| 身体几乎不离地，只在原地扭一下 | 存在 World-space/线性控制或 pelvis 未 Simulated | 检查实际 Control 类型、LinearStrength、pelvis Body 状态 |
| 整个人像木板一起飞 | 角强度/约束过硬 | 与自由 ragdoll A/B，先降 Torso/Leg Strength，不增加动画 |
| 像尸体一样完全折叠 | 角控制未创建/未启用或 Torque 太低 | 读回实际 Names 与 `SetControlDatas` 返回值 |
| 颈部“直升机”旋转 | Physics Asset 颈部自由度或 Head 驱动失稳 | 先进入 FreeFallback，再决定是否需专用 Physics Asset 副本 |
| 身体撞墙后持续震动 | 控制与碰撞/约束争夺 | 看角速度安全阈值、亲子碰撞、手部挂墙，不用更大 Torque 硬压 |
| 玩家身体飞出镜头 | Actor 没按 PostPhysics 跟 pelvis 或最大滞后过大 | 记录 pelvis/Actor 距离与 Camera 画面 |
| 恢复后不能走/抓取/追击 | Movement、Capsule、磁力或局部 Physics Control 快照遗漏 | 强制恢复路径逐项断言，不调视觉参数 |
| 受控版与自由 ragdoll 几乎一样 | 控制没有真实参与或收益不足 | 停止扩展；核对运行记录，再由用户决定是否放弃路线 |

### 13.3 技术收益门槛

“没有爆炸、能恢复”不等于成功。追猎者和玩家分别都要满足：

- 同一侧向冲量下，位移量与自由 ragdoll 同量级，不被控制明显吃掉；
- 受控版在至少两个明显难看指标上优于自由 ragdoll：例如躯干折叠、颈部翻转、四肢缠绕、落地轮廓；
- 空地与墙边结果明显不同，证明环境确实参与而不是播放固定结果；
- 观察者在不看 Debug 的情况下能说出“这个人被重物撞飞了”，而不是“角色播了受击”或“角色突然变尸体”。

若第一轮三档 A/B 不能达到这些门槛，应把结论写成“该控制路线未产生足够可见收益”，而不是用更多代码掩盖。
