### [已失败/回退] Step 1：导入 FBX 到 MeleeAnimation（绑定 X_Bot_Skeleton）
- 方法：官方 MCP `SkeletalMeshTools.import_file`，`import_animations=true`，`skeleton=X_Bot_Skeleton`。
- **结果：每个 FBX 生成了 3 个资产**（1 个 SkeletalMesh + 2 个 AnimSequence），因为 import_file 无法"只导动画跳过网格"，每个动画都带出独立 Mixamo 网格。用户指出"为什么每个动画都创建骨骼"。
- **结论：官方 MCP import_file 不适合本场景**，需改用手动编辑器导入（可勾掉网格）。
- 已生成的 6 个多余资产（待清理）：
  - `Getting_Up_FaceUp`（SkeletalMesh，多余）
  - `Getting_Up_FaceUp_Anim_Take_001`（AnimSequence）
  - `Getting_Up_FaceUp_Anim_mixamo_com`（AnimSequence）
  - `Getting_Up_FaceDown`（SkeletalMesh，多余）
  - `Getting_Up_FaceDown_Anim_Take_001`（AnimSequence）
  - `Getting_Up_FaceDown_Anim_mixamo_com`（AnimSequence）
- 观察：每个 FBX 含 `Take 001` 与 `mixamo.com` 两个 AnimStack，各自生成一个 AnimSequence（内容近似）。

### [完成] Step 1（重试版）：官方 MCP import_file 重新导入 + 清理
- 结论：`import_file` 无法"只导动画"，必然生成 SkeletalMesh + 2 个 AnimSequence（Take_001 与 mixamo.com 两个 AnimStack）。
- 处理：导入两个 FBX → 删除 2 个多余 SkeletalMesh + 2 个 Take_001 占位 → 重命名 2 个 `_Anim_mixamo_com` 为规范名 → 保存。
- 最终落盘（已用 list_dir 确认磁盘真实存在）：
  - `/Game/MeleeAnimation/Getting_Up_FaceUp`：AnimSequence，X_Bot_Skeleton，8.33s/250帧，bEnableRootMotion=false ✓
  - `/Game/MeleeAnimation/Getting_Up_FaceDown`：AnimSequence，X_Bot_Skeleton，8.6s/258帧，bEnableRootMotion=false ✓
- 备注：首次尝试的 6 个资产已被用户手动清理；本步骤为重新导入后的干净结果。

### [完成] Step 2：确认重定向三件套可用
- 官方 MCP 实测确认：
  - 源 IK Rig：`IK_XBot`（preview=`X_Bot`）
  - 目标 IK Rig：`IK_SciFi08`（preview=`SK_Sci_Fi_Character_08_Full_01`）
  - Retargeter：`RTG_XBot`（source=`IK_XBot` → target=`IK_SciFi08`）
- 结论：追猎者侧**无需新建任何 Rig/Retargeter**。

### [完成] Step 2b：加速（rateScale=2）
- 用户反馈：动画结尾是拳击 idle 姿势（与项目 idle 不一致）且 8 秒太慢像慢镜头。
- 处理：官方 MCP set_properties 设置 `rateScale=2` 并保存：
  - `Getting_Up_FaceUp`：8.33s→4.17s（播放）
  - `Getting_Up_FaceDown`：8.6s→4.3s（播放）
- 决策：在重定向前处理源动画，重定向副本自动继承，只需处理一次。
- 裁剪（拳击结尾）：AnimSequence 无 MCP 可改的 start/end 帧属性，需编辑器手动裁剪（见下）。

### [进行中] Step 3：重定向 → 追猎者副本（需用户编辑器手动操作）
- 原因：官方 MCP 无 IK Retarget 工具集；本地 MCP 无 retarget action。已确认两个 MCP 均无法自动化 Retarget Anim Assets。
- 操作（Content Browser）：
  1. 选中 `/Game/MeleeAnimation/Getting_Up_FaceUp` 和 `Getting_Up_FaceDown` 两个动画
  2. 右键 → Retarget Anim Assets
  3. Select IK Retargeter：`RTG_XBot`
  4. Target Skeleton：`UE4_Mannequin_Skeleton`
  5. 勾选 Create New Assets，命名 `MM_SciFi_Character_08_GetUp_FaceUp` / `MM_SciFi_Character_08_GetUp_FaceDown`
  6. 产物移到 `/Game/ZeroEscape/Enemies/Animation/`
