# 机关设计修正：逃亡节奏下的陷阱逻辑

> 日期：2026-08-13
> 性质：设计讨论稿，修正 `2026-08-13-机关设计深化-陷阱三原则.md`。确认后并入 `DOC/Design/CHALLENGE_DESIGN.md`。
> 触发：制作人指出「玩家往前跑就能躲开，那玩家根本不会管这个陷阱」与「AI 会跳过来，控制不了」。
> 命名说明：「通过型空间」「停留型空间」「周期不对称」为本项目内部命名，不是 UE 官方概念或行业术语。

---

## 一、我的根本错误

制作人的批评正确，而且指出的是同一个错误在两个机关上的重复表现。

**错误：我设计的是「潜行/塔防游戏的陷阱」，而这是逃亡游戏。**

两者的玩家默认行为完全相反：

| | 潜行/塔防 | **逃亡（本项目）** |
|---|---|---|
| 玩家默认行为 | 停留、观察、布置 | **一直往前跑** |
| 「停下来设置陷阱」 | 符合本能 | **对抗本能** |
| 陷阱的意义 | 玩家的主动工具 | 玩家眼中的障碍 |

我的「斗牛结构」假设玩家愿意停下来当诱饵。但在逃亡游戏里，**玩家为什么要停下来？往前跑就赢了。**

于是必然陷入你指出的死锁：

```
设计成玩家跑得掉 → 玩家一直跑 → 陷阱被无视
设计成玩家跑不掉 → 百分百命中 → 玩家没有应对手段
```

**这个死锁无解，因为前提就错了。任何依赖「玩家主动停下来布置」的一次性陷阱，在逃亡游戏中都会失败。**

---

## 二、修正后的核心原则

### 原则：用周期性威胁，不用一次性触发陷阱

| | 一次性触发陷阱 | **周期性持续威胁** |
|---|---|---|
| 机会次数 | 一次，错过即废 | **持续存在，可反复利用** |
| 要求玩家 | 停下来精心设置 | **只需走位** |
| 与逃亡节奏 | 冲突 | **兼容** |
| 容错 | 低 | 高 |
| 开发成本 | 新机关 | **零，四类机关已实现** |

### 关键认识：平庸的不是周期机关，是「周期机关只威胁玩家」

你说「按固定周期攻击就是无聊且平庸」——在当前版本里这个判断完全正确，因为现在冲锤只会砸玩家。

**但只要追猎者也会被砸，同一个机关的性质立刻改变：**

```
玩家：能观察周期 → 学会等待时机通过 → 这是技巧
追猎者：不算周期，直奔玩家 → 硬闯被砸 → 这是玩家的奖励
```

**这个不对称不需要任何新开发。** 它只需要两个条件，而两个条件都已经具备：

1. 机关对追猎者生效 —— HeavyImpact 双向共享，已实现
2. 追猎者不会避让机关 —— 我们本来就不打算给它避让逻辑（`CHALLENGE_DESIGN.md` 2.3）

**所以正确的做法不是发明压力板，而是把已有的周期机关放到正确的位置。**

### 画面感

> 一段窄走廊，中段有一台液压冲锤，每三秒砸下一次。你在走廊口停住，数了两个周期。
>
> 锤子抬起的瞬间你冲进去，擦着它跑过。身后传来砸击声。
>
> 追猎者跟着冲进走廊——它不会数。锤子正好落下，把它砸得歪进侧墙。
>
> 你没有停下来，也没有设置任何东西。你只是**比它更懂这个走廊**。

**玩家的成就感来源是「我掌握了节奏而它没有」，而不是「我布置了一个陷阱」。** 前者符合逃亡节奏，后者不符合。

### 进阶玩法会自己涌现

玩家熟练后自然会发现：

> 我可以在锤子前面故意慢半拍，等它跟进来一起进入锤击区，然后我先过、它被砸。

**这就是你想要的「玩家利用机关攻击 AI」，而且是玩家自己发明的，不需要压力板。** 好机制的标志正是能生出设计者没编排的用法。

## 三、AI 跳跃攻击：这是机会，不是障碍

你担心「AI 会直接跳过来击飞你，还怎么控制」。我核实了已实现的参数，结论相反——**跳跃攻击是当前最可被玩家利用的行为。**

### 已实现的关键特性

| 参数 | 值 | 含义 |
|---|---|---|
| `JumpAttackLaunchDelay` | 0.65 s | 起手到离地的前摇 |
| `JumpAttackFlightSeconds` | 0.65 s | 飞行时间 |
| **总窗口** | **约 1.3 s** | **玩家的反应时间** |
| `JumpAttackLeadSeconds` | 0.35 s | 按玩家当前速度预判落点 |
| 落点锁定 | 起手时锁定一次 | **空中不追踪**（`PursuerAttackComponent` 头文件明确） |
| `JumpAttackImpactRadius` | 160 cm | 落地结算范围 |

**三个特性使它可被玩家利用：**

1. **1.3 秒是很长的反应窗口** —— 玩家完全来得及做出应对
2. **落点在起手时锁定** —— 玩家在它离地后移动，它必然落空
3. **落点基于速度预判** —— 玩家急停或变向，落点就偏了

### 由此产生的玩法：诱导落点

**这才是「玩家利用机关打 AI」的正确形态，而且零开发。**

> 你退到摆锤的摆动线旁边，停下来面对它。
>
> 它起手了——身体后仰，准备起跳。你有 1.3 秒。
>
> 它跳起来的瞬间，落点已经锁死在你现在站的位置。
>
> 你侧身滚开。它砸在你刚才站的地方——那里正是摆锤扫过的弧线。
>
> 摆锤把还在落地硬直中的它扫飞出去。

**这个玩法的完整结构：**

| 环节 | 玩家做什么 | 风险与技巧 |
|---|---|---|
| 站位 | 站在危险区边缘 | 站错位置就是自杀 |
| 等待 | 让它进入跳跃距离（220~650cm） | 太近它会用斧击，太远它不跳 |
| 判读 | 看到起跳前摇 | 需要认识动作 |
| 闪避 | 在它离地后移动 | 早了它会重新锁点，晚了被砸 |
| 收益 | 它落在危险区且有落地硬直 | 换来数秒窗口 |

**玩家全程承担风险（站在危险区边缘、必须放它靠近），技巧体现在闪避时机。** 这完全满足你要的「玩家通过决策应对得到奖励，没应对则受惩罚」。

而且它不需要压力板、不需要新机关、不需要任何新代码——**只需要把周期机关放在追猎者会跳过来的地方**。

### 附带好处

这个机制让 `JumpAttackImpactRadius = 160cm` 的落地范围从「难以躲避的威胁」变成「可预测的机会」。玩家学会读起跳动作后，跳跃攻击从最危险的招式变成最有价值的破绽。

**前提是玩家能看懂起跳前摇** —— 这再次说明动作可读性与音效是玩法前提。

## 四、悬挂重物：从陷阱改为资源

### 你的批评是对的

> 要么百分百砸中（玩家没有应对），要么玩家可以跑出去（玩家会无视），要么只有击中才掉落（玩家还是无视）。

三条路都不通。因为**它作为陷阱本身就不成立**。

### 修正：它不是陷阱，是需要额外操作才能获得的高价值资源

**取消「经过就掉落」的威胁属性。** 它就是一个挂在高处的重型磁力物，玩家想要就必须停下来把它拽下来。

| | 作为陷阱（废弃） | **作为资源** |
|---|---|---|
| 触发方式 | 玩家经过自动掉落 | **玩家主动用磁力拽** |
| 玩家关系 | 被动受害 | **主动选择** |
| 成本 | 无（跑过去就行） | **停留时间 = 真实风险** |
| 会被无视吗 | 会 | **不会——玩家需要武器** |

**「需要停下来拽它」这个成本，在被追逐时就是真实的风险。** 这是设计里唯一需要的张力，不需要它砸人。

### 画面感

> 你被追进一条走廊，手上什么都没有——上一个箱子已经砸碎了。
>
> 头顶悬着一个铸铁配重块，比你还大，锁链锈迹斑斑。
>
> 你停下来，转身，用磁力抓住它。锁链绷紧，发出刺耳的摩擦声——这东西太重，要一秒多才能拽下来。
>
> 脚步声在身后逼近。你能听见它已经拐过了转角。
>
> 锁链断了。配重块落进你的控制范围，沉甸甸地悬在身前，把你的视野挡住一半，移动慢得像在水里走。
>
> 它冲出转角的那一刻，你把这一吨铁砸了出去。

### 为什么这个版本成立

1. **不会被无视** —— 玩家在没有武器时会主动寻找它，这是需求驱动而非强制
2. **有真实成本** —— 拽取需要停留，被追逐时停留就是风险
3. **有明确收益** —— 全场最重的投掷物，能造成 HeavyImpact 级别的击飞
4. **有战术深度** —— 提前拽下来备用（安全但要搬着走、拖慢移动），还是等需要时再拽（省事但要冒险）
5. **零矛盾** —— 不需要回答「砸不砸得中玩家」这个无解问题

### 与光球玩法的天然协同

它可以和光球放在同一个死胡同：玩家进去拿光球，顺手拽下配重块，转身面对堵在门口的追猎者——**手上正好有全场最重的武器**。

这让死胡同从「高风险」变成「高风险高回报」，风险结构完整。

## 五、压力板：建议砍掉

理由已在第一节说清：它依赖「玩家主动停下来布置」，而逃亡游戏中玩家不会这么做。

你的原始直觉是对的——「总感觉不太对劲」，因为它把玩家变成了安全的旁观者，或者变成了必然被砸的受害者，两者都不成立。

**它想达成的目标（玩家利用机关打 AI），已经被第二节的周期不对称和第三节的诱导落点完全覆盖，且那两条零开发成本。**

## 六、更根本的修正：区分两类空间

这是本次讨论最重要的结论，它解释了为什么我前一版全错。

我之前把「威胁玩家」和「玩家的武器」两个功能放在同一个陷阱上，必然矛盾。**正确做法是按空间类型分开。**

### 通过型空间（走廊、楼梯、门口）

- **玩家在这里的目标：尽快通过**
- **机关的作用：通行税** —— 消耗时间与血量，让追猎者拉近距离
- **玩家的应对：学会周期，快速正确通过**
- **不要求玩家利用它打 AI**（虽然追猎者硬闯会被砸，那是附赠）

**这类机关的价值是制造压力，不是当武器。** 认识到这一点，就不需要为它们设计复杂的利用方式。

### 停留型空间（死胡同、光球点、终点守场区）

- **玩家在这里的目标：必须停留**（拿光球、守场）
- **机关的作用：战斗竞技场** —— 玩家被迫在危险区内应对追猎者
- **玩家的应对：走位 + 诱导落点 + 利用机关**
- **这里才是「玩家利用机关打 AI」真正发生的地方**

**因为玩家在这里跑不掉，所以才会用陷阱。** 这直接回答了你最初的问题——不是设计更巧妙的陷阱让玩家停下来，而是**把陷阱放在玩家本来就必须停留的地方**。

### 这个区分带来的直接结论

| 空间 | 机关配置 | 玩家行为 |
|---|---|---|
| 走廊 / 窄点 | 周期机关（冲锤、地刺、摆锤） | 学周期、快速通过 |
| 死胡同 + 光球 | 周期机关 + 悬挂重物 | 拿光球、拽武器、应战 |
| 终点守场区 | 周期机关 + 定期刷资源 | 长时间战斗，反复利用 |

**同样的机关，放在不同空间自动承担不同职能，不需要为每种职能开发不同机关。**

## 七、修正后的开发清单

| 项 | 开发量 | 说明 |
|---|---|---|
| **周期机关放窄点 + AI 不避让** | **零新开发** | 摆放规则调整；四类机关已实现，HeavyImpact 已双向共享 |
| **诱导跳跃落点** | **零新开发** | 跳跃攻击已实现且落点锁定；只需把周期机关放在会被跳跃波及的位置 |
| **悬挂重物（作为资源）** | **低** | 高处磁力物 + 拽取需要停留；可复用现有磁力持有链 |
| 刺轮 | 低 | 保持推荐，它是唯一「玩家可击杀」的正反馈来源 |
| ~~压力板~~ | — | **砍掉** |
| ~~低摩擦~~ | — | **建议一并砍掉**，理由见下 |

### 关于低摩擦的补充判断

按本次的修正逻辑重新评估，低摩擦的问题和压力板同类：它要求特定关卡结构（长直滑道 + 尽头危险 + 岔路），而 PCG 无法保证生成；退化成「直走廊+转角」后，它提供的体验与「周期机关 + AI 硬闯」高度重叠，但成本更高。

**建议砍掉，把时间给表现层。**

## 八、需要制作人决策

1. **接受「用周期不对称替代一次性陷阱」这个修正吗？** 它的核心是零开发——把已有四类机关放到窄点，追猎者不避让，玩家学周期。
2. **接受「诱导跳跃落点」作为玩家利用机关的主要形态吗？** 它同样零开发，且充分利用了你已经做完的跳跃攻击。
3. **悬挂重物改为「高处重型资源」而非陷阱，是否可行？** 我认为这是它唯一成立的形态。
4. **确认砍掉压力板与低摩擦。**
5. **是否接受「通过型 / 停留型」两类空间的摆放区分？** 这会直接影响 PCG 摆放规则的设计。
