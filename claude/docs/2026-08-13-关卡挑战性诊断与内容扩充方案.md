# 关卡挑战性诊断与内容扩充方案

> 日期：2026-08-13
> 性质：统揽层设计方案，讨论稿。不含实现细节，未获实施授权。
> 关联：`DOC/Design/ENDGAME_GAMEPLAY_DESIGN.md`（光球与守场）、2026-08-12 已验收的机关分层 Population
> 命名说明：文中「遭遇组」「压力板触发」「战术地形」为本项目内部命名，不是 UE 官方概念或行业术语。

---

## 一、无聊感的三个根因（按严重度排序）

### 根因一：追猎者会追丢 —— 这一条使其余问题全部无解

机关的压力**不来自机关本身，而来自「你没有时间处理它」**。

追猎者一旦追丢，玩家可以：停下 → 观察机关周期 → 从容绕行。此时无论地图上有 5 种还是 15 种机关，全部降级为静态装饰。

**这是当前无聊感的第一位原因，且它会吞掉所有内容扩充的收益。** 先修它，再谈机关。

已知的结构性成因：追猎者每次攻击循环都在「帮玩家逃跑」——攻击冷却、命中恢复、跳跃落空恢复期间它不移动，而玩家全程在跑。速度优势只有 11%（且当前是负的），几个攻击循环累积就足以脱离丢失半径。

**方向：追猎者不应该有「放弃」这个概念。** 这是逃亡游戏，猎手放弃就没有游戏了。丢失视野后应转入向玩家最后已知位置推进，而不是终止追击。这是参数与状态层面的调整，不是新系统。

### 根因二：机关放在可绕开的地方 = 机关是免费的

玩家的成本是「绕一下」，收益是「完全免疫」。这个交换永远划算，所以机关等于不存在。

**关键区分：机关的威胁强度不由伤害决定，由「是否可回避」决定。** 一个 5 点伤害的不可回避机关，比一个 50 点伤害的可绕开机关更有存在感。

### 根因三：全局最小间距把机关打散成孤立点

你的判断正确，而且问题比「空旷」更深一层。

**孤立的机关只产生单一决策**（绕 / 不绕），玩家两秒内解决完，不构成挑战。**组合的机关产生复合决策**，才有玩法。

而当前 Population 的全局最小间距（间距 2）从机制上排除了组合的可能——它保证了每个机关都是孤立的。

## 二、最高杠杆：改摆放规则，而不是加机关种类

这一节是本方案的核心。**不新增任何机关，只改摆放，就能显著提升挑战性。**

### 原则一：从「均匀撒点」改为「成组遭遇 + 空旷呼吸」

取消全局统一最小间距，改为两级：

- **组内允许紧邻甚至相交** —— 这才能产生组合
- **组间保持较大距离** —— 留出空旷段

节奏来自对比。全图均匀密度既不紧张也不放松，是最无聊的分布。**空旷段的作用是让遭遇段显得可怕。**

### 原则二：机关只放在必经窄点，不放在开阔区

这条直接解决「可以绕过」。

PCG 已知道每个格子的形状（走廊 / 转角 / 死胡同 / 房间，`FZeroEscapeWfcShapeWeights` 里都是一等公民）。规则应当是：

| 位置 | 是否放机关 | 理由 |
|---|---|---|
| 走廊、门口、楼梯口（窄点） | **优先放** | 无法绕开，必须处理 |
| 主路线上的必经格 | **优先放** | 同上 |
| 开阔房间中央 | **不放** | 绕开成本为零，等于没放 |
| 死胡同内部 | 特殊用途，见原则五 | |

**同一个机关放在走廊还是放在大厅，威胁强度差一个数量级。** 这是零成本的强度提升。

### 原则三：一组内的机关必须约束不同维度

好的组合让两个机关限制**不同**的东西，玩家必须同时满足：

| 组合 | 机关 A 约束 | 机关 B 约束 | 玩家必须 |
|---|---|---|---|
| 地刺 + 冲锤 | **时间**（等刺降下） | **空间**（贴墙躲锤） | 同时算时机和站位 |
| 摆锤 + 窄门 | **节奏**（等摆锤过） | **通路唯一** | 掌握周期，且不能久等 |
| 发射器 + 磁力箱 | **弹道**（暴露即被击） | 提供掩体 | 用箱子挡，或抓箱当移动掩体 |

坏的组合是两个同类机关——两段地刺只是一段更长的地刺，决策没有变化。

### 原则四：机关前必须留可读距离

一转弯就是机关等于随机死亡，玩家会觉得不公平而非有挑战。每组机关前留一小段空地，让玩家能看见、判断、准备。

这条同时保护「机关可读」和「玩家有解」两个底线。

### 原则五：死胡同 = 光球 + 入口机关

配合已立案的光球玩法：死胡同放光球，**入口处放机关**。

> 进去容易，出来时机关和追猎者同时在门口。

死胡同只有一个出口，这个风险结构由几何形状自动成立，不需要额外设计。**这是把「负资产死胡同」变成「高风险高回报」的完整形态。**

## 三、第二杠杆：把现有机关变成玩家可用的武器（零新机关）

当前四类机关全是「周期自动」，玩家只能被动躲避。

**建议给现有机关增加一种触发模式：压力板 / 区域触发。**

改动很小，但性质完全翻转：

| | 周期自动（现状） | 触发式 |
|---|---|---|
| 玩家关系 | 被动躲避 | **可主动利用** |
| 战术空间 | 无 | 引诱追猎者踩上去 |
| 与物理系统关系 | 无 | 磁力物也能触发 |

> 你退到冲锤对面，等追猎者踩上压力板的那一刻侧身闪开。锤子把它砸进墙里。

**这一项的价值远高于新增一种机关**：它让已经做好的四类机关全部获得「武器」这一新身份，玩家第一次有理由主动接近机关。

而且它服务同一个目标——让玩家和追猎者、机关三者互相作用，而不是各自独立。

## 四、机关候选评估

评估标准：实现成本、是否不可回避、是否与物理系统相关、是否与现有机关区分。

### 你提出的三个

**① 刺轮（会追玩家的地面滚动威胁）—— 推荐，最高性价比**

| 维度 | 评价 |
|---|---|
| 成本 | 低。素材已有；不需要导航，朝玩家方向地面移动即可 |
| 不可回避 | **优秀**。它会追你，这是唯一从机制上无法绕开的机关类型 |
| 物理关联 | **可以很强**：如果它能被磁力物撞翻、被投掷物打偏、被摆锤砸飞，它就是物理玩法 |
| 区分度 | 高。当前四类机关全是固定位置，它是第一个移动威胁 |

**关键设计要求：必须让它可以被物理手段解决。** 如果只能躲不能打，它就只是一个恼人的追赶者；如果一个磁力箱能把它掀翻，它立刻成为「玩家能赢的小对手」，提供追猎者无法提供的正反馈——因为追猎者是打不死的。

这一条把它从「非物理机关」变成「物理机关」，且几乎不增加成本。

**② 低摩擦走廊 —— 有条件推荐，但需要重新定位**

先说风险：**在追逐中让玩家失去控制，是高挫败感设计。** 玩家会认为「我不是因为决策失误而死」。单独作为障碍，它偏恼人而非有趣。

但有一个翻转能救它：

> **低摩擦对追猎者的惩罚大于对玩家的惩罚。**

因为追猎者的主攻击是助跑跳跃与冲撞——高速直线运动在低摩擦地面会明显失控、滑过头、撞墙。而玩家速度更低、可以主动减速。

这样它就不是障碍，而是**战术地形**：玩家学会把追猎者引到滑面上，看它冲过头。

另外磁力物在低摩擦地面会滑行很远，可以形成「远距离送物体」的玩法，物理感也成立。

技术上需要注意：角色移动不直接受 Physical Material 摩擦影响，需要通过角色移动参数实现，这一点要在实施前验证。成本仍属低。

**建议：只有在「战术地形」这个定位下做，且必须与其他机关或地形组合（滑面尽头有东西），不做纯滑走廊。**

**③ 激光（跳过去）—— 建议本次砍掉**

你自己的判断是对的：单纯「跳过去的激光」与地刺重复，无新决策。

激光真正有价值的形态是「视线威胁 + 可被物体阻挡」——玩家用磁力物当盾牌穿过，正好实现 `GAME_DESIGN.md` 2.4 的「铁板可阻挡弹道、成为移动掩体」。

但这个形态需要扫射逻辑、阻挡判定和视觉资产，**今天做不完，且与现有发射器机关的生态位重叠**（发射器已经是远程威胁）。

**结论：砍掉。如果想要「掩体玩法」，用发射器 + 磁力箱的组合摆放即可实现，成本为零。**

### 我建议补充的两个

**④ 悬挂重物（一次性掉落）—— 推荐**

天花板悬挂重物，玩家投掷或射击打断悬挂，重物砸落。

| 维度 | 评价 |
|---|---|
| 成本 | 低。可参照现有摆锤经验，改为一次性掉落比持续摆动更简单 |
| 物理关联 | **强**。真实 Chaos 落体，可复用 HeavyImpact |
| 玩法 | **玩家主动触发的陷阱**，与压力板同一思路 |
| 视觉 | 冲击力强，适合演示 |

它和压力板触发是同一个设计方向：**让玩家成为机关的使用者，而不只是受害者。**

**⑤ 用「组合摆放」制造的伪新机关 —— 零成本**

几个已有机关的特定组合，玩家会感知为「新的关卡类型」，而实际没有新代码：

| 组合 | 玩家感知 |
|---|---|
| 窄走廊 + 地刺 + 两侧冲锤 | 「精准通过挑战」 |
| 高厅 + 摆锤 + 出口窄门 | 「节奏门」 |
| 直走廊 + 发射器 + 沿途磁力箱 | 「掩体推进」 |
| 死胡同 + 光球 + 入口冲锤 | 「宝箱陷阱」 |

**内容丰富度的感知，主要来自组合数量，不是机关种类数量。** 4 种机关的有意义组合远多于 4 种。

### 汇总优先级

| 项 | 成本 | 价值 | 结论 |
|---|---|---|---|
| 修追丢 | 极低 | **极高** | **今天必做，第一件** |
| PCG 组合摆放规则 | 中（半天） | **极高** | **今天必做，第二件** |
| 压力板触发现有机关 | 低 | 高 | 强烈推荐 |
| 刺轮（可被物理解决） | 低 | 高 | 推荐 |
| 悬挂重物 | 低 | 中高 | 有时间则做 |
| 低摩擦（战术地形定位） | 低 | 中 | 排在上述之后 |
| 激光 | 中 | 低 | **砍掉** |

### 明确砍掉

| 项 | 理由 |
|---|---|
| 激光机关 | 与发射器生态位重叠，成本不低，用组合摆放可替代 |
| 终点守场（阶段二） | 已在策划案中标为候选；工期不足优先放弃 |
| 物理轻受击调参与验收 | 审计有两个阻塞项 + 一条静默失效路径，历史返工率最高，玩家感知远低于音效特效 |
| 任何第二种追猎者 / 新玩家能力 | 不在剩余工期内 |

### 优先级判断原则

如果 8/13 只能做完一件事，做**修追丢**。
如果能做两件，加**PCG 组合摆放**。

理由：这两项不增加任何内容，但会让**已经做好的四类机关、36 处摆放、磁力系统、HeavyImpact 全部产生压力**。而新增一种机关只增加一种体验。

**当前项目的瓶颈不是内容数量，是现有内容没有产生压力。**

## 六、需要制作人决策

1. **接受「先修追丢 + 改 PCG 摆放规则」优先于新机关吗？** 这会占用 8/13 大部分时间，爆裂投掷顺延到 8/14。
2. **压力板触发要不要做？** 它是零新机关但翻转机关性质的改动，我认为价值高于任何一个新机关。
3. **刺轮是否要求「可被磁力物撞翻」？** 我强烈建议要求。这是它从「非物理机关」变成「物理机关」的唯一条件，成本增加很小。
4. **低摩擦是否接受「战术地形」定位**（即主要用于惩罚追猎者的冲撞，而非单纯让玩家滑倒）？若坚持做纯滑倒障碍，我建议不做。
5. **确认砍掉激光。**
