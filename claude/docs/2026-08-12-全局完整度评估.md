## 二、用五层框架看「完整游戏」

一个能交付的游戏需要五层同时成立。当前分布极不均衡：

| 层 | 内容 | 完成度 | 判断 |
|---|---|---|---|
| **L1 世界层** | 关卡生成、空间、导航、资产 | ★★★★★ | 运行时多层 WFC + 三维净空 + 整栋连通 + Seed 复现，**过剩** |
| **L2 对抗层** | 玩家能力、敌人行为、机关、物理反馈 | ★★★★☆ | 磁力全链 + 破碎 + Heavy/Light 双层受击 + 4 类机关 + 双段攻击，**今天补齐后已充分** |
| **L3 目标层** | 玩家为什么跑、往哪跑、何时算赢 | ★☆☆☆☆ | **几乎为零**，见第三节 |
| **L4 感知层** | 玩家如何知道发生了什么 | ☆☆☆☆☆ | **完全为零**：无音效、无特效、无镜头反馈、无血条、无教学 |
| **L5 交付层** | 打包、稳定性、性能、材料 | ★☆☆☆☆ | **从未打包过**，无回归数据，末期 PPT 未开始 |

粗略量化：**技术系统约 85%，游戏完成度约 40%。**

这个形态很典型——深挖了 L1/L2，但把它们变成「一局游戏」的粘合层（L3/L4）和交付层（L5）几乎没动。

## 三、最关键的结构性判断：L3 缺失会让今天的投入贬值

这是我认为现在最该看清的一件事。

**当前规则下，出口一开局就是可通过的。** 证据：全项目 grep `Objective` / `Lockdown` / `Unlock` 为 0 命中；`AZeroEscapeExitVolume` 只有 `Activate()` 和 `bReached`，没有 Locked 状态；`EZeroEscapeRoundState` 只有 `InProgress / Won / Lost` 三态，GameState 无目标计数字段；胜利唯一来源是 ExitVolume 的 Overlap。

于是产生一个矛盾：

> 今天刚验收的机关分层放置——26~30 每百格密度、精心的类型权重、整栋通行图最小间距拒绝采样、资源避让机关——在当前规则下，**玩家有强烈动机全部绕开**。

因为最优策略是「从 Start 直线冲向 Exit」。玩家不需要磁力箱，不需要碰机关，不需要进支路。今天放进关卡的 36 个机关和 13 个资源，理性玩家一个都不会主动接触。

同样贬值的还有：
- L1 生成的支路、环路、多层结构 → 没有进入的理由；
- L2 的磁力投掷、破碎、受击层级 → 没有使用的场合（不打追猎者也能赢）；
- 策划案「一局 8~12 分钟」→ 实际可能 1~2 分钟。

**所以 L3 不是「一条待办」，而是让 L1+L2 全部投入产生意义的开关。** 它是当前唯一一处「几十行代码解锁整个项目已有价值」的位置：出口加锁 + 1~2 个沿途目标 + GameState 计数 + HUD 显示目标进度。

这是我对「还差多少」的第一个回答：**差的不是系统，是把系统串成游戏的那一层。**

## 四、L4 感知层：把最强的卖点静音播放

`Source/Demo` 全量搜索结果：

- `USoundBase` / `UAudioComponent` / `PlaySoundAtLocation` / `UMetaSound` → **0 命中**
- `UNiagaraSystem` / `SpawnSystemAtLocation` / `UParticleSystem` / `CameraShake` → **0 命中**
- `Content` 下自制音效资产 → **0 个**（唯一 `*Cue*` 来自第三方 SciFiHydroLab 的水泡声）

这意味着：铁板砸中追猎者没有撞击声、没有火花、没有镜头抖动；玩家不知道自己血量；追猎者在墙后逼近没有脚步声（而 `ENEMY_DESIGN.md` 第 7 节自己就写了「声音应帮助玩家在遮挡和转角后判断距离与状态」）。

一个以「物理力量感」为核心卖点的项目，力量感的三个主要载体——**声音、特效、镜头**——一个都没有。今天做的局部物理轻受击是在雕琢第四位载体（骨骼位移细节），而前三位是空的。

顺带一处结构性障碍：`UHealthComponent` 只暴露 `OnHealthDepleted`（归零广播），没有 `OnHealthChanged` 也没有 `GetHealthPercent()`，`CurrentHealth` 为 private。**HUD 目前技术上拿不到血量。**

这是第二个回答：**差的是让玩家感受到已经做好的东西。**

> 补记（同日晚）：`claude/tasks/active/TASK-20260812-001-游戏音效需求讨论.md` 已建立，Owner Codex，处于「只读盘点与方案讨论」阶段，尚未接入任何音频资产。方向正确，但需注意它的验收目标是「需求表 + 素材获取建议」，**不是可听的音效**。L4 完成度在实际接入前仍按 0 计。

## 六、完整清单：还差什么

按「对完整游戏的必要性」排序，不按工作量：

**必须有，否则不成立**

1. 沿途目标 → 撤离解锁 → 出口加锁（L3 核心，解锁全部已有投入）
2. 独立打包并实测可运行（L5，唯一的不可替代项）
3. 正式一局真实追逐证据（L2/L5 前提，Recast）
4. 撞击/脚步/机关/胜负音效（L4，力量感第一载体）
5. 血条 + 目标进度 HUD（L4，玩家基本信息权）

**应该有，否则明显不像成品**

6. 撞击特效 + 命中镜头抖动 + 受伤屏幕反馈
7. 操作教学（最省：主菜单一页图文 + 开局提示淡出）
8. 局内计时 + 结算统计（用时/投掷/击退/Seed 回显）
9. 追猎者双段攻击提交、构建、验收收口

**加分，时间允许**

10. 多 Seed 批量回归数据（PPT「测试数据」页需要）
11. UI 统一打磨
12. 演示视频 + 失败备用视频

**建议明确不做**

- 任何新物理系统或新敌人

## 七、战略判断

**核心建议：今天起停止在 L1/L2 上投入，把剩余 5 天全部给 L3 / L4 / L5。**

理由是边际收益已经反转：

- L1/L2 再投入 1 天 → 评委几乎感知不到（物理细节已经很好，且没有对照物）
- L3 投入半天 → 整局游戏从「跑向出口」变成「在迷宫里冒险」，L1+L2 全部激活
- L4 投入 1 天 → 整个 Demo 的观感提升一个档次（从静音演示变成有打击感的游戏）
- L5 投入 1 天 → 从「不能交付」变成「能交付」

## 八、结论

**距离「完整游戏」还差的，不是任何一项技术能力，而是三件事：**

1. **一个让玩家不得不进迷宫的理由**（目标层，工作量最小、杠杆最大）
2. **一套让玩家听得见、看得见、感觉得到的反馈**（感知层，投产比最高）
3. **一次能双击运行的独立构建**（交付层，唯一不可替代）

这三件事都不需要新的技术深度，都不涉及重构已验收系统，合计约 3 天。真正的风险不是做不完，而是**继续在已经足够好的物理系统上追求更好**，把这 3 天挤掉。

系统已经赢了，现在缺的是把它变成一场游戏。
