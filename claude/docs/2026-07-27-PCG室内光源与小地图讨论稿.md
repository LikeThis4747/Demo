# PCG 室内光源与小地图讨论稿

> 状态：仅讨论与代码预览，尚未写入 Source、Content 或 Config。

## 1. 结论

第一版只扩展现有 Generator、Presentation Profile 和 Canvas HUD，不新增系统、插件、UMG、SceneCapture、RenderTarget、Tick Actor 或测试专用依赖。

- 光源：先在 Level0 按 Demonstration 的真实顶装方向直接放置 HydroLab 原始 `BP_HydroLab_LampA` 验证。样例证据为 Pivot 贴天花板表面、通常 `Roll=180°` 朝向室内，Yaw 只随走廊方向变化。若实际可用，Presentation Profile 只引用可替换的灯 Actor 类，PCG Spawn 原始灯具 Blueprint；不复制它已有的 RectLight、强度、颜色和材质逻辑。
- 灯位：Start、Exit、房间 Anchor 先作为必选灯位；随后用多源 BFS 计算每个可通行格到最近灯的连通距离，在最远的未覆盖格补灯，直到全部格都在可调距离内。灯位不消费随机数，不改变 WFC、Seed 或 Layout Hash。
- 小地图：直接绘制 Ready Plan 的逻辑格与 OpeningMask，不重新扫描场景、不用俯视相机。生成结束时复制最多 72 个格，HUD 每帧只换算玩家标记。
- 首版完整显示地图。探索揭示、奖励/敌人/陷阱标记留给玩法确定后再加。

## 2. 可调参数与位置

### 当前 Seed

关卡中选中 `BP_ZeroEscapeRuntimeLevelGenerator` 实例：

`细节（Details） → PCG → Default Request → Seed`

当前未修改时就是 `12345`。未来菜单不需要改这份属性，而是构造 `FZeroEscapeGenerationRequest` 后调用现有 `GenerateFromRequest`。

### 室内灯光

位置：`/Game/ZeroEscape/Generation/Presentation/DA_Presentation_SciFiHydroLab`

- `LightActorClass`：当前使用 `BP_HydroLab_LampA`，未来换素材只改这里。
- `LightPivotCorrection`：灯具 Pivot 相对规范天花板灯位的修正；当前 LampA 候选为零平移、`Roll=180°`，最终值以 Level0 预览为准。
- `MaxDistanceToLightTiles`：每个可通行格到最近灯最多相隔几个连通格；越小灯越多。

颜色、强度、半径、材质和 RectLight 组件属性继续由素材 Blueprint 自己拥有。只有实际 PIE 证明默认值不合适时，才在取得许可后直接调整该 Blueprint 默认值；不为规避一次资产设置而复制一套映射参数。

### 小地图

首版样式值放在 `AZeroEscapeHUD` 的 `EditDefaultsOnly` 属性中：开关、尺寸、边距、背景/墙/房间/起点/终点/玩家颜色。当前原生 HUD 直接使用 C++ 默认值；正式 UI 阶段再决定是否做 HUD Blueprint 或 UMG 配置，不提前新增资产。

```cpp
// 概念代码：标准多源 BFS 计算连通距离；最远格仍超出阈值时补一盏灯。
TArray<int32> LightCellIndices = BuildRequiredLightCellIndices(Plan, Settings);
for (const int32 CellIndex : LightCellIndices)
{
    const FIntPoint Cell = Plan.Cells[CellIndex].GridCoordinate;
    const FTransform CanonicalTransform(FVector(
        Cell.X * Plan.LogicalTileSizeCm,
        Cell.Y * Plan.LogicalTileSizeCm,
        PresentationProfile->CeilingPivotZCm));
    const FTransform WorldTransform =
        Settings.LightPivotCorrection * CanonicalTransform * GeneratedRoot->GetComponentTransform();
    AActor* Light = GetWorld()->SpawnActor<AActor>(Settings.LightActorClass, WorldTransform);
    GeneratedLightActors.Add(Light); // Spawn 后立即登记，确保任意失败可统一回滚。
}
```

## 5. 风险与回退

- 灯 Actor 过多：调大 `MaxDistanceToLightTiles`；其数量天然受最多 72 个有效格约束。
- 穿墙漏光或亮度不合适：先直接调整素材 Blueprint 默认值；不以天空光补室内，也不在 PCG 复制同名参数。
- 小地图与实际场景不一致：只读同一份 Ready Plan，不从 Mesh 或 Actor 名反推。
- 重生成残留：灯组件与 HISM 一样由 Generator 统一登记并在 Clear/失败/EndPlay 销毁。
- 回退边界：可分别关闭 Presentation Profile 的灯光开关或 HUD 的小地图开关；WFC 布局代码不受影响。

## 6. 验收顺序

1. 先只看光源：Seed 12345 主视口 PIE，检查房间、直路、拐角、T/十字处无明显黑段和严重穿墙。
2. 再看小地图：确认地图形状、墙口、Start/Exit 和玩家移动方向一致。
3. 手动改为两个不同 Seed 重跑，确认地图和灯位同步刷新，旧灯与旧地图不残留。
4. 实施结束报告相关 PCG/UI C++ 的总行数与净变化；不运行用户已明确跳过的自动化/批量 Seed 检查。
