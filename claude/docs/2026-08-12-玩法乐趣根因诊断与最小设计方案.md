# 玩法乐趣的根因诊断与最小设计方案

> 日期：2026-08-12 晚
> 性质：设计讨论稿，不含实现方案，未获实施授权。
> 出发问题：为什么当前规则下玩家会直线冲向出口、不接触任何机关与资源；怎样让游戏好玩。

---

## 一、根因不是缺目标，是追逐关系不成立

### 决定性数据

| 项 | 值 | 来源 |
|---|---|---|
| 玩家 MaxWalkSpeed | **500** | `ZeroEscapeCharacter.cpp:50` |
| 追猎者 MaxWalkSpeed | **450** | `PursuerConfig.h:35` |
| 持有物体时玩家减速 | **无** | grep `ElectromagneticGrabComponent` 未见任何 MaxWalkSpeed 写入 |

`PursuerConfig.h:32` 的注释写着「应接近或快于玩家(500)以形成持续压力」，实际初值 450。**注释与实现矛盾，这是一个被遗漏的调参，不是设计决策。**

### 连锁后果

```
玩家比追猎者快 11%
  → 玩家可以无条件脱离追逐
    → 「迟滞追猎者」没有必要
      → 磁力投掷没有使用场合
        → 磁力箱不需要去拿
          → 机关只是纯负面障碍（碰到掉血，绕开零成本）
            → 支路、环路、多层结构没有进入理由
              → 直线冲刺是唯一理性策略
```

**这解释了为什么 36 个机关和 13 个资源玩家一个都不会碰。** 不是因为出口没锁，而是因为玩家不需要任何东西就能赢。

### 为什么单加出口锁无效

如果只补目标链而不动速度关系，最优策略会变成「直线冲向目标 A → 直线冲向目标 B → 直线冲向出口」。玩家依然不需要战斗、不需要资源、不需要理解空间。**机关和磁力系统仍然是死的。**

---

## 二、乐趣从哪来：把「距离」变成一种资源

追逐类游戏的乐趣不来自「跑得掉」，而来自**管理一个持续被消耗的安全距离**。

要让这个循环成立，距离必须满足两条：

1. **会自然缩短** — 否则玩家没有压力
2. **能用代价换回来** — 否则玩家没有手段，只剩绝望

当前项目两条都不满足：距离只会变长（玩家更快），也不需要换回来。

### 目标形态：距离经济

```
距离缩短的原因（压力来源）
  ├─ 追猎者略快于玩家 → 直线奔跑也会被慢慢拉近
  ├─ 玩家必须停下做事 → 读条、抓取、瞄准时距离急剧缩短
  └─ 持有重物时移动变慢 → 带着武器逃跑要付速度代价

距离拉长的手段（玩家的解法）
  ├─ 磁力投掷命中 → 短暂迟滞（已有 Light Stop）
  ├─ 高动能命中 / 引入机关 → 击倒 + 起身时间（已有 Heavy）
  └─ 利用转角、环路、视线断开 → 进入搜索状态（已有 LoseSightRadius）
```

**这三条压力来源和三条解法，项目已经全部具备技术实现。缺的只是让它们互相咬合的约束。**

---

## 三、核心机制：停留式目标 = 压力阀门

这是我认为杠杆最大的单一设计。

**沿途目标不做成「走过去 Overlap 就完成」，而做成「必须停留 N 秒」**（例如激活供电节点，读条 4~6 秒，中断则进度保留或部分回退）。

一个设计同时解决全部问题：

| 问题 | 停留式目标如何解决 |
|---|---|
| 玩家为什么进迷宫 | 目标在支路里 |
| 玩家为什么不能一路跑 | 必须停下，停下就被追上 |
| 玩家为什么需要磁力箱 | 读条前要先清场或制造距离 |
| 玩家为什么需要机关 | 把追猎者引进去能换到最长的安全窗口 |
| 紧张感从哪来 | 读条时是全局最脆弱的时刻 |
| 玩家为什么要理解空间 | 需要提前知道箱子和机关在哪 |

**读条是把「空间探索」和「物理战斗」强行绑进同一个时刻的装置。** 没有它，两个系统各自空转。

### 由此产生的决策三角

每到一个目标点，玩家面临三个都有真实代价的选择：

| 选项 | 代价 | 收益 | 适用 |
|---|---|---|---|
| 直接硬读 | 赌追猎者还远，被打断则更危险 | 最快 | 追猎者刚被甩开 |
| 先清场再读 | 消耗一个磁力箱 + 时间 | 安全窗口可控 | 手上有资源 |
| 把追猎者引向机关 | 走位风险，自己也可能被机关命中 | 最长窗口，可能倒地 | 目标点旁有摆锤/冲锤 |

**有意义的选择 = 每个选项都有真实代价和真实收益。** 这是「好玩」最朴素的定义，当前版本只有一个选项有意义（跑），所以不好玩。

## 四、第二个高杠杆设计：持有重物减速

策划案 2.6 本来就写了「重物：控制慢且拖累移动」，但未实现。

补上它会创造一个纯粹的两难：

- 想带着武器行动 → 移动变慢 → 追猎者逼近
- 想跑得快 → 必须放下武器 → 遇到威胁时手上没东西

这个取舍**每一秒都在发生**，且不需要任何 UI 解释，符合物理直觉。它把「资源管理」从一次性决定变成持续张力。

按质量分档即可（轻物几乎不减速、铁板明显减速、重物大幅减速），复用现有 `MagneticObjectComponent` 的质量数据。

---

## 五、机关的角色必须从「障碍」翻转为「武器」

当前机关对玩家和追猎者都生效（HeavyImpact 双向共享），但玩家没有理由使用它——因为不需要迟滞追猎者。

一旦追逐关系成立，机关会自动变成玩家最强的手段，因为**同一次命中对双方的后果不对称**：

- 命中玩家：掉血（有限损失，可承受）
- 命中追猎者：击飞 + 倒地 + 起身（数秒完全丧失行动力，是玩家能获得的最长窗口）

这个不对称已经在代码里成立了，不需要新增任何东西。**需要的只是关卡层面把机关和目标点放在同一区域**，让「引它进摆锤然后安心读条」成为一个玩家能自己发现的战术。

今天验收的分层 Population 已经具备这个能力（机关优先、资源避让机关、按类型权重），只需增加一条空间关系约束。

## 六、可读性是玩法必需，不是打磨项

这一点会改变 L4 音效的优先级判断。

如果玩家要管理距离，就必须**随时知道追猎者在哪**。而当前：没有脚步声、没有呼吸声、没有方向提示、没有血量显示。

在第三人称视角下，追猎者从背后或墙后接近时，玩家**完全没有信息来源**。这会让上面所有设计失效——玩家不是在做决策，而是在猜。

`ENEMY_DESIGN.md` 第 7 节自己写了：「声音应帮助玩家在遮挡和转角后判断距离与状态，例如脚步、撞击、呼吸、机械噪声」。

**结论：追猎者脚步声 + 距离衰减，不是「音效打磨」，是让距离管理可玩的前提条件。** 它和速度参数、停留式目标是同一优先级。

---

## 七、节奏：一局 8~12 分钟怎么填

三段式，压力递增：

| 段 | 内容 | 设计意图 |
|---|---|---|
| 开局约 2 分钟 | 追猎者尚未锁定或距离较远，玩家探索、拿第一个箱子、完成第一个目标 | 教学与建立空间认知，允许犯错 |
| 中段约 5 分钟 | 追猎者稳定追击，完成剩余目标 | 决策三角反复出现，是游戏主体 |
| 终段约 3 分钟 | 出口解锁后的撤离，压力最高 | 玩家已耗掉部分资源，形成收尾高潮 |

这不需要新系统，只需要：追猎者开局有一段延迟或距离，出口在解锁后仍有一段路。

## 八、最小改动清单（按杠杆排序，均非新系统）

| # | 改动 | 性质 | 解决什么 |
|---|---|---|---|
| 1 | 追猎者速度 450 → 略高于玩家（如 520） | 一个 DataAsset 参数 | 追逐关系成立，全部系统被激活 |
| 2 | 沿途目标改为「停留 N 秒」而非走过即得 | 目标层设计选择 | 压力阀门，绑定探索与战斗 |
| 3 | 出口需 N 个目标解锁 | 目标层 | 迷宫有理由 |
| 4 | 持有重物按质量减速 | 参数 + 少量逻辑 | 持续的资源两难 |
| 5 | 目标点附近保证有机关 + 资源 | Population 空间约束 | 机关从障碍变武器 |
| 6 | 追猎者脚步声 + 距离衰减 | 音效接入 | 距离管理可读，玩法前提 |
| 7 | 血量 + 目标进度 HUD | UI | 玩家的基本信息权 |
| 8 | 击倒追猎者的明确反馈 | 音效/特效/镜头 | 让玩家感知到「我赢了 5 秒」 |

**没有一项是新玩法系统。全部是给已有系统加约束和反馈。**

## 九、需要警惕的方向

苦恼「不好玩」时最容易走错的一步，是**再加一个玩法系统**（蓄力投掷、体力、升级、第二种敌人、新机关类型）。

当前项目的问题恰恰相反：**功能已经过剩，约束严重不足。** 

- 有四类机关，但玩家没有理由碰任何一类
- 有完整的磁力抓取投掷破碎链，但玩家不需要用
- 有 Heavy / Light 两层受击，但玩家打不打追猎者都能赢
- 有多层 PCG 迷宫，但玩家只走一条直线

**乐趣来自约束，不来自功能数量。** 再加系统只会让「没有理由使用的功能」变成五类、六类。

同样要警惕把难度做成「数值更高」：追猎者不需要更多血或更高伤害，它只需要**追得上**。

---

## 十、结论

你观察到的「玩家会直线冲向出口」是准确的，但它的根因比目标层缺失更靠前：

> **玩家跑得比追猎者快，所以整局游戏不需要任何一个已经做好的系统。**

修正它需要的不是策划创意，而是：

1. 让追猎者追得上（参数）
2. 让玩家必须停下（停留式目标）
3. 让带武器有代价（持物减速）
4. 让玩家听得见追猎者（音效）

这四条到位后，你已经做好的磁力、破碎、受击层级、四类机关、多层迷宫会在同一局里**同时变得必要**。项目缺的从来不是玩法内容，而是让现有内容变成必需品的那几个约束。
