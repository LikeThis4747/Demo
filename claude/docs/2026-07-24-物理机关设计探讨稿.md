# 物理机关 / 陷阱设计探讨稿

> 状态：讨论稿（AI 工作区）。仅用于探讨物理机关方向与优先级；敲定满意内容后再整理移入 `DOC/Design/`。
> 日期：2026-07-24。基准策划：`DOC/Design/GAME_DESIGN.md`《零号逃亡》。

## 0. 背景约束（机关设计的前提）

- 游戏：第三人称物理追逐。玩家用磁力抓/持/投 Chaos 刚体对抗难以杀死的追猎者，在 PCG 运行时生成的工业迷宫逃生。
- 现有系统：`ElectromagneticGrabComponent`（磁力状态机）+ `MagneticObjectComponent`/`MagneticPrototypeProp`（磁性刚体）+ `MagneticGrabTuningData`（调参 DataAsset）；追猎者受击分级（轻 / 中 / 强 / 环境重击）已在策划定义。
- 硬约束：
  - 机关必须能被 **PCG 数据驱动摆放**（自包含、模块化 Actor，靠连接口 / 空间标签放置，不手工精确编排）。
  - 默认关 Tick，优先碰撞 / Overlap / Timer / 事件 / Delegate / AnimNotify。
  - **能用 Chaos / UE 现成能力就不自研**；自研只写玩法规则层。

## 1. 机关筛选标准（值不值得做）

1. **服务核心循环**：能否制造"追猎者迟滞 / 拉开距离 / 争取时间"。
2. **三方交互**：玩家能用、追猎者会中招、玩家能把追猎者"喂"给机关；纯玩家躲避型价值最低。
3. **可被 PCG 摆放**：自包含、数据驱动。
4. **复用现有系统**：能挂到"磁力持有"与"追猎者失衡结算"上的机关边际成本最低。

## 2. 物理技术盘点：UE/Chaos 自有 vs 自研边界

原则：机关物理执行全用 Chaos 现成能力；自研只写"触发条件 + 差异化后果 + 与磁力/失衡的联动 + PCG 契约"这层薄逻辑。

| 物理原语 | UE/Chaos 自带（直接用） | 本项目只写这层（自研） |
|---|---|---|
| 摆锤/门/吊桥/活板门 | Physics Constraint（铰链/角度限制/马达） | 触发时机、相位、被磁力干预规则 |
| 爆炸/冲击波推飞 | RadialForceComponent 或 Physics Field | 引爆条件、对追猎者失衡分级 |
| 碎裂/可破坏结构 | Geometry Collection / Chaos Destruction | 何时破、破后是否产生可再吸取碎块 |
| 持续推力（风扇/气流/弹射） | PhysicsThruster / AddImpulse / AddForce | 力区判定、与磁力持有物叠加 |
| 力场吸引/排斥区 | Physics Field（Chaos） | 只对金属/磁性物生效的过滤规则 |
| 表面摩擦/弹性/滑 | Physical Material | 哪些地面用哪种材质（数据） |
| 布娃娃/物理受击 | PhysicalAnimationComponent / Ragdoll（追猎者已用） | 受击强度→blend 权重分级（已在做） |
| 触发/压力板 | Overlap 事件 + 质量检测 | 按重量/物体类型的开关逻辑 |
| 缆绳/链条视觉 | CableComponent | 仅表现，可选物理 |

红线：自研的是"玩法规则"，不是"物理求解"。摆锤别自己积分、爆炸别自己遍历施力、碎裂别自己做体素。

## 3. 机关 idea 清单

### A 类·环境危险区（最低成本，中期加分项）

**A1 地刺 / 升降刺阵**（策划已列）
- Chaos：碰撞体 Overlap + Timeline/Timer 升降；Physical damage。
- 自研：铁板覆盖检测（玩家放铁板→临时安全通道）、把追猎者击退到刺上触发"环境重击"。
- 三方：玩家躲 / 铁板搭桥；把追猎者击退到刺阵 = 环境重击（验证最高受击级别的最小机关）。

### B 类·物理联动机关（最能体现物理玩法主题，主推）

**B2 摆锤 / 移动重击物（钟摆、旋转钢梁）**
- Chaos：Physics Constraint（铰链）+ 大质量刚体，周期摆动。
- 自研：可被磁力"拉停 / 推动改变相位"——接入磁力系统的关键钩子。
- 三方：玩家计时穿过 / 磁力控制节奏开窗口；追猎者被撞飞。
- 参考：《Half-Life 2》物理谜题、神庙滚石类。

**B3 爆炸桶 / 高压储罐**
- Chaos：RadialForceComponent（冲击波）+ Geometry Collection（碎裂）。
- 自研：引爆条件（磁力投掷命中 / 被撞）、径向冲击对追猎者失衡结算。
- 三方：玩家吸起来当"手雷"投向追猎者；或引诱追猎者靠近后远程引爆。
- 参考：《Half-Life 2》红桶、《Control》可投掷环境物。

**B4 可倒塌堆叠 / 抽支撑塌方**
- Chaos：刚体堆叠 + 碰撞。
- 自研：磁力抽掉关键支撑→塌方封路 / 砸追猎者。
- 三方：用物理改变追逐路线的直接体现。
- 参考：《Teardown》状态改变路线、《旷野之息》系统联动。

### C 类·力区与推动（中等成本，丰富追逐节奏）

**C5 磁力弹射板 / 磁轨**
- Chaos：PhysicsThruster / 大冲量 AddImpulse。
- 自研：磁力持有物放上→高速弹射当远程击退；或弹射玩家做位移。
- 三方：玩家借机关强化投掷动能。

**C6 气流通道 / 输送带 / 大风扇**（策划 7.2 已提输送带）
- Chaos：持续力 + Physical Material。
- 自研：力区判定。
- 三方：玩家借力推物体、追猎者被推偏 / 减速。

### D 类·炫技候选（末期"选一个深化"，非必做）

**D7 磁力场区域（Physics Field）**：进入区域的金属物被吸/斥，既是障碍也是工具，与磁力主题深度耦合，适合 PPT 技术亮点。
**D8 活板门 / 塌陷地板**：追猎者经过时坍塌坠落（Physics Constraint 门 or Geometry Collection）。

## 4. 优先级建议（结合三周排期）

当前 PCG 第一优先、追猎者第二、机关为加分项。

| 优先级 | 机关 | 理由 |
|---|---|---|
| P0 中期加分 | A1 地刺 | 最简单、策划已列、验证"环境重击"闭环、易被 PCG 摆放 |
| P1 完整版核心 | B3 爆炸桶、B2 摆锤 | 最能体现物理主题，三方交互强，Chaos 现成能力多 |
| P2 丰富度 | B4 塌方、C5 弹射板、C6 气流 | 提升追逐节奏与解法多样性 |
| P3 末期炫技（选一） | D7 磁力场 | PPT 技术亮点，与磁力主题深度绑定 |

建议节奏：先只做 A1 打通"机关 ←→ PCG 摆放 ←→ 追猎者失衡结算"链路，之后每个新机关复用同一套契约"填数据"，边际成本骤降。

## 5. 待拍板问题

1. 机关公共基类/接口是否现在抽？倾向抽薄接口 `IHazardInteractable`（触发、对 Actor 施加物理后果、PCG 放置元数据），A1 先做具体实现，避免过早抽象。
2. 机关"后果"是否统一走追猎者失衡结算组件？建议是（机关命中追猎者 = 复用撞击分级）。
3. 机关偏"玩家主动使用的工具"（弹射板、摆锤控相位）还是"引诱追猎者中招的陷阱"（地刺、活板门）？倾向前者更贴合磁力物理操作深度。

## 6. 参考游戏与借鉴边界（沿用策划第 5 节）

- 《Half-Life 2》：场景物既是武器也是工具、爆炸桶；不复制关卡与重力枪实现。
- 《Control》：抓取/投掷/命中反馈手感链；不复制超能力组合与叙事。
- 《Teardown》：环境状态改变路线；不复制体素破坏技术。
- 《旷野之息/王国之泪》：同一物理能力多解、系统互作用；不复制神庙谜题。
