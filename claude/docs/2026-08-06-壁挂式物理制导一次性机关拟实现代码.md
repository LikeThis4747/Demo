> **已被 2026-08-10 的《狭窄走廊预判抛射 Chaos 机关——重新设计与拟实现代码》取代。** 本文保留为推进/制导稳定性重构的历史记录，不再作为后续实施依据。
>
> 状态：2026-08-08 稳定性重构审阅稿，不是已落盘代码。
>
> 本稿取代旧版“单个偏转喷口制导、首碰后继续推进”的方案。当前 Source、Blueprint、DataAsset、Level0 和 Config 均未按本稿修改；必须经用户明确允许并通过完整 Git 基线门禁后才能实施。

## 1. 本轮目标

当前 Level0 体验存在三个阻塞问题：

1. 弹体快到看不清；即使把 `ThrustStrength` 降到 1000，现象仍存在。
2. 弹体出生后乱飞，并出现直接穿墙。
3. 弹体难以与玩家或追猎者形成可靠接触。

本轮不扩展循环发射、对象池、PCG 自动放置或受击表现，只把现有一次性机关修到“看得见、能稳定飞、能产生接触、首碰后自由物理”的最小可用状态。

## 2. 已核对的现场事实

通过 UE5.8 官方 MCP 回读：

- `/Game/ZeroEscape/Hazards/Physics/Data/DA_ThrustGuidedHazard_Default`
  - `ProjectileMassKilograms = 100 kg`
  - `ThrustStrength = 1000`
  - `PoweredDurationSeconds = 0.8 s`
- Level0 两个 `BP_ThrustGuidedHazardLauncher` 实例均引用上述 DA 和同一个 Projectile Blueprint。
- Projectile CDO 的 Thruster 仍保存旧默认值 120000，但当前 C++ 在开启模拟前会用运行时 DA 覆盖；新方案仍会把 Blueprint 继承组件默认值显式清零，避免残留值造成误判。

按当前 DA，理想情况下推进加速度约为：

```text
1000 / 100 kg = 10 cm/s²
0.8 s 内速度增量约为 8 cm/s
```

因此当前“瞬间飞走”不可能主要由 1000 推力造成。现有代码中更值得优先处理的风险是：

- Launcher 在 Muzzle 中心使用 `AlwaysSpawn`，没有检查完整弹体胶囊是否与墙、炮管或外壳重叠。
- `bStartPenetrating` 不算有效碰撞，出生穿透不会关闭推进。
- 首次有效碰撞只停止读取目标，Thruster 仍持续到计时结束。
- 主推进力和转向转矩由同一个偏转喷口耦合产生，碰撞前也容易过冲和翻滚。
- Projectile 对 Pawn 只 Overlap；HeavyImpact 未及时准备时可能直接穿过角色 Capsule。

出生重叠目前是高概率原因，但仍需由新增长度检查和运行日志确认，不能在未验证前写成既定结论。

## 3. 当前有效设计结论

项目内部把发射后的第一段称为 `PoweredControlled`，这不是 UE 官方状态名，只表示：弹体仍是 Chaos 动态刚体，但允许 C++ 在有限时间内施加主推力和姿态转矩。

```text
Uninitialized
    ↓
PoweredControlled
    ├─ 推进时间到期
    ├─ 第一次阻挡碰撞
    ├─ 目标失效
    └─ 控制输入或速度异常
    ↓
Coasting ↔ Sleeping

任意不可安全运行的配置错误 → Disabled
```

关键规则：

- 主 Thruster 固定沿弹体局部 `+Z` 推进，不再偏转喷口。
- 追踪通过独立的真实转矩完成，不直接写 Transform、旋转、线速度或角速度。
- 推进不再固定满推力，而是追求可读的目标速度。
- 第一次阻挡碰撞立即关闭推进和转向；碰撞本身以及后续反弹仍完全由 Chaos 计算。
- 目标丢失后立即结束受控阶段，不再进入继续盲推的 `PoweredUnguided`。
- HeavyImpact 是否最终提交不作为本轮飞行验收门槛；先证明弹体确实能撞到角色。

### 6.2 动态初始前置

```cpp
FVector AThrustGuidedHazardLauncher::CalculateInitialLaunchDirection(
	const USceneComponent* TargetComponent) const
{
	const FVector MuzzleForward = Muzzle->GetForwardVector().GetSafeNormal();
	if (!IsValid(TargetComponent) || MuzzleForward.IsNearlyZero())
	{
		return MuzzleForward;
	}

	const FVector ToCurrentTarget =
		TargetComponent->GetComponentLocation() - Muzzle->GetComponentLocation();
	const float Distance = ToCurrentTarget.Size();
	const float LeadSeconds = FMath::Clamp(
		Distance / FMath::Max(TuningData->TargetPoweredSpeed, 1.0f),
		0.0f,
		TuningData->MaximumTargetLeadTimeSeconds);

	const FVector PredictedTargetLocation =
		TargetComponent->GetComponentLocation()
		+ TargetComponent->GetComponentVelocity() * LeadSeconds;

	const FVector DesiredDirection =
		(PredictedTargetLocation - Muzzle->GetComponentLocation()).GetSafeNormal();

	return ClampDirectionToCone(
		MuzzleForward,
		DesiredDirection,
		FMath::DegreesToRadians(TuningData->MaximumInitialAimAngleDegrees));
}
```

`ClampDirectionToCone` 保持为 Launcher cpp 内部纯函数，不抽成公共模块。

### 6.3 出生胶囊检查

```cpp
bool AThrustGuidedHazardLauncher::TryBuildSpawnTransform(
	const USceneComponent& TargetComponent,
	FTransform& OutSpawnTransform,
	FString& OutFailureReason) const
{
	const FVector InitialDirection =
		CalculateInitialLaunchDirection(&TargetComponent);
	if (InitialDirection.IsNearlyZero() || InitialDirection.ContainsNaN())
	{
		OutFailureReason = TEXT("无法得到有限的初始发射方向。");
		return false;
	}

	const float CenterOffset =
		TuningData->ProjectileHalfHeight
		+ TuningData->SpawnClearanceMargin;
	const FVector SpawnCenter =
		Muzzle->GetComponentLocation() + InitialDirection * CenterOffset;
	const FQuat SpawnRotation =
		FQuat::FindBetweenNormals(FVector::UpVector, InitialDirection);

	OutSpawnTransform = FTransform(
		SpawnRotation,
		SpawnCenter,
		FVector::OneVector);
	return IsSpawnPoseClear(OutSpawnTransform, OutFailureReason);
}
```

```cpp
bool AThrustGuidedHazardLauncher::IsSpawnPoseClear(
	const FTransform& SpawnTransform,
	FString& OutFailureReason) const
{
	UWorld* World = GetWorld();
	if (!IsValid(World))
	{
		OutFailureReason = TEXT("出生检查没有有效 World。");
		return false;
	}

	const FCollisionShape Shape = FCollisionShape::MakeCapsule(
		TuningData->ProjectileRadius,
		TuningData->ProjectileHalfHeight);
	FCollisionQueryParams QueryParams(
		SCENE_QUERY_STAT(ThrustGuidedHazardSpawn),
		false);

	// 故意不忽略 Launcher；若弹体仍与炮管或外壳阻挡，摆位必须失败。
	if (World->OverlapBlockingTestByChannel(
		SpawnTransform.GetLocation(),
		SpawnTransform.GetRotation(),
		ECC_PhysicsBody,
		Shape,
		QueryParams))
	{
		OutFailureReason = TEXT("弹体出生胶囊与场景或发射器阻挡重叠。");
		return false;
	}

	return true;
}
```

实施时若需要输出具体阻挡组件，把布尔查询替换为 `OverlapMultiByChannel` 并只收集对 `ECC_PhysicsBody` 返回 Block 的组件；不自动搜索或瞬移到另一个出生点。

### 6.4 发射顺序

`Phase = Spent` 从函数开头移动到 `FinishSpawningActor` 成功之后：

```cpp
void AThrustGuidedHazardLauncher::FireLockedTarget()
{
	if (Phase != EThrustGuidedHazardLauncherPhase::Warning)
	{
		return;
	}

	GetWorldTimerManager().ClearTimer(WarningTimerHandle);

	USceneComponent* TargetComponent = LockedTargetComponent.Get();
	if (!IsValid(TargetComponent))
	{
		ReturnToArmedAfterCancelledWarning(TEXT("locked target became invalid"));
		return;
	}

	FTransform SpawnTransform;
	FString FailureReason;
	if (!TryBuildSpawnTransform(*TargetComponent, SpawnTransform, FailureReason))
	{
		DisableHazard(FailureReason);
		return;
	}

	const FGuid LaunchId = FGuid::NewGuid();
	AThrustGuidedHazardProjectile* Projectile =
		GetWorld()->SpawnActorDeferred<AThrustGuidedHazardProjectile>(
			ProjectileClass,
			SpawnTransform,
			this,
			GetInstigator(),
			ESpawnActorCollisionHandlingMethod::AlwaysSpawn);

	if (!IsValid(Projectile))
	{
		DisableHazard(TEXT("延迟生成弹体失败。"));
		return;
	}

	Projectile->ConfigureLaunch(TuningData, TargetComponent, LaunchId);
	if (!IsValid(UGameplayStatics::FinishSpawningActor(Projectile, SpawnTransform)))
	{
		DisableHazard(TEXT("完成弹体生成失败。"));
		return;
	}

	Phase = EThrustGuidedHazardLauncherPhase::Spent;
	WarningVisualRoot->SetVisibility(false, true);
	LockedTargetActor.Reset();
	LockedTargetComponent.Reset();
}
```

这里仍使用 `AlwaysSpawn`，只是因为 CDO 的 ProjectileBody 在 BeginPlay 前保持 NoCollision；安全依据已经改为显式完整胶囊检查，`AlwaysSpawn` 不再承担避碰职责。

### 7.3 Tick 与速度控制

```cpp
void AThrustGuidedHazardProjectile::Tick(const float DeltaSeconds)
{
	Super::Tick(DeltaSeconds);

	if (Phase != EThrustGuidedHazardProjectilePhase::PoweredControlled)
	{
		return;
	}

	if (!IsValid(RuntimeTuningData)
		|| !FMath::IsFinite(DeltaSeconds)
		|| DeltaSeconds <= 0.0f)
	{
		FinishPoweredPhase(TEXT("invalid powered tick input"));
		return;
	}

	PoweredElapsedSeconds += DeltaSeconds;
	if (PoweredElapsedSeconds >= RuntimeTuningData->PoweredDurationSeconds)
	{
		FinishPoweredPhase(TEXT("powered timeout"));
		return;
	}

	if (!IsLockedTargetUsable())
	{
		FinishPoweredPhase(TEXT("locked target became invalid"));
		return;
	}

	FVector DesiredDirection = FVector::ZeroVector;
	float Throttle = 0.0f;
	if (!TryCalculateControlCommand(DesiredDirection, Throttle)
		|| !ApplyPhysicalAttitudeControl(DesiredDirection))
	{
		FinishPoweredPhase(TEXT("control command became invalid"));
		return;
	}

	const float ActualMass = ProjectileBody->GetMass();
	if (!FMath::IsFinite(ActualMass) || ActualMass <= 0.0f)
	{
		FinishPoweredPhase(TEXT("rigid body mass became invalid"));
		return;
	}

	Thruster->ThrustStrength =
		ActualMass
		* RuntimeTuningData->MaximumPoweredAcceleration
		* FMath::Clamp(Throttle, 0.0f, 1.0f);
}
```

控制命令：

```cpp
bool AThrustGuidedHazardProjectile::TryCalculateControlCommand(
	FVector& OutDesiredDirection,
	float& OutThrottle) const
{
	OutDesiredDirection = FVector::ZeroVector;
	OutThrottle = 0.0f;

	if (!IsLockedTargetUsable() || !IsValid(RuntimeTuningData))
	{
		return false;
	}

	const USceneComponent* Target = LockedTargetComponent.Get();
	const FVector BodyCenter = ProjectileBody->GetCenterOfMass();
	const FVector BodyForward = ProjectileBody->GetUpVector().GetSafeNormal();
	const FVector BodyVelocity = ProjectileBody->GetPhysicsLinearVelocity();
	const FVector TargetLocation = Target->GetComponentLocation();
	const FVector TargetVelocity = Target->GetComponentVelocity();

	if (BodyCenter.ContainsNaN()
		|| BodyForward.IsNearlyZero()
		|| BodyVelocity.ContainsNaN()
		|| TargetLocation.ContainsNaN()
		|| TargetVelocity.ContainsNaN())
	{
		return false;
	}

	const float TotalSpeed = BodyVelocity.Size();
	if (!FMath::IsFinite(TotalSpeed)
		|| TotalSpeed >= RuntimeTuningData->MaximumPoweredSpeed)
	{
		return false;
	}

	const float Distance = FVector::Distance(BodyCenter, TargetLocation);
	const float LeadSeconds = FMath::Clamp(
		Distance / RuntimeTuningData->TargetPoweredSpeed,
		0.0f,
		RuntimeTuningData->MaximumTargetLeadTimeSeconds);
	const FVector PredictedTarget =
		TargetLocation + TargetVelocity * LeadSeconds;

	OutDesiredDirection =
		(PredictedTarget - BodyCenter).GetSafeNormal();
	if (OutDesiredDirection.IsNearlyZero())
	{
		return false;
	}

	const float ForwardSpeed =
		FVector::DotProduct(BodyVelocity, BodyForward);
	const float SpeedThrottle = FMath::Clamp(
		(RuntimeTuningData->TargetPoweredSpeed - ForwardSpeed)
			/ RuntimeTuningData->SpeedControlBand,
		0.0f,
		1.0f);
	const float AlignmentThrottle = FMath::Max(
		0.0f,
		FVector::DotProduct(BodyForward, OutDesiredDirection));

	OutThrottle = SpeedThrottle * AlignmentThrottle;
	return FMath::IsFinite(OutThrottle);
}
```

`MaximumPoweredSpeed` 是异常关机线，不调用 `SetPhysicsLinearVelocity`。正常飞行在 `TargetPoweredSpeed` 附近会自然收油；如果异常速度来自穿透或外力，代码只停止继续施力并留下诊断。

### 7.4 真实惯量转矩

```cpp
bool AThrustGuidedHazardProjectile::ApplyPhysicalAttitudeControl(
	const FVector& DesiredDirection) const
{
	const FVector BodyForward = ProjectileBody->GetUpVector().GetSafeNormal();
	const FVector NormalizedDesired = DesiredDirection.GetSafeNormal();
	if (BodyForward.IsNearlyZero() || NormalizedDesired.IsNearlyZero())
	{
		return false;
	}

	const float Dot = FMath::Clamp(
		FVector::DotProduct(BodyForward, NormalizedDesired),
		-1.0f,
		1.0f);
	const float ErrorRadians = FMath::Acos(Dot);
	FVector ErrorAxis =
		FVector::CrossProduct(BodyForward, NormalizedDesired).GetSafeNormal();
	if (ErrorAxis.IsNearlyZero() && Dot < 0.0f)
	{
		ErrorAxis = ProjectileBody->GetForwardVector().GetSafeNormal();
	}

	const FVector AngularVelocity =
		ProjectileBody->GetPhysicsAngularVelocityInRadians();
	FVector DesiredAngularAcceleration =
		ErrorAxis * ErrorRadians * RuntimeTuningData->OrientationGain
		- AngularVelocity * RuntimeTuningData->AngularVelocityDampingGain;
	DesiredAngularAcceleration = DesiredAngularAcceleration.GetClampedToMaxSize(
		RuntimeTuningData->MaximumAngularAcceleration);

	if (AngularVelocity.ContainsNaN()
		|| DesiredAngularAcceleration.ContainsNaN())
	{
		return false;
	}

	FBodyInstance& BodyInstance = ProjectileBody->BodyInstance;
	const FVector LocalInertia = BodyInstance.GetBodyInertiaTensor();
	const FTransform MassToWorld = BodyInstance.GetMassSpaceToWorldSpace();
	if (LocalInertia.ContainsNaN()
		|| LocalInertia.GetMin() <= KINDA_SMALL_NUMBER
		|| !MassToWorld.IsValid())
	{
		return false;
	}

	const FVector LocalAngularAcceleration =
		MassToWorld.InverseTransformVectorNoScale(DesiredAngularAcceleration);
	const FVector LocalTorque = LocalAngularAcceleration * LocalInertia;
	const FVector WorldTorque =
		MassToWorld.TransformVectorNoScale(LocalTorque);

	if (WorldTorque.ContainsNaN())
	{
		return false;
	}

	ProjectileBody->AddTorqueInRadians(WorldTorque, NAME_None, false);
	return true;
}
```

这里使用 UE5.8 `FBodyInstance::GetBodyInertiaTensor()` 返回的局部质量空间惯量，并使用 `GetMassSpaceToWorldSpace()` 转换。`bAccelChange=false`，所以传入的是物理转矩，不是忽略质量的角加速度命令。

### 7.5 受控阶段统一出口

```cpp
void AThrustGuidedHazardProjectile::FinishPoweredPhase(const TCHAR* Reason)
{
	if (Phase != EThrustGuidedHazardProjectilePhase::PoweredControlled)
	{
		return;
	}

	Phase = EThrustGuidedHazardProjectilePhase::Coasting;
	LockedTargetComponent.Reset();
	LockedTargetActor.Reset();

	Thruster->ThrustStrength = 0.0f;
	Thruster->Deactivate();
	Thruster->SetComponentTickEnabled(false);
	ExhaustVisualRoot->SetVisibility(false, true);

	ProjectileBody->SetEnableGravity(true);
	ProjectileBody->SetLinearDamping(RuntimeTuningData->CoastingLinearDamping);
	ProjectileBody->SetAngularDamping(RuntimeTuningData->CoastingAngularDamping);
	SetActorTickEnabled(false);

	UE_LOG(
		LogThrustGuidedHazardProjectile,
		Display,
		TEXT("LaunchId=%s powered phase finished after %.3f s: %s; Chaos owns motion."),
		*LaunchId.ToString(EGuidFormats::DigitsWithHyphensLower),
		PoweredElapsedSeconds,
		Reason);
}
```

HeavyImpact 准备 Timer 不在这里关闭；Coasting 期间的后续真实碰撞仍可能需要准备接收者。休眠时按现有逻辑停止，外力唤醒后恢复。

### 7.6 第一次阻挡碰撞

```cpp
void AThrustGuidedHazardProjectile::HandleProjectileHit(
	UPrimitiveComponent* /*HitComponent*/,
	AActor* OtherActor,
	UPrimitiveComponent* OtherComponent,
	const FVector NormalImpulse,
	const FHitResult& Hit)
{
	++ContactSequence;
	// 保留当前实现已有的 ContactSequence、速度、角速度、冲量和接触点诊断日志。

	const AActor* ContactOwner = IsValid(OtherActor)
		? OtherActor
		: (IsValid(OtherComponent) ? OtherComponent->GetOwner() : nullptr);
	const bool bBlockingContact =
		Hit.bBlockingHit
		&& IsValid(OtherComponent)
		&& IsValid(ContactOwner)
		&& ContactOwner != this;

	if (!bBlockingContact || bHadMeaningfulBlockingContact)
	{
		return;
	}

	bHadMeaningfulBlockingContact = true;
	if (Hit.bStartPenetrating)
	{

			LogThrustGuidedHazardProjectile,
			Warning,
			TEXT("LaunchId=%s received penetrating blocking contact with %s."),
			*LaunchId.ToString(EGuidFormats::DigitsWithHyphensLower),
			*GetNameSafe(ContactOwner));
	}

	FinishPoweredPhase(
		Hit.bStartPenetrating
			? TEXT("penetrating blocking contact")
			: TEXT("first blocking contact"));
}
```

不再排除 Launcher Owner。正常出生不应与炮管接触；若仍接触，必须立即切断推进并留下错误证据。

## 8. 角色接触与 HeavyImpact 边界

ProjectileBody 对 Pawn 改为 Block 是保底规则：

- HeavyImpact 预测及时 Accepted：角色 Capsule 按现有接收端逻辑退出物理阻挡，Projectile 与实际 Skeletal Mesh/PhysicsBody 接触。
- HeavyImpact 未接受、Busy、Invalid 或预测太晚：Projectile 至少被角色 Capsule 阻挡，不会无反馈穿过角色。
- Projectile 不对角色调用 `AddImpulse`、`LaunchCharacter` 或补偿位移。
- 是否达到轻/重受击阈值由受击系统独立决定，不再通过人为提高弹体速度保证重受击。
- `MaximumPreparationLeadTime` 第一轮提高至 0.35 s，只扩大准备时机，不改变最终受击强弱。

现有 `BuildPreparationRequest`、胶囊表面距离计算、LaunchId 去重和 60 Hz 采样逻辑原则上保持不变。实施时只调整它们读取的新 DA 字段，不在本轮重构公共层。

## 11. 本轮明确不做

- 不做循环发射器和对象池。
- 不做比例导航、绕墙追踪或隔墙等待目标。
- 不做逻辑反射、手写反弹方向或直接速度钳制。
- 不为尚未复现的碰撞抖动增加冷却/去抖框架。
- 不修改全局 Chaos 子步进；在 800 cm/s 上限和 CCD 下仍穿墙时，先核对具体墙体碰撞和通道。
- 不接入 PCG Population；Level0 飞行闭环通过后再定义“墙面接口 + 出生包络 + 发射走廊 + 触发体积”的 PCG 空间合同。
- 不因为当前 HeavyImpact 门槛而抬高速度或质量。

## 12. 回退顺序

若第一轮姿态控制仍出现不可接受的摆动：

1. 先降低 `MaximumAngularAcceleration` 和 `OrientationGain`，提高 `AngularVelocityDampingGain`。
2. 暂时把 `MaximumAngularAcceleration` 设为极低值，保留目标速度控制和直线推进，验证出生/碰撞闭环。
3. 若真实转矩换算存在 UE5.8 运行期异常，保留固定 Thruster 和状态机，单独审阅惯量接口；不退回旧的单喷口偏转耦合方案。

无论如何都不恢复“首碰后继续推进”，因为它会在第一次反弹后继续放大不可控速度和穿墙风险。
