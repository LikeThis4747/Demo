## 3. 实现中修正的关键风险

1. 用 `Mesh->bPauseAnims` 代替 UE5.8 不存在的 `SetPauseAnims()`。
2. 请求和调参拒绝 NaN/Inf、负 ETA、非法跨字段关系。
3. PCA 必须精确编译六个叶到根 Limb；每个 Limb 禁止 World Space Control。编译默认数据本身必须保持 Kinematic/QueryOnly/Gravity 1/Blend 0/CCD Off/Parent Control Disabled，避免 BeginPlay 就模拟或被钉在世界。
4. 五个 Profile 不只检查名称存在，还检查 `ParentSpace` / `All` 更新的实际 Sparse 语义；空 Profile、线性拉回、无限 MaxTorque、逐 Limb 覆盖、Additional/Initial 数据或错误刚体阶段都会在 BeginPlay 前被拒绝。
5. PCA 创建后逐 Limb 核对真实 Parent Control/Body Modifier，并要求 `All` Body Modifier 数量覆盖 Mesh Physics Asset 的全部刚体；不允许“六个名字都在、实际上只控制半身”。
6. `Prepared` 的最小 ETA 为 `max(MinimumPreparationLeadSeconds, 当前帧时长 × 1.25)`；发送端与接收端的最大窗口在低帧率下会临时扩为最多 `2.5 × 当前帧时长`（硬上限 0.5 秒），正常 30/60 FPS 仍使用资产值。
7. 每次 Accepted 都会固化当帧计算出的最大等待时间，Prepared 不再用旧的固定上限提前回滚。摆锤预测体积还按“摆锤预期速度 + `MaximumExpectedReceiverSpeed`”覆盖 0.5 秒低帧率窗口；默认接收者速度 600 cm/s、提前距离 500 cm。
8. 若真实接触仍发生在进入 Prepared 的同一帧，运行时会报 Error 并明确进入 FreeFallback，不把未准备好的首撞伪装成受控结果，也不会回到受击前位置。
9. `FreeFallback` 后不再回切 LandingRecovery/Flight；无地面支撑的硬超时不会把身体睡在空中。
10. `Downed` 先排队一帧，让 FreeFallback 进入求解器，再 Sleep 并关闭共享组件与 PhysicsControl Tick。
11. Downed 只有动态模拟组件产生非零真实 Solver Impulse 时才再次唤醒，地面静态残余接触不能触发。
12. 只有完整进入 Prepared 的请求才写入去重缓存；预测、快照或状态转换失败时，同一 ImpactId 可以稍后重试。
13. PCA 创建失败时也抓取并精确清理由本次调用部分创建的 Controls/BodyModifiers；从不调用 `DestroyAllControlsAndBodyModifiers()`。

### Limb 编译数据

必须恰好建立以下六个 Limb，不得增加额外 Limb，并严格按叶到根顺序：`Head=head`、`ArmLeft=upperarm_l`、`ArmRight=upperarm_r`、`LegLeft=thigh_l`、`LegRight=thigh_r`、`Spine=spine_01`。所有 Limb：

- `Create World Space Controls = false`
- `Create Parent Space Controls = true`
- `Create Body Modifiers = true`
- 只有 `Spine` 的 `Include Parent Bone = true`，把 pelvis 纳入躯干

Character Setup 默认值：

- Parent Control：Disabled；Linear Strength/Extra Damping 为 0
- Body Modifier：Kinematic、QueryOnly、Gravity 1、Physics Blend 0、CCD Off

### 五个项目 Profile 的首轮语义

每个 Profile 必须包含且精确命名两条更新：Control Update 的 Set 名为 `ParentSpace`，Modifier Update 的 Set 名为 `All`。名字不同、只更新单个 Limb、或漏掉任一条都会被运行时校验拒绝。

`Additional Controls and Modifiers`、`Additional Sets`、`Initial Control and Modifier Updates` 必须全部为空；每个 Profile 的 `Control Multiplier Updates` 也必须为空。不要添加 Profile 内的单 Control/单 Limb 覆盖。

| Profile | `ParentSpace` Enabled | Linear Strength | Linear Extra Damping | Angular Strength / MaxTorque | Use Skeletal Animation | `All` Body | Gravity | Collision | Blend | CCD |
|---|---:|---:|---:|---|---:|---|---:|---|---:|---:|
| Inactive | false | 不要求 | 不要求 | 不要求 | 不要求 | Kinematic | 1 | QueryOnly | 0 | Off |
| Prepared | true | 0 | 0 | 两者均为有限且严格大于 0 | true | Simulated | 0 | QueryAndPhysics | 1 | On |
| Flight | true | 0 | 0 | 两者均为有限且严格大于 0 | true | Simulated | 1 | QueryAndPhysics | 1 | On |
| LandingRecovery | true | 0 | 0 | 两者均为有限且严格大于 0；首轮可略强于 Flight | true | Simulated | 1 | QueryAndPhysics | 1 | On |
| FreeFallback | false | 不要求 | 不要求 | 不要求 | 不要求 | Simulated | 1 | QueryAndPhysics | 1 | On |

五个 Profile 都必须显式勾选 Sparse `Enabled` 字段：`Prepared / Flight / LandingRecovery` 的值为 true，`Inactive / FreeFallback` 的值为 false；后两者不能因为值为 false 就漏勾该字段。三个启用控制的 Profile 还必须逐项勾选 `Linear Strength`、`Linear Extra Damping`、`Angular Strength`、`Max Torque`、`Use Skeletal Animation`。五个 Profile 的 `All` Modifier 也必须显式勾选 Movement、Collision、Gravity、Physics Blend 和 CCD。UE 中 `MaxTorque=0` 可表示无限，但本项目为避免把身体硬拉回姿态，会明确拒绝 0。首轮强度不在文档里伪装成已标定值；用真实摆锤做 Soft/Base/Strong 三档后再保存正式值。
